# 다크 테마 대비 검사

사이트의 모든 HTML을 실제 Chromium에서 열어 검사한다. 패키지를 자동 설치하지 않는다. `playwright`가 기존 `node_modules`에 있으면 그대로 사용하고, 별도 제공된 모듈은 `PLAYWRIGHT_MODULE` 환경 변수로 지정한다. 모듈이 없으면 설정 안내와 종료 코드 2를 반환한다.

- `npm run check:contrast`: 전체 HTML
- `npm run check:contrast:quick`: 홈·과정 안내·D01·D05·D11·J01·B01과 이전 과정 대표 6쪽
- `--out <결과 디렉터리>`: JSON 결과 저장 위치. 기본값은 운영체제 임시 디렉터리 아래 `javaexperience-contrast`다.
- `--root <사이트 루트>`, `--workers <동시 페이지 수>`, `--limit <페이지 수>`: 격리 fixture와 도구 자체 검증용 옵션

1440×900에서 기본·접기 펼침·데이터 속성 기반 단계/탭·CSS 규칙별 대표 hover/focus·연속 키보드 Tab 상태를 검사한다. 큰 글자는 3:1, 일반 본문·코드·placeholder는 4.5:1, 활성 컨트롤 경계와 SVG 선은 3:1을 적용한다. 시스템의 라이트 선호에서도 단일 다크 테마가 유지되는지 검사한다. HTTP 서버는 실행마다 빈 포트를 할당받고 성공·실패 모두 종료한다.

`contrast-results.json`에는 페이지와 상태, 요소 선택자, 실제 전경·배경, 대비율, 기준, 관찰 횟수와 오류가 남는다. 위반은 종료 코드 1, 실행·누락 오류는 2, 모든 검사 통과는 0이다. 같은 규칙을 사용하는 모든 인스턴스의 hover/focus를 각각 검사한 것은 아니다.

배경색은 조상 레이어의 알파 합성과 텍스트 opacity로 계산한다. 비활성 컨트롤은 대비 기준의 적용 대상에서 제외한다. 활성 컨트롤은 외부 배경과 경계 또는 채움 중 하나로 구분되면 통과한다. SVG 텍스트는 텍스트 중심 뒤에 실제로 칠해진 도형의 채움색을 포함한다. 이미지·그라디언트 배경과 복잡한 SVG 겹침은 캡처로 추가 대조해야 한다. 자동 검사 통과를 이미지 내부 글자나 실제 서버 응답의 검증으로 해석하지 않는다.
