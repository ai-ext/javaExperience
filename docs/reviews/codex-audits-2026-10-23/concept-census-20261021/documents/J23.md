## 트리·이진 트리·BST의 정의

현재 판정: **부분** / 우선순위: high

**정의와 실제 역할:** 트리는 parent/child 계층, binary tree는 최대 자식 2개, BST는 왼쪽 전체<node<오른쪽 전체의 key invariant를 더 가집니다.

**언제 사용하는가:** 키 경로 탐색과 정렬 순회가 필요할 때 BST를 사용합니다.

**대안과 경계:** Binary tree는 자동으로 BST도 balanced tree도 아닙니다.

**예시·실행 근거:** 삽입한 값과 인덱스 조회 값을 출력해 배열의 위치 접근을 확인합니다.

**선수개념:** node/edge; ordering

**관련 표기·별칭:** 

**보완·검증 필요 사항:**

- duplicate key policy must match insertion/validation/search.

**초보자가 시작할 질문:**

- 루트가 10인 트리에서 왼쪽 자식 아래 12가 있어도 부모 5보다 크다면 BST인가요?

## BST 연산과 균형 한계

현재 판정: **부분** / 우선순위: high

**정의와 실제 역할:** BST search/insert는 O(h)이며 h는 root-to-leaf height입니다. 균형이면 O(log n), 정렬 삽입으로 편향되면 O(n)입니다.

**언제 사용하는가:** 입력 순서를 알 수 없고 최악 보장이 필요하면 TreeMap을 검토합니다.

**대안과 경계:** 단순 BST는 자동 회전/균형을 하지 않습니다.

**예시·실행 근거:** 배열 복사 전후에 원본·복사본 값을 바꾸어 얕은 복사 동작을 확인합니다.

**선수개념:** BST invariant; height

**관련 표기·별칭:** 

**보완·검증 필요 사항:**

- AVL/red-black rotation implementation outside range.

**초보자가 시작할 질문:**

- 키 1,2,3,4,5를 순서대로 BST에 넣으면 각 다음 탐색은 몇 번씩 내려가나요?
- TreeMap을 단순 BST 대신 쓸 때 API 차이를 무엇으로 고려하나요?

## DFS traversal·BFS level order

현재 판정: **부분** / 우선순위: high

**정의와 실제 역할:** 전위 순회는 현재 노드→왼쪽→오른쪽, 중위는 왼쪽→현재→오른쪽, 후위는 왼쪽→오른쪽→현재 순서입니다. 레벨 순회는 FIFO queue로 같은 깊이의 노드를 방문합니다.

**언제 사용하는가:** 직렬화·집계·정렬값·깊이별 출력 목적에 따라 순서를 택합니다.

**대안과 경계:** inorder가 정렬되는 것은 BST에서만 성립합니다. Recursion stack은 높이 h에 비례합니다.

**예시·실행 근거:** ArrayList에서 요소 추가·삭제 후 인덱스와 크기 변화를 관찰합니다.

**선수개념:** stack/queue; recursion

**관련 표기·별칭:** 

**보완·검증 필요 사항:**

- 깊은 tree stress not run.

**초보자가 시작할 질문:**

- 같은 binary tree를 모든 노드 방문하면서 자식을 먼저 집계하려면 어느 DFS가 편한가요?
- 정렬 입력으로 편향된 tree를 재귀 순회할 때 추가로 어떤 JVM 한계를 고려하나요?

## 전역 BST 검증·LCA

현재 판정: **부분** / 우선순위: high

**정의와 실제 역할:** 각 node에 allowed lower/upper bound를 전달해 조상 제한까지 확인합니다. BST LCA는 key order로 split point를 찾고 누락 key 정책을 둡니다.

**언제 사용하는가:** BST 검증은 local parent compare가 아니라 전역 경계를 확인합니다.

**대안과 경계:** General binary tree LCA는 BST key order로 한쪽을 버릴 수 없습니다.

**예시·실행 근거:** 제네릭 타입과 wildcard 경계에 맞는 복사 호출을 작성하고 컴파일 결과를 확인합니다.

**선수개념:** BST bounds; recursion

**관련 표기·별칭:** 

**보완·검증 필요 사항:**

- contains precheck adds another traversal in missing-key safe version.

**초보자가 시작할 질문:**

- 각 노드는 부모와 비교만 통과했는데 전체 BST가 아닐 수 있는 예는 무엇인가요?
- BST에 없는 key를 LCA 입력으로 받았을 때 반환 정책은 무엇인가요?
