## Spring Data derived query·@Query·Specification

현재 판정: **부분** / 우선순위: P0

**정의와 실제 역할:** Repository proxy는 CRUD를 연결하고 메서드명을 해석해 query를 만들거나 @Query JPQL/SQL을 실행한다. Specification은 Criteria predicate를 조합한다.

**언제 사용하는가:** 단순 고정 조건은 derived method, 길거나 복잡한 고정 쿼리는 @Query, 선택 검색 필터는 Specification.

**대안과 경계:** 메서드명은 query DSL이다. Page는 count가 필요할 수 있다. PredicateSpecification은 JPA4에서 query-independent predicate에 집중한다.

**예시·실행 근거:** findByActiveTrue projection, 이메일 대소문자 무시 @Query, active+lastname 조건 Specification 조합.

**선수개념:** JPA mapping; JPQL; Criteria API

**관련 표기·별칭:** Repository; query derivation; @Query; Specification; PredicateSpecification

**판정 이유:** 개념 정의와 선택 기준은 다루지만 실습/실행이나 학습 과제의 검증 근거가 부족해 부분 판정.

**보완·검증 필요 사항:**

- 예제 및 Querydsl processor build는 실행하지 않았다.

## Projection·Page/Slice/Window·도구 선택

현재 판정: **부분** / 우선순위: P1

**정의와 실제 역할:** Projection은 결과 모양, Page는 total, Slice는 다음 chunk, Window는 scroll position을 표현한다. 도구 선택은 SQL 제어 수준과 매핑 책임을 정한다.

**언제 사용하는가:** 목록 DTO에 필요한 필드만 받을 때 projection; 정확한 total 필요 시 Page, 다음만 필요하면 Slice, 큰 scroll에는 Window/cursor. SQL 소유권이 핵심이면 MyBatis/jOOQ/JdbcClient 검토.

**대안과 경계:** Projection이 N+1을 자동 제거하지 않는다. Page count 비용 가능. Querydsl 포크/processor, jOOQ license/edition, MyBatis explicit SQL, JdbcClient facade tradeoff.

**예시·실행 근거:** Customer list projection과 auditing CreatedDate; 작은 SQL에는 JdbcClient.

**선수개념:** pagination; DTO; SQL plan

**관련 표기·별칭:** Page; Slice; Window; Projection; Querydsl; jOOQ; MyBatis; JdbcClient

**판정 이유:** 개념 정의와 선택 기준은 다루지만 실습/실행이나 학습 과제의 검증 근거가 부족해 부분 판정.

**보완·검증 필요 사항:**

- Database plan 및 Querydsl code generation을 실행하지 않았다.
