## 혼동하기 쉬운 개념 쌍

현재 판정: **부분** / 우선순위: high

**정의와 실제 역할:** 자주 혼동하는 개념 쌍의 의미 차이를 짧게 대비한다.

**언제 사용하는가:** 서로 비슷한 용어를 혼동할 때 구분 기준을 찾는다.

**대안과 경계:** UNION과 Union-Find는 이름이 비슷해도 SQL 결과 결합과 자료구조 연산으로 분야가 다르다. R07에 UNION ALL SQL 사용이 있지만 정의/차이는 별도 학습이 필요하다.

**예시·실행 근거:** 동음이의어 alias를 영역별로 나눠 SQL UNION과 Union-Find를 각 owner 문서로 연결한다.

**선수개념:** 분야별 용어 alias

**관련 표기·별칭:** Concept pairs

**보완·검증 필요 사항:**

- 현재 glossary의 30개 비교쌍에 SQL UNION/UNION ALL의 설명이 없다. 검색 실행 결과에서는 UNION이 J22 Union-Find만 찾는다.

**초보자가 시작할 질문:**

- UNION을 검색했을 때 SQL 결과 결합과 Union-Find 중 무엇을 찾는지 어떻게 구별하나?
