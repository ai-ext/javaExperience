## SMTP sender와 MIME

현재 판정: **미검증** / 우선순위: high

**정의와 실제 역할:** Spring mail abstraction은 SMTP 전송을 감싸며 MIME은 본문·첨부·inline 이미지 형식을 표현한다.

**언제 사용하는가:** 알림 메일 본문을 보내거나 HTML·첨부 파일을 포함할 때 사용한다.

**대안과 경계:** SMTP server가 메시지를 받았다는 사실은 최종 수신함 도착을 보장하지 않는다.

**예시·실행 근거:** Mailpit에서 받은 메일의 raw MIME과 첨부 구조를 확인한다.

**선수개념:** SMTP; MIME

**관련 표기·별칭:** JavaMailSender; SimpleMailMessage; MimeMessageHelper

**보완·검증 필요 사항:**

- 애플리케이션 코드는 실행되지 않았다.

**초보자가 시작할 질문:**

## SMTP port·TLS·timeout 설정

현재 판정: **부분** / 우선순위: high

**정의와 실제 역할:** SMTP 전송 포트에 따라 TLS 시작 방식이 다르고 연결·읽기·쓰기 대기 시간을 제한할 수 있다.

**언제 사용하는가:** 메일 provider의 SMTP 연결 설정을 구성할 때 사용한다.

**대안과 경계:** Mailpit 로컬 포트는 인증 없는 개발 설정이다. 운영에서는 secret과 TLS 설정을 사용한다.

**예시·실행 근거:** Mailpit 로컬 capture에 메일을 보내 확인한다.

**선수개념:** TLS; network

**관련 표기·별칭:** SMTP port·TLS·timeout; Ports, TLS, timeouts; 25; 587; 465; STARTTLS

**보완·검증 필요 사항:**

- provider 설정과 포트 안내는 변경될 수 있으므로 해당 서비스의 현재 공식 안내를 확인해야 한다.

**초보자가 시작할 질문:**

## commit 이후 outbox와 재시도

현재 판정: **미검증** / 우선순위: high

**정의와 실제 역할:** DB commit 이후 보내야 하는 알림 요청을 지속 저장하고 재시도 상태와 중복 방지 key로 관리한다.

**언제 사용하는가:** 업무 변경이 commit된 경우에만 알림을 보내고, 프로세스 중단 후에도 발송을 복구해야 할 때 사용한다.

**대안과 경계:** AFTER_COMMIT callback만으로는 commit 직후 process가 종료되는 구간을 복구하지 못한다. outbox는 업무 행과 알림 요청을 같은 transaction으로 저장한다. 일시 오류와 영구 오류도 나눈다.

**예시·실행 근거:** 상태·시도 횟수·다음 재시각·발송시각을 기록한다.

**선수개념:** transaction; 멱등성

**관련 표기·별칭:** after commit, outbox, retry; AFTER_COMMIT; outbox; dedup key

**보완·검증 필요 사항:**

- 실제 메일 provider와 연계한 운영 발송은 검증하지 않았다.

**초보자가 시작할 질문:**

## 메일 실제 전달 가능성

현재 판정: **부분** / 우선순위: high

**정의와 실제 역할:** SMTP capture는 메일 형식을 검사하지만 도메인 평판이나 인증 상태는 검증하지 않는다.

**언제 사용하는가:** 실제 provider를 통한 메일 발송을 시작할 때 사용한다.

**대안과 경계:** provider별 발송 quota와 스팸 판정 정책은 서로 다르다.

**예시·실행 근거:** 테스트 도메인에서 적은 수량으로 발송해 도착·인증 결과를 확인한다.

**선수개념:** DNS; SMTP

**관련 표기·별칭:** deliverability; SPF; DKIM; DMARC

**보완·검증 필요 사항:**

- 현재 provider의 발송 안내와 정책은 변경될 수 있으므로 재확인이 필요하다.

**초보자가 시작할 질문:**

## 시각 구조와 보완 장면

**기존 표현**

- MIME 코드, Compose 설정, curl과 Mailpit 확인 절차를 설명한다.

**정적 구조의 한계**

- 원문 애플리케이션은 실행되지 않았으며 Mailpit 캡처만으로 실제 메일 배달을 입증할 수 없다.

**추가할 의미 장면**

- DB commit→outbox worker→SMTP 수락→Mailpit 확인과 실제 배달 차이를 시간 순서로 보여준다.
