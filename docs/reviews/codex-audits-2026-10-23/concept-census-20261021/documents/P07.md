## 공통·프로파일·시크릿 설정

현재 판정: **부분** / 우선순위: high

**정의와 실제 역할:** application.yml은 공통값, profile 파일은 환경별 차이, 환경변수/비밀관리 시스템은 민감값을 공급합니다. 프로파일 파일명만으로 자동 활성화되지는 않습니다.

**언제 사용하는가:** 각 환경에서 필요한 프로파일을 시작 옵션으로 선택하고 실제 활성 프로파일 로그를 확인합니다.

**대안과 경계:** Git에 올라간 비밀번호는 파일 삭제만으로 노출이 취소되지 않아 credential 교체가 필요합니다.

**예시·실행 근거:** `--spring.profiles.active=local`, `PORT`, `DB_PASSWORD`. 예제 Spring 실행은 미실행.

**선수개념:** 환경변수; YAML; Spring Profile

**관련 표기·별칭:** 

**보완·검증 필요 사항:**

- 예제 실행은 미실행으로 표시되어 있어 코드를 동작 근거로 단정할 수 없습니다.

**초보자가 시작할 질문:**

## 로그·예외·Actuator 진단

현재 판정: **부분** / 우선순위: high

**정의와 실제 역할:** 시작 로그의 profile/port/Started 단계와 가장 안쪽 Caused by로 실패를 좁힙니다. Actuator mappings/beans는 등록 상태를 살핍니다. SQL bind trace에는 민감값이 포함될 수 있습니다.

**언제 사용하는가:** 시작 실패, HTTP 매핑 실패, DB 접속 실패를 분리하고 로컬에서 필요한 로그만 잠깐 켭니다.

**대안과 경계:** TRACE/Actuator 공개 범위는 보안 경계입니다. endpoint 포함과 운영 공개는 별도 판단입니다.

**예시·실행 근거:** `/actuator/mappings`, beans, Hibernate SQL logger 예시. 결과 미실행.

**선수개념:** logging; 예외 체인; Actuator

**관련 표기·별칭:** 

**보완·검증 필요 사항:**

- 예제 실행은 미실행으로 표시되어 있어 코드를 동작 근거로 단정할 수 없습니다.

**초보자가 시작할 질문:**

- 포트가 떴는데 404면 어떤 mapping을 확인하나요?
- SQL binding TRACE를 운영에 켜면 어떤 데이터가 로그로 새어날 수 있나요?
