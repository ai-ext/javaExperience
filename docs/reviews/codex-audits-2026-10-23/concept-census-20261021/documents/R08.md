## HTTP 요청에서 SQL connection까지

현재 판정: **부분** / 우선순위: high

**정의와 실제 역할:** HTTP worker가 service transaction에 들어가 connection pool에서 connection을 빌리고 transaction 후 반환하는 흐름이다.

**언제 사용하는가:** query latency와 connection 보유 시간을 request 경로에서 추적할 때 사용한다.

**대안과 경계:** 기존 pool connection을 재사용하면 HTTP 요청마다 physical TCP 연결을 새로 열 필요는 없다. Connection.close는 pool에 반환할 수 있다.

**예시·실행 근거:** 사용 중 connection이 있는 경우와 새 connection 생성이 필요한 경우 sequence를 비교한다.

**선수개념:** HTTP; DI; transaction

**관련 표기·별칭:** request-to-SQL connection lifecycle; JDBC; HikariCP; MySQL session

**보완·검증 필요 사항:**

- 도식은 설명이고 live instrumentation 관찰이 아니다.

**초보자가 시작할 질문:**

## network 주소와 topology

현재 판정: **부분** / 우선순위: high

**정의와 실제 역할:** localhost는 client가 실행된 network namespace를 가리킨다. host port mapping 또는 Compose service DNS를 사용한다.

**언제 사용하는가:** host app, app container와 private DB의 JDBC 주소를 설정할 때 사용한다.

**대안과 경계:** app container 안 localhost는 그 app container 자신이지 MySQL service가 아니다.

**예시·실행 근거:** host에서 localhost:13307, Compose network에서 mysql:3306 주소를 표로 비교한다.

## thread·pool·server connection 예산

현재 판정: **부분** / 우선순위: high

**정의와 실제 역할:** request worker, Hikari pool과 DB server connection은 각각 다른 동시성 제한을 가진다.

**언제 사용하는가:** 앱 instance 수와 DB connection budget을 함께 계산할 때 사용한다.

**대안과 경계:** instance별 pool 크기는 전체 복제 수만큼 누적된다. pool을 늘려도 DB 처리량이 반드시 늘지는 않는다.

**예시·실행 근거:** 앱 3개×pool 10과 MySQL max connection 151, 운영 여유를 비교한다.

**선수개념:** concurrency; DB connection

**관련 표기·별칭:** thread/pool/server connection budget; Tomcat threads; maximumPoolSize; max_connections

**보완·검증 필요 사항:**

- 기본값은 버전·설정에 따라 다르며 공식 설정과 실제 구성 확인이 필요하다.

**초보자가 시작할 질문:**

## timeout과 connection 지표

현재 판정: **부분** / 우선순위: high

**정의와 실제 역할:** timeout은 connection 획득·TCP connect 등 서로 다른 대기 단계를 제한한다. active/idle/pending pool 값과 DB processlist 상태도 의미가 다르다.

**언제 사용하는가:** 접속 실패, pool starvation과 오래된 idle session을 구분할 때 사용한다.

**대안과 경계:** Hikari connectionTimeout은 pool에서 빌릴 때 기다리는 시간으로 TCP connect timeout과 다르다. keepalive는 idle connection 점검이지 모든 timeout 해결책이 아니다.

**예시·실행 근거:** HTTP 전후 pool metrics와 processlist를 비교한다.

**선수개념:** metrics; SQL

**관련 표기·별칭:** timeout and metrics; connectionTimeout; wait_timeout; hikaricp.connections.pending

**보완·검증 필요 사항:**

- 과거 runtime 관찰은 날짜/버전에 한정되어 현재 모든 설정에 일반화할 수 없다.

**초보자가 시작할 질문:**
