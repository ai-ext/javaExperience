## 정렬·lower/upper bound

현재 판정: **부분** / 우선순위: high

**정의와 실제 역할:** 오름차순 배열에서 lower bound는 첫 `>=x`, upper bound는 첫 `>x` 경계입니다. 중복 개수는 둘의 차입니다.

**언제 사용하는가:** 중복 값의 첫/끝 위치와 삽입 지점을 찾을 때 반열린 [l,r) 불변식을 씁니다.

**대안과 경계:** Arrays.binarySearch는 중복의 첫 지점을 보장하지 않고 없으면 음수 encoding을 돌려줍니다.

**예시·실행 근거:** SearchDemo lower=0/upper=2 및 boundary checks.

**선수개념:** array sort; binary search

**관련 표기·별칭:** 

**보완·검증 필요 사항:**

- 전제인 sort 상태를 호출부에서 보장해야 합니다.

**초보자가 시작할 질문:**

- 정렬 배열 [2,2,4]에서 x=2의 첫 위치와 개수를 구하려면 두 경계를 각각 어떻게 찾나요?
- while(l<r)로 구현할 때 hi를 exclusive로 두면 빈 배열은 어떤 결과가 되나요?

## BFS·DFS·Dijkstra·PriorityQueue

현재 판정: **부분** / 우선순위: high

**정의와 실제 역할:** BFS는 무가중치 최단 레벨, DFS는 경로/백트래킹, 비음수 가중치 최단은 Dijkstra입니다.

**언제 사용하는가:** 작업 종류, edge weight, recursion depth에 따라 큐/스택/PQ를 선택합니다.

**대안과 경계:** PriorityQueue iterator 전체는 정렬되지 않고 lazy deletion은 오래된 거리 pair를 건너뜁니다.

**예시·실행 근거:** 같은 요소를 List와 Set에 넣어 중복 허용 여부를 출력합니다.

**선수개념:** graph adjacency; queue/heap

**관련 표기·별칭:** 

**보완·검증 필요 사항:**

- 음수 edge는 별도 Bellman-Ford 등 필요.

**초보자가 시작할 질문:**

- edge weight가 0,1로만 있으면 일반 BFS와 Dijkstra 중 어떤 경계를 고려하나요?
- 재귀 DFS가 O(V)여도 StackOverflowError가 날 수 있는 이유는?

**근거:**

## prefix sum·two pointers·stack·DP·Union-Find

현재 판정: **부분** / 우선순위: high

**정의와 실제 역할:** prefix sum은 범위합, monotone pointer는 조건 단조 window, monotone stack은 next greater, DP는 상태 재사용, Union-Find는 component/group 질의에 씁니다.

**언제 사용하는가:** 연속구간 조건과 반복 하위문제를 발견해 자료구조/상태 전이를 설계합니다.

**대안과 경계:** 음수가 있으면 일부 sliding window 전제는 깨지고 0-1 배낭은 역순 용량 갱신이 필요합니다.

**예시·실행 근거:** Map의 key/value 삽입과 key 기준 조회 결과를 확인합니다.

**선수개념:** array/list; recurrence

**관련 표기·별칭:** 

**보완·검증 필요 사항:**

- 각 문제 유형별 proof/엣지 케이스는 예제 수가 제한됩니다.

**초보자가 시작할 질문:**

- 합이 제한인 연속 구간에서 값이 음수면 window를 줄이는 방향이 항상 맞을까요?
- 0-1 배낭을 용량 정방향으로 갱신하면 같은 물건이 왜 두 번 쓰이나요?

**근거:**

현재 판정: **부분** / 우선순위: high

**정의와 실제 역할:** Scanner throughput, recursive depth, int overflow, comparator, PriorityQueue ordering, array boundary가 알고리즘 지식을 오답으로 만들 수 있습니다.

**언제 사용하는가:** BufferedReader/StringBuilder, long INF, 경계 입력, 직접 불변식 테스트를 적용합니다.

**대안과 경계:** PriorityQueue를 정렬 배열처럼 보거나 empty Deque에 null을 넣지 않습니다.

**예시·실행 근거:** Queue에 넣고 꺼내는 순서와 Deque 양끝 연산 결과를 비교합니다.

**선수개념:** Java collections; boundary testing

**관련 표기·별칭:** 

**보완·검증 필요 사항:**

- 환경별 시간은 측정 전 일반화하지 않습니다.
