## 자료구조와 정책 선택

현재 판정: **부분** / 우선순위: high

**정의와 실제 역할:** 키 기반 메모리 저장소와 원자 명령형 자료구조.

**언제 사용하는가:** cache/session/counter/queue/ranking 용도별

**대안과 경계:** 캐시 재생성 가능, 주문/결제 원장 대체 아님; 복구/일관성 설계 필요.

**예시·실행 근거:** 각 목적의 key/자료형/규칙 표.

**선수개념:** key-value 저장 모델; TTL 만료

**관련 표기·별칭:** String; Hash; List; Set; Sorted Set

**보완·검증 필요 사항:**

- 실패 복구 정책과 원본 DB 관계는 소개 수준.

## Redis Template과 serializer 선택

현재 판정: **부분** / 우선순위: high

**정의와 실제 역할:** Template은 serializer와 자료형 Operations를 제공, Redis는 바이트/자료형 계약만 안다.

**언제 사용하는가:** 문자열 또는 객체 저장 시

**대안과 경계:** JDK serialization은 Java class 결합; JSON도 schema/type/version 문제 남는다.

**예시·실행 근거:** GET raw value와 JSON DTO를 구분한다.

**선수개념:** 객체 직렬화; JSON 형식

**관련 표기·별칭:** Template·serializer; StringRedisTemplate; RedisTemplate

**보완·검증 필요 사항:**

- 실행 가능한 serializer compatibility migration 없음.

## TTL·자료형·atomicity

현재 판정: **부분** / 우선순위: high

**정의와 실제 역할:** TTL은 key에 붙고 INCR는 server-side 원자 counter 명령이다.

**언제 사용하는가:** 캐시 만료, 증가 카운터, 큐와 순위표를 다룰 때 사용한다.

**대안과 경계:** set+expire 별 호출은 원자 아님; WRONGTYPE은 키 자료형 계약 위반.

**예시·실행 근거:** INCR+TTL+WRONGTYPE 원인 확인.

**선수개념:** Redis key와 자료형; 동시 요청

**관련 표기·별칭:** expire; INCR; WRONGTYPE

**보완·검증 필요 사항:**

- demo도 increment 뒤 expire라 명령 묶음은 비원자.

## Spring cache abstraction과 HTTP session

현재 판정: **미검증** / 우선순위: high

**정의와 실제 역할:** CacheManager는 method result cache, Session은 HTTP session 저장소다.

**언제 사용하는가:** 반복 조회 결과를 캐시하거나 여러 인스턴스 사이에서 HTTP session을 공유할 때 사용한다.

**대안과 경계:** template 명령과 cache abstraction 구분; proxy self-invocation은 cache 우회.

**예시·실행 근거:** 캐시별 TTL과 key prefix를 지정하고, 조회 결과 무효화와 session 만료를 비교한다.

**선수개념:** Spring proxy 동작; HTTP session

**관련 표기·별칭:** Cache abstraction·Session; CacheManager; @Cacheable; Spring Session

**보완·검증 필요 사항:**

- 예제 미실행, 실제 만료 관찰 필요.
