## starter와 조건부 자동 구성

현재 판정: **부분** / 우선순위: high

**정의와 실제 역할:** classpath, 설정값과 사용자 Bean 조건을 평가해 Spring Boot가 기본 Bean을 자동 구성한다.

**언제 사용하는가:** 새 애플리케이션의 기본 구성을 빠르게 만들고 특정 기본 동작을 바꿀 때 사용한다.

**대안과 경계:** Bean definition의 존재와 DB 연결 성공은 별도다. 자동 구성 조건이 맞아도 실제 연결은 실패할 수 있다.

**예시·실행 근거:** starter dependency와 DataSource 조건이 Bean 등록에 미치는 영향을 확인한다.

**선수개념:** Spring IoC; classpath

**관련 표기·별칭:** Starter→conditional autoconfiguration; @ConditionalOnMissingBean

**보완·검증 필요 사항:**

- 전체 애플리케이션은 DB 설정 누락으로 기동되지 않아 일부 근거만 있다.

## 실행 중 Bean 목록과 역할

현재 판정: **부분** / 우선순위: high

**정의와 실제 역할:** 실행 중인 애플리케이션의 Bean 이름·타입·의존 관계는 프로젝트 구성에 따라 달라진다.

**언제 사용하는가:** context에 어떤 구현이 등록됐는지 진단할 때 사용한다.

**대안과 경계:** 특정 프로젝트에서 관찰한 Bean 수 333은 모든 Spring 앱의 고정 개수가 아니며 조건 매치 수와도 다르다.

**예시·실행 근거:** Actuator beans/conditions 결과에서 실제 Bean을 확인한다.

**선수개념:** Actuator

**관련 표기·별칭:** Bean inventory/roles; DispatcherServlet; DataSource; transactionManager

**보완·검증 필요 사항:**

- 관리 endpoint의 노출·접근 제한 정책도 함께 다뤄야 한다.

## 기본 자동 구성 수정

현재 판정: **미검증** / 우선순위: high

**정의와 실제 역할:** 기본 동작은 우선 지원 properties와 customizer로 바꾸고, 필요할 때 조건을 확인한 뒤 같은 역할 Bean을 대체한다.

**언제 사용하는가:** Boot 자동 구성 기본값을 유지하면서 필요한 동작만 바꿀 때 사용한다.

**대안과 경계:** @EnableWebMvc를 무심코 추가하면 MVC 기본 자동 구성을 바꿀 수 있고 같은 타입 Bean 추가는 후보 충돌을 일으킬 수 있다.

**예시·실행 근거:** JsonMapper 설정 전후와 조건 평가를 비교한다.

**선수개념:** configuration properties

**관련 표기·별칭:** Customizing defaults; properties; customizer; replacement bean

**보완·검증 필요 사항:**

- 설정 코드 예제는 실행되지 않았다.

## 자동 구성 조건 진단

현재 판정: **부분** / 우선순위: high

**정의와 실제 역할:** condition report는 자동 구성 조건의 평가 결과를 설명하고 beans endpoint는 등록된 Bean을 보여준다.

**언제 사용하는가:** 기동 중 기본 Bean이 생성되거나 생성되지 않은 이유를 조사할 때 사용한다.

**대안과 경계:** 조건 평가 보고서와 실제 Bean 목록은 서로 다른 자료다. endpoint 노출에는 별도 설정이 필요하다.

**예시·실행 근거:** 조건 일치/불일치와 최종 Bean 등록 결과를 나란히 확인한다.

**선수개념:** Actuator

**관련 표기·별칭:** Condition diagnostics; --debug; /actuator/conditions; /actuator/beans

**보완·검증 필요 사항:**

- Actuator endpoint의 접근 보호는 더 분명히 설명할 필요가 있다.

**기존 표현**
