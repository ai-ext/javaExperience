## 배열·List 수정 가능성

현재 판정: **부분** / 우선순위: high

**정의와 실제 역할:** 배열은 길이가 고정되고 Arrays.asList는 원 배열에 연결된 고정 크기 뷰입니다. List.of는 변경 불가이며 ArrayList 복사본은 구조 수정 가능합니다.

**언제 사용하는가:** 호출자가 add/remove/set할지 보고 구현/복사를 고릅니다.

**대안과 경계:** Arrays.asList의 set은 원 배열에 반영되지만 add/remove는 실패하고, primitive 배열은 List<int[]> 한 원소가 됩니다.

**예시·실행 근거:** source array->asList->set 값 반영/추가 예외.

**선수개념:** Java 기본 문법과 해당 API의 연산 의미

**관련 표기·별칭:** 

**보완·검증 필요 사항:**

- 중첩 객체까지 deep copy되지 않습니다.

**초보자가 시작할 질문:**

- Arrays.asList(source).set(0, ...) 후 source[0]은 어떻게 되나요?
- int[]를 Arrays.asList에 넣으면 왜 숫자 여러 개가 아니라 원소 한 개가 되나요?

## Set/Map의 중복·동등성·순서

현재 판정: **부분** / 우선순위: high

**정의와 실제 역할:** Hash 기반은 equals/hashCode로 key/member를 찾고 순서를 보장하지 않습니다. LinkedHash는 삽입 순서, Tree는 comparator 순서를 유지합니다.

**언제 사용하는가:** 순서가 공개 계약이면 적절한 구현/정렬을 명시하고 mutable hash key를 피합니다.

**대안과 경계:** TreeSet은 비교가 0인 원소를 중복으로 간주해 equals와 결과가 다를 수 있습니다.

**예시·실행 근거:** TreeSet/HashMap 예시와 `computeIfAbsent`/`merge`.

**선수개념:** Java 기본 문법과 해당 API의 연산 의미

**관련 표기·별칭:** 

**보완·검증 필요 사항:**

- HashMap 내부와 예상 비용은 J07

**초보자가 시작할 질문:**

- 같은 key 객체가 아닌데도 HashMap 항목 하나를 덮어쓰게 하려면 어떤 두 메서드 계약이 맞아야 하나요?
- TreeSet comparator가 0을 내면 equals가 false여도 추가가 막힐 수 있는 이유는 무엇인가요?

## Queue·Deque·PriorityQueue 동작

현재 판정: **부분** / 우선순위: high

**정의와 실제 역할:** Queue는 FIFO, Deque는 양끝 연산, PriorityQueue는 comparator 최우선 원소를 head로 둡니다.

**언제 사용하는가:** FIFO/LIFO는 ArrayDeque, 동적으로 최소값 하나씩 꺼낼 때 PriorityQueue를 씁니다.

**대안과 경계:** poll/peek는 빈 값을 null로 표현, remove/element는 예외; PQ iterator 전체 순서는 정렬되지 않습니다.

**예시·실행 근거:** sample PriorityQueue.poll() 최소 2 출력.

**선수개념:** Java 기본 문법과 해당 API의 연산 의미

**관련 표기·별칭:** 

**보완·검증 필요 사항:**

- ArrayDeque는 null 불가·thread-safe 아님

**초보자가 시작할 질문:**

- 빈 queue에서 remove와 poll은 어떻게 다르게 실패를 표현하나요?
- PriorityQueue를 for-each로 돌면 왜 poll 순서와 같다고 할 수 없나요?

## Collection mutation·complexity

현재 판정: **부분** / 우선순위: high

**정의와 실제 역할:** 자료구조별 연산복잡도와 순회 중 구조 변경 규칙이 다릅니다.

**언제 사용하는가:** List 중간 삭제에는 이동비용을, 순회 삭제에는 removeIf/Iterator.remove를 고려합니다.

**대안과 경계:** Fail-fast는 동기화가 아니며 LinkedList 인덱스 접근 O(n), 해시 O(1)은 기대치입니다.

**예시·실행 근거:** 연산 표와 CME/UnsupportedOperationException 예시.

**선수개념:** Java 기본 문법과 해당 API의 연산 의미

**보완·검증 필요 사항:**
