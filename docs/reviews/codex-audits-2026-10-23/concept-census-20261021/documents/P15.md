## Gradle 모델과 JDK 선택

현재 판정: **부분** / 우선순위: medium

**정의와 실제 역할:** IDE는 build.gradle/Wrapper를 바탕으로 모델을 가져오며 Project SDK와 Gradle JVM은 서로 다른 역할을 합니다.

**언제 사용하는가:** 터미널/IDE Wrapper, JDK 25 설정, gradle -version을 함께 맞춥니다.

**대안과 경계:** 소스 루트 수동 설정이나 Lombok IDE plugin은 실제 Gradle/annotation processor 설정을 대체하지 않습니다.

**예시·실행 근거:** Settings/Project Structure와 `./gradlew -version` 확인법. 예시 Spring 미실행.

**선수개념:** Java·Gradle 프로젝트; IDE 실행/디버깅

**관련 표기·별칭:** 

**보완·검증 필요 사항:**

- IDE 제품 버전·라이선스·메뉴는 시점별로 바뀔 수 있음

**초보자가 시작할 질문:**

- IDE에서 코드가 초록인데 터미널 Gradle이 Java 버전 오류를 내면 무엇을 각각 비교하나요?
- Lombok 플러그인이 있는데도 컴파일 processor 오류가 나는 이유는 무엇인가요?

## Run Configuration과 환경

현재 판정: **부분** / 우선순위: medium

**정의와 실제 역할:** 저장된 Run Configuration은 main/args/env/working directory/JRE를 재현합니다.

**언제 사용하는가:** profile·port 등 반복 설정을 목적 이름으로 저장하고 secrets는 local env로 둡니다.

**대안과 경계:** IDE 실행 구성은 CI 배포 config가 아니며 프로그램 인자와 환경변수의 역할이 다릅니다.

**예시·실행 근거:** 두 구현의 응답 결과와 대기 시간을 비교하는 예입니다.

**선수개념:** Java·Gradle 프로젝트; IDE 실행/디버깅

**관련 표기·별칭:** 

**보완·검증 필요 사항:**

- 실행 결과 미실행

## HTTP Client·Database·Git 도구

현재 판정: **부분** / 우선순위: medium

**정의와 실제 역할:** `.http`는 재현 요청 파일, Database tool window는 SQL 관찰, Git window는 diff/충돌 검토의 접점입니다.

**언제 사용하는가:** 사용/리뷰해야 할 API 요청을 프로젝트 파일로 관리하고 staged diff를 확인합니다.

**대안과 경계:** 운영 DB는 read-only 권한을 고려하고 Git resolve 클릭만으로 의미상 해결이 되는 것은 아닙니다.

**예시·실행 근거:** 요청을 처리하는 단계별 시간을 표시해 병목 위치를 찾습니다.

**선수개념:** Java·Gradle 프로젝트; IDE 실행/디버깅

**관련 표기·별칭:** 

**보완·검증 필요 사항:**

- 기능/단축키 availability depend on IntelliJ version/edition.

**초보자가 시작할 질문:**

## 시각 구조와 보완 장면

**기존 표현**

- 원문에는 흐름·코드·표, 운영 실패 사례와 실행/미실행 표시가 있다.

**정적 구조의 한계**

- 캡처가 없어 시각/모바일 상태를 주장하지 않는다. 런타임 주장은 원문에 적힌 근거 범위에 한정한다.

**추가할 의미 장면**

- 요청 byte가 DTO/converter/Entity/저장소를 통과해 응답 값이 되는 흐름
- 동시 갱신 경쟁과 원자적 UPDATE 영향 행 수 결과 비교
- 업로드 pending/available 상태와 정리 경로

## 실제 캡처 관찰

- 데스크톱 첫 화면에는 IDE 설정 흐름 요약과 접힌 섹션이 보인다. 캡처된 문서 사이트 화면에는 IDE UI, breakpoint, refactoring 상태가 없다.
- 모바일 요약은 읽을 수 있고 가로 넘침 없이 줄바꿈된다. 긴 제목은 두 줄로 표시된다.
- core 이미지에는 SDK/JVM, Run Configuration, refactoring, debugger, HTTP Client, database/Git 등 소주제 10개가 접힌 제목으로 보이며 상세 지침은 열리지 않았다.

**관찰 범위:** 이 화면은 문서 사이트이지 실행 중인 IntelliJ 세션이 아니다. 캡처는 단축키 사용이나 실제 디버깅 동작을 검증하지 않는다.
