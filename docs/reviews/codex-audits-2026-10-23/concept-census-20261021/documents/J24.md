## compile·interpret·JIT 단계

현재 판정: **부분** / 우선순위: high

**정의와 실제 역할:** javac는 source를 JVM class bytecode로 컴파일하고 HotSpot은 bytecode를 interpret/JIT native path로 실행할 수 있습니다.

**언제 사용하는가:** 언어 이름 대신 어떤 구현 단계가 어떤 표현을 만들고 실행하는지 설명합니다.

**대안과 경계:** javac compile은 CPU native executable 생성과 같지 않으며 JIT는 모든 method를 컴파일하지 않습니다.

**예시·실행 근거:** 재귀 호출이 종료 조건에 도달하는 입력과 도달하지 않는 입력을 비교합니다.

**선수개념:** Java compile/run; class file

**관련 표기·별칭:** 

**보완·검증 필요 사항:**

- JIT details are HotSpot-specific.

## class-file/API/runtime 호환성

현재 판정: **부분** / 우선순위: high

**정의와 실제 역할:** JVM bytecode는 플랫폼 간 호환 모델을 주지만 class version, Java API, OS/native dependency 조건이 남습니다.

**언제 사용하는가:** 빌드 target/--release와 실제 runtime image를 같이 고정하고 실행 검증합니다.

**대안과 경계:** WORA는 모든 OS 환경에서 identical behavior/performance 보장이 아닙니다.

**예시·실행 근거:** 매개변수로 받은 배열을 순회하며 조건에 맞는 값을 세는 예입니다.

**선수개념:** JDK toolchain; API version

**관련 표기·별칭:** 

**보완·검증 필요 사항:**

- No cross-platform matrix execution.

**초보자가 시작할 질문:**

## source-file mode와 AOT variants

현재 판정: **부분** / 우선순위: high

**정의와 실제 역할:** `java File.java`는 launcher가 source를 compile하고 실행합니다. JEP483 AOT cache는 HotSpot class load/link 준비를 저장하고 Native Image는 OS native binary를 빌드합니다.

**언제 사용하는가:** 한 파일 실습엔 source mode; startup constraints에는 다른 AOT 방식과 운영 기능을 비교합니다.

**대안과 경계:** source mode는 interpretation-only가 아니고 AOT cache는 Native Image가 아닙니다.

**예시·실행 근거:** 인접 리스트로 그래프를 구성하고 방문 배열을 이용해 탐색합니다.

**선수개념:** javac/javap; JVM runtime

**관련 표기·별칭:** 

**보완·검증 필요 사항:**

- AOT cache not executed in examples.

**초보자가 시작할 질문:**

- `java Hello.java`에서 javac 명령이 생략된 것이 실제 compile 단계가 없다는 뜻인가요?
- CDS/AOT class cache를 켜도 HotSpot JVM이 계속 필요한 이유는?

**예시·실행 근거:** 입력 크기를 키우며 같은 문제의 실행 횟수와 추가 공간을 비교합니다.

**선수개념:** static type; runtime object

## 실제 캡처 관찰

- desktop/mobile 첫 화면은 source→bytecode→JVM/JIT 차이와 source/runtime 버전 주의를 설명한다. 모바일 제목은 줄바꿈되지만 읽을 수 있다.
- core 캡처는 javap 출력이나 classfile→native 전환 대신 개요와 접힌 섹션을 보여 준다.
- 캡처에는 실제 compile/runtime 오류 상태가 보이지 않는다.

**관찰 범위:** 제공된 캡처에서는 코드 예시와 JVM 실행 흐름을 설명할 뿐 실제 실행하지 않는다. viewport 하나의 상태만 확인했다.
