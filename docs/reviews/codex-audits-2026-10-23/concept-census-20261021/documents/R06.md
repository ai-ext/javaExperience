## DB client·JDBC driver·server 역할

현재 판정: **부분** / 우선순위: high

**정의와 실제 역할:** GUI DB 도구는 query를 보내고 metadata/result를 보여주는 client이며 server는 데이터를 저장한다.

**언제 사용하는가:** 수동 schema 조사, query 실행과 로컬 DB 관리를 할 때 사용한다.

**대안과 경계:** JDBC는 Java client API이지 모든 DB의 SQL dialect가 같다는 뜻은 아니다.

**예시·실행 근거:** DBeaver→JDBC API→driver→wire protocol→DB server 연결을 따른다.

**선수개념:** network; client/server

**관련 표기·별칭:** client/server and JDBC drivers; DBeaver; JDBC; Connector/J

**보완·검증 필요 사항:**

- 연결·query 실행 절차는 정적 안내이며 실제 UI 동작 검증은 제한적이다.

## port mapping과 DB 인증

현재 판정: **부분** / 우선순위: high

**정의와 실제 역할:** client가 실행되는 host의 published port로 연결하며 인증과 schema 권한은 별도 검사한다.

**언제 사용하는가:** 개발 DB 도구 연결을 설정할 때 사용한다.

**대안과 경계:** localhost는 client가 실행되는 machine/container 기준이다. DB 계정과 SSH 계정은 다른 자격 증명이다.

**예시·실행 근거:** Compose 13307:3306 port mapping과 MySQL account를 확인한다.

**선수개념:** TCP; port mapping

**관련 표기·별칭:** port, profile and auth; host port; container port; DB user

**보완·검증 필요 사항:**

- 일부 캡처는 개요만 보이며 실제 DBeaver 연결 과정을 보여주지 않는다.

**초보자가 시작할 질문:**

## SQL 실행·ERD·데이터 변경

현재 판정: **부분** / 우선순위: high

**정의와 실제 역할:** metadata 도구는 schema/FK를 보여주지만 row 편집과 export는 server 상태를 바꿀 수 있다.

**언제 사용하는가:** DB 구조를 조사하고 제한된 로컬 data 작업을 할 때 사용한다.

**대안과 경계:** FK가 없으면 tool이 관계선을 추론하지 못할 수 있다. autocommit off만으로 안전성이 보장되지는 않는다.

**예시·실행 근거:** read-only query와 transaction rollback 절차를 비교한다.

**선수개념:** FK metadata; transaction

**관련 표기·별칭:** SQL execution, ERD and data changes; Navigator; ERD; Data Editor; auto-commit

**보완·검증 필요 사항:**

- 실제 GUI client에서 실행하지 않았다.

**초보자가 시작할 질문:**

## SSH·TLS·권한과 export 보안

현재 판정: **부분** / 우선순위: high

**정의와 실제 역할:** SSH는 네트워크 경로를 보호하고 TLS는 DB server 인증서를 검증한다. SQL 권한과 export 파일 보호는 별도 경계다.

**언제 사용하는가:** 원격 DB 연결과 최소 권한 진단, 결과 export를 설계할 때 사용한다.

**대안과 경계:** 계정 권한과 credential을 제한해도 개인 정보가 든 export는 별도 유출 위험이 있다.

**예시·실행 근거:** SSH jump host와 DB endpoint를 구분하고 필요한 열만 export한다.

**선수개념:** network; data privacy

**관련 표기·별칭:** SSH/TLS/export security; SSH tunnel; TLS certificate; CSV export

**보완·검증 필요 사항:**

- vendor 기능과 유료판 지원은 현재 공식 자료/화면을 확인해야 한다.

**초보자가 시작할 질문:**

- SSH tunnel이면 DB TLS 불필요? CSV가 read-only면 안전?
