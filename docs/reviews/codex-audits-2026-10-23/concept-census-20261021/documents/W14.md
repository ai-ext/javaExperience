## 동기/비동기와 블로킹/논블로킹의 두 축

현재 판정: **부분** / 우선순위: P0

**정의와 실제 역할:** 동기/비동기는 결과 전달 흐름, 블로킹/논블로킹은 호출 thread가 기다리는지 분류한다. 두 축은 독립이라 CompletableFuture 작업도 get()에서 호출자는 blocking할 수 있다.

**언제 사용하는가:** 스레드 고갈, I/O 대기, HTTP 응답 완료 시점 문제의 원인을 측정할 때. 일반 MVC/JPA CRUD는 동기 경로를 기본으로 둔다.

**대안과 경계:** 가상 스레드는 동기 블로킹 코드 대기 비용을 낮출 수 있으나 외부 지연/DB pool 한계를 없애지 않는다. WebFlux는 end-to-end nonblocking driver가 있어야 이벤트 루프 장점을 얻는다.

**예시·실행 근거:** MVC/JDBC 요청 thread가 8초 기다리면 응답 latency는 그대로; 가상 thread는 concurrency, queue는 request completion과 durable work 분리.

**선수개념:** threads; executor; I/O; Reactor; HTTP lifecycle

**관련 표기·별칭:** sync/async; blocking/nonblocking; CompletableFuture

**판정 이유:** 개념 정의와 선택 기준은 다루지만 실습/실행이나 학습 과제의 검증 근거가 부족해 부분 판정.

**보완·검증 필요 사항:**

- 코드 예제 일부는 미실행; Java25 `CompletableFuture` source while project toolchain21.
- 순수 Java virtual thread example is marked executed by author; this audit did not rerun it.
- 가상 스레드의 Boot 자동 executor 동작은 설정/버전 확인과 실제 부하 실험 필요.

## 응답 비동기·@Async·메시지 큐·작업 상태의 전달 보장

현재 판정: **부분** / 우선순위: P1

**정의와 실제 역할:** Servlet async response는 요청 thread를 반납하고 같은 HTTP 응답을 후속 완료 때 재디스패치한다. @Async는 executor 후처리, broker는 durable delivery 설정/consumer 책임, @Scheduled는 실행 시각만 예약한다.

**언제 사용하는가:** 응답 완료가 느린 합성 I/O와 작업 완료 전 수락 응답을 구분한다. 유실 허용 후처리는 제한 executor, 재시작 후 복구/재시도 요구는 작업 테이블·outbox/broker를 사용한다.

**대안과 경계:** `DeferredResult`는 작업 생성 안함; `@Async void` 예외는 caller에 전달 안됨; broker는 중복처리 가능. 요청 tx는 worker thread로 전파되지 않는다.

**예시·실행 근거:** 작업 row/outbox 기록 후 202+job id; worker 별도 transaction으로 RUNNING→SUCCEEDED/FAILED, idempotency key로 재전달 흡수.

**선수개념:** Spring proxy; thread-bound transaction; HTTP status semantics; broker ack/redelivery

**관련 표기·별칭:** Callable; DeferredResult; @Async; Kafka; outbox; idempotency

**판정 이유:** 개념 정의와 선택 기준은 다루지만 실습/실행이나 학습 과제의 검증 근거가 부족해 부분 판정.

**보완·검증 필요 사항:**

- Spring/Kafka code is marked unexecuted.
- Outbox and consumer idempotency are design guidance, not exercised in this document.
- Timeout, executor bounds/rejection, trace/MDC propagation and user state endpoint need actual config.
