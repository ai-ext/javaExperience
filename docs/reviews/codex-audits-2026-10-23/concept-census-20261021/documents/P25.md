## Client 선택

현재 판정: **부분** / 우선순위: high

**정의와 실제 역할:** Spring의 RestClient, WebClient, HTTP Interface는 동기/반응형 호출 방식과 선언형 계약에 따라 고른다.

**언제 사용하는가:** MVC의 동기 호출, WebFlux의 논블로킹 처리, 반복 호출 계약 중 어떤 방식이 필요한지 정할 때 사용한다.

**대안과 경계:** WebClient에서 block()하면 논블로킹 이점을 잃을 수 있다. RestTemplate은 기존 코드에서 볼 수 있는 선택지다.

**예시·실행 근거:** 요청 DTO를 보내고 응답 DTO를 받는 외부 REST 호출을 만든다.

**선수개념:** HTTP 요청과 응답; MVC 또는 reactive 처리

**관련 표기·별칭:** RestClient; WebClient; RestTemplate; HTTP Interface

**보완·검증 필요 사항:**

- 실행 방식별 성능 비교나 부하 측정 결과는 없다.

## timeout과 응답 오류 변환

현재 판정: **부분** / 우선순위: high

**정의와 실제 역할:** connect timeout과 응답 대기 timeout을 구분하고 외부 status를 애플리케이션 오류로 변환한다.

**언제 사용하는가:** 외부 서비스 응답 지연과 실패가 현재 요청에 미치는 범위를 제한할 때 사용한다.

**대안과 경계:** 연결과 응답 대기 모두 제한해야 한다. 재시도 시간도 전체 호출 예산에 포함해야 한다.

**예시·실행 근거:** WireMock에서 지연 또는 503을 반환해 애플리케이션의 timeout/status 변환을 확인한다.

**선수개념:** TCP 연결; HTTP status; 예외 처리

**관련 표기·별칭:** timeouts·response error mapping; connect timeout; read timeout; retrieve; onStatus

**보완·검증 필요 사항:**

- 테스트의 stub 설정 일부가 주석으로 남아 바로 실행할 수 있는 완성 예제가 아니다.

## 인증·로그·retry idempotency

현재 판정: **부분** / 우선순위: high

**정의와 실제 역할:** 외부 API 자격 증명과 로그의 민감 데이터를 보호하고 재시도할 요청을 제한한다.

**언제 사용하는가:** 외부 API 연동의 인증·정보 노출·가용성 정책을 정할 때 사용한다.

**대안과 경계:** GET은 멱등한 경우에 한해 일시 오류 재시도를 고려한다. POST는 멱등 키가 없으면 응답 유실 뒤 자동 재시도 시 중복 생성 위험이 있다.

**예시·실행 근거:** POST 응답이 유실된 상황에서 동일 key를 재전송하고 서버가 중복을 어떻게 처리하는지 확인한다.

**선수개념:** HTTP header; secret 관리; 멱등성

**관련 표기·별칭:** API key; bearer; Idempotency-Key

**보완·검증 필요 사항:**

- 구체적인 재시도 규칙은 외부 provider 계약마다 달라 별도 확인이 필요하다.

**초보자가 시작할 질문:**

- 결제 POST 응답이 끊겼는데 다시 보내면 주문이 중복될까?

## HTTP interface와 테스트

현재 판정: **부분** / 우선순위: high

**정의와 실제 역할:** HTTP Interface는 선언형 Java interface를 client proxy로 등록해 호출한다. 테스트는 네트워크 경계에 따라 대역을 선택한다.

**언제 사용하는가:** 반복되는 외부 API 호출을 선언형으로 정리하거나 status·지연·재시도 처리를 시험할 때 사용한다.

**대안과 경계:** interface 선언만으로 timeout, 오류 변환, 관측 정책이 자동 결정되지는 않는다.

**예시·실행 근거:** 테스트용 HTTP server에서 status와 지연 응답을 반환해 client 동작을 검증한다.

**선수개념:** Spring proxy; HTTP client

**관련 표기·별칭:** @HttpExchange; WireMock; MockRestServiceServer

**보완·검증 필요 사항:**

- 원문 테스트는 assertion 이외의 stub 구성이 완성되지 않았다.

**기존 표현**

- RestClient/WebClient 선택, YAML, 코드, WireMock 예시와 curl/테스트 안내를 담고 있다.

**정적 구조의 한계**
