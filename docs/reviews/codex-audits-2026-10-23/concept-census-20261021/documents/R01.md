## DBMS 계층과 client/server 역할

현재 판정: **부분** / 우선순위: high

**정의와 실제 역할:** DBMS는 서버로 실행되며 논리 데이터베이스와 객체를 관리한다. client가 인증한 뒤 SQL을 보내 대상 객체를 조회·변경한다.

**언제 사용하는가:** 네트워크 연결, 인증, 데이터베이스 선택, 테이블 오류를 서로 구분할 때 사용한다.

**대안과 경계:** MySQL의 schema는 database와 비슷한 단위로 쓰이지만 PostgreSQL은 database 안에 schema가 있다.

**예시·실행 근거:** MySQL SHOW DATABASES와 DATABASE(), PostgreSQL의 schema/table 확인 명령을 비교한다.

**선수개념:** TCP 연결; SQL

**관련 표기·별칭:** Database hierarchy and client/server roles; DBMS; server; database; schema; table

**보완·검증 필요 사항:**

- 예제는 기대 결과만 있고 데이터베이스 서버에서 실행하지 않았다.

## storage engine과 서버 자원

현재 판정: **부분** / 우선순위: high

**정의와 실제 역할:** storage engine은 DBMS 아래에서 테이블·인덱스 저장과 복구를 관리한다.

**언제 사용하는가:** DB의 메모리·디스크·잠금 책임을 나눠 이해할 때 사용한다.

**대안과 경계:** buffer pool은 DB cache이며 애플리케이션 JVM heap과 별도 자원이다.

**예시·실행 근거:** SHOW TABLE STATUS와 SHOW CREATE TABLE을 확인한다.

**선수개념:** table; storage

**관련 표기·별칭:** Storage engine and server resources; InnoDB; buffer pool; redo log

**보완·검증 필요 사항:**

- 실제 MySQL 상태 관찰은 없다.

## DB 연결 오류 단계

현재 판정: **부분** / 우선순위: high

**정의와 실제 역할:** listener/network, 인증과 데이터베이스 선택은 연결 과정의 서로 다른 단계다.

**언제 사용하는가:** 애플리케이션의 DB 연결 실패 원인을 순서대로 좁힐 때 사용한다.

**대안과 경계:** connection refused는 인증보다 앞에서 발생한다. Unknown database는 DB 서버에 도달한 이후의 문제다.

**예시·실행 근거:** 연결 오류 표와 CLI 검사로 서버 도달 여부, 인증, database 선택을 나눈다.

**선수개념:** host와 port; 자격 증명

**관련 표기·별칭:** Connectivity error layers; Connection refused; Unknown database; Access denied

**보완·검증 필요 사항:**

- 실제 오류를 재현하지 않았다.

**초보자가 시작할 질문:**

## 시각 구조와 보완 장면

**기존 표현**

- Mermaid client→server/storage 흐름, CLI 예제와 계층별 오류 표가 있다.

**정적 구조의 한계**
