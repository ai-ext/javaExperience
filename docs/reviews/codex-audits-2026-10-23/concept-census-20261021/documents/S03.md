## @SpringBootApplication과 후보 발견 경로

현재 판정: **부분** / 우선순위: P0

**정의와 실제 역할:** 합성 애노테이션은 configuration, package-relative component scan, auto-configuration을 켠다. 앱 컴포넌트는 스캔으로, library auto-config는 JAR imports metadata로 발견된다.

**언제 사용하는가:** 메인 클래스는 루트 package에 둔다. 서비스 빈은 scan 범위, 라이브러리 기능은 Boot starter/module와 imports candidate를 확인한다.

**대안과 경계:** 스타터는 의존성 묶음이고 자동 구성 코드는 조건이 맞아야 BeanDefinition을 등록한다. `scanBasePackages`는 엔티티/저장소 탐색도 자동 확장하지 않는다.

**예시·실행 근거:** 형제 패키지의 @Service는 누락되지만 classpath의 auto-config 후보는 로드될 수 있다.

**선수개념:** Spring component scan; classpath JAR resource

**관련 표기·별칭:** @SpringBootConfiguration; @EnableAutoConfiguration; @ComponentScan; AutoConfiguration.imports; AutoConfigurationImportSelector

**판정 이유:** 개념 정의와 선택 기준은 다루지만 실습/실행이나 학습 과제의 검증 근거가 부족해 부분 판정.

**보완·검증 필요 사항:**

- Boot4 custom auto-config 샘플 미실행; 모듈/패키지 이동은 버전별 확인 필요.

**초보자가 시작할 질문:**

- AutoConfiguration.imports는 무엇인가?

## 조건부 자동 구성, 진단과 readiness

현재 판정: **부분** / 우선순위: P0

**정의와 실제 역할:** Deferred auto-config candidates는 imports에서 발견되고 조건이 classpath, Environment, 현재 BeanDefinition을 검사해 기본 빈을 등록한다. Context refresh 뒤 runners가 실행되고 이후 ready/readiness 상태가 열린다.

**언제 사용하는가:** 사용자 빈으로 override 허용, optional class 참조는 nested conditional config, 필수 데이터 warmup은 동기 runner에서 실패를 숨기지 않는다. condition report로 원인을 진단한다.

**대안과 경계:** @AutoConfiguration(after)는 definition 처리 순서일 뿐 인스턴스 생성 순서 아님. @Primary 중복 빈을 제거 안 함. 비동기 runner가 즉시 반환하면 readiness가 준비 전에 열릴 수 있다.

**예시·실행 근거:** 조건부 AuditSink default 빈과 usersink override; required data warmup runner 예외는 readiness를 차단.

**선수개념:** BeanDefinition registration; Boot startup events

**관련 표기·별칭:** @ConditionalOnClass; @ConditionalOnMissingBean; @ConditionalOnProperty; ConditionEvaluationReport; ApplicationRunner; ApplicationReadyEvent; readiness

**판정 이유:** 개념 정의와 선택 기준은 다루지만 실습/실행이나 학습 과제의 검증 근거가 부족해 부분 판정.

**보완·검증 필요 사항:**

- Boot4 custom starter/JAR merge 및 condition report는 local 실행하지 않았다.

**초보자가 시작할 질문:**

- 조건이 맞는데 기본 빈이 왜 중복되나?
- 조건 순서와 객체 생성 순서의 차이?
- Runner 전에 readiness가 열리나?
- --debug report는 무엇을 보여주나?
