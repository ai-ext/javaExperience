## JSON·Jackson·HttpMessageConverter

현재 판정: **부분** / 우선순위: critical

**정의와 실제 역할:** JSON은 텍스트 형식이고 Jackson은 Java↔JSON 변환기이며 Spring MVC converter가 media type과 target type에 맞춰 읽고 씁니다.

**언제 사용하는가:** Controller 입출력은 DTO로 고정하고 Content-Type/Accept와 converter를 확인합니다.

**대안과 경계:** @RequestBody가 Jackson 직접 호출은 아니며 415는 media/converter, 400은 JSON·type/creator 오류가 흔합니다.

**정의와 실제 역할:** Instant/offset/date-only, enum wire value, unknown property policy, creator/record constructor는 JSON 의미 계약을 결정합니다.

**언제 사용하는가:** 시각대와 Enum 표시값, 불변 타입 creator를 DTO 단위로 명시합니다.

## JSON failure diagnosis

현재 판정: **부분** / 우선순위: critical

**정의와 실제 역할:** JSON 처리 실패는 문법 파싱·타입 변환·생성자 구성 오류, converter 부재, 순환 참조, 지연 로딩 접근 등 서로 다른 원인으로 발생합니다.

**언제 사용하는가:** 상태 코드와 예외 종류를 보고 입력 오류·미지원 media type·직렬화 문제·DB 세션 문제를 분리해 조사합니다.

**대안과 경계:** 415는 처리할 media type이 없을 때, HttpMessageNotReadableException은 읽을 수 없는 요청 본문에서 흔합니다. 순환 참조는 StackOverflowError, 세션 종료 뒤 지연 프록시 접근은 LazyInitializationException으로 나타날 수 있습니다.

**예시·실행 근거:** 415, HttpMessageNotReadableException에 의한 400, 순환 참조의 StackOverflow, LazyInitializationException을 서로 다른 실패 원인으로 나눕니다.

**선수개념:** Exceptions, JPA.

**관련 표기·별칭:** 

**보완·검증 필요 사항:**
