## 판정

## 목표·선수 지식·학습자 작업

프로필 API 한 번으로 가입시각, viewer가 볼 수 있는 글 수, 팔로워·팔로잉 수, followedByMe를 반환한다. 비로그인·팔로워·본인에서 공개 글 수가 달라지고 검색 author 결과 totalElements와 같아야 한다. 선수는 2-3 공개규칙, 8-4 검색 COUNT, follow/block 공통 정책이다.

GET /api/members/{id} DTO·Service·COUNT를 설계한다. 글 수는 검색이 쓰는 visibility 조건을 공유하고 follow counts는 엔티티 목록 대신 DB count로 계산한다. 차단 양방향 여부를 response 구성 전에 확인해 404로 통일한다.
