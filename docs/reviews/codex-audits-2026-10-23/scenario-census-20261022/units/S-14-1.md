post 13에는 반응이 없고 회원 2/3은 인증 가능하다. 별도 20개 글 page와 reaction data도 준비한다.

- 같은 회원이 HEART PUT을 두 번 barrier로 동시에 보내 응답 두 개와 최종 1행을 본다.
- Decide retry/read-after-conflict response policy.
- 20개 목록에서 post별 count 호출과 post_id GROUP BY 단일 query를 비교한다.

**정상 사례**

**실패·경계 사례**

**동시성·성능**

같은 owner/post 두 요청과 20개 ID grouped query의 execution plan을 각각 측정한다.

**DB 관찰**

post/member당 한 행, 반응 요약이 일치하며 다중 글 집계의 query count/계획 tradeoff를 남긴다.
