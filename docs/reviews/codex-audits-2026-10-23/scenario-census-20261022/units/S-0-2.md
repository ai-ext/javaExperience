## 판정

어노테이션을 장식 문법으로 외우지 않고 Spring 등록과 요청 mapping의 결과로 연결하는 강한 오류 중심 단계다. HTTP 체크는 충분히 구체적이나 자동 테스트는 이 endpoint를 보호하지 않는다.

## 목표·선수 지식·학습자 작업

0-1에서 사용한 @RestController와 @GetMapping을 Spring이 읽는 방식 및 요청 라우팅 결과를 관찰한다. 기존 Spring 앱 실행 경험과 0-1 코드가 선수다.

PingController를 작성하고 매핑된 응답과 오타 URL의 404를 확인한다. 이어서 @RestController/@GetMapping 제거·@Controller 대체·패키지 이동·중복 경로 등의 변형을 직접 적용하고 복구한다.
