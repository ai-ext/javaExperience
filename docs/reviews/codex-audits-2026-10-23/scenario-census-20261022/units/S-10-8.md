### PUT replacement 불변 키·빈 태그 확인

상태: **제안·미구현**. 이 문서 작성만으로 학습 실습이 구현됐다고 표시하지 않는다.

**이유**

원문 계약의 full replacement와 immutable author/board/id를 DB row로 확인한다.

**시작 상태**

작성자 글에 기존 tags 및 content가 있는 격리 test fixture.

**학습자가 할 일**

- tags 생략/visibility 생략으로 PUT한다.
- 응답과 post/post_tag row에서 새 기본값, 관계 제거, id/board/author 불변을 확인한다.

**정상 사례**

- 원문 checker가 지정한 정상 경계값과 정상 row/response를 유지한다.

**실패·경계 사례**

- 문서가 요구한 오류 코드와 오류 전후 DB state를 단언한다.

**동시성·성능**

동시성은 해당 실험에서만 barrier/별도 transaction으로 확인한다. 측정하지 않은 성능 개선은 주장하지 않는다.

**DB 관찰**

- 독립 disposable DB에서 핵심 relation/row/count의 전후값을 확인한다.

**합격 기준**

tags 생략은 빈 목록, visibility 생략은 PUBLIC, id/board/author는 보존된다.

**기존 과제와 중복·연결**

현재 단위의 원문 C/D/R 계약만 자동 검증한다. 기존 follow-up 단계의 책임을 이 단계에 복사하지 않는다.
