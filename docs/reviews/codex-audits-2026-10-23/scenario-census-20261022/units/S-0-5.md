## 판정

## 목표·선수 지식·학습자 작업

500과 4xx, 요청 처리 실패와 앱 기동 실패를 구분하며, 스택트레이스에서 예외 원인과 학습자 코드 위치를 찾아 문제를 고친다. Java 예외와 0-3의 Spring 바인딩 400 사례가 선수다.

메모리 Map으로 회원 별명 API를 만들되 처음에는 null 검사를 생략한다. 회원 id 1과 3을 호출해 200/500, 로그 원인 줄을 찾고 null을 검사해 없는 회원을 404로 바꾼다. Map.of(null) 사례와 설정 주입 기동 실패도 비교한다.
