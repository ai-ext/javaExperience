## 판정

SQL JOIN/WHERE를 실제 schema 관계에서 시작해 JPA repository와 DTO로 옮기며 쿼리 조건, 안정 정렬, 빈 결과와 404 차이를 다룬다. integration test도 성공·빈 목록·누락 입력을 포함한다. query-param method validation의 공통 오류 body는 S-2-2와 공유된 미확인 지점이다.

## 목표·선수 지식·학습자 작업

회원 프로필에서 개발 게시판에 작성한 공개 글의 요약을 얻는 새 API를 만든다. SQL JOIN/WHERE/정렬로 예상 행을 먼저 확인한 뒤 derived query에서 JPQL @Query로 조건을 확장하고 DTO projection 필요성을 비교한다. 2-1~2-4 조회, 관계, DTO 경험이 선수다.

GET /api/members/{memberId}/posts?board=slug를 만들고 회원/게시판을 먼저 존재 확인한다. DB query는 작성자·게시판·발행·PUBLIC·미삭제 조건을 적용하고 게시판 글 요약 4필드만 DTO로 반환한다.
