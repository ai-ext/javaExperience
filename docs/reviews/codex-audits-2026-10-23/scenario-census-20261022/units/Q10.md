## 확장 개발 명세

### 게시판과 작성자 필터의 교집합 확인

상태: **제안·미구현**. 이 문서 작성만으로 학습 실습이 구현됐다고 표시하지 않는다.

**이유**

필수 조건 boardSlug=dev AND authorId=P.author.id가 동시에 적용되는지 확인한다.

**시작 상태**

P는 tok-p05가 dev 게시판에 만든 게시글이므로 기대 authorId는 P.body.author.id다. 요청 A/B는 같은 두 조건을 각각 JPA와 MyBatis에 보낸다.

**학습자가 할 일**

A/B 결과에서 P.id 포함을 확인하고, 모든 item이 dev board와 P.author.id의 글인지 확인한다.

**정상 사례**

- 필수 조건 boardSlug=dev AND authorId=P.author.id가 동시에 적용되는지 확인한다.

**실패·경계 사례**

board만 맞는 다른 작성자 글 또는 같은 작성자의 다른 board 글은 교집합에서 제외되어야 한다.

**동시성·성능**

이 단위는 쿼리 정확성과 응답 계약을 확인한다. 실행 계획과 시간 측정은 DB-08~14에 연결한다.

**DB 관찰**

응답 id/boardSlug/authorId와 직접 SQL board.slug=dev AND post.author_id=P.author.id 결과를 대조한다.

**합격 기준**

A와 B의 ID 배열/total이 같고 P.id 포함, 조건 밖 두 대조 글은 제외.

**기존 과제와 중복·연결**

Q09 DTO projection과 같은 조회이며, Q10은 AND 조건 조합을 검증한다.

**우선순위**

medium
