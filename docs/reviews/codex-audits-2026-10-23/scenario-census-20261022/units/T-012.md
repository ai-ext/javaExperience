## 판정

요구와 HTTP·SQL 결과 기준이 순차 페이지의 중복/누락, own-only, 인증과 cursor 오류를 확인 가능하게 한다. 새 동시 삽입/관계 변경은 scope outside로 명시해야 하며 정답 snapshot 부재를 구현 결함으로 세지 않는다.

## 목표·선수 지식·학습자 작업

내 글과 내가 팔로우 중인 회원 글을 공개 규칙/차단을 적용해 최신순 keyset feed로 이어 읽는다. 선수는 2-3 접근규칙, 8-4 query, 기존 내 목록의 Cursor 인코딩/size+1 방식.

GET /api/me/feed 필수 인증, size 1~50, cursor decode/400, `(published_at,id)` 두 키를 이용한 단일 쿼리와 `size+1` 응답을 설계한다. author IN 목록을 Java에서 합치거나 회원별 쿼리로 나누지 않고 차단/삭제/상태 필터를 포함한다.
