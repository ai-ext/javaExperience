## 목표·선수 지식·학습자 작업

댓글 트리 응답·접근결과를 그대로 보존하고 viewer 차단 판정을 댓글마다 양방향 query하는 N+1을 request당 bulk blocked id fetch로 줄인다. 선수는 2-3 block policy, batched Set, Hibernate statistics.

login viewer에 대해 blockRelatedIds 한 번 조회하고 최상위/답글 author를 Set.contains로 판정한다. 댓글 fetch behavior/shape/order/slot, nonlogin behavior unchanged. 필수 T1은 8 comments 및 추가 comments에서도 SQL <=6 and not growing.
