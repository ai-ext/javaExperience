## 목표·선수 지식·학습자 작업

notification 원본 row는 보존하면서 읽기 시 삭제된 글 또는 삭제 댓글을 가리키는 알림을 목록/안 읽음 개수 양쪽에서 제외한다. 선수는 notification LEFT JOIN, type-specific nullable comment, unread count/query condition consistency.

목록 쿼리에서 post.deleted_at 및 comment.deleted_at을 필터하고 댓글 없는 LIKE 알림은 LEFT JOIN으로 유지한다. unreadCount가 전체 row count가 아니라 동일 visibility 조건으로 계산되게 한다. 알림 row 자체는 삭제하지 않는다.
