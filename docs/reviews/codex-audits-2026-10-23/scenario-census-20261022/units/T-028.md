## 목표·선수 지식·학습자 작업

인기 집계에 TTL cache를 두되 공개 여부 변화는 성공 commit 뒤 즉시 무효화하고 rollback은 cache를 보존한다. cache stampede, expiry clock, 여러 서버 무효화가 심화 선택이다.

days/limit 포함 cache key, immutable value, TTL/Clock, after-commit invalidation, 공개/숨김 상태 mutation 경로를 연결한다. 좋아요/댓글처럼 허용된 stale change는 TTL에 맡기고 X-Cache 관측을 낸다. Cold key 동시 요청은 한 번 집계하게 구성한다.
