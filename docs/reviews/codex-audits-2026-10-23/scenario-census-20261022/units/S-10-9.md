## 확장 개발 명세

### 댓글 트리·잠금 경합의 상태 검사

상태: **제안·미구현**. 이 문서 작성만으로 학습 실습이 구현됐다고 표시하지 않는다.

**이유**

한 단계 reply 조건과 post→comment lock 경로에서 삭제/답글 동시 상태를 확인한다.

**시작 상태**

서로 다른 author의 최상위/답글 seed와 disposable post.

**학습자가 할 일**

- 상세 및 댓글 list가 동일 tree를 반환하는지 검사한다.
- parent reply와 delete를 겹쳐 최종 부모/자식/삭제 상태가 일관적인지 확인한다.

**정상 사례**

- 원문 checker가 지정한 정상 경계값과 정상 row/response를 유지한다.

**실패·경계 사례**

- 문서가 요구한 오류 코드와 오류 전후 DB state를 단언한다.

**동시성·성능**

동시성은 해당 실험에서만 barrier/별도 transaction으로 확인한다. 측정하지 않은 성능 개선은 주장하지 않는다.

**DB 관찰**

- 독립 disposable DB에서 핵심 relation/row/count의 전후값을 확인한다.

**합격 기준**

경쟁 뒤 깨진 parent link/부모 삭제 후 유효 답글이 생기지 않고 HTTP status가 계약을 따른다.

**기존 과제와 중복·연결**

현재 단위의 원문 C/D/R 계약만 자동 검증한다. 기존 follow-up 단계의 책임을 이 단계에 복사하지 않는다.

**우선순위**
