## 판정

## 목표·선수 지식·학습자 작업

기존 목록·검색의 항목마다 현재 viewer의 likedByMe/bookmarkedByMe 두 boolean을 추가하되 순서/총건수/비로그인 결과는 유지한다. 선수는 response assembly 공유 위치, IN batch query/Set 조회, N+1 검사.

current page item IDs를 모아 로그인 viewer의 likes/bookmarks를 각각 bulk read하고 Set membership으로 응답 DTO를 구성한다. 비로그인은 추가 query 없이 false. 게시글 검색, 목록 등 공유 response conversion에 일관 적용.

## 요구·구현·검사 대조

### 1. 좋아요/북마크 membership은 viewer 기준이고 차단/숨김/삭제로 목록에 없는 ID는 보이지 않는다. 목록 순서·size·page/count는 바꾸지 말 것. 즉시 좋아요 반영(별도 cache 금지), 비로그인 필드 포함+false.

구현 대조: 정답 snapshot은 지정되지 않았다. 이 독립 과제의 요구로 확인했으며 미제공 정답을 구현 결함으로 판정하지 않는다.

검사 대조: C1~C5는 사용자별 좋아요/북마크 조합, search에도 필드, 비로그인 false, 좋아요 직후 최신 반영을 확인한다. D1/D2는 기초 테이블의 row를 보되 응답에는 화면에 노출된 목록 항목만 true여야 한다. T1은 선택적 SQL 수 등식.

공백 또는 한계: 요구와 검사 근거를 적었으며 정답 구현 결과는 본 감사 범위에서 미확인이다.
