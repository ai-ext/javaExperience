## 판정

DTO를 단순 파일 모양이 아닌 Jackson의 입력 생성과 출력 노출 계약으로 가르친다. 요청/응답을 나누고 정상·형식오류·서버 DTO 오류·조용한 빈 응답까지 실제 케이스로 설명해 교육 범위가 탄탄하다. 자동 검사에는 핵심 성공·타입오류만 있고 DTO 함정은 수동 실험으로 남는다.

## 목표·선수 지식·학습자 작업

JSON을 받을 객체와 응답으로 직렬화할 DTO가 어떤 생성·접근 규칙을 지켜야 하는지 record, static class, 기본 생성자, getter를 비교한다. 0-3의 @RequestBody와 Map/DTO 차이가 선수다.

ProfileController 내부 record 요청·응답 DTO를 사용해 POST /profile을 만들고 성인 여부를 계산한다. static 누락, getter 누락, primitive 입력 누락/타입 불일치, 생성자 매개변수 메타데이터 사례를 고장 실험한다.
