## 판정

정적 구현·상세 HTTP check는 정책에 대응한다. 관계·timestamp 보존과 30일 cutoff equality는 현재 checker에서 직접 증명되지 않아 보강 필요.

## 목표·선수 지식·학습자 작업

3-2 soft delete를 연장해 삭제자(actor) 기록과 30일 복구 정책을 구현한다. V22 이전의 tombstone은 deleted_by를 추측해 백필하지 않아 복구 권한을 얻지 못한다. 선행은 post의 soft-delete, auth identity, 2-3 가시성, Clock, 관계를 보존하는 기존 좋아요/댓글/태그/이미지 수명이다.

직접 설계: deleted_by migration, 삭제에서 deleted_at/deleted_by 동시 기록, 인증된 사용자의 최근 30일 복구 목록, restore 오류 판정 순서와 Clock, deleted fields만 제거하는 entity 상태 변경, 쿼리/응답 연계. 제공: 기존 post FK/soft-delete/related entities와 인증 기반.

**이유**

**시작 상태**

**정상 사례**
