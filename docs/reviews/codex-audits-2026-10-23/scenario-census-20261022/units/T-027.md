## 판정

## 목표·선수 지식·학습자 작업

기존 offset page 응답을 유지하면서 keyset nextCursor를 추가해 깊은 page에서 건너뛸 행과 COUNT query를 줄인다. 선수는 복합 정렬 key, index, opaque cursor, API backward compatibility다.

published_at과 id를 모두 encode한 cursor로 keyset range 조회를 구현한다. 기존 page mode fields를 보존하고 cursor mode는 total/page를 null로 두며 COUNT query를 생략한다. 깨진 cursor 400, tie-break 및 해당 index 순서를 맞춘다.
