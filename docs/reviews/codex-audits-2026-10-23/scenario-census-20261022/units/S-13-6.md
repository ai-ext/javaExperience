## 목표·선수 지식·학습자 작업

ADMIN-only report export는 UTF-8 BOM, RFC4180 quote/CRLF, localized value/current status, spreadsheet formula prefix escape를 적용한 CSV를 반환한다. status filter는 선택적이고 Clock 기준 filename을 만든다. 전체 bytes를 메모리에 모으는 한계도 판단한다.

EXPORT_DATA 권한, status parser, reporter/handler JOIN, deterministic row order, header/CSV escaping/formula prefix neutralization, Unicode filename을 구현하고 셀 단위 codec test를 작성한다. 대량 report 시 byte[] memory ceiling이 운영에 미치는 영향을 설명한다.

## 확장 개발 명세

### Large export streaming threshold

상태: **제안·미구현**. 이 문서 작성만으로 학습 실습이 구현됐다고 표시하지 않는다.

**이유**

전체 메모리 방식의 한계를 데이터량/connection hold/first-byte latency 측정과 대안 선택으로 연결한다.

**시작 상태**

detail 길이를 달리한 report 1천/5만/20만 건을 disposable DB에 만들고 heap baseline을 기록한다.

**학습자가 할 일**

- 각 row 수에서 현재 export peak heap, 처리시간, 결과 byte를 측정한다.
- bounded query/StreamingResponseBody를 시도하고 DB connection 점유 시간과 비교한다.
- 측정치를 기준으로 row threshold 및 기간 필터/비동기 파일 생성 선택을 문서화한다.

**정상 사례**

- Small export remains byte-for-byte compatible.

**실패·경계 사례**

- client disconnect/DB 오류에서 cursor/connection 종료와 partial file 처리 정책을 명시한다.

**동시성·성능**

peak heap, 첫 byte 응답 지연, DB connection 점유 시간, row/byte 수, DB version을 기록한다.

**DB 관찰**

실행계획, fetch row 수, transaction lifetime를 확인하고 reporter/handler가 N+1 없이 조회되는지 본다.

**합격 기준**

전환 threshold가 측정 근거를 가지며 합의한 volume에서 OOM 없이 응답하고 CSV byte/escape는 유지되며 중단 시 자원이 닫힌다.

**기존 과제와 중복·연결**

S-13-2는 paged moderation list이지 export가 아니다. H9 CSV/time와 S-15 batch는 인접 운영 주제다.
