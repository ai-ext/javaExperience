## 판정

네 입력 위치를 요청-매개변수-응답으로 추적하고 Map/DTO 차이를 실패 사례까지 설명하는 충실한 입문 단위다. HTTP 검사 계약은 핵심 정상 경로와 일부 오류를 포함하지만 모든 서술된 오류를 자동으로 실행하지 않는다.

## 목표·선수 지식·학습자 작업

하나의 POST 요청에서 경로 변수, 쿼리, 헤더, JSON 본문이 각각 어느 Spring 매개변수에 바인딩되는지 비교한다. 본문을 Map과 record DTO로 받을 때 알려진 키와 추가 키가 어떻게 달라지는지도 관찰한다.

두 endpoint를 직접 구현한다. Map 버전은 본문 전체를 그대로 echo하고 DTO 버전은 title/tags만 받는다. q와 X-Client가 필수이며 CORS에 X-Client 허용 설정을 준비해야 한다.
