## 목표·선수 지식·학습자 작업

PATCH는 JSON key 부재와 memo:null/문자열을 구분해 PATCH semantics를 직접 구현한다. owner-only lookup, preserve all untouched columns.

요청 body의 key 존재 여부로 변경 없음과 null 삭제를 구별하고 id 유지, folder/createdAt 보존, 잘못된 값/내부 플래그 입력을 거부한다.
