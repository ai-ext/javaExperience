## 판정

단일 고정 응답의 구조를 Java 타입 문법과 연결하는 의도에 충실하다. API/DB 심화 과제가 아니며 난도를 억지로 올릴 필요가 없다. checker는 응답 필드를 모두 확인하지만 별도 저장소 자동 테스트는 없다.

## 목표·선수 지식·학습자 작업

Java 기본 문법은 알지만 Spring API 코드를 읽을 때 타입 위치, primitive/reference, static/final, Class 객체가 헷갈리는 학습자를 위한 짧은 복습 단위다. DB 저장 없이 고정값 기반 summary endpoint를 만든다.

SummaryController와 SummaryResponse를 읽거나 작성하고 /summary를 호출한다. 정해진 unread count를 static final 상수로 두고 hasNotice 계산 결과와 class simple name을 응답에 포함한다.
