## 시작 상태

격리 seed에 공개 P1/P2, HIDDEN H1, 삭제 D1, PRIVATE V1, 글 0 개 게시판 B0, 태그 2 개 글 T1, 같은 좋아요수 글 3 개를 명시한다. 날짜 경계 from/to의 바로 전·정확히 경계·바로 후 행을 둔다.

## 학습자가 할 일

1. SQL로 독립 기대 ID 집합·순서·count를 먼저 작성하고 JPA/MyBatis/QueryDSL 각각에 적용한다.
2. Q16은 제목 일치와 본문 일치를 분리하고 H1의 본문에도 검색어를 넣어 공개 AND (제목 OR 본문)을 확인한다.
3. Q12는 B0의 count0 포함, Q13은 [from,to)의 to 제외, Q18은 동률 id DESC와 page/count 같은 조건을 확인한다.
4. 비공개 조건 또는 정렬 보조키를 제거한 잘못된 구현을 격리 복사본에 넣어 검사가 실제로 실패하는지 확인한다.

## 정상 입력과 기대 결과

- 공개 정상 ID와 모든 응답 필드가 독립 기대값에 맞는다.
- page size3과 5를 각각 검사한다. 예시와 체크의 크기가 다르다는 이유만으로 결함으로 처리하지 않는다.

## 실패·경계·반례

- H1/D1/V1 이 한 개라도 새면 실패한다.
- JOIN으로 T1 이 두 번 나오거나 B0가 사라지면 실패한다.
- 빈 조건·없는 ID·NULL·%/_ 검색을 명세대로 구분한다.
