## 일자 페이지 구성 (§5-1)

```
# DNN. <마일스톤>
> 1단계/2단계/마무리 · 오늘의 Java JNN · 말하기 카드 n장
[오늘 순서] ① … → ② … → ③ …   (체크로 진도)
[오늘의 Java] JNN 열기(30~60분) — course/java/JNN.md
[오늘 흐름] 요청 흐름 재생(정지 상태 읽힘)
─────
① <순서 제목>
  만들 파일(files) · 겪을 것(trap) · 완료 조건(done) · 명세(specRefs → spec-v2 앵커)
  ▸ 막히면: 힌트 (hints.json)
  ▸ 정답 보기: 이 순서의 커밋 answer(DNN-n)에서 그 순서 파일의 코드만(diff 또는 변경 후 파일). 커밋 링크
② …
─────
말하기 카드(TC-DNN-*) · AI 채점 프롬프트 · 내일 미리보기(tomorrow) · 날짜별 전체 snapshot(그날 마지막 정답 커밋 트리 링크) · 참고 자료 접기(기존 scenario/docs 링크)
```

- 2단계(D11~D14): 순서 칸에 그날 티켓(필수/선택 배지)·`messy-server` 실행법·티켓 페이지 링크. 정답 칸은 티켓 페이지의 "원인과 정답"으로 연결(티켓 정답은 티켓 페이지에만).
- D15: 말하기 카드 전체에서 무작위 10문항(페이지에서 뽑기 버튼, 정지 상태에서는 전체 목록), 회고 양식.
- D0: J00 워밍업 안내(선택).
- 정답 전체를 접기 하나에 몰지 않는다. 순서마다 그 순서 코드만.
- 정답 코드는 페이지에 인라인으로 넣는다(커밋 SHA는 PR 머지 방식에 따라 사라질 수 있어 링크만으로 두지 않는다 — Ruling).

## 순서

1. **P5-1 생성기·일자 페이지(D01~D10, D0)**: build-days.mjs, hints.json(D01~D10), course/spring, course/start. 검증: 생성기 테스트, `validate:course` 확장(일자 페이지가 roadmap 순서·카드·Java와 일치), 사이트 빌드 링크 오류 0.
2. **P5-2 렌더러·홈·지도**: 일자 페이지 배치, 진도 체크, 홈 재구성, 과정 지도. 검증: 빌드·audit, 브라우저(데스크톱·모바일 폭) 확인, 콘솔 오류 0.
3. **P5-3 흐름 재생·미캔 요소**: 요청 흐름 재생 컴포넌트, 티켓 장애 흐름, 미캔 탐색·적용·기록. 검증: 정지 상태 가독성, 재생 조작, 모바일.
4. **P5-4 2단계·마무리 일자(D11~D15)**: P4 결과(티켓 페이지·messy-server)가 끝난 뒤. hints.json(D11~D15), 티켓 배지.
5. 단계마다 codex 리뷰 → 반영 → 커밋 → PR #9 push → 원장(`plans/2026-10-23-p5-ledger.md`) 기록.
