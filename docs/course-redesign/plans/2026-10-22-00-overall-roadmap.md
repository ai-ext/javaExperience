## P7. 시나리오 전체 재검증 (마지막, 사용자 요청 2026-10-22)

P1~P6이 끝나면 학습자 입장에서 D0부터 D15까지, J0부터 J15까지, 티켓 B1부터 B16까지 처음부터 끝까지 다시 따라가며 검증한다.

- **정독**: 일자 페이지마다 다음을 확인한다.
  - "오늘 순서"만 보고 무엇을 만들지 알 수 있는가.
  - 명세서 v2·순서표·말하기 카드·정답 코드가 서로 맞는가.
  - 기술 사실에 오류는 없는가.
- **실행**: 다음을 실제로 돌린다.
  - 일자별 정답 snapshot에서 테스트가 통과하는지(Colima).
  - 페이지의 요청 예시가 정답 서버에서 기대 응답을 돌려주는지.
  - Java 학습 테스트에서 정답이 통과하고 빈칸 상태가 실패하는지.
  - 티켓 재현 스크립트가 증상을 재현하는지.
- **화면**: gstack 브라우저로 데스크톱 폭과 모바일 폭에서 확인한다. 흐름 재생, 정지 상태 가독성, 콘솔 오류 0을 본다.
- **결과물**: 문제 목록과 수정 PR. P1~P6의 검증과 별개로, 학습자 한 명이 처음 보는 눈으로 전부 따라가 본 기록을 남긴다.
