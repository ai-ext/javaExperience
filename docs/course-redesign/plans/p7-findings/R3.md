  - 999/1000 경계, 3000 상한, 음수 -1, 소문자 등급, null 등급은 하나도 고정하지 않아도 완료된다.
- 제안: 변형을 2~3개 더한다(`amount < 1000` → `<= 1000`, 상한 3000 → 3001, `"VIP".equals` → `equalsIgnoreCase`). 또는 페이지에 "변형을 다 잡아도 경계 목록을 스스로 채운다"를 완료 조건 밖의 권장으로 적는다.

**m13. J03 타입 한 컷: MyBatis `resultType="long"` 설명이 부정확하다**

- 위치: `course/java/J03.md:126`("`long sum = mapper.sumByMember(id);` (MyBatis `resultType="long"`, …)")
- 근거:
  - MyBatis 별칭 `long`은 `java.lang.Long`이다(기본형은 `_long`). 그래서 `resultType="long"` 자체는 null을 담는다. NPE는 매퍼가 `Long`을 돌려주고 호출부가 `long`으로 받을 때 난다.
  - 매퍼 메서드의 반환 타입을 기본형 `long`으로 선언하면 NPE가 아니라 MyBatis `BindingException`("attempted to return null from a method with a primitive return type")이 난다.
  - 같은 문장이 `D07.md:542`에도 있다(R1 교차 확인 권장).
- 제안: "매퍼가 `Long`을 돌려주는데 `long` 변수로 받으면 NPE, 매퍼 반환 타입 자체를 `long`으로 두면 MyBatis가 `BindingException`을 던진다."

**m14. J02 Lombok 표: `@RequiredArgsConstructor`의 대상 설명이 빠져 있다**

- 위치: `course/java/J02.md:148`
- 근거: Lombok 문서 기준으로 대상은 "초기화하지 않은 `final` 필드 + 초기화하지 않은 `@NonNull` 필드"다. 표는 final만 적었다. 과제 범위에서 틀린 결과를 내지는 않는다.
- 제안: 주의 칸에 "(`@NonNull`을 붙인 비-final 필드도 받는다)"를 한 마디 더한다.

**m15. J15 정률 할인의 넘침 회피 방법이 페이지 본문에 없다. 정답을 펴야만 나온다**

- 위치: `course/java/J15.md:49`
- 근거:
  - 테스트는 아래를 정확히 단언한다(`J15CouponCalculatorTest.java:40-48`).
    - `RateDiscount(100, Long.MAX_VALUE).discountOf(Long.MAX_VALUE) == Long.MAX_VALUE`
    - 33% × (`Long.MAX_VALUE`-1)를 BigInteger 결과와 비교
  - 본문은 "넘치면 안 된다(그대로 곱하면 -1)"만 말한다. 몫·나머지 분해는 [정답]에만 있다. 이 분해는 J04의 "`long`으로 곱하기"보다 한 단계 어려운데, J04 해법으로는 이 테스트를 통과할 수 없다.
  - 마지막 날이라 시간을 더 쓰기 쉽다(M2와 겹친다). 정답을 펴면 풀 수 있어 minor로 둔다.
- 제안: 본문에 한 줄 힌트를 둔다. "`price / 100 * percent + price % 100 * percent / 100`처럼 나눠 계산하거나 `BigInteger`·`Math.multiplyHigh`를 쓴다."

**J10 (어노테이션·리플렉션·JDK 동적 프록시)**

- 한 일: 페이지([정답] 제외), 뼈대(`TimedProxy`·`AuditStats`·`UploadLimits`와 주어진 인터페이스·구현·어노테이션), `J10TimedProxyTest`를 읽었다. `wrap`·`isTimed`·`countByAction`·`UploadLimits`를 채웠다.

  - 아래 두 가지가 본문 "막히는 곳 두 군데"에 정확히 적혀 있다. 이 둘이 이 과제의 핵심 난관이라 페이지 품질이 높다.
    - 인터페이스 `Method`에서는 구현 클래스의 어노테이션이 안 보인다
    - `getDeclaringClass() == Object.class` 분기, `InvocationTargetException`을 벗겨야 한다
  - `equals`·`hashCode`·`toString` 규칙도 테스트가 보는 그대로 본문에 있다.

- 테스트의 구현 강제: 없다. `toString` 형식은 "비어 있지 않고 target의 `toString`을 부르지 않음"만 본다. `Timing` 시간 값은 단언하지 않는다.
- 학습자 추정: 50~70분. 프록시·리플렉션이 처음인 학습자에게는 개념 비용이 크다.
