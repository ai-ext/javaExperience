30일 고정안은 스키마 확장·백필·롤백/복원, 작업 상태·중단/재개·두 프로세스를 하루에 합쳐야 했다. 40일안도 네 회의와 새 사례 설명·독립 변경/장애를 압축해야 했다. 45일안은 위험한 경계별 실험을 별도 날짜로 분리한다. 기존 과제의 번호·정답 커밋 연결·카드 ID는 유지하고 D15를 중간 점검으로 바꾼다. D07–D10·D14는 여러 순서를 체크하며 나눠 공부할 수 있다. 이번에 기존 날을 재번호화하지 않았으므로 전후 대응은 D01–D15 동일, TC-D01-–TC-D15- 동일이다. 기존 하루 분량 적정성을 실측했다고 주장하지 않는다.

#개인 경로·작업 위치

D16에서 A는 미수행 B05–B11, B는 고르지 않은 Security/Redis 영역에서 고른다. 모두 했으면 요청 수·지연 등 새 조건과 새 실패 증거를 고정한다. D17/18은 그 A/B만 필수 채점하고 무관한 미선택 티켓은 제외한다. 원인·정답은 기존 티켓 접기에 두며 제목/SQL/공개 프롬프트로 누출하지 않는다. D19 이후 전원 필수 완료 조건은 같고, 기존 동일 증거는 실행 조건/일자/새 반례와 함께 재사용한다.

D16–18은 messy-server 사본의 DB/포트를 명시하고, D19 이후는 1단계 결과에 붙인다. board-server·messy-server 원본 코드는 수정하지 않는다. 실제 업무 접근권은 전제가 아니다. D35의 제공 변형은 시작 전 예약 취소, D37은 시작 후 미지급 대상 취소다. D40/45는 진행자가 원인을 숨긴다. 독립 진행자가 없으면 공개 실험과 확인 불가를 기록한다.

Java J16–J45는 기존 J를 재사용하는 연결 페이지이며 새 Java 강좌/실습 모듈을 추가하지 않는다. 오늘 필요한 작은 실험·파일·명령·완료 조건은 Dnn.json.java에서 생성한다. ThreadLocal·실행기·JVM은 기존 J에 없던 실험을 명시한다. Spring/Java/card/SQL/grader 내용 원본은 날짜별 JSON만이다.

#못 한 것·검증 범위

모바일 브라우저 확인은 사용자 결정대로 보류했다. imagegen 시안 제작/대조를 하지 않았으므로 신규 항목을 시각 장부의 verified로 올리지 않았다. 학습자의 D16–D45 실제 구현·배포·측정·비공개 훈련과 교육 효과는 수행하지 않았다. 이 작업의 통과는 과정 자료·생성/검증 도구·PC 화면의 통과다. 학습자의 미실행·도움받은 범위·독립 진행자 부재는 각 날 채점에서 실패/확인 불가로 분리한다. 원본 서버 변경·원격 반영은 없다.
