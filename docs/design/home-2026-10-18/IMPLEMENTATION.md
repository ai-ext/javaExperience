# 홈 구현 · 2026-10-18

## 범위와 출처
사용자가 전달한 H01–H06 설명과 홈 개발 요청을 기준으로 기존 visual-learning-next worktree에서 구현한다. H01–H06 원본 이미지 파일은 확보하지 못했다. 새 ImageGen 참고 시안은 별도 원본이며, 과거 시안과 같다고 표현하지 않는다. 원문 README와 서버 학습 코드는 보존한다.

## 화면과 동작
- 상단: 홈 / 서비스 만들기 / 실전 미션 / 개념 학습. 홈에서 명칭을 먼저 적용하고 기존 목록 URL로 연결한다.
- 첫 방문: 목적과 기본 0-1 과제, API·작성 파일·완료 목표, 입력값이 응답에 이어지는 예시.
- 시작점 선택: Java 0-1 / 게시글 요청 1-1 / SQL DB-01. radio 선택만으로 진행 기록을 바꾸지 않고 적용으로 추천을 변경한다. 과제 시작 버튼에서 진행을 기록한다.
- 재방문: 명시적으로 시작한 과제의 마지막 장면 복원. 다른 자료·과제 개요 열람은 현재 작업을 바꾸지 않는다.
- 완료: 학습 화면에 명시적 수동 확인 버튼을 제공한다. 자동 채점과 구분한다. 완료 시 다음 과제의 개요와 시작 링크를 보여준다.
- 스크롤 하단: 학습 방법 세 단계, 실전 미션과 시각 개념 진입, FAQ 세 개, 환경 안내, 원문 README 전체와 푸터.
- new 패널: 같은 Greeting(name/message/nameLength) 예시의 생성 전/객체 생성/참조 연결을 버튼으로 비교. DB 저장과 구분. 닫으면 focus·scroll 복귀, Escape·backdrop·닫기 버튼 지원.
- 모바일: 1열, 44px 이상 조작, 모달 전체 화면, 글·코드 넘침 방지.

## 구현 순서와 검증
1. 홈 renderer·CSS 재구성 → 기본 추천의 API·파일·원문 앵커와 링크 대조.
2. 추천 데이터·진행 상태·모달 구현 → 선택 취소·시작·재방문·장면 복원·저장소 오류·수동 완료 검사.
3. 공통 build에 홈 script와 지원 과제의 진행 연결 → 기존 first-Java/DB UI 실행 뒤 복원.
4. build, audit:visual, audit:version-cards, audit:parity, 홈 동작 검사와 관련 회귀 검사.
5. visual inventory 갱신. 원본 시안 대조 및 브라우저 검증이 없으면 verified로 올리지 않는다.

## 현재 제약
브라우저 도구의 file:// 열기가 URL 보안 정책으로 거절됐다. 다른 브라우저 경로나 로컬 서버로 우회하지 않는다. DOM 기반 기능 검증과 실제 브라우저 렌더 검증을 분리해 보고한다.

## 후속 구현
완성 예시를 raw JSON보다 먼저 보이게 하고, 이름·게시글 form submit, DB-02 커서 예시를 추가했다. 6개 과제의 다중 탭 기록 변경은 최신 저장소 상태를 기준으로 처리한다. CSS는 기존 시안의 색·2열 구조를 유지하면서 글자 크기와 780px 이하 배치를 보완했다. 실제 브라우저 시각 대조 전까지 구현 상태로 남긴다.
