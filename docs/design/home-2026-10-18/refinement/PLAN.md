# 홈 개선 4개 항목 구현 계획

사용자가 전후 분석에서 지적한 4개 항목 모두의 구현을 승인했다. 기존 홈과 미커밋 작업은 유지하며 아래만 보완한다. H01–H06 원본을 확보한 것으로 간주하지 않는다.

1. 최종 게시판 서비스의 HTML 미리보기와 new의 큰 이미지·코드·값 비교를 추가한다. 시안은 내장 imagegen으로 만들고 docs/design에 보관한다. 최종 서비스 예시는 현재 과제 범위와 분리해 아직 만들지 않은 기능을 현재 요구사항으로 오인하지 않게 한다. new는 선언/생성/대입/같은 객체의 참조 공유/새 객체의 차이를 동일 Greeting 값으로 보여 준다. 0-1의 record를 기준으로 Java 실행 증거를 남긴다.
2. 공통 탐색을 홈/서비스 만들기/실전 미션/개념 학습으로 통일하고 각 페이지의 현재 공간을 aria-current로 표시한다. 기존 원문 제목·본문·앵커는 보존한다.
3. 시작점 선택을 적용하면 큰 카드와 미리보기에 선택한 과제를 즉시 보여 준다. 기존 진행 과제는 보존하며 별도의 이어하기 경로를 보여 준다. 새 과제 시작 버튼을 눌러야 active가 바뀐다. 취소·재방문·완료·다중 탭을 검사한다.
4. 첫 시작 버튼 바로 아래에 IDE/서버/DB 준비 안내를 배치하고 기존 환경 안내로 이어지게 한다. 준비 완료를 자동 추정하거나 과제 시작을 강제 차단하지 않는다.

검증: 관련 실패 재현/상태·DOM 검사 → 사이트 build → audit:visual/version-cards/parity 및 기존 관련 회귀 검사 → inventory 갱신과 근거 기록. 로컬 브라우저 자동 접근은 앞서 보안 정책으로 거절돼 다른 경로로 우회하지 않는다. 실제 렌더·모바일·같은 뷰포트 캡처가 없으면 verified로 표시하지 않는다.
