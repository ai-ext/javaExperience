# 개념 학습 웹 ChatGPT 시안 이관 · 2026-10-19

사용자 지시에 따라 기존 웹 ChatGPT 대화에 상세 요청을 실제 전송하고, 웹에서 생성한 이미지 원본 12장을 다운로드했다. 내부 imagegen으로 새로 만든 결과물이 아니다. 대화 URL과 원본 파일명·해시는 asset-index.json에 기록한다.

1. 웹 응답·이미지·134개 대기표 수신 → 다운로드 원본과 출처 확인.
2. K01~K04/K06A·B의 탐색·검색·빈 상태 구현 → 실제 134개 문서, DTO 7건, 필터 해제 시 검색어 보존 검사.
3. K05/K05B/K06C의 P16 대표 상세 구현 → 원문 3.2의 keyboard/quantity 2/고정 id 1L/고정 Instant와 단계별 상태 대조.
4. 원문·앵커 보존 및 빌드·관련 회귀·감사 → 기존 135개 Markdown SHA와 HTML ID 보존 확인.

## 범위와 기술 교정

- 원본은 docs/knowledge/P16-json-jackson-practical.md 3.2다. JSON 변환은 Controller 본문 호출 전의 인자 준비다. 예제는 DB를 사용하지 않으며 id=1L과 createdAt은 코드의 고정값이다.
- 시안 K03/K06B의 짧은 과제명 `1-2 DTO 응답`은 현 원문 제목과 다르므로 구현에서는 실제 과제 이름을 사용한다. P02의 관련 과제 1-3은 보정본 K03을 참조하되 링크의 문맥을 확인한다.
- 원래 문서·정답·출처·앵커를 보존한다. 공통 카탈로그 적용은 134개 상세의 개별 학습 시각화 완료가 아니다.
- 로컬 페이지 접근이 브라우저 보안 정책으로 거절된 상태여서 다른 접속 경로로 우회하지 않는다. DOM 동작 검사와 정적 감사를 수행하고 실제 렌더·모바일 시각 대조는 미검증으로 기록한다.

## 현재 단계

- 이미지 12장 수신·해시 보존·직접 시각 확인.
- P16 상세 구현과 빌드 연결, DOM 검사 및 원문 135개/기존 앵커 보존 확인.
- 카탈로그 데이터·뷰·CSS·검색 및 복귀 컨트롤러와 DOM 검사 준비.
- 웹 최종 개발 명세·134개 분류표 수신과 로컬 대조를 마쳤고, 카탈로그를 실제 생성 HTML에 연결했다. 원문 보존과 관련 검사를 통과했으며 실제 화면 대조는 남아 있다.
