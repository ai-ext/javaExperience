# 개념 학습 적용·검증 · 2026-10-19

## 적용한 화면

K01/K02/K03/K04/K06A/K06B는 개념 학습 목록 한 페이지의 상태다. 현재 과제가 있을 때만 관련 개념을 보여주며, Java·객체 / 요청·응답 / DB·데이터 / 설계·운영의 한 단계 분류와 대표 3행, 전체 분야 보기, 추천 순서와 기존 원문 진입을 제공한다.

K05/K05B/K06C는 P16 §3.2의 요청 인자 준비 → 응답 객체 생성 → 응답 JSON이다. keyboard·수량2·고정1L·고정Instant를 원문과 대조했다. 잘못된 수량 문자열은 Controller 본문 호출 전 실패한다. 실제 서버 응답으로 표기하지 않는다. 읽음은 명시적 버튼으로 기록·해제하고 학습 과제 진도와 분리한다.

134개 기존 문서에 목록·검색 결과 및 하던 과제 복귀 링크를 붙였다. 이것은 134개 고유 상세를 새로 완성한 것이 아니다.

## 실제 화면 검증은 남아 있다

이 세션의 로컬 페이지 브라우저 접근은 보안 정책으로 거절됐다. 다른 주소·포트·자동화 도구로 우회하지 않았다. 실제 360/390px 렌더, 시안과 같은 뷰포트의 화면 캡처, 실제 IME·모바일 키보드·브라우저 파일 탐색 검사는 아직 하지 않았다. DOM 검사는 브라우저 시각 검증을 대신하지 않는다. 이번 항목의 상태는 implemented이며 verified가 아니다.
