## 6단계 확인 범위

서비스 전용 렌더러·CSS·요청 모델을 공통 부품 체계에 맞췄다. 목록의 빈 3열, 상세의 좁은 내부 열, 요청 도구 stylesheet 누락을 제거했다. 준비·SQL·전후 사례를 노출하고 빈 본문 생성 응답의 Location ID 재사용 결함을 회귀 테스트로 수정했다. 목록과 상세 3개는 PC 1440×900에서 실제 조작했으며 격리 목 서버의 요청 확인은 학습자 API 검증과 구분한다. file 탐색과 기존 진도 키 보존을 확인했다. 전체 기획 품질·개별 시안 동등성·사용자 직관성은 8단계에서 계속 확인한다. 상세는 [서비스 통합 진행표](../full-integration-2026-10-25/PROGRESS.md)의 화면 흡수 단계 절을 따른다. 개념 학습 페이지와 그 사이드바는 수정하지 않았다.
