## 공통 화면 틀

모든 생성 문서가 site-frame.css의 공통 틀을 사용한다. 헤더 64px, 본문 바깥 여백 40px, 왼쪽 열 208px, 열 간격 32px, 본문 최대 1080px이다. 전역 메뉴는 고정 폭 브랜드 다음에 배치한다. 문서의 실제 시작은 x=280px, y=96px이며 스크롤바 공간도 고정한다. 홈·목록·상세·출발 자료·개념에 서로 다른 바깥 컨테이너를 두지 않는다.

기존 페이지 탐색과 일자 단계 탐색을 공통 왼쪽 열로 옮기며, 원문·기존 앵커·키보드 전환·진도·선택 티켓·복사·설정 탭은 유지한다.

## 첫 페인트

서버 생성 단계에서 사이드바와 기본 단계·탭을 렌더링한다. head에서 html.js·저장된 설정 형식과 해시 단계의 CSS 상태를 적용하고, 본문 초기 controller가 같은 상태를 인계받는다. html 배경을 다크로 고정한다. 시스템 글꼴을 사용하며 외부 폰트 교체를 추가하지 않는다.

## 홈

오늘 할 일(오늘 일자·Java → Spring → 채점·구현 순서·D00 안내), 과정 전체 설명(직접 만들기 → 티켓 → 설계·운영·독립 수행과 매일 흐름), 대주제 안내 네 곳만 둔다. 45일 과정의 Java·티켓·출발 자료·지도는 짧은 용도와 링크로 안내한다. 전체 진도·미리보기·개념 예제를 홈에서 복제하지 않는다.

## 회귀 검사

- test:navigation: 전역 메뉴 5개·한 층·떠다니는 바 0·전체 생성 문서의 경로와 현재 영역.
- check:frame: 출발 자료 ↔ 개념 학습, 일자 목록 ↔ Java, 티켓 ↔ 서비스 만들기, 홈 ↔ 45일 과정, 실전 미션 ↔ 개념 학습의 헤더·메뉴·사이드바·본문 좌표 차이 0px.
- check:reload: 0~1.5초 DOM·CLS 측정과 40ms 간격 캡처 요청. 기본 페이지·해시 단계·저장 설정을 같은 조건으로 비교한다. 실제 캡처 시각을 JSON에 남긴다.
- 사이트 test·audit·HTML 링크 검사, 대비 quick, tools/course 전체 test.

측정 원자료와 캡처는 검사 실행 시 출력되는 저장소 밖 임시 결과 폴더에 저장한다. `--out`으로 보관 위치를 지정할 수 있다.

`check:frame`·`check:reload`와 공통 Playwright 실행기는 저장소 루트를 빈 포트에 직접 제공하고 검사 종료 시 자체 서버만 닫는다. `--base-url` 또는 `SITE_BASE_URL`로 외부 서버를 지정할 수도 있다. Playwright는 `PLAYWRIGHT_MODULE`을 우선하고, 없으면 node_modules의 `playwright`를 찾는다. 둘 다 사용할 수 없으면 설치·지정 방법을 출력하고 종료 코드 2를 반환한다. Git 스테이징·커밋·stash·reset과 패키지 설치는 하지 않는다. check:generated의 HEAD 대조 실패는 미커밋 변경이 있는 이번 작업에서 재빌드 일치 여부와 구분한다.

## 개념 학습 통합

개념 목록의 필수/선택·기초/응용/심화 필터, 7개 분야와 C01–C06 단원 링크를 유지한다. 리더의 원문 목차는 공통 왼쪽 열에 배치하고, 핵심 단원은 별도 본문 사이드바 없이 공통 영역 메뉴에서 선택한다. 단계 전환·복사·원문 연결·검색 이력은 각 controller가 유지한다. 틀·새로고침 검사는 Spring 분야와 6단원 URL을 포함하며 원문 읽기 모드도 새로고침을 검사한다.

## 과거 검증 기록의 경로 정규화

main에서 유입된 과거 검증 기록 1,692개 텍스트 파일의 개인 홈 경로와 임시 폴더 접두사를 각각 `LOCAL_HOME/`, `LOCAL_TMP/` placeholder로 정규화했다. 원본 전체는 r27 외부 보관소의 tar와 SHA-256 manifest로 보존했다. 이 처리는 경로 표기만 바꾼 것으로, 과거 실행을 재현하거나 기존 관찰값·검증 판정을 새로 확인한 것이 아니다. 기록 속 기존 해시는 당시 원본 바이트의 증거로 유지하며, 현재 파일 무결성을 검사하는 D08 runner와 JPG provenance의 현재 무결성 지문은 정규화된 바이트에 맞췄다. placeholder가 들어간 과거 스크립트를 재실행할 때는 해당 환경의 실제 경로를 지정해야 한다. 생성 HTML은 원본에서 다시 빌드한다.

P13의 충돌 구분선 교육 예시 2개는 fenced code를 들여쓰기 code block으로 표현했다. 표시되는 예시·전체 코드 문자열·본문 텍스트는 `marked` 렌더 전후 동일하며, 실제 병합 잔재와 소스 형태를 구분하기 위한 변경이다. 과거 baseline 원문은 유지하고 현재 승인 기준의 P13 원본 지문과 해당 파일의 해시 연결만 갱신했다.
