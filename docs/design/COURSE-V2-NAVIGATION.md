# 과정 v2 내비게이션 통합

## 목표와 범위

다크 단일 테마, 1440 × 900 화면에서 전역 탐색을 한 줄로 줄이고 페이지 안 선택은 왼쪽 세로 사이드바 하나로 모은다. 학습 내용·원문 앵커·진도·체크·선택 티켓·복사·설정 탭·의미색·3열 일자 목록·2단계 원인 비노출을 보존한다.

## 확정 IA

| 전역 메뉴 | 목적지 | 포함 범위 |
|---|---|---|
| 홈 | 학습 홈 | 오늘 할 일, 진도, 선택 티켓 |
| 과정 | 일자 목록 | D00~D45 선택과 단계별 필터 |
| 지도 | 과정 지도 | Java·일자·티켓·결함 영역 관계 |
| 자료 | 자료 목록 | 과정 안내, Java 연습, 티켓, 출발 자료, 개념 학습 |
| 이전 과정 | 이전 과정 안내 | 서비스 만들기, 실전 미션, 기존 레슨·티켓 |

전역 메뉴는 모든 페이지에서 같은 순서로 정확히 다섯 개다. 브랜드는 홈 링크다. 종류별 보조 메뉴는 제거한다. 가이드·일정·연습·과제·참고는 페이지 머리의 종류 표시로만 쓴다. 일반적인 행동 배지는 페이지 머리에 반복하지 않는다. 이전 과정 안에서는 해당 메뉴를, 자료의 상세 페이지에서는 자료 메뉴를 현재 위치로 표시한다.

## 페이지 안 탐색

- 페이지 선택 메뉴·필터·목차는 왼쪽 사이드바 하나에 묶는다. 상단 전역 메뉴는 문서 흐름에 있고 따라 내려오지 않는다. 왼쪽 사이드바만 화면 안에서 고정될 수 있다.
- 홈은 오늘 할 일·진도·선택 티켓·학습 자료·참고 도감·개발 환경을 선택한다. 도감의 하위 메뉴도 같은 사이드바에 모은다.
- 과정 목록은 전체·선택 워밍업·1단계·2단계·중간 점검·3단계를 세로로 선택한다. 3열 일자 타일을 유지한다.
- 일자는 기존 단계형 작업대의 왼쪽 오늘 순서를 그대로 사용한다. 전체 보기에서도 가로 메뉴로 바뀌지 않는다.
- Java·티켓·출발 자료·개념 상세·이전 과정은 해당 페이지 목차와 목록 필터만 왼쪽에 둔다. 코드 언어 탭·설정 비교 탭·흐름 재생은 본문 작업 도구로 유지하되 떠다니지 않는다.
- 지도는 관계 지도·연결 목록을 사이드바에서 선택한다. 관계 선택과 검색은 해당 본문 안의 작업 도구로 두며 고정하지 않는다.
- 화면마다 경로 한 줄과 제목·용도 설명을 한 번만 노출한다. 본문 위에 두 번째 전역 메뉴나 종류 메뉴를 만들지 않는다.

## 전환 동작과 접근성

다른 페이지는 실제 href를 가진 일반 링크로 이동한다. 같은 페이지 선택은 원문 DOM을 보존한 상태에서 본문만 교체하고 history에 선택을 기록한다. scrollY는 유지하되 문서가 짧아져 읽던 위치를 유지할 수 없으면 본문 시작점으로 즉시 보정한다. smooth scroll은 사용하지 않는다. 방향키·Home·End·뒤로 가기·직접 해시 진입과 현재 선택·포커스 표시를 보존한다. 사이드바 탭은 세로 방향을 명시한다.

## 작업 순서와 합격 기준

1. 전체 생성 페이지 브라우저 조사 → 유형별 메뉴 수·위치·고정 여부·중복 및 대표 캡처 기록.
2. 공통 메뉴·자료 출발점·사이드바 구현 → 모든 페이지에 공통 IA 적용, 원문과 학습 상태 보존.
3. 빌드·기존 검사·회귀 검사 → 상단 한 층, 전역 다섯 개 이하, 본문 위 떠다니는 바 0개.
4. 1440 화면 전후 비교 → 메뉴 클릭 직후 이후 1초 동안 지연 스크롤 0, 주요 과제 경로 클릭 수 기록.

## 적용 기준의 근거

[웹 인터페이스 기준 원문](https://raw.githubusercontent.com/vercel-labs/web-interface-guidelines/main/command.md)을 2026-10-25 확인했다. 실제 링크·버튼 의미 구분, URL 상태 보존, 가시적인 키보드 포커스, 본문 건너뛰기, 고정 요소의 포커스 가림 방지 기준을 적용했다. 스크롤 애니메이션은 이번 작업 요구에 따라 사용하지 않는다. 원문은 변경 가능한 main 브랜치 문서이며 별도 버전 고정은 하지 않았다.

## 동작과 기능 보존

- 공통 메뉴·종류 메뉴를 하나의 전역 행으로 통합하고 자료·이전 과정의 출발점을 별도 페이지로 만들었다. Java 46개·현재 티켓 16개, 기존 레슨 50개·기존 티켓 30개를 실제 원문·과정 메타로 연결한다.
- 페이지 선택·분야·난이도·관계 목록·학습 장면은 왼쪽 한 사이드바에 둔다. 원래 목차는 DOM과 앵커를 보존하며 자바스크립트가 없으면 그대로 쓸 수 있다.
- 체크·진도·선택 티켓·순서별 완료 기록·데이터 복사·다운로드·yml/properties 탭·2단계 원인 접기와 의미색을 기존 검사로 확인했다. 학습자 서버·Java 과제·일자 JSON은 변경하지 않았다.
- 본문 위 sticky 바를 제거하고 일자 전체 보기에서도 왼쪽 순서를 유지했다. 일부 장면의 뷰포트 기준 폭을 본문 폭 기준으로 바꾸고, 넓은 산문은 72ch 안에서 읽게 했다.
- 개념 분야 필터를 옮긴 뒤 결과 제목이 전체로 표시되는 오류를 테스트로 재현하고 버튼 selector를 한정해 수정했다. 기존 집중 화면의 원문 제목 보조 읽기 처리도 새 본문 래퍼에 이어 붙였다.

## 검사 범위와 방법

사이트 내비게이션 전수는 460쪽에서 새 자료·이전 과정 2쪽을 더한 462쪽이다. 별도 시각 검증 대시보드 1쪽까지 포함하는 레이아웃 감사는 463쪽, 일자 전체 보기 46개를 더해 509개 상태를 측정한다. 두 범위의 페이지 수를 섞지 않는다.

상단 전역 항목 수·메뉴 층·떠다니는 요소를 검사하는 브라우저 회귀 테스트와 세로 방향키·해시·원문 보존·분야 필터 재배치·장면 선택 테스트를 test:navigation에 연결했다. 브라우저 테스트에는 PLAYWRIGHT_MODULE을 지정하며, 지정하지 않았을 때 브라우저 항목은 생략됨을 명시한다. 이번 검증에서는 모듈을 지정해 생략 없이 실행했다.

Java·티켓은 종류 메뉴로 긴 홈의 특정 카드에 진입한 뒤 접힌 목록을 열어야 했다. 자료 허브에서는 펼쳐진 목록의 대상을 바로 고른다. 출발 자료는 전역 종류 메뉴의 직접 링크를 제거해 자료 허브를 거치는 한 클릭이 늘었다. 메뉴를 줄인 대가를 클릭 개선으로 포장하지 않는다.

## 클릭 뒤 스크롤 검증

대표 유형의 실제 메뉴·필터를 하나씩 클릭하고 animation frame별 scrollY를 최소 1초 기록했다. 변경 전 294회, 변경 후 274회에서 오류·빈 샘플·1초 미만 기록은 모두 0건이었다. 공통 탐색의 같은 문서 전환은 스크롤 이동 10건(최대 1362px)에서 0건으로 줄었다. 100ms 이후 지속되는 이동은 전후 모두 0건이다.

다른 문서의 지정 앵커로 진입하는 일반 링크는 초기 위치 이동이 전 21건·후 5건이며 별도 집계했다. 이는 목적지로의 일반 링크 이동이다. 깊은 스크롤에서는 홈·일자 목록·개념 목록·지도 네 유형 모두 600px에서 본문 시작점 76px로 즉시 정렬한 뒤 1초간 추가 변화가 0이었다. 학습 장면의 내부 선택은 장면 본문 시작점에 즉시 맞추는 기존 동작으로 따로 확인한다.

원자료는 before/after-inventory.json, before/after-clicks.json, before/after-tasks.json, after-deep-clicks.json에, 대표 캡처는 before·after 디렉터리에 기록했다. 각 측정은 원본 페이지를 다시 불러 초기 상태에서 수행하며, 닫힌 details 내부는 가시성 검사로 제외했다.

Java·티켓의 기존 exercise-kind와 공통 content-page-kind가 겹치는 머리 표시는 기존 종류 줄만 제거해 한 번으로 통합했다. 과제 ID·h1·본문·용도 안내는 보존하며 재적용 시 중복되지 않는 회귀 테스트를 추가했다.

첫 Java API의 내부 장면 20개도 전후로 각각 선택했다. 활성 장면·현재 표시가 모두 20/20 일치했고 장면 시작점으로 즉시 정렬한 뒤 100ms부터 1초까지 추가 이동은 모두 0이었다. 공통 메뉴·필터의 이동 0과 의도한 장면 정렬을 혼합해 모든 같은 문서 조작이 이동 0이라고 표시하지 않는다.

검증 서버를 종료하고 18998 포트의 LISTEN 부재와 연결 거부를 확인했다. 측정 시작 시 기존 서버의 세션 소유를 확인하기 전에 종료한 실수가 있었으며 같은 포트에 새 검증 서버를 띄워 검사를 수행했다. 이 종료 이력은 최종 서버 정리와 구분해 기록한다.
