# 과정 v2 흐름 재생: 디자인 참고 자료 탐색과 적용 (P5-3, 2026-10-23)

설계 §7(2026-10-22 사용자 지시)은 시각 요소를 디자인 참고 자료에서 충분히 찾아 쓰라고 한다. 이 문서는 P5-3의 기록이다. 일자 페이지 [오늘 흐름]과 티켓 페이지 [장애 흐름]을 만들면서 무엇을 검색했고, 무엇을 골랐고, 어디에 썼는지 적는다. 요소 파일을 직접 넣지 않은 이유도 함께 남긴다.

## 결론

- 템플릿 검색 2회(검색어 6개)로 후보 60개를 얻었다. 그중 20개는 페이지 미리보기로 비교했고, 템플릿 1개는 구조(manifest)와 원본 페이지 2장까지 확인했다.
- 요소 검색은 3회 했다. 검색어 14개에 후보 70개가 나왔다.
- 요소 파일(SVG·이미지)은 리포에 넣지 않았다. 대신 고른 템플릿의 톤과 구성을 참고해 인라인 SVG 26개와 CSS로 다시 그렸다.
  - 아이콘: `tools/site/course-flow.mjs`의 `ICON_PATHS`
  - 타일·연결선·꼬리표: `tools/site/course-flow.css`
- 검색된 요소 70개는 모두 유료 자산이었다. 공개 리포에 재배포하지 않았고, 탐색 당시 도구에는 외부 내보내기 기능도 없었다. 외부 계정에 디자인을 쓰는 작업은 수행하지 않았다.

## 탐색 기록

### 템플릿 검색

| 회 | 검색어 | 결과 | 비교 |
|---|---|---|---|
| 1 | `서버 시스템 구성도`, `IT 아키텍처`, `데이터 흐름 다이어그램` | 30개 | 20개 미리보기 비교 |
| 2 | `장애 대응 보고`, `정보 보안 위험`, `업무 프로세스 흐름도` | 30개 | 1회차와 겹치는 후보를 확인한 뒤 새 후보는 더 보지 않았다 |

미리보기로 비교한 주요 후보:

| 이름(미리보기 표지) | 판단 |
|---|---|
| 정보 시스템 개발 제안서(라이트·초록) | **채택.** 각 노드는 선 아이콘을 넣은 정사각 타일로, 두꺼운 테두리에 어긋난 그림자가 붙는다. 노드 사이에는 실선·점선 연결선이 있고, 연결선이 노드에 닿는 곳에 작은 원(이음 점)이 있다. 강조색 알약 꼬리표(SYSTEM·DEVELOPMENT)와 단계 카드 위 날짜 칩(14쪽 "시스템 운영 프로세스")도 있다. 요청 흐름 지도에 그대로 맞는다 |
| 같은 제안서의 다크(청록) 판 | 다크 모드에서도 같은 구성이 읽히는지 참고했다. 타일 테두리를 밝은 선으로 바꿔도 위계가 유지된다 |
| 같은 계열 변형(초록·청록) | 단계 카드와 번호 칩 배치를 참고했다 |
| 개발자를 위한 ERD | 레트로 창 장식과 원색 도형이 강하다. 노드 수가 많은 흐름 지도에서는 산만해 채택하지 않았다 |
| 기술 세미나 / 그룹웨어 매뉴얼(다크·네온) | 배경 그래픽 비중이 크다. 학습 본문 사이에 끼우면 시선을 빼앗는다 |
| 타임라인 인포그래픽 | 단계 진행 표현을 참고했다. 색이 단계마다 바뀌어서 "그날 새로 만든 층" 강조와 충돌한다 |

채택 참고안 구조:
- 팔레트: `#000000`(글자·그림자·일러스트), `#ffffff`, 강조 `#00d045`(일러스트·면), `#f7f7f7`(면), `#191d21`
- 아이콘 칸: 약 54~60px 정사각 `illust`

### 요소 검색 (채택 참고안의 아이콘 칸 기준)

| 회 | 검색어 | 비교·구현 판단 |
|---|---|---|
| 1 | 서버 랙·데이터베이스 원통·캐시·결제·사용자 선 아이콘 | 서버 가로 칸은 `stack`, 원통은 `db`, 번개는 `bolt`, 카드는 `card`, 사람은 `user`로 직접 그렸다 |
| 2 | 보안 필터·경고·대기 시간 초과·모니터링·코드 괄호 | `shield`·`clock`·`search`를 구현했다. 경광등은 삼각형 `alert`로 단순화하고, 적합한 후보가 없는 `brackets`는 직접 그렸다 |
| 3 | 데이터베이스·깔때기·화살표 연결선·외부 파트너 | 원통은 1회차 후보로 충분했다. `filter`는 직접 그리고 연결선은 점선과 이음 점으로 표현했다. 채도 높은 제휴 일러스트 대신 외부 PG는 `card`로 유지했다 |

검색 결과의 썸네일은 비교에만 사용했고 페이지에 연결하지 않았다. 외부 서비스의 URL과 자산 식별자는 이 기록에 보관하지 않는다.

## 적용 위치

| 요소 | 디자인 참고 근거 | 구현 |
|---|---|---|
| 노드 타일 | 채택 템플릿 표지의 아이콘 타일(테두리 + 어긋난 그림자) | `.flow-tile` 44px, `box-shadow: 3px 3px 0`. 그날 만든 층은 강조색 테두리·그림자 |
| 선 아이콘 26종 | 위 표의 선 아이콘 톤(단색 선, 둥근 끝) | `ICON_PATHS`: `stroke: currentColor`, `stroke-width: 1.6`, `round`. 라이트·다크에서 글자색을 따른다 |
| 연결선 | 표지의 점선 연결 + 이음 점 | 기본은 점선과 빈 원이다. 재생 중 지나온 길만 강조색 실선과 찬 원으로 바뀐다(`.is-path`) |
| 알약 꼬리표 | SYSTEM·DEVELOPMENT 강조색 알약 | `.flow-new` "오늘 만듦" |
| 단계 카드·번호 칩 | 14쪽 "시스템 운영 프로세스"의 카드 위 칩 | `.flow-step-no`(테두리 사각 번호), `.flow-when`(점선 알약: "트랜잭션 안 · 커밋 전" 등 관찰 시점) |
| 색 | 템플릿 강조 `#00d045` | 그대로 쓰지 않았다. 사이트 강조 토큰(`--accent` #2f6f4f / 다크 #7cc59d)을 쓴다. 대비를 맞추고 다른 화면과 색을 같게 하기 위해서다. 티켓 흐름은 과정 지도의 티켓 색(#a5521b / #f0a56d), 원인 접기는 함정 색(#8a5a00 / #f2c46b) |

## 남은 것

- imagegen 시안과 시안 대조(`visual-parity.jsonl`)는 하지 않았다. 그래서 새 시각 항목(`visual:flow`, `visual:flow-links`)은 목록에 `unreviewed`로 남겼다.
- 티켓 페이지(`course/tickets/*`)의 흐름은 목록 대상이 아니다. 목록 스크립트가 티켓 화면을 담당에게 남겨 두기 때문이며, 티켓 HTML과 함께 들어간다.
