1) 필드 대입 직전 참조값 복사: caller p→A, changeObject의 매개변수 p→같은 A, A.nickname은 아직 Ada. 호출 전(매개변수 없음)·필드 변경 후(Grace)와 구별되는 실제 PNG가 필요합니다. ID P09-reference-copy.
2) false && (++calls > 0)의 현재 상태 PNG P09-15-and: 오른쪽 미평가, calls=0, 결과 false.
3) 다음 true || (++calls > 0)의 현재 상태 PNG P09-15-or: 오른쪽 미평가, calls=0, 결과 true. 기존 boolean & 현재 그림은 calls=1이라 앞 두 상태의 그림으로 대신 쓰지 않습니다.
4) eligible 비교 PNG P09-eligible: quantity=3, discounted=3240, quantity>=3 true, discounted>=3000 true, 최종 eligible=true.
5) 정수 몫·나머지 PNG P09-division-mod: 7/3=2, 7%3=1.
6) 호출자가 새 참조를 받는 추가 설명 PNG P09-return-reference: 같은 한 줄 profile = normalize(profile); 의 호출식 평가 뒤/대입 전에는 profile→A Grace, 반환 참조→B Local only. 대입 뒤 profile→B Local only. normalize 구현은 return new Profile("Local only"); 인 추가 설명 예시이며 원문 실행 출력과 혼합하지 않습니다. A/B는 주소가 아님.
