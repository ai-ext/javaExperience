# P09 구현·검증 기록

확인일: 2026-10-20 KST. P09의 원문 기반 구현과 아래 자동·브라우저 검사를 마쳤다. **개념 문서 전체 134개의 작업은 계속 진행 중**이며, 학습자 이해도와 전체 시안의 픽셀 동일성은 검증하지 않았다.

## 구현 범위

- 원문 489줄 전체를 다시 대조했다. 질문 27개를 `questions.json`에, 20개 주제·84개 상태를 `tools/site/p09-lesson-data.mjs`에 연결했다.
- 선택한 실제 생성 이미지 45장: 화면에 쓰는 44장과 모바일 참조 배치 설계 1장이다. 웹 ChatGPT 10장, built-in image_gen 35장이다. 교정 전 초안 12장은 별도 보관한다.
- new·생성자·this·필드/지역 변수/배열 원소·메서드 선언·return·static·오버로드·varargs·접근·캡슐화·final·main·연산·오류를 다룬다. 원문에 없던 실험값은 추가 예시로 표시했다.
- 호출 전 Ada → 참조값 A 복사 → 같은 객체의 nickname Grace → 복귀 → Grace에서 다음 호출 → 매개변수만 B Local only → 복귀 후 호출자 A Grace를 분리했다. A/B는 설명용 기호이며 실제 주소가 아니다. B의 즉시 GC를 주장하지 않는다.
- 선택·이전·다음에서 그림/강조 구간, 현재 값, 관련 코드와 짧은 설명이 함께 바뀐다. 비교를 펼칠 수 있고 코드·라벨은 선택·복사 가능한 DOM 텍스트다.
- 모바일 참조는 P09-16의 세로 배치를 바탕으로 DOM 관계를 재구성했다. 다른 가로 그림은 축소 전체 보기와 읽을 수 있는 크기의 부분 확대/내부 좌우 이동을 제공한다. 확대 영역은 키보드로도 움직인다. 화면 크기 변경 때 수동 확대 여부와 관계없이 참조 배치를 갱신한다.
- 기존 제목·서두·전체 원문은 원문 펼치기 안에 보존했다. 원문 깊은 링크가 접힌 조상을 열고 목표 절로 이동한다. 학습 과제 진도에는 쓰지 않는다.

## 이미지 검토와 남은 검증

생성 과정에서 참조 연결선의 끝점, 없는 기본 생성자, prefix/반환 문자열의 공백, boolean & 표기, 나눗셈 분자 라벨, 전위/후위 실행 순서를 오해할 화살표를 찾아 교정했다. 선택본은 `asset-review.json`, 교정 이전은 `images/drafts/`와 생성 기록에 연결했다.

이번 최종 화면 확인에서는 데스크톱 참조값 복사·숫자 경계와 모바일 참조/A·B 분리·메서드·선언의 판독성을 직접 확인했다. 나머지 이미지도 원본 의미·값은 생성 시 개별 검토했고, 최종 브라우저에서는 전수 로드·전환과 이미지별 캡처를 남겼다. **모든 캡처를 같은 강도로 사람 눈으로 정밀 대조했다고 주장하지 않는다.** 교육용 plate와 실제 전체 화면은 구성도 다르므로 parity 원장은 implemented로 유지한다. 원문/동작 검사 통과와 parity verified는 별개다.

Spring Boot 4.1.1·Java25·HTTP와 실제 학습자 서버는 실행하지 않았다. Greeting JSON은 원문 예상값이며 실측 응답이 아니다. Java25·Spring/Lombok/JPA의 현재 지원 여부를 새 웹 조사로 확인한 작업도 아니다. 이번 브라우저는 Chrome이며 다른 브라우저·실제 휴대폰·스크린리더·학습자 이해도는 미검증이다.

일부 모바일 캡처에는 브라우저 번역 확장의 고정 overlay가 보인다. 키보드 조작 중 chrome-extension URL에서 TypeError도 관찰했다. 이것을 사이트 코드 오류나 사이트 전체 무오류로 확대하지 않는다. 확장 설정은 바꾸지 않았다. 첫 지연된 클립보드 읽기는 일치하지 않아, 클릭→성공 상태→즉시 읽기를 두 번 다시 수행해 현재 코드와 일치를 확인했다.

## 생성 경로

웹 ChatGPT 새 대화: https://chatgpt.com/c/6ad632f9-7120-83e8-a4aa-faf4b15cbccd . 실제 스킬 기준·예제·장면을 `web-request.txt`로 전달했다. 업로드의 파일 URL 권한 실패 뒤 설정을 바꾸지 않고 본문에 실제 내용을 전달했다. 후속 메시지 시간 초과 후 같은 요청을 재시도했지만 새 답이나 최종 ZIP을 확인하지 못했고, 마지막 관찰에서 중지 제어는 0개였다. 웹 작업이 현재 실행 중이라고 표시하지 않는다. 이후 부족한 이미지는 built-in image_gen으로 생성했다. `direct-generation-records.json`에 실제 도구 경로와 프롬프트/교정 이력을 보관한다. 첫 참조값 복사 그림은 실제 생성 원본 경로를 남겼지만 별도 정확한 프롬프트 사본은 보관되지 않았다.

`file://`는 브라우저 도구에서 차단되어 허용된 loopback HTTP로 개념 문서와 필요한 공개 자산만 제공했다. 작업은 LOCAL_HOME/code/javaExperience/.worktrees/concept-learning-night 에만 보관하며 merge·push·PR은 하지 않는다.
