[P09 원문 예제와 정확성 계약]
1. package/import: package com.example.billing; import java.math.BigDecimal; public class Invoice { private BigDecimal total; }. 소스 경로 src/main/java/com/example/billing/Invoice.java. 공개 최상위 클래스 basename Invoice.java. package→타입 위치, import→타입의 짧은 이름, class→멤버 선언. 파일명을 어긋내면 javac 오류.
2. 생성자: public class Invoice { private final String number; public Invoice(String number) { this.number = number; } }. 생성자는 클래스명과 같고 반환 타입 없음. 직접 생성자가 없을 때만 기본 no-arg 생성자. new가 객체를 만들고 생성자가 필드를 초기화. 이 예제 원문에 고정 number 값은 없으니 값을 추가하면 설명용 추가값임을 표시.
3. 변수: private int retryCount; private static int issuedCount; public void send() { int attempt = retryCount + 1; }. 인스턴스 필드는 객체별 retryCount=0, static issuedCount는 공유 0, 호출 시 지역 attempt=1, 종료 후 지역 범위 끝. 참조 필드 null/boolean false도 설명. 지역 변수는 자동 기본값 없고 읽기 전에 직접 대입. 매개변수는 호출마다 인자값. 요청별 상태를 static에 두지 않음.
4. 메서드 선언: public BigDecimal totalWithTax(BigDecimal rate) throws ArithmeticException { return total.multiply(BigDecimal.ONE.add(rate)); }. 접근/반환타입/이름/매개변수 타입과 이름/throws/본문을 구별. 이 예제 total/rate 고정 수치 없음. static 문맥에는 this가 없음.
5. 호출 this return: invoice.total(), Invoice.parse(...)는 문법 설명용 호출. 인스턴스 안 recalculate()는 this.recalculate(). this.number=number는 필드와 동명 인자 구별. public boolean overdue(LocalDate due) { return due.isBefore(LocalDate.now()); } / public void markPaid() { if (paid) return; paid = true; }. 비void 모든 정상 종료 경로는 반환값 필요; void return;은 일찍 종료. 날짜 실측값 발명 금지.
6. 접근·캡슐화: private 같은 클래스, 생략 같은 패키지, protected 같은 패키지+타 패키지 하위클래스 문맥 제약, public 공개. 접근과 이름 스코프는 별개. private int quantity; public int getQuantity(){return quantity;} public void setQuantity(int quantity){if(quantity<0) throw new IllegalArgumentException(); this.quantity=quantity;} . 음수 거부시 필드 안 바뀜. final 변수 재대입 금지와 객체 자체의 불변을 혼동하지 않음. final 메서드 재정의 금지/final 클래스 상속 금지.
7. 오버로딩 varargs: String find(long id), String find(String code). 반환타입만 또는 인자 이름만 변경하면 중복. 마지막 매개변수만 ... 가능. static int sum(int... values){ int total=0; for(int value:values) total+=value; return total; }.
8. main: public static void main(String[] args). args는 명령행 인자. SpringApplication.run(GreetingApplication.class,args)로 시작. main이 일반 객체 생성과 DB 저장을 자동으로 하는 것처럼 그리지 않음.

Greeting { private final String message; public Greeting(String message){this.message=message;} public String getMessage(){return message;} }. 원문은 Java의 큰따옴표 문자열이며 여기 프롬프트의 작은따옴표는 설명 표기입니다. 실제 그림 코드는 Java 큰따옴표로. 10. PassByValueDemo 원문 순서 고정:
private static class Profile { private String nickname; Profile(String n){nickname=n;} }
private static void changeObject(Profile p){p.nickname="Grace";}
private static void replaceLocalReference(Profile p){p=new Profile("Local only");}
private static void changePrimitive(int n){n=99;}
public static void main(String[] args){
 Profile p=new Profile("Ada"); changeObject(p);
 System.out.println("after field mutation="+p.nickname);
 replaceLocalReference(p);
 System.out.println("after parameter reassignment="+p.nickname);
 int n=1; changePrimitive(n);
 System.out.println("after primitive parameter assignment="+n);
}
실제 원문 출력은 after field mutation=Grace / after parameter reassignment=Grace / after primitive parameter assignment=1. changeObject 호출 전 caller p→A nickname Ada. 호출 중 callee p가 복사한 참조값 A→같은 객체 A. 필드 대입 후 A nickname Grace. 복귀 후 caller p→A Grace 유지, 매개변수 프레임 종료. 다음 replaceLocalReference 시작은 반드시 Grace (Ada로 되돌리지 않음). 호출 중 새 객체 B nickname Local only로 callee p만 바뀜. caller p는 계속 A Grace. 복귀 후 caller p→A Grace. B가 즉시 메모리에서 삭제됐다고 그리지 말고 이 예제에 남은 접근 가능한 참조 없음, GC 시점 미확정. 기본형 caller n=1→callee n=1→callee n=99→복귀 caller n=1. 참조도 값으로 전달.
11. MethodsDemo 원문:
private final String prefix; private static int created;
public MethodsDemo(String prefix){this.prefix=prefix;created++;}
public String format(String name){return prefix+name;}
public String format(String name,int count){return format(name).repeat(count);}
public void printAll(String... messages){for(String message:messages)System.out.println(message);}
public static int createdCount(){return created;}
main: MethodsDemo demo=new MethodsDemo("Hello, "); println(demo.format("Ada")); println(demo.format("Hi! ",2)); demo.printAll("one","two"); println("created="+MethodsDemo.createdCount());
정확 출력 Hello, Ada / Hello, Hi! Hello, Hi! (끝 공백 있음) / one / two / created=1. created는 클래스 공유/this.prefix는 인스턴스, this와 static을 섞지 않음. format(name,count)→같은 this의 format(name)→repeat(2)→반환을 추적. 이 예제와 Profile 혼합 금지.
