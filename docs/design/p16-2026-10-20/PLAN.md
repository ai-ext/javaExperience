# P16 개념 학습 확장 계획

1. 원문 전체와 기존 3단계 화면을 읽고 질문·실행 범위를 나눈다 → source SHA와 질문 목록.
2. 기존 캐시의 Jackson3.1.5/JDK21 및 Spring7.0.9 독립 MVC 검사 → stdout·의존성 SHA·원문 추출본.
3. 값·경계를 확인한 뒤 의미 장면별 실제 imagegen 생성 → 프롬프트·원본·선택/교정 기록.
4. 좁은 UI 구현을 위임하고 기존 정상/실패 장면·명시 읽음·원문을 유지 → DOM/원문 보존 검사.
5. desktop/mobile 전체 상태와 조작 확인 → 캡처·parity는 증거 범위에 맞춤.
6. build·관련 테스트·필수 감사·독립 리뷰 → 로컬 커밋, 통합/push 없음.

HTTP 앱 서버·Boot4.1.1·Java25·JPA 실행과 isolated mapper/MVC 검사는 별개다. 원문의 '미실행' 설명을 고치지 않고 현재 추가 실험의 범위를 화면에 명시한다. unknown-property의 strict는 설정 선택이며 Jackson3 기본값이라고 오해시키지 않는다.
