2. 기존 연구와 원문 대조·direct Luna/OpenAI 공식 조사 → URL/DNS/TCP/QUIC/TLS/proxy/Boot 사실과 문헌 접근 한계를 구분한다.
3. 원문 ProbeApplication.java 그대로 추가 Java21 Gradle 환경에서 실행 → 새 loopback port0·실제200/ok/404·정상 종료·의존성 SHA를 확인한다. 원문 Java25/8080 설정 실행과 구분한다.

5. 공개 demo CA/cert는 새 run 안에만 생성하고 개인키0600 → 정상 체인/hostname 검증과 불일치/신뢰 부재 거부를 검사한다. 검증을 끄지 않는다. Python proxy를 Nginx 실측이라고 부르지 않는다.
6. root/TLD/cache·wildcard bind/외부 도달·NAT/L4/L7·forwarded 신뢰·QUIC은 추가 명시 모델 또는 문헌 → 실행하지 않은 운영 경로·보안/성능을 실측처럼 쓰지 않는다.
7. main fresh replay·독립 temp 재현 → frozen 전체와 raw 자료·자체 PID/socket 종료를 확인한다.
