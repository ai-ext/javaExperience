# 개념 학습 JPG 전환

사용자의 최신 지시로 개념 학습 이미지 산출물은 JPG로 제공한다. gpt-image-prompt의 기본 PNG 권고보다 이 지시를 우선한다. 실제 제작은 image_gen으로 유지하며 raw 생성 PNG는 생성 도구 원본/기존 Git 이력으로 구분하고 학습 화면·전달 자산을 JPG로 변환한다.

1. 새 개념 작업의 PNG363개와 현재 개념 화면의 기존 PNG 참조를 목록화 → 범위·원본 SHA·기존 Git blob을 기록한다. 홈·시나리오 개편으로 확장하지 않는다.
2. 글자 많은 샘플의 quality90/92/95를 실제 비교 → 해상도·글자 판독성을 유지한 quality92를 선택한다. 예시1696009→487760bytes이며 모든 파일 비율을 이 값으로 단정하지 않는다.
3. sips JPEG 인코딩만 수행 → 그림/내용/캔버스를 재구성하지 않고 각 실제 크기·형식·SHA·파일 용량을 확인한다.
4. 화면 registry/HTML과 이미지 metadata/선정 SHA·parity의 자산 참조를 함께 갱신 → 과거 PNG 캡처는 과거 관찰로 보존하며 포맷 전환 후의 새 검수 범위를 별도로 기록한다.
5. PNG 전용 header 검사를 PNG/JPEG 실제 크기 검사로 바꾸고 관련 suite/build/3audit → 모든 자산의 연결과 원문·학습자 코드 보존을 검사한다.
6. 실제 desktop/mobile 대표 화면과 작은 글자/코드/숫자의 JPG 판독성을 확인 → 전수 픽셀 일치·새 학습자 검증으로 확대하지 않는다. 원문과 기존 작업 트리는 보존한다.

공유 원본 PNG가 개념 외 화면에서 사용되면 해당 원본은 유지하고 개념 참조만 JPG로 연결한다. 기존 Git 이력을 재작성하지 않으므로 현재 학습 자산의 크기와 전체 저장소/디스크 사용량은 구분한다. 이후 새 시안도 검수된 JPG만 화면 자산으로 등록한다.
