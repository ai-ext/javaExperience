#상황

"댓글 오타를 고칠 수가 없어서 지우고 다시 쓰는 분이 많아요. 수정할 수 있게 해 주세요. 대신 고친 댓글에는 '수정됨'을 꼭 붙여 주세요. 답글이 달린 뒤에 내용을 바꿔 버리면 대화가 엉뚱해지거든요."

5장에서 댓글을 만들고(5-1) 지웠다(5-3). 이번에는 고치기다. 3-1(글 PATCH)과 비슷하지만 두 가지가 다르다.

  • 누가 고칠 수 있나 — 작성자만. 수정에서는 없거나 볼 수 없으면 404를 먼저 확인하고, 남의 댓글이면 403을 반환한다.
  • "수정됨"을 무엇으로 판단하나 — comment.updated_at은 이미 있지만 5-3의 삭제도 이 값을 바꾼다. 그래서 "수정했다"는 사실만 담는 컬럼을 새로 둔다. 내용이 그대로인 요청은 수정이 아니다.

글의 "수정됨"은 티켓 T-002가 updated_at과 created_at 비교로 다룬다. 댓글은 삭제도 updated_at을 바꾸므로 같은 방법을 쓸 수 없다 — 이 차이가 이 단계의 핵심이다.

#구현 가이드

화면 시나리오의 서버·DB 흐름을 이 단계에서 바뀐 파일에 연결한다. 먼저 만들 것의 계약대로 직접 작성하고, 필요한 역할만 펼쳐 파일 전문과 비교한다.

이 단계의 처리 흐름:

  • 댓글 찾기(지웠으면 404) → 그 글을 볼 수 있나(2-3 규칙, 아니면 404) → 작성자인가(아니면 403) → 내용이 다를 때만 바꾸고 edited_at을 찍는다
  • 변경 감지(더티 체킹) — 내용이 같으면 UPDATE 자체가 나가지 않는다
  • 댓글도 있고 글도 볼 수 있다 → 작성자가 아니다 → 403

package org.example.comment;

import org.example.post.InvalidParametersException;
import tools.jackson.databind.JsonNode;

import java.util.Map;

// 원문 JSON 타입을 보존해 숫자·배열을 문자열로 강제 변환하지 않는다.
// 작성(5-1)의 1~1000자·공백 금지 규칙을 수정에도 적용한다.
public record CommentUpdateRequest(JsonNode content) {
    public String validatedContent() {
        if (content == null || content.isNull() || !content.isTextual()) {
            throw new InvalidParametersException(Map.of("content", "댓글은 문자열이어야 합니다."));
        }
        String value = content.asText();
        if (value.isBlank()) {
            throw new InvalidParametersException(Map.of("content", "댓글을 입력해 주세요."));
        }
        if (value.length() > 1000) {
            throw new InvalidParametersException(Map.of("content", "댓글은 1000자 이하여야 합니다."));
        }
        return value;
    }
}

CommentService.java, CommentRepository.java. 댓글 행을 잠근 뒤 권한·내용을 검사하고 수정한다. 위 서버 처리 순서가 어디에서 검증·조회·상태 변경으로 이어지는지 따라간다. 변경된 메서드: edit. 트랜잭션 경계는 아래 코드의 @Transactional 위치에서 확인한다.

// 12-1 — 작성자만 고친다. 확인 순서: 없거나 지운 댓글·볼 수 없는 글의 댓글 404 → 남의 댓글 403.
    // 내용이 그대로면 아무것도 바꾸지 않는다(edited_at이 안 찍혀 "수정됨"이 붙지 않는다).
    @Transactional
    public Comment edit(Long commentId, AuthenticatedMember loginMember, CommentUpdateRequest request) {
        Comment comment = commentRepository.findByIdForUpdate(commentId)
                .filter(c -> c.getDeletedAt() == null)
                .orElseThrow(CommentNotFoundException::new);
        if (!accessPolicy.canView(loginMember, comment.getPost())) {
            throw new CommentNotFoundException();
        }
        if (!comment.getMember().getId().equals(loginMember.id())) {
            throw new CommentForbiddenException("본인 댓글만 수정할 수 있습니다.");
        }

        comment.edit(request.validatedContent(), LocalDateTime.now());

        // 컨트롤러가 세션 밖에서 DTO를 만든다 — 지연 로딩 연관을 미리 읽어 둔다
        comment.getMember().getNickname();
        comment.getPost().getId();
        if (comment.getParent() != null) {
            comment.getParent().getId();
        }
        return comment;
    }

import jakarta.persistence.Column;
import jakarta.persistence.Entity;

// 댓글 — parent_id가 있으면 답글(1단계까지만)
@Entity
@Table(name = "comment")
public class Comment {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @ManyToOne(fetch = FetchType.LAZY)
    @JoinColumn(name = "post_id", nullable = false)
    private Post post;

    @ManyToOne(fetch = FetchType.LAZY)
    @JoinColumn(name = "member_id", nullable = false)
    private Member member;

    // 자기 참조 — 부모 댓글(답글일 때만). 지연 로딩
    @ManyToOne(fetch = FetchType.LAZY)
    @JoinColumn(name = "parent_id")
    private Comment parent;

    @Column(nullable = false)
    private String content;

    @Column(name = "created_at", nullable = false)
    private LocalDateTime createdAt;

    @Column(name = "updated_at", nullable = false)
    private LocalDateTime updatedAt;

    @Column(name = "deleted_at")
    private LocalDateTime deletedAt;

    // 12-1 — 내용을 실제로 바꾼 마지막 시각. 한 번도 안 고쳤으면 null
    @Column(name = "edited_at")
    private LocalDateTime editedAt;

    protected Comment() {
        // JPA
    }

    public Comment(Post post, Member member, Comment parent, String content, LocalDateTime now) {
        this.post = post;
        this.member = member;
        this.parent = parent;
        this.content = content;
        this.createdAt = now;
        this.updatedAt = now;
    }

    // 내용이 같으면 아무것도 바꾸지 않는다("수정됨"이 붙지 않는다). 바꿨으면 true
    public boolean edit(String newContent, LocalDateTime now) {
        if (this.content.equals(newContent)) {
            return false;
        }
        this.content = newContent;
        this.editedAt = now;
        this.updatedAt = now;
        return true;
    }

    public Long getId() {
        return id;
    }

    public Post getPost() {
        return post;
    }

    public Member getMember() {
        return member;
    }

    public Comment getParent() {
        return parent;
    }

    public String getContent() {
        return content;
    }

    public LocalDateTime getCreatedAt() {
        return createdAt;
    }

    public LocalDateTime getUpdatedAt() {
        return updatedAt;
    }

    public LocalDateTime getDeletedAt() {
        return deletedAt;
    }

    public LocalDateTime getEditedAt() {
        return editedAt;
    }

    public boolean isEdited() {
        return editedAt != null;
    }
}

MyBatis Mapper — 댓글 수정 SQL 대체 구현

정답의 MyBatis 대체 구현 코드 토글에서 CommentEditMapper.java·CommentEditMapper.xml·수정된 CommentService.java 전문을 볼 수 있다. 작성자·글 공개 범위를 먼저 확인하고, Java에서 다른 내용인지 검사하고, SQL은 deleted_at IS NULL인 행만 바꾼다.

    SET content = #{content}, edited_at = #{now}, updated_at = #{now}

Mapper가 행을 바꾼 뒤에는 EntityManager.refresh(comment)로 JPA가 관리하던 댓글을 다시 읽는다. 그래야 같은 트랜잭션의 응답에 새 내용과 editedAt이 들어간다. 값이 같으면 UPDATE하지 않는다. MySQL의 기본 문자열 비교는 대소문자를 무시할 수 있으므로 변경 여부는 행 잠금 뒤 Java String.equals로 판단한다.

@Service

    this.postRepository = postRepository;
    this.memberRepository = memberRepository;

// 댓글 저장과 comment_count 증가를 한 트랜잭션으로 묶는다 — 둘 중 하나만 반영되면 숫자가 틀어진다
@Transactional
public Comment create(Long postId, AuthenticatedMember loginMember, CommentCreateRequest request) {
    Post post = findCommentablePost(postId, loginMember);
    Comment parent = resolveParent(postId, request.parentId());

    Member author = memberRepository.getReferenceById(loginMember.id());
    Comment saved = commentRepository.save(new Comment(post, author, parent, request.content(), LocalDateTime.now()));
    postRepository.incrementCommentCount(postId);
    // 9-4: 글 작성자에게 COMMENT 알림(자기 글에 자기 댓글은 리스너 쪽에서 거른다). 같은 트랜잭션에서 만든다
    eventPublisher.publishEvent(new CommentCreatedEvent(postId, saved.getId(), loginMember.id()));

    // 트랜잭션 안에서 지연 로딩 연관을 미리 읽어 둔다(컨트롤러가 세션 밖에서 DTO를 만든다)
    saved.getMember().getNickname();
    return saved;
}

// 12-1 — 작성자만 고친다. 확인 순서: 없거나 지운 댓글·볼 수 없는 글의 댓글 404 → 남의 댓글 403.
// 내용이 그대로면 아무것도 바꾸지 않는다(edited_at이 안 찍혀 &quot;수정됨&quot;이 붙지 않는다).
@Transactional
public Comment edit(Long commentId, AuthenticatedMember loginMember, CommentUpdateRequest request) {
    Comment comment = commentRepository.findByIdForUpdate(commentId)
            .filter(c -&gt; c.getDeletedAt() == null)
            .orElseThrow(CommentNotFoundException::new);
    if (!accessPolicy.canView(loginMember, comment.getPost())) {
        throw new CommentNotFoundException();
    }
    if (!comment.getMember().getId().equals(loginMember.id())) {
        throw new CommentForbiddenException(&quot;본인 댓글만 수정할 수 있습니다.&quot;);
    }

    comment.edit(request.validatedContent(), LocalDateTime.now());

    // 컨트롤러가 세션 밖에서 DTO를 만든다 — 지연 로딩 연관을 미리 읽어 둔다
    comment.getMember().getNickname();
    comment.getPost().getId();
    if (comment.getParent() != null) {
        comment.getParent().getId();
    }
    return comment;
}

// 작성자만 지운다(soft delete). 없거나 이미 지운 댓글은 404, 남의 댓글은 403.
// comment_count 감소는 같은 트랜잭션에서 원자적으로 한다.
@Transactional
public void delete(Long commentId, AuthenticatedMember loginMember) {
    Comment comment = commentRepository.findById(commentId)
            .filter(c -&gt; c.getDeletedAt() == null)
            .orElseThrow(CommentNotFoundException::new);

    if (!comment.getMember().getId().equals(loginMember.id())) {
        throw new CommentForbiddenException();
    }

    // 앞선 읽기와 별개로 DB에서 deleted_at IS NULL을 다시 검사한다.
    // 동시에 같은 댓글을 지울 때 한 요청만 1행을 변경하고 댓글 수를 내린다.
    if (commentRepository.softDeleteIfLive(commentId, LocalDateTime.now()) != 1) {
        throw new CommentNotFoundException();
    }
    if (postRepository.decrementCommentCount(comment.getPost().getId()) != 1) {
        throw new IllegalStateException(&quot;댓글 수 변경 실패&quot;);
    }
}

// 그 글의 댓글을 작성자와 함께 한 번에 읽어(N+1 없음) 메모리에서 트리로 조립한다.
// 표시 규칙: 지운 최상위는 살아 있는 답글이 있을 때만 &quot;삭제된 댓글입니다&quot; 자리를 남긴다,
// 지운 답글은 뺀다, 보는 사람과 차단 관계인 회원의 댓글은 뺀다(최상위면 답글까지).
@Transactional(readOnly = true)
public List&lt;CommentThreadResponse&gt; list(Long postId, AuthenticatedMember viewer) {
    Post post = postRepository.findById(postId)
            .orElseThrow(PostNotFoundException::new);
    if (!accessPolicy.canView(viewer, post)) {
        throw new PostNotFoundException();
    }

    List&lt;Comment&gt; all = commentRepository.findByPostIdWithMember(postId);
    Long viewerId = viewer == null ? null : viewer.id();
    Set&lt;Long&gt; blockedMemberIds = viewerId == null ? Set.of() : blockPolicy.blockRelatedIds(viewerId);

    Map&lt;Long, List&lt;Comment&gt;&gt; repliesByParent = all.stream()
            .filter(c -&gt; c.getParent() != null)
            .collect(Collectors.groupingBy(c -&gt; c.getParent().getId(), LinkedHashMap::new, Collectors.toList()));

    List&lt;CommentThreadResponse&gt; result = new ArrayList&lt;&gt;();
    for (Comment top : all) {
        if (top.getParent() != null) {
            continue; // 답글은 부모와 함께 처리
        }
        if (blockedMemberIds.contains(top.getMember().getId())) {
            continue; // 차단 — 최상위째 뺀다(답글도 함께)
        }

        // &quot;살아 있는 답글&quot;은 지운 것·차단으로 빠지는 것을 제외하고 센다
        List&lt;Comment&gt; visibleReplies = repliesByParent.getOrDefault(top.getId(), List.of()).stream()
                .filter(r -&gt; r.getDeletedAt() == null)
                .filter(r -&gt; !blockedMemberIds.contains(r.getMember().getId()))
                .toList();

        boolean deleted = top.getDeletedAt() != null;
        if (deleted &amp;&amp; visibleReplies.isEmpty()) {
            continue; // 지웠고 남은 답글도 없으면 자리도 남기지 않는다
        }

        List&lt;CommentReplyResponse&gt; replies = visibleReplies.stream()
                .map(r -&gt; new CommentReplyResponse(r.getId(), toAuthor(r.getMember()), r.getContent(), r.getCreatedAt(),
                        r.isEdited()))
                .toList();

        result.add(new CommentThreadResponse(
                top.getId(),
                deleted ? null : toAuthor(top.getMember()),
                deleted ? &quot;삭제된 댓글입니다&quot; : top.getContent(),
                top.getCreatedAt(),
                !deleted &amp;&amp; top.isEdited(),
                deleted,
                replies
        ));
    }
    return result;
}

private Post findCommentablePost(Long postId, AuthenticatedMember loginMember) {
    Post post = postRepository.findById(postId)
            .orElseThrow(PostNotFoundException::new);
    if (!accessPolicy.canView(loginMember, post) || !PUBLISHED.equals(post.getStatus())) {
        throw new PostNotFoundException();
    }
    return post;
}

// 부모 댓글 검증 — 같은 글의, 최상위, 지워지지 않은 댓글이어야 한다.
// 부모가 없으면 404(CommentNotFoundException), 있는데 규칙에 안 맞으면 400(InvalidParentCommentException).
private Comment resolveParent(Long postId, Long parentId) {
    if (parentId == null) {
        return null;
    }
    Comment parent = commentRepository.findById(parentId)
            .orElseThrow(CommentNotFoundException::new);
    if (!parent.getPost().getId().equals(postId)) {
        throw new InvalidParentCommentException(&quot;다른 글의 댓글에는 답글을 달 수 없습니다.&quot;);
    }
    if (parent.getParent() != null) {
        throw new InvalidParentCommentException(&quot;답글에는 답글을 달 수 없습니다.&quot;);
    }
    if (parent.getDeletedAt() != null) {
        throw new InvalidParentCommentException(&quot;지워진 댓글에는 답글을 달 수 없습니다.&quot;);
    }
    return parent;
}

        if (value.length() > 1000) {

        }
        return value;
    }
}

@Transactional
public Comment edit(Long commentId, AuthenticatedMember loginMember, CommentUpdateRequest request) {
    Comment comment = commentRepository.findByIdForUpdate(commentId)
            .filter(c -&gt; c.getDeletedAt() == null)
            .orElseThrow(CommentNotFoundException::new);
    if (!accessPolicy.canView(loginMember, comment.getPost())) {
        throw new CommentNotFoundException();
    }
    if (!comment.getMember().getId().equals(loginMember.id())) {
        throw new CommentForbiddenException(&quot;본인 댓글만 수정할 수 있습니다.&quot;);
    }

    String content = request.validatedContent();
    if (!comment.getContent().equals(content)) {
        // 같은 트랜잭션에서 UPDATE한 뒤 JPA 관리 엔티티도 다시 읽는다.
        int updated = editMapper.editIfLive(commentId, content, LocalDateTime.now());
        if (updated != 1) throw new CommentNotFoundException();
        entityManager.refresh(comment);
    }

    // 컨트롤러가 세션 밖에서 DTO를 만든다 — 지연 로딩 연관을 미리 읽어 둔다
    comment.getMember().getNickname();
    comment.getPost().getId();
    if (comment.getParent() != null) {
        comment.getParent().getId();
    }
    return comment;
}

@Transactional
public void delete(Long commentId, AuthenticatedMember loginMember) {

            .filter(c -&gt; c.getDeletedAt() == null)
            .orElseThrow(CommentNotFoundException::new);

// 표시 규칙: 지운 최상위는 살아 있는 답글이 있을 때만 &quot;삭제된 댓글입니다&quot; 자리를 남긴다,
// 지운 답글은 뺀다, 보는 사람과 차단 관계인 회원의 댓글은 뺀다(최상위면 답글까지).
@Transactional(readOnly = true)
public List&lt;CommentThreadResponse&gt; list(Long postId, AuthenticatedMember viewer) {
    Post post = postRepository.findById(postId)
            .orElseThrow(PostNotFoundException::new);
    if (!accessPolicy.canView(viewer, post)) {
        throw new PostNotFoundException();
    }

    List&lt;Comment&gt; all = commentRepository.findByPostIdWithMember(postId);
    Long viewerId = viewer == null ? null : viewer.id();
    Set&lt;Long&gt; blockedMemberIds = viewerId == null ? Set.of() : blockPolicy.blockRelatedIds(viewerId);

    Map&lt;Long, List&lt;Comment&gt;&gt; repliesByParent = all.stream()
            .filter(c -&gt; c.getParent() != null)
            .collect(Collectors.groupingBy(c -&gt; c.getParent().getId(), LinkedHashMap::new, Collectors.toList()));

    List&lt;CommentThreadResponse&gt; result = new ArrayList&lt;&gt;();
    for (Comment top : all) {
        if (top.getParent() != null) {
            continue; // 답글은 부모와 함께 처리
        }
        if (blockedMemberIds.contains(top.getMember().getId())) {
            continue; // 차단 — 최상위째 뺀다(답글도 함께)
        }

        // &quot;살아 있는 답글&quot;은 지운 것·차단으로 빠지는 것을 제외하고 센다
        List&lt;Comment&gt; visibleReplies = repliesByParent.getOrDefault(top.getId(), List.of()).stream()
                .filter(r -&gt; r.getDeletedAt() == null)
                .filter(r -&gt; !blockedMemberIds.contains(r.getMember().getId()))
                .toList();

        boolean deleted = top.getDeletedAt() != null;
        if (deleted &amp;&amp; visibleReplies.isEmpty()) {
            continue; // 지웠고 남은 답글도 없으면 자리도 남기지 않는다
        }

        List&lt;CommentReplyResponse&gt; replies = visibleReplies.stream()
                .map(r -&gt; new CommentReplyResponse(r.getId(), toAuthor(r.getMember()), r.getContent(), r.getCreatedAt(),
                        r.isEdited()))
                .toList();

        result.add(new CommentThreadResponse(
                top.getId(),
                deleted ? null : toAuthor(top.getMember()),
                deleted ? &quot;삭제된 댓글입니다&quot; : top.getContent(),
                top.getCreatedAt(),
                !deleted &amp;&amp; top.isEdited(),
                deleted,
                replies
        ));
    }
    return result;
}

// 볼 수 있는 PUBLISHED 글인가 — 아니면 404(4-1 LikeService.findLikeablePost와 같은 규칙)
private Post findCommentablePost(Long postId, AuthenticatedMember loginMember) {
    Post post = postRepository.findById(postId)
            .orElseThrow(PostNotFoundException::new);
    if (!accessPolicy.canView(loginMember, post) || !PUBLISHED.equals(post.getStatus())) {
        throw new PostNotFoundException();
    }
    return post;
}

// 부모 댓글 검증 — 같은 글의, 최상위, 지워지지 않은 댓글이어야 한다.
// 부모가 없으면 404(CommentNotFoundException), 있는데 규칙에 안 맞으면 400(InvalidParentCommentException).
private Comment resolveParent(Long postId, Long parentId) {
    if (parentId == null) {
        return null;
    }
    Comment parent = commentRepository.findById(parentId)
            .orElseThrow(CommentNotFoundException::new);
    if (!parent.getPost().getId().equals(postId)) {
        throw new InvalidParentCommentException(&quot;다른 글의 댓글에는 답글을 달 수 없습니다.&quot;);
    }
    if (parent.getParent() != null) {
        throw new InvalidParentCommentException(&quot;답글에는 답글을 달 수 없습니다.&quot;);
    }
    if (parent.getDeletedAt() != null) {
        throw new InvalidParentCommentException(&quot;지워진 댓글에는 답글을 달 수 없습니다.&quot;);
    }
    return parent;
}

판단 기준
"수정됨"을 updated_at과 created_at 비교가 아니라 edited_at IS NOT NULL로 판단한다. 삭제가 updated_at을 바꾼다는 이유를 말할 수 있다




R2
확인 순서
404(없음·지움·볼 수 없는 글) → 403(남의 것) 순서다. 거꾸로면 볼 수 없는 글의 댓글이 있다는 사실이 403으로 드러난다(3-1과 같은 이유)

바꾸는 곳
JPA에서는 내용 비교·edited_at 기록이 엔티티 edit에 있고, 같은 내용이면 더티 체킹 UPDATE가 없다. MyBatis 대안에서는 행 잠금 뒤 Service가 Java 문자열을 비교하고 Mapper가 edited_at을 기록하며, 같은 내용이면 Mapper를 호출하지 않는다




R4
검증 재사용
작성(5-1)의 @NotBlank·@Size(max = 1000)과 같은 값 규칙을 수정 DTO의 validatedContent()에도 적용한다. 원문 JsonNode로 숫자·배열을 거르므로 문자열 강제 변환을 막는다. 1001자를 그대로 저장하려다 DB 오류(500)가 나는 대신 저장 전에 400으로 막는다




R5
