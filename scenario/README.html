#시나리오 — 게시판 API를 단계별로 키우며 만들기

이 공개 저장소에는 100개 단계의 요구사항과 HTML, 각 단계의 구현 가이드·역할별 전체 코드 접기, JPA/MyBatis 대체 코드, 쿼리 연습 18개가 들어 있다. GitHub 로그인 없이 저장소를 다운로드해 따라갈 수 있다. 정답 코드는 직접 구현해 본 뒤 접기를 열어 비교한다.

#브라우저에서 API 요청 보내기

시나리오 HTML의 직접 확인에는 각 HTTP 요청 버튼이 있다. 페이지 위쪽의 서버 주소 기본값은 http://localhost:8080이다. 서버 주소를 바꿀 수 있고, 경로·본문·일반 헤더도 요청별로 편집할 수 있다. 문서에 공개된 연습용 Authorization 값은 기본 입력값으로 표시되며 편집할 수 있다. 실제 토큰이 필요한 요청은 입력란이 비어 있으므로 직접 입력한다. 입력한 토큰은 저장하지 않는다. 각 요청의 Postman 설정 보기에는 method, 전체 URL, 헤더, raw body, 기대 결과가 있다. 응답 상태·브라우저에서 읽을 수 있는 헤더·본문은 요청 아래에 표시된다.

HTML을 파일로 바로 열면 브라우저 보안 정책 때문에 요청이 안정적으로 동작하지 않을 수 있다. 저장소 루트에서 정적 사이트를 HTTP로 제공한다.

python3 -m http.server 8765 --bind 127.0.0.1

그다음 http://127.0.0.1:8765/scenario/README.html을 연다. Spring Boot 서버의 CORS 설정에서 페이지 출처 http://127.0.0.1:8765와 사용하는 method·headers를 허용해야 한다. JSON, Authorization 또는 사용자 지정 헤더 요청은 브라우저가 먼저 CORS preflight를 보낼 수 있다. SQL, Gradle, 여러 요청의 결과를 다음 요청에 연결하는 확인은 페이지에 별도 수동 지시로 남아 있다.

#진행 방법

  1. 레포 루트에서 docker compose up -d로 DB를 띄우고 IntelliJ에서 Main을 실행한다(README의 실행).
  2. 목차에서 장·단계를 골라 화면 시나리오 → 요청·응답 계약 → 구현 가이드 순서로 읽는다. 화면 시나리오의 각 흐름을 펼치면 사용자 행동, HTTP, 서버, DB, 응답이 차례대로 보인다.
  3. 직접 구현하고 직접 확인의 요청 버튼으로 HTTP 동작을 확인한다. SQL·테스트 등 수동 확인은 해당 단계 지시를 따른다. 막힐 때만 역할별 전체 코드 접기와 필요한 지식 문서를 연다.
  4. 결과 테스트 프롬프트를 Codex 또는 Claude Code에 붙여 넣어 해당 단계의 계약을 검토한다. GitHub 로그인은 필요하지 않다.
  5. 단계별로 커밋하고 이전·다음 링크로 진행한다. 본편은 9-5 다음에 11-1로 이어지며, 10장은 별도 명세서 프로젝트다.

단계가 진행되며 같은 API의 응답 계약이 확장된다. 이전 단계의 채점이 나중에 실패할 수 있다. community, practice, project는 서로 다른 DB이므로 DB를 바꾼 뒤에는 이전 글 ID를 그대로 사용할 수 없다.

  • 작업 브랜치 — 각자 새 브랜치를 만들어 구현한다. 공개 저장소를 읽거나 다운로드할 때는 계정이 필요하지 않다. 원격에 push하거나 PR을 보낼 때는 GitHub 계정과 권한이 필요하다.
  • DB 초기화 — docker compose down -v && docker compose up -d는 로컬 실습 데이터를 모두 지운다. 필요한 데이터를 먼저 보관한다.

#쿼리 설계 18개 연습

기존 게시판 기능으로 만든 데이터를 같은 ID로 계속 조회하고 검색한다. L12: 파생 쿼리·MyBatis 8개 → L13: @Query·동적 SQL 6개 → L14: QueryDSL 4개 순서다. 각 Q 시나리오에 Controller·Service·DTO·Repository·Mapper 코드 접기가 있다. 이 연습용 완성 프로젝트는 python3 tools/materialize-query-practice.py --output /tmp/query-practice로 별도 폴더에 복원할 수 있다.
