#2-1. 단건 조회와 404

#상황

글을 쓸 수는 있는데 읽을 수가 없다. 프론트가 글 상세 화면을 만든다.

"글 id로 상세를 가져오고 싶어요. 조회수도 하나 올려 주세요. 없는 글이면 404로 주시고요."

조회는 로그인하지 않아도 된다. 1-6에서 만든 토큰 확인이 모든 /api/**에 걸려 있다면 GET은 토큰 없이도 지나가게 바꿔야 한다.

#화면 시나리오

#만들 것

항목 내용
메서드·경로 GET /api/posts/{id}
인증 필요 없음(토큰 없이 200)

조회수 호출할 때마다 post.view_count를 1 올린다. 응답의 viewCount는 올린 뒤의 값
없는 글 404, application/problem+json(1-5의 에러 형식)

이 단계에서는 임시저장·삭제·공개 범위를 따지지 않는다(2-3에서 한다). 채점도 공개 글(2번)과 없는 글로만 한다.

findById(id)는 id가 같은 행을 찾을 뿐 deleted_at이나 운영자 숨김을 자동으로 걸러 주지 않는다. 여기서는 가장 작은 단건 조회를 만들고, 2-3에서 삭제·숨김·공개 범위에 맞게 조회 경로를 확장한다.

#구현 가이드

화면 시나리오의 서버·DB 흐름을 이 단계에서 바뀐 파일에 연결한다. 먼저 만들 것의 계약대로 직접 작성하고, 필요한 역할만 펼쳐 파일 전문과 비교한다.

이 단계의 처리 흐름:

  • PostQueryService(@Transactional): 글을 찾고, 조회수를 1 올리고, 트랜잭션 안에서 작성자·태그를 DTO로 옮긴다
  • 글이 없다 → 1-5의 전역 에러 처리(@RestControllerAdvice)가 404 ProblemDetail로
Controller — HTTP 연결

PostController.java. 매핑과 메서드의 입력·응답을 위 만들 것의 HTTP 계약과 대조한다. 이번 단계 매핑: @GetMapping("/{id}").

DTO — 요청·응답 필드

PostDetailResponse.java. 필드 이름·타입·검증·응답 형태를 위 만들 것과 대조한다.

Service — 처리 순서

PostQueryService.java. 위 서버 처리 순서가 어디에서 검증·조회·상태 변경으로 이어지는지 따라간다. 트랜잭션 경계는 아래 코드의 @Transactional 위치에서 확인한다.

Entity — 테이블·상태

Post.java. 실제 테이블의 컬럼·외래키와 엔티티 매핑을 대조한다. 변경된 메서드: increaseViewCount.

예외 처리 — 실패 응답

ApiExceptionHandler.java, PostNotFoundException.java. 예외가 어떤 HTTP 상태와 오류 본문으로 바뀌는지 실패 계약과 대조한다. 변경된 메서드: handlePostNotFound.

MyBatis — 상세 SELECT와 조회수 UPDATE

아래 MyBatis 대체 구현 코드의 7개 파일을 이 단계 전체 소스에 적용한다. PostReadMapper.findDetail은 post·board·member를 JOIN해 상세 응답에 필요한 열을 PostDetailRow로 읽는다. 결과가 없으면 기존 PostNotFoundException으로 404를 돌린다. 태그는 post_tag·tag JOIN으로 읽어 PostDetailResponse에 넣는다. #{id}는 요청 ID를 바인딩하므로 SQL 문자열에 직접 이어 붙이지 않는다.

PostQueryService.getDetail의 @Transactional 안에서 UPDATE post SET view_count = view_count + 1 WHERE id = #{id}를 실행하고, 응답 viewCount는 조회 직전 값에 1을 더한다. JPA의 변경 감지와 달리 MyBatis는 UPDATE를 명시적으로 쓴다. G1·G2를 두 번 실행해 응답과 DB의 조회수가 각각 1씩 증가하는지 D1/D2로 확인한다. 이 단계에는 아직 2-3의 공개·차단 조건을 추가하지 않는다.

import org.springframework.web.bind.MethodArgumentNotValidException;
import org.springframework.web.bind.annotation.ExceptionHandler;
import org.springframework.web.bind.annotation.RestControllerAdvice;


import java.net.URI;
import java.util.List;
import java.util.Map;


// 모든 컨트롤러의 에러 응답을 한 곳에서 RFC 9457 Problem Details로 만든다.
// 컨트롤러마다 try-catch를 두지 않는다.
@RestControllerAdvice
public class ApiExceptionHandler {


@ExceptionHandler(MethodArgumentNotValidException.class)
public ProblemDetail handleValidation(MethodArgumentNotValidException ex, HttpServletRequest request) {
    ProblemDetail problem = ProblemDetail.forStatusAndDetail(HttpStatus.BAD_REQUEST, &quot;입력값이 올바르지 않습니다.&quot;);
    problem.setInstance(URI.create(request.getRequestURI()));
    List&lt;Map&lt;String, String&gt;&gt; errors = ex.getBindingResult().getFieldErrors().stream()
            .map(fieldError -&gt; Map.of(
                    &quot;field&quot;, fieldError.getField(),
                    &quot;message&quot;, fieldError.getDefaultMessage() == null ? &quot;&quot; : fieldError.getDefaultMessage()
            ))
            .toList();
    problem.setProperty(&quot;errors&quot;, errors);
    return problem;
}

@ExceptionHandler(HttpMessageNotReadableException.class)
public ProblemDetail handleUnreadable(HttpServletRequest request) {
    ProblemDetail problem = ProblemDetail.forStatusAndDetail(HttpStatus.BAD_REQUEST, &quot;요청 본문을 읽을 수 없습니다.&quot;);
    problem.setInstance(URI.create(request.getRequestURI()));
    return problem;
}

@ExceptionHandler(BoardNotFoundException.class)
public ProblemDetail handleBoardNotFound(BoardNotFoundException ex, HttpServletRequest request) {
    ProblemDetail problem = ProblemDetail.forStatusAndDetail(HttpStatus.NOT_FOUND, ex.getMessage());
    problem.setInstance(URI.create(request.getRequestURI()));
    return problem;
}

@ExceptionHandler(PostNotFoundException.class)
public ProblemDetail handlePostNotFound(PostNotFoundException ex, HttpServletRequest request) {
    ProblemDetail problem = ProblemDetail.forStatusAndDetail(HttpStatus.NOT_FOUND, ex.getMessage());
    problem.setInstance(URI.create(request.getRequestURI()));
    return problem;
}

@ExceptionHandler(BoardWriteForbiddenException.class)
public ProblemDetail handleBoardWriteForbidden(BoardWriteForbiddenException ex, HttpServletRequest request) {
    ProblemDetail problem = ProblemDetail.forStatusAndDetail(HttpStatus.FORBIDDEN, ex.getMessage());
    problem.setInstance(URI.create(request.getRequestURI()));
    return problem;
}

// 누구인지 모름 — WWW-Authenticate 헤더를 함께 내려준다
@ExceptionHandler(AuthenticationRequiredException.class)
public ResponseEntity&lt;ProblemDetail&gt; handleAuthenticationRequired(AuthenticationRequiredException ex,
                                                                   HttpServletRequest request) {
    ProblemDetail problem = ProblemDetail.forStatusAndDetail(HttpStatus.UNAUTHORIZED, ex.getMessage());
    problem.setInstance(URI.create(request.getRequestURI()));
    return ResponseEntity.status(HttpStatus.UNAUTHORIZED)
            .header(HttpHeaders.WWW_AUTHENTICATE, &quot;Bearer&quot;)
            .body(problem);
}

// 누구인지는 알지만(토큰은 유효) 회원 상태 때문에 안 됨
@ExceptionHandler(MemberNotActiveException.class)
public ProblemDetail handleMemberNotActive(MemberNotActiveException ex, HttpServletRequest request) {
    ProblemDetail problem = ProblemDetail.forStatusAndDetail(HttpStatus.FORBIDDEN, ex.getMessage());
    problem.setInstance(URI.create(request.getRequestURI()));
    return problem;
}


}

package org.example.post;


import jakarta.validation.Valid;
import org.example.auth.AuthenticatedMember;
import org.example.auth.LoginMember;
import org.example.tag.Tag;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.PathVariable;
import org.springframework.web.bind.annotation.RequestParam;
import org.springframework.web.bind.annotation.RequestBody;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RestController;


import java.net.URI;
import java.util.List;


@RestController
@RequestMapping("/api/posts")
public class PostController {


private static final Logger log = LoggerFactory.getLogger(PostController.class);

private final PostService postService;
private final PostQueryService postQueryService;

public PostController(PostService postService, PostQueryService postQueryService) {
    this.postService = postService;
    this.postQueryService = postQueryService;
}

@GetMapping(&quot;/{id}&quot;)
public PostDetailResponse getOne(@PathVariable Long id) {
    return postQueryService.getDetail(id);
}

@PostMapping
public ResponseEntity&lt;PostResponse&gt; create(@LoginMember AuthenticatedMember loginMember,
                                            @Valid @RequestBody PostCreateRequest request) {
    log.info(&quot;게시글 작성 요청 제목: {}&quot;, request.title());

    Post post = postService.create(loginMember.id(), request);
    PostResponse response = toResponse(post);

    return ResponseEntity.created(URI.create(&quot;/api/posts/&quot; + post.getId())).body(response);
}

@PostMapping(&quot;/{sourceId}/copies&quot;)
public ResponseEntity&lt;PostResponse&gt; copy(@PathVariable Long sourceId,
                                         @RequestParam(defaultValue = &quot;false&quot;) boolean copyTags,
                                         @LoginMember AuthenticatedMember loginMember,
                                         @Valid @RequestBody CopyPostRequest request) {
    Post post = postService.copy(sourceId, loginMember.id(), copyTags, request);
    return ResponseEntity.created(URI.create(&quot;/api/posts/&quot; + post.getId()))
            .body(toResponse(post));
}

private PostResponse toResponse(Post post) {
    List&lt;String&gt; tagNames = post.getTags().stream().map(Tag::getName).toList();
    AuthorResponse author = new AuthorResponse(post.getAuthor().getId(), post.getAuthor().getNickname());
    return new PostResponse(
            post.getId(),
            post.getBoard().getSlug(),
            post.getTitle(),
            post.getContent(),
            tagNames,
            post.getVisibility(),
            author,
            post.getCreatedAt()
    );
}


}

DTO — src/main/java/org/example/post/PostQueryService.java
package org.example.post;


import org.example.tag.Tag;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;


// 글 조회 전용 서비스 — 1-3/1-4의 PostService(쓰기)와 책임을 나눈다
@Service
public class PostQueryService {


private final PostRepository postRepository;

public PostQueryService(PostRepository postRepository) {
    this.postRepository = postRepository;
}

@Transactional
public PostDetailResponse getDetail(Long id) {
    Post post = postRepository.findById(id)
            .orElseThrow(PostNotFoundException::new);

    post.increaseViewCount();
    return toDetailResponse(post);
}

private PostDetailResponse toDetailResponse(Post post) {
    // 트랜잭션 안에서 지연 로딩 연관을 읽어 DTO로 옮긴다(open-in-view: false)
    return new PostDetailResponse(
            post.getId(),
            post.getBoard().getSlug(),
            post.getTitle(),
            post.getContent(),
            post.getTags().stream().map(Tag::getName).toList(),
            post.getVisibility(),
            new AuthorResponse(post.getAuthor().getId(), post.getAuthor().getNickname()),
            post.getViewCount(),
            post.getLikeCount(),
            post.getCommentCount(),
            post.getCreatedAt()
    );
}


}

DTO — src/main/java/org/example/post/PostQueryService.java
package org.example.post;


import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;
import java.util.List;


// 글 상세 조회와 조회수 증가를 같은 트랜잭션에서 실행한다.
@Service
public class PostQueryService {
    private final PostReadMapper mapper;


public PostQueryService(PostReadMapper mapper) {
    this.mapper = mapper;
}

@Transactional
public PostDetailResponse getDetail(Long id) {
    PostDetailRow row = mapper.findDetail(id);
    if (row == null) throw new PostNotFoundException();
    mapper.increaseViewCount(id);
    List&lt;String&gt; tags = mapper.findTagsByPostIds(List.of(id)).stream()
            .map(PostTagRow::name).toList();
    return new PostDetailResponse(row.id, row.boardSlug, row.title, row.content,
            tags, row.visibility, new AuthorResponse(row.authorId, row.authorNickname),
            row.viewCount + 1, row.likeCount, row.commentCount, row.createdAt);
}


}

MyBatis / Mapper — src/main/java/org/example/post/PostReadMapper.java
package org.example.post;


import java.util.List;
import org.apache.ibatis.annotations.Mapper;
import org.apache.ibatis.annotations.Param;


@Mapper
public interface PostReadMapper {
    PostDetailRow findDetail(@Param("id") Long id);
    int increaseViewCount(@Param("id") Long id);
    List<PostTagRow> findTagsByPostIds(@Param("postIds") List<Long> postIds);
}

MyBatis / XML — src/main/resources/mapper/PostReadMapper.xml
<?xml version="1.0" encoding="UTF-8" ?>
<!DOCTYPE mapper PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN" "https://mybatis.org/dtd/mybatis-3-mapper.dtd">
<mapper namespace="org.example.post.PostReadMapper">
    <select id="findDetail" resultType="org.example.post.PostDetailRow">
        SELECT p.id, b.slug AS board_slug, p.title, p.content, p.visibility,
               m.id AS author_id, m.nickname AS author_nickname,
               p.view_count, p.like_count, p.comment_count, p.created_at
        FROM post p JOIN board b ON b.id = p.board_id
                    JOIN member m ON m.id = p.author_id
        WHERE p.id = #{id}
    </select>
    <update id="increaseViewCount">
        UPDATE post SET view_count = view_count + 1 WHERE id = #{id}
    </update>
    <select id="findTagsByPostIds" resultType="org.example.post.PostTagRow">
        SELECT pt.post_id AS postId, t.name FROM post_tag pt
        JOIN tag t ON t.id = pt.tag_id
        WHERE pt.post_id IN
        <foreach collection="postIds" item="id" open="(" separator="," close=")">#{id}</foreach>
        ORDER BY t.name
    </select>
</mapper>

#힌트 (막힐 때만)



힌트 1 — GET만 토큰 없이 통과시키기


인터셉터라면 request.getMethod()가 GET이고 헤더가 없을 때는 그냥 통과시킨다(헤더가 있으면 2-3에서 확인한다). 경로 패턴을 나눠 등록하는 방법도 있다.






힌트 2 — LazyInitializationException


서비스 메서드(@Transactional) 안에서 post.getAuthor().getNickname(), post.getTags()를 읽어 DTO를 만들어 반환한다. 컨트롤러에서 엔티티의 연관 필드를 건드리면 트랜잭션이 끝난 뒤라 실패한다.
