Controller — HTTP 연결

CommentController.java. 매핑과 메서드의 입력·응답을 위 만들 것의 HTTP 계약과 대조한다. 이번 단계 매핑: @GetMapping("/api/posts/{postId}/comments"), @DeleteMapping("/api/comments/{id}"). 변경된 메서드: list, delete.

@GetMapping("/api/posts/{postId}/comments")
public List<CommentThreadResponse> list(@PathVariable Long postId,
        @LoginMember AuthenticatedMember viewer) {
    return commentService.list(postId, viewer);
}

@DeleteMapping("/api/comments/{id}")
@ResponseStatus(HttpStatus.NO_CONTENT)
public void delete(@PathVariable Long id, @LoginMember AuthenticatedMember member) {
    commentService.delete(id, member);
}

목록에서 viewer는 비로그인일 때 null이다. 삭제는 로그인과 작성자 확인이 필요하며 성공 본문 없이 204를 보낸다. 아래 전체 구현 코드 접기에 Controller 전문이 있다.

DTO — 요청·응답 필드

CommentReplyResponse.java, CommentThreadResponse.java. 필드 이름·타입·검증·응답 형태를 위 만들 것과 대조한다.

public record CommentThreadResponse(Long id, AuthorResponse author, String content,
        LocalDateTime createdAt, boolean deleted, List<CommentReplyResponse> replies) {}

답글 DTO에는 id, author, content, createdAt만 있다. 삭제·차단된 답글은 DTO로 만들지 않는다. 삭제된 최상위 댓글만 author=null, 자리표시자 content, deleted=true로 만든다.

Service — 처리 순서

CommentService.java, PostAccessPolicy.java, BlockPolicy.java. 위 서버 처리 순서가 어디에서 검증·조회·상태 변경으로 이어지는지 따라간다. 변경된 메서드: delete, list. 트랜잭션 경계는 아래 코드의 @Transactional 위치에서 확인한다.

@Transactional(readOnly = true)
public List<CommentThreadResponse> list(Long postId, AuthenticatedMember viewer) {
    Post post = postRepository.findById(postId).orElseThrow(PostNotFoundException::new);
    if (!accessPolicy.canView(viewer, post)) throw new PostNotFoundException();
    List<Comment> all = commentRepository.findByPostIdWithMember(postId);
    Long viewerId = viewer == null ? null : viewer.id();
    Set<Long> blocked = viewerId == null ? Set.of() : blockPolicy.blockRelatedIds(viewerId);
    // 답글을 parent ID별로 묶고, 최상위마다 삭제·차단 규칙을 적용해 DTO를 만든다.
}

위 코드는 흐름 발췌다. 실제 전문은 Map<Long, List<Comment>>에 답글을 묶고, 지운 최상위에 보이는 답글이 없을 때만 최상위를 뺀다. 차단 상대 ID는 한 번에 읽으므로 댓글 수에 따라 차단 조회가 늘지 않는다. delete는 서비스에서 작성자를 확인한 뒤 조건부 soft delete의 영향 행이 1일 때만 댓글 수를 감소시킨다. 숫자 변경도 1행이어야 하며, 아니면 같은 트랜잭션을 롤백한다.

JPA / Repository — DB 조건

CommentRepository.java, PostRepository.java. 쿼리·파생 메서드의 조건을 화면 시나리오의 DB 단계 및 직접 확인 SQL과 대조한다. 직접 작성한 JPQL·SQL과 아래 파일의 @Query를 비교한다.

@Query("SELECT c FROM Comment c JOIN FETCH c.member " +
       "WHERE c.post.id = :postId ORDER BY c.createdAt ASC, c.id ASC")
List<Comment> findByPostIdWithMember(@Param("postId") Long postId);

@Modifying
@Query("UPDATE Comment c SET c.deletedAt = :now, c.updatedAt = :now " +
       "WHERE c.id = :id AND c.deletedAt IS NULL")
int softDeleteIfLive(@Param("id") Long id, @Param("now") LocalDateTime now);

@Modifying
@Query("UPDATE Post p SET p.commentCount = p.commentCount - 1 " +
       "WHERE p.id = :id AND p.commentCount > 0")
int decrementCommentCount(@Param("id") Long id);

댓글·작성자를 한 번에 읽고, 차단 상대 ID도 MemberBlockRepository.findBlockRelatedIds 한 번으로 조회한다. 트리 조립 중 댓글마다 DB를 조회하지 않는다. 숫자 감소는 DB의 조건부 UPDATE로 실행한다.

Entity — 테이블·상태

Comment.java. 선행 단계의 deleted_at 매핑을 확인한다. 이번 단계는 조건부 UPDATE로 삭제하므로 엔티티 변경 메서드를 추가하지 않는다.

@Column(name = "deleted_at")
private LocalDateTime deletedAt;

행을 지우지 않아 기존 답글의 parent_id가 유지된다. deleted_at이 채워진 최상위의 표시 여부는 목록 Service가 결정한다. 같은 댓글에 동시 DELETE가 와도 WHERE deleted_at IS NULL을 통과한 한 요청만 댓글 수를 내린다.

    public CommentController(CommentService commentService) {
        this.commentService = commentService;

    @ResponseStatus(HttpStatus.NO_CONTENT)
    public void delete(@PathVariable Long id, @LoginMember AuthenticatedMember loginMember) {

package org.example.comment;

import org.example.auth.AuthenticatedMember;
import org.example.member.Member;
import org.example.member.MemberRepository;
import org.example.post.Post;
import org.example.post.PostAccessPolicy;
import org.example.post.PostNotFoundException;
import org.example.post.AuthorResponse;
import org.example.post.PostRepository;
import org.example.social.BlockPolicy;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

import java.time.LocalDateTime;
import java.util.ArrayList;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;
import java.util.Set;
import java.util.stream.Collectors;

@Service
public class CommentService {

    private static final String PUBLISHED = "PUBLISHED";

    private final CommentRepository commentRepository;
    private final PostRepository postRepository;
    private final MemberRepository memberRepository;
    private final PostAccessPolicy accessPolicy;
    private final BlockPolicy blockPolicy;

    public CommentService(CommentRepository commentRepository, PostRepository postRepository,
                           MemberRepository memberRepository, PostAccessPolicy accessPolicy,
                           BlockPolicy blockPolicy) {
        this.commentRepository = commentRepository;
        this.postRepository = postRepository;
        this.memberRepository = memberRepository;
        this.accessPolicy = accessPolicy;
        this.blockPolicy = blockPolicy;
    }

    // 댓글 저장과 comment_count 증가를 한 트랜잭션으로 묶는다 — 둘 중 하나만 반영되면 숫자가 틀어진다
    @Transactional
    public Comment create(Long postId, AuthenticatedMember loginMember, CommentCreateRequest request) {
        Post post = findCommentablePost(postId, loginMember);
        Comment parent = resolveParent(postId, request.parentId());

        Member author = memberRepository.getReferenceById(loginMember.id());
        Comment saved = commentRepository.save(new Comment(post, author, parent, request.content(), LocalDateTime.now()));
        postRepository.incrementCommentCount(postId);

        // 트랜잭션 안에서 지연 로딩 연관을 미리 읽어 둔다(컨트롤러가 세션 밖에서 DTO를 만든다)
        saved.getMember().getNickname();
        return saved;
    }

    // 작성자만 지운다(soft delete). 없거나 이미 지운 댓글은 404, 남의 댓글은 403.
    // comment_count 감소는 같은 트랜잭션에서 원자적으로 한다.
    @Transactional
    public void delete(Long commentId, AuthenticatedMember loginMember) {
        Comment comment = commentRepository.findById(commentId)
                .filter(c -> c.getDeletedAt() == null)
                .orElseThrow(CommentNotFoundException::new);

        if (!comment.getMember().getId().equals(loginMember.id())) {
            throw new CommentForbiddenException();
        }

        // 앞선 읽기와 별개로 DB에서 deleted_at IS NULL을 다시 검사한다.
        // 동시에 같은 댓글을 지울 때 한 요청만 1행을 변경하고 댓글 수를 내린다.
        if (commentRepository.softDeleteIfLive(commentId, LocalDateTime.now()) != 1) {
            throw new CommentNotFoundException();
        }
        if (postRepository.decrementCommentCount(comment.getPost().getId()) != 1) {
            throw new IllegalStateException("댓글 수 변경 실패");
        }
    }

    // 그 글의 댓글을 작성자와 함께 한 번에 읽어(N+1 없음) 메모리에서 트리로 조립한다.
    // 표시 규칙: 지운 최상위는 살아 있는 답글이 있을 때만 "삭제된 댓글입니다" 자리를 남긴다,
    // 지운 답글은 뺀다, 보는 사람과 차단 관계인 회원의 댓글은 뺀다(최상위면 답글까지).
    @Transactional(readOnly = true)
    public List<CommentThreadResponse> list(Long postId, AuthenticatedMember viewer) {
        Post post = postRepository.findById(postId)
                .orElseThrow(PostNotFoundException::new);
        if (!accessPolicy.canView(viewer, post)) {
            throw new PostNotFoundException();
        }

        List<Comment> all = commentRepository.findByPostIdWithMember(postId);
        Long viewerId = viewer == null ? null : viewer.id();
        Set<Long> blockedMemberIds = viewerId == null ? Set.of() : blockPolicy.blockRelatedIds(viewerId);

        Map<Long, List<Comment>> repliesByParent = all.stream()
                .filter(c -> c.getParent() != null)
                .collect(Collectors.groupingBy(c -> c.getParent().getId(), LinkedHashMap::new, Collectors.toList()));

        List<CommentThreadResponse> result = new ArrayList<>();
        for (Comment top : all) {
            if (top.getParent() != null) {
                continue; // 답글은 부모와 함께 처리
            }
            if (blockedMemberIds.contains(top.getMember().getId())) {
                continue; // 차단 — 최상위째 뺀다(답글도 함께)
            }

            // "살아 있는 답글"은 지운 것·차단으로 빠지는 것을 제외하고 센다
            List<Comment> visibleReplies = repliesByParent.getOrDefault(top.getId(), List.of()).stream()
                    .filter(r -> r.getDeletedAt() == null)
                    .filter(r -> !blockedMemberIds.contains(r.getMember().getId()))
                    .toList();

            boolean deleted = top.getDeletedAt() != null;
            if (deleted && visibleReplies.isEmpty()) {
                continue; // 지웠고 남은 답글도 없으면 자리도 남기지 않는다
            }

            List<CommentReplyResponse> replies = visibleReplies.stream()
                    .map(r -> new CommentReplyResponse(r.getId(), toAuthor(r.getMember()), r.getContent(), r.getCreatedAt()))
                    .toList();

            result.add(new CommentThreadResponse(
                    top.getId(),
                    deleted ? null : toAuthor(top.getMember()),
                    deleted ? "삭제된 댓글입니다" : top.getContent(),
                    top.getCreatedAt(),
                    deleted,
                    replies
            ));
        }
        return result;
    }

    // 볼 수 있는 PUBLISHED 글인가 — 아니면 404(4-1 LikeService.findLikeablePost와 같은 규칙)
    private Post findCommentablePost(Long postId, AuthenticatedMember loginMember) {
        Post post = postRepository.findById(postId)
                .orElseThrow(PostNotFoundException::new);
        if (!accessPolicy.canView(loginMember, post) || !PUBLISHED.equals(post.getStatus())) {
            throw new PostNotFoundException();
        }
        return post;
    }

    // 부모 댓글 검증 — 같은 글의, 최상위, 지워지지 않은 댓글이어야 한다.
    // 부모가 없으면 404(CommentNotFoundException), 있는데 규칙에 안 맞으면 400(InvalidParentCommentException).
    private Comment resolveParent(Long postId, Long parentId) {
        if (parentId == null) {
            return null;
        }
        Comment parent = commentRepository.findById(parentId)
                .orElseThrow(CommentNotFoundException::new);
        if (!parent.getPost().getId().equals(postId)) {
            throw new InvalidParentCommentException("다른 글의 댓글에는 답글을 달 수 없습니다.");
        }
        if (parent.getParent() != null) {
            throw new InvalidParentCommentException("답글에는 답글을 달 수 없습니다.");
        }
        if (parent.getDeletedAt() != null) {
            throw new InvalidParentCommentException("지워진 댓글에는 답글을 달 수 없습니다.");
        }
        return parent;
    }

    private AuthorResponse toAuthor(Member member) {
        return new AuthorResponse(member.getId(), member.getNickname());
    }
}

package org.example.post;

import org.example.auth.AuthenticatedMember;
import org.example.social.BlockPolicy;
import org.example.social.FollowRepository;
import org.springframework.stereotype.Component;

// "이 사람이 이 글을 볼 수 있나" 규칙을 한 곳에 모은다.
// 상세(GET /api/posts/{id})는 이 자바 코드로 판정하고, 목록(게시판 목록)은
// 같은 다섯 조건을 PostRepository의 JPQL(findViewableByBoard)로 옮겨 건다.
// 규칙을 바꿀 때는 두 곳을 같이 고쳐야 한다.
@Component
public class PostAccessPolicy {

    private static final String PUBLISHED = "PUBLISHED";
    private static final String DRAFT = "DRAFT";
    private static final String HIDDEN = "HIDDEN";
    private static final String PUBLIC = "PUBLIC";
    private static final String FOLLOWERS = "FOLLOWERS";
    private static final String ADMIN_ROLE = "ADMIN";

    private final FollowRepository followRepository;
    private final BlockPolicy blockPolicy;

    public PostAccessPolicy(FollowRepository followRepository, BlockPolicy blockPolicy) {
        this.followRepository = followRepository;
        this.blockPolicy = blockPolicy;
    }

    public boolean canView(AuthenticatedMember viewer, Post post) {
        // 1. 삭제된 글은 작성자 본인도 못 본다
        if (post.getDeletedAt() != null) {
            return false;
        }

        Long viewerId = viewer == null ? null : viewer.id();
        Long authorId = post.getAuthor().getId();
        boolean isAuthor = viewerId != null && viewerId.equals(authorId);
        boolean isAdmin = viewer != null && ADMIN_ROLE.equals(viewer.role());

        // 2. 상태별 허용 — DRAFT는 작성자만, HIDDEN은 운영자만
        boolean statusOk = switch (post.getStatus()) {
            case PUBLISHED -> true;
            case DRAFT -> isAuthor;
            case HIDDEN -> isAdmin;
            default -> false;
        };
        if (!statusOk) {
            return false;
        }

        // 3. PUBLISHED + FOLLOWERS 공개는 작성자 본인이거나 팔로워만
        if (PUBLISHED.equals(post.getStatus()) && FOLLOWERS.equals(post.getVisibility()) && !isAuthor) {
            boolean follows = viewerId != null
                    && followRepository.existsByFollower_IdAndFollowee_Id(viewerId, authorId);
            if (!follows) {
                return false;
            }
        }

        // 4. 둘 사이에 차단이 있으면(어느 쪽이 차단했든) 못 본다
        if (viewerId != null && !isAuthor && blockPolicy.isBlockedEitherWay(viewerId, authorId)) {
            return false;
        }

        // 5. 발행 글의 공개 범위가 알려진 값인지 검사한다.
        // 비로그인과 일반 열람자는 PUBLIC 또는 위에서 확인한 FOLLOWERS만 볼 수 있다.
        // DB에 PRIVATE/알 수 없는 값이 들어와도 공개로 취급하지 않는다.
        if (PUBLISHED.equals(post.getStatus()) && !isAuthor
                && !PUBLIC.equals(post.getVisibility())
                && !FOLLOWERS.equals(post.getVisibility())) {
            return false;
        }
        return true;
    }
}

public interface PostRepository extends JpaRepository<Post, Long> {

class CommentConcurrentDeleteTest {
    @Autowired CommentService comments;
    @Autowired JdbcTemplate jdbc;

    @Test
    void duplicateDeletesOnlyDecreaseCountOnce() throws InterruptedException {
        AuthenticatedMember author = new AuthenticatedMember(2L, "김자바", "USER");
        Long id = comments.create(3L, author, new CommentCreateRequest("동시 삭제 검증", null)).getId();
        int before = jdbc.queryForObject("SELECT comment_count FROM post WHERE id = 3", Integer.class);
        int parallel = 8;
        ExecutorService pool = Executors.newFixedThreadPool(parallel);
        CountDownLatch ready = new CountDownLatch(parallel);
        CountDownLatch start = new CountDownLatch(1);
        CountDownLatch done = new CountDownLatch(parallel);
        List<String> results = new CopyOnWriteArrayList<>();
        for (int i = 0; i < parallel; i++) {
            pool.submit(() -> {
                try {
                    ready.countDown();
                    start.await();
                    comments.delete(id, author);
                    results.add("deleted");
                } catch (CommentNotFoundException e) {
                    results.add("not_found");
                } catch (Exception e) {
                    results.add(e.getClass().getSimpleName());
                } finally {
                    done.countDown();
                }
            });
        }
        boolean allReady = ready.await(10, TimeUnit.SECONDS);
        start.countDown();
        assertTrue(allReady, "모든 삭제 요청이 출발 전에 준비돼야 한다");
        assertTrue(done.await(30, TimeUnit.SECONDS), "모든 삭제 요청이 끝나야 한다");
        pool.shutdown();

        assertEquals(1, results.stream().filter("deleted"::equals).count(), results.toString());
        assertEquals(parallel - 1, results.stream().filter("not_found"::equals).count(), results.toString());
        int after = jdbc.queryForObject("SELECT comment_count FROM post WHERE id = 3", Integer.class);
        int live = jdbc.queryForObject("SELECT COUNT(*) FROM comment WHERE post_id = 3 AND deleted_at IS NULL", Integer.class);
        assertEquals(before - 1, after);
        assertEquals(live, after, "댓글 수와 실제 미삭제 행 수가 같아야 한다");
        assertEquals(1, jdbc.queryForObject("SELECT deleted_at IS NOT NULL FROM comment WHERE id = ?", Integer.class, id));
    }

import java.util.ArrayList;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;
import java.util.Set;
import java.util.stream.Collectors;

@Service
public class MyBatisCommentQueryService {
    private final PostVisibilityMapper posts;
    private final MyBatisCommentMapper comments;

    public MyBatisCommentQueryService(PostVisibilityMapper posts, MyBatisCommentMapper comments) {
        this.posts = posts;
        this.comments = comments;
    }

    @Transactional(readOnly = true)
    public List<CommentThreadResponse> list(Long postId, AuthenticatedMember viewer) {
        Long viewerId = viewer == null ? null : viewer.id();
        String role = viewer == null ? null : viewer.role();
        if (posts.findVisibleDetail(postId, viewerId, role) == null) throw new PostNotFoundException();
        List<CommentTreeRow> all = comments.selectThreadRows(postId);
        Set<Long> blocked = viewerId == null ? Set.of() :
                Set.copyOf(comments.selectBlockedMemberIds(viewerId));
        Map<Long, List<CommentTreeRow>> replies = all.stream()
                .filter(r -> r.parentId != null)
                .collect(Collectors.groupingBy(r -> r.parentId, LinkedHashMap::new, Collectors.toList()));
        List<CommentThreadResponse> result = new ArrayList<>();
        for (CommentTreeRow top : all) {
            if (top.parentId != null || blocked.contains(top.authorId)) continue;
            List<CommentReplyResponse> visible = replies.getOrDefault(top.id, List.of()).stream()
                    .filter(r -> r.deletedAt == null && !blocked.contains(r.authorId))
                    .map(r -> new CommentReplyResponse(r.id,
                            new AuthorResponse(r.authorId, r.authorNickname), r.content, r.createdAt))
                    .toList();
            boolean deleted = top.deletedAt != null;
            if (deleted && visible.isEmpty()) continue;
            result.add(new CommentThreadResponse(top.id,
                    deleted ? null : new AuthorResponse(top.authorId, top.authorNickname),
                    deleted ? "삭제된 댓글입니다" : top.content, top.createdAt, deleted, visible));
        }
        return result;
    }

public class MyBatisCommentService {
    private final PostVisibilityMapper visiblePosts;
    private final MyBatisCommentMapper comments;

    public MyBatisCommentService(PostVisibilityMapper visiblePosts, MyBatisCommentMapper comments) {
        this.visiblePosts = visiblePosts;
        this.comments = comments;
    }

    @Transactional
    public CommentResponse create(Long postId, AuthenticatedMember me, CommentCreateRequest request) {
        PostDetailRow post = visiblePosts.findVisibleDetail(postId, me.id(), me.role());
        if (post == null || !"PUBLISHED".equals(comments.findPostStatus(postId)))
            throw new PostNotFoundException();

        Long parentId = request.parentId();
        if (parentId != null) {
            ParentCommentRow parent = comments.findParent(parentId);
            if (parent == null) throw new CommentNotFoundException();
            if (!postId.equals(parent.postId))
                throw new InvalidParentCommentException("다른 글의 댓글에는 답글을 달 수 없습니다.");
            if (parent.parentId != null)
                throw new InvalidParentCommentException("답글에는 답글을 달 수 없습니다.");
            if (parent.deletedAt != null)
                throw new InvalidParentCommentException("지워진 댓글에는 답글을 달 수 없습니다.");
        }
        CommentInsertRow row = new CommentInsertRow(postId, me.id(), parentId,
                request.content(), LocalDateTime.now());
        if (comments.insertComment(row) != 1) throw new IllegalStateException("댓글 저장 실패");
        if (comments.incrementCommentCount(postId) != 1)
            throw new IllegalStateException("댓글 수 변경 실패");
        return new CommentResponse(row.id, postId, parentId,
                new CommentAuthorResponse(me.id(), me.nickname()), row.content, row.at, false);
    }

    // 삭제 표시와 댓글 수 감소를 같은 트랜잭션에서 실행한다.
    @Transactional
    public void delete(Long id, AuthenticatedMember member) {
        CommentDeleteRow row = comments.findForDelete(id);
        if (row == null || row.deletedAt != null) throw new CommentNotFoundException();
        if (!member.id().equals(row.memberId)) throw new CommentForbiddenException();

@Service
public class MyBatisLikeService {
    private static final int MAX_ATTEMPTS = 10;
    private final PostVisibilityMapper visiblePosts;
    private final MyBatisLikeMapper likes;
    private final TransactionTemplate transactions;

    public MyBatisLikeService(PostVisibilityMapper visiblePosts, MyBatisLikeMapper likes,
                              PlatformTransactionManager manager) {
        this.visiblePosts = visiblePosts;
        this.likes = likes;
        this.transactions = new TransactionTemplate(manager);
    }

    public LikeResponse like(Long postId, AuthenticatedMember me) {
        return withDeadlockRetry(() -> transactions.execute(status -> doLike(postId, me)));
    }

    public LikeResponse unlike(Long postId, AuthenticatedMember me) {
        return withDeadlockRetry(() -> transactions.execute(status -> doUnlike(postId, me)));
    }

    private LikeResponse doLike(Long postId, AuthenticatedMember me) {
        PostDetailRow post = findLikeablePost(postId, me);
        if (post.authorId.equals(me.id())) throw new SelfLikeNotAllowedException();
        if (likes.insertIgnoreLike(postId, me.id()) == 1) likes.increaseLikeCount(postId);
        return new LikeResponse(postId, true, likes.findLikeCount(postId));
    }

    private LikeResponse doUnlike(Long postId, AuthenticatedMember me) {
        findLikeablePost(postId, me);
        if (likes.deleteLike(postId, me.id()) == 1) likes.decreaseLikeCount(postId);
        return new LikeResponse(postId, false, likes.findLikeCount(postId));
    }

    @Transactional(readOnly = true)
    public MyLikesResponse myLikes(AuthenticatedMember me, int size, String cursor) {
        LocalDateTime cursorAt = null;
        Long cursorId = null;
        if (cursor != null) {
            String[] parts = decodeCursor(cursor);
            cursorAt = LocalDateTime.parse(parts[0]);
            cursorId = Long.valueOf(parts[1]);
        }
        List<MyLikeRow> rows = likes.findMyLikes(me.id(), cursorAt, cursorId, size + 1);
        boolean hasNext = rows.size() > size;
        List<MyLikeRow> page = hasNext ? rows.subList(0, size) : rows;
        List<MyLikeItemResponse> items = page.stream()
                .map(row -> new MyLikeItemResponse(row.postId, row.title,
                        new AuthorResponse(row.authorId, row.authorNickname), row.likedAt))
                .toList();
        String nextCursor = hasNext ? encodeCursor(page.get(page.size() - 1)) : null;
        return new MyLikesResponse(items, nextCursor);
    }

    private String encodeCursor(MyLikeRow last) {
        String raw = last.likedAt + "|" + last.likeId;
        return Base64.getUrlEncoder().withoutPadding()
                .encodeToString(raw.getBytes(StandardCharsets.UTF_8));
    }

    private String[] decodeCursor(String cursor) {
        try {
            String raw = new String(Base64.getUrlDecoder().decode(cursor), StandardCharsets.UTF_8);
            String[] parts = raw.split("\\|", -1);
            if (parts.length != 2) throw new IllegalArgumentException();
            LocalDateTime.parse(parts[0]);
            if (Long.parseLong(parts[1]) < 1) throw new IllegalArgumentException();
            return parts;
        } catch (IllegalArgumentException | DateTimeException ex) {
            throw new ResponseStatusException(HttpStatus.BAD_REQUEST, "올바르지 않은 cursor입니다.");
        }
    }

    private PostDetailRow findLikeablePost(Long postId, AuthenticatedMember me) {
        PostDetailRow post = visiblePosts.findVisibleDetail(postId, me.id(), me.role());
        if (post == null || !"PUBLISHED".equals(likes.findPostStatus(postId)))
            throw new PostNotFoundException();
        return post;
    }

    private LikeResponse withDeadlockRetry(java.util.function.Supplier<LikeResponse> action) {
        for (int attempt = 1; ; attempt++) {
            try {
                return action.get();
            } catch (ConcurrencyFailureException e) {
                if (attempt >= MAX_ATTEMPTS) throw e;
                try {
                    Thread.sleep((long) (Math.random() * 20 * attempt));
                } catch (InterruptedException interrupted) {
                    Thread.currentThread().interrupt();
                    throw e;
                }
            }
        }
    }

@Service
public class PostPatchMyBatisService {
    private static final int TITLE_MAX_LENGTH = 200;
    private static final int TAGS_MAX_COUNT = 5;
    private static final int TAG_NAME_MAX_LENGTH = 30;

    private final PostVisibilityMapper visibilityMapper;
    private final PostReplaceMapper replaceMapper;

    public PostPatchMyBatisService(PostVisibilityMapper visibilityMapper,
                                   PostReplaceMapper replaceMapper) {
        this.visibilityMapper = visibilityMapper;
        this.replaceMapper = replaceMapper;
    }

    @Transactional
    public PostDetailResponse patch(Long id, AuthenticatedMember me, PostUpdateRequest request) {
        PostDetailRow current = visibilityMapper.findVisibleDetail(id, me.id(), me.role());
        if (current == null) throw new PostNotFoundException();
        if (!current.authorId.equals(me.id())) throw new PostForbiddenException();

        // 모든 입력을 확인한 뒤 쓰기를 시작한다.
        if (request.title() != null) validateTitle(request.title());
        if (request.content() != null) validateContent(request.content());
        if (request.tags() != null) validateTags(request.tags());
        if (request.visibility() != null) validateVisibility(request.visibility());

        List<String> tags;
        if (request.tags() == null) {
            tags = visibilityMapper.findTagsByPostIds(List.of(id)).stream()
                    .map(PostTagRow::name).toList();
        } else {
            List<PostReplaceTagRow> resolved = new ArrayList<>();
            Set<Long> seenIds = new HashSet<>();
            for (String name : request.tags()) {
                replaceMapper.insertTagIfMissing(name);
                PostReplaceTagRow tag = replaceMapper.findTagByName(name);
                if (seenIds.add(tag.id)) resolved.add(tag);
            }
            replaceMapper.deletePostTags(id);
            for (PostReplaceTagRow tag : resolved) replaceMapper.insertPostTag(id, tag.id);
            tags = resolved.stream().map(tag -> tag.name).toList();
        }
        replaceMapper.patchPost(id, request.title(), request.content(), request.visibility());
        return new PostDetailResponse(id, current.boardSlug,
                request.title() == null ? current.title : request.title(),
                request.content() == null ? current.content : request.content(),
                tags,
                request.visibility() == null ? current.visibility : request.visibility(),
                new AuthorResponse(current.authorId, current.authorNickname),
                current.viewCount, current.likeCount, current.commentCount, current.createdAt);
    }

    private void validateTitle(String title) {
        if (title.isBlank()) throw new InvalidPostFieldException("title", "제목을 입력해 주세요.");
        if (title.length() > TITLE_MAX_LENGTH)
            throw new InvalidPostFieldException("title", "제목은 " + TITLE_MAX_LENGTH + "자 이하여야 합니다.");
    }

    private void validateContent(String content) {
        if (content.isBlank()) throw new InvalidPostFieldException("content", "본문을 입력해 주세요.");
    }

    private void validateTags(List<String> tags) {
        if (tags.size() > TAGS_MAX_COUNT)
            throw new InvalidPostFieldException("tags", "태그는 " + TAGS_MAX_COUNT + "개까지입니다.");

            if (tag == null || tag.isBlank() || tag.length() > TAG_NAME_MAX_LENGTH)
                throw new InvalidPostFieldException("tags", "태그 이름은 1~" + TAG_NAME_MAX_LENGTH + "자여야 합니다.");
        }
    }

@Service

    private final PostVisibilityMapper visibilityMapper;
    private final PostReplaceMapper replaceMapper;

    public PostReplaceMyBatisService(PostVisibilityMapper visibilityMapper,
                                     PostReplaceMapper replaceMapper) {
        this.visibilityMapper = visibilityMapper;
        this.replaceMapper = replaceMapper;
    }

    @Transactional
    public PostDetailResponse replace(Long id, AuthenticatedMember me, PostReplaceRequest request) {
        PostDetailRow current = visibilityMapper.findVisibleDetail(id, me.id(), me.role());
        if (current == null) {
            throw new PostNotFoundException();
        }
        if (!current.authorId.equals(me.id())) {
            throw new ResponseStatusException(HttpStatus.FORBIDDEN);
        }

        // 이름이 다른 대소문자 표기도 같은 tag 행으로 연결한다.
        List<PostReplaceTagRow> tags = new ArrayList<>();
        Set<Long> seenTagIds = new HashSet<>();
        for (String name : request.tags()) {
            replaceMapper.insertTagIfMissing(name);
            PostReplaceTagRow tag = replaceMapper.findTagByName(name);
            if (seenTagIds.add(tag.id)) {
                tags.add(tag);
            }
        }
        replaceMapper.updatePost(id, request.title(), request.content(), request.visibility());
        replaceMapper.deletePostTags(id);
        for (PostReplaceTagRow tag : tags) {
            replaceMapper.insertPostTag(id, tag.id);
        }
        return new PostDetailResponse(id, current.boardSlug, request.title(),
                request.content(), tags.stream().map(tag -> tag.name).toList(),
                request.visibility(),
                new AuthorResponse(current.authorId, current.authorNickname),
                current.viewCount, current.likeCount, current.commentCount, current.createdAt);
    }

    @Autowired

    void differentMembersLikingAtOnceKeepsCountConsistent() throws InterruptedException {

            members.add(new AuthenticatedMember(7L + i, "동시성" + (i + 1), "USER"));
        }

        List<Exception> errors = runConcurrently(threadCount, index -> likeService.like(POST_ID, members.get(index)));

        assertTrue(errors.isEmpty(), "모든 요청이 예외 없이 끝나야 한다: " + errors);
        Integer likeCount = postRepository.findLikeCountById(POST_ID);
        long rowCount = postLikeRepository.countByPost_Id(POST_ID);

        assertEquals(20L, rowCount, "서로 다른 회원 20명이 좋아요했으니 행도 20개여야 한다");
        assertEquals(rowCount, likeCount.longValue(), "like_count는 실제 post_like 행 수와 같아야 한다");
    }

    @Test
    void sameMemberLikingFiveTimesAtOnceInsertsOnlyOneRow() throws InterruptedException {
        AuthenticatedMember member = new AuthenticatedMember(7L, "동시성01", "USER");

        List<Exception> errors = runConcurrently(5, index -> likeService.like(POST_ID, member));

        assertTrue(errors.isEmpty(), "중복 키 오류 등으로 실패한 요청이 있으면 안 된다: " + errors);
        long rowCount = postLikeRepository.countByPost_IdAndMember_Id(POST_ID, member.id());
        assertEquals(1L, rowCount, "같은 회원이 동시에 여러 번 눌러도 행은 1개여야 한다");
    }

    private List<Exception> runConcurrently(int count, java.util.function.IntConsumer task) throws InterruptedException {
        ExecutorService pool = Executors.newFixedThreadPool(count);
        CountDownLatch ready = new CountDownLatch(count);
        CountDownLatch start = new CountDownLatch(1);
        CountDownLatch done = new CountDownLatch(count);
        List<Exception> errors = new CopyOnWriteArrayList<>();

        for (int i = 0; i < count; i++) {
            int index = i;
            pool.submit(() -> {
                try {
                    ready.countDown();
                    start.await();
                    task.accept(index);
                } catch (Exception e) {
                    errors.add(e);
                } finally {
                    done.countDown();
                }
            });
        }

        boolean allReady = ready.await(10, TimeUnit.SECONDS);
        start.countDown(); // 모든 스레드가 준비된 뒤 한꺼번에 출발시킨다
        assertTrue(allReady, "모든 스레드가 출발 전에 준비돼야 한다");
        assertTrue(done.await(30, TimeUnit.SECONDS), "모든 요청이 끝나야 한다");
        pool.shutdown();
        return errors;
    }
}

package org.example.post;

import org.apache.ibatis.executor.Executor;
import org.apache.ibatis.mapping.MappedStatement;
import org.apache.ibatis.plugin.Interceptor;
import org.apache.ibatis.plugin.Intercepts;
import org.apache.ibatis.plugin.Invocation;
import org.apache.ibatis.plugin.Signature;
import org.apache.ibatis.session.ResultHandler;
import org.apache.ibatis.session.RowBounds;
import org.springframework.stereotype.Component;

// 테스트 중 Mapper가 실행한 SELECT 문장 수를 요청 스레드별로 센다.
@Component
@Intercepts(@Signature(type = Executor.class, method = "query",
        args = {MappedStatement.class, Object.class, RowBounds.class, ResultHandler.class}))
public class MyBatisStatementCounter implements Interceptor {
    private final ThreadLocal<Long> count = ThreadLocal.withInitial(() -> 0L);

    @Override
    public Object intercept(Invocation invocation) throws Throwable {
        count.set(count.get() + 1);
        return invocation.proceed();
    }

    public void clear() { count.set(0L); }
    public long getCount() { return count.get(); }
}
