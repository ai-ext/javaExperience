#상황

"글 아래에 댓글을 보여 주세요. 답글은 그 댓글 아래에요. 댓글을 지웠는데 답글이 달려 있으면 대화가 끊겨 보이니까 '삭제된 댓글입니다'로 자리만 남겨 주세요."

#구현 가이드

화면 시나리오의 서버·DB 흐름을 이 단계에서 바뀐 파일에 연결한다. 먼저 만들 것의 계약대로 직접 작성하고, 필요한 역할만 펼쳐 파일 전문과 비교한다.

이 단계의 처리 흐름:

  • 한 번에 읽는다 — 댓글마다 답글을 따로 조회하지 않는다
  • 메모리에서 트리로: 지운 4번은 살아 있는 답글(5)이 있어 자리만 남기고, 답글 없는 지운 6번은 뺀다
  • 한차단과 김자바는 차단 관계 → 3번 댓글을 뺀다

CommentController.java. 매핑과 메서드의 입력·응답을 위 만들 것의 HTTP 계약과 대조한다. 이번 단계 매핑: @GetMapping("/api/posts/{postId}/comments"), @DeleteMapping("/api/comments/{id}"). 변경된 메서드: list, delete.

DTO — 요청·응답 필드

CommentReplyResponse.java, CommentThreadResponse.java. 필드 이름·타입·검증·응답 형태를 위 만들 것과 대조한다.

public record CommentThreadResponse(Long id, AuthorResponse author, String content,
        LocalDateTime createdAt, boolean deleted, List<CommentReplyResponse> replies) {}

답글 DTO에는 id, author, content, createdAt만 있다. 삭제·차단된 답글은 DTO로 만들지 않는다. 삭제된 최상위 댓글만 author=null, 자리표시자 content, deleted=true로 만든다.

Service — 처리 순서

CommentService.java, PostAccessPolicy.java, BlockPolicy.java. 위 서버 처리 순서가 어디에서 검증·조회·상태 변경으로 이어지는지 따라간다. 변경된 메서드: delete, list. 트랜잭션 경계는 아래 코드의 @Transactional 위치에서 확인한다.

@Transactional(readOnly = true)

    Long viewerId = viewer == null ? null : viewer.id();
    Set<Long> blocked = viewerId == null ? Set.of() : blockPolicy.blockRelatedIds(viewerId);
    // 답글을 parent ID별로 묶고, 최상위마다 삭제·차단 규칙을 적용해 DTO를 만든다.
}

위 코드는 흐름 발췌다. 실제 전문은 Map<Long, List<Comment>>에 답글을 묶고, 지운 최상위에 보이는 답글이 없을 때만 최상위를 뺀다. 차단 상대 ID는 한 번에 읽으므로 댓글 수에 따라 차단 조회가 늘지 않는다. delete는 서비스에서 작성자를 확인한 뒤 조건부 soft delete의 영향 행이 1일 때만 댓글 수를 감소시킨다. 숫자 변경도 1행이어야 하며, 아니면 같은 트랜잭션을 롤백한다.

JPA / Repository — DB 조건

CommentRepository.java, PostRepository.java. 쿼리·파생 메서드의 조건을 화면 시나리오의 DB 단계 및 직접 확인 SQL과 대조한다. 직접 작성한 JPQL·SQL과 아래 파일의 @Query를 비교한다.

@Query("SELECT c FROM Comment c JOIN FETCH c.member " +
       "WHERE c.post.id = :postId ORDER BY c.createdAt ASC, c.id ASC")
List<Comment> findByPostIdWithMember(@Param("postId") Long postId);

@Modifying
@Query("UPDATE Comment c SET c.deletedAt = :now, c.updatedAt = :now " +
       "WHERE c.id = :id AND c.deletedAt IS NULL")
int softDeleteIfLive(@Param("id") Long id, @Param("now") LocalDateTime now);

@Modifying
@Query("UPDATE Post p SET p.commentCount = p.commentCount - 1 " +
       "WHERE p.id = :id AND p.commentCount > 0")
int decrementCommentCount(@Param("id") Long id);

댓글·작성자를 한 번에 읽고, 차단 상대 ID도 MemberBlockRepository.findBlockRelatedIds 한 번으로 조회한다. 트리 조립 중 댓글마다 DB를 조회하지 않는다. 숫자 감소는 DB의 조건부 UPDATE로 실행한다.

Entity — 테이블·상태

Comment.java. 선행 단계의 deleted_at 매핑을 확인한다. 이번 단계는 조건부 UPDATE로 삭제하므로 엔티티 변경 메서드를 추가하지 않는다.

@Column(name = "deleted_at")
private LocalDateTime deletedAt;

행을 지우지 않아 기존 답글의 parent_id가 유지된다. deleted_at이 채워진 최상위의 표시 여부는 목록 Service가 결정한다. 같은 댓글에 동시 DELETE가 와도 WHERE deleted_at IS NULL을 통과한 한 요청만 댓글 수를 내린다.

CommentForbiddenException.java, ApiExceptionHandler.java. 예외가 어떤 HTTP 상태와 오류 본문으로 바뀌는지 실패 계약과 대조한다. 변경된 메서드: handleCommentForbidden.

    throw new CommentForbiddenException(); // 403

없거나 이미 지운 댓글은 CommentNotFoundException으로 404다. 권한 확인은 Controller가 아니라 Service에서 하며, 전역 ApiExceptionHandler가 Problem Details 응답으로 바꾼다.

MyBatis — JOIN 목록·차단·조건부 삭제 SQL

대체 구현의 MyBatisCommentMapper.xml은 댓글과 작성자를 JOIN해 평평한 행 전체를 작성 순으로 읽고, MyBatisCommentQueryService에서 부모별로 묶는다.

           c.content, c.created_at, c.deleted_at

    if (!comment.getMember().getId().equals(loginMember.id())) {
        throw new CommentForbiddenException();

    if (commentRepository.softDeleteIfLive(commentId, LocalDateTime.now()) != 1) {
        throw new CommentNotFoundException();

        throw new IllegalStateException(&quot;댓글 수 변경 실패&quot;);
    }
}

public List&lt;CommentThreadResponse&gt; list(Long postId, AuthenticatedMember viewer) {
    Post post = postRepository.findById(postId)
            .orElseThrow(PostNotFoundException::new);
    if (!accessPolicy.canView(viewer, post)) {
        throw new PostNotFoundException();
    }

    List&lt;Comment&gt; all = commentRepository.findByPostIdWithMember(postId);
    Long viewerId = viewer == null ? null : viewer.id();
    Set&lt;Long&gt; blockedMemberIds = viewerId == null ? Set.of() : blockPolicy.blockRelatedIds(viewerId);

    Map&lt;Long, List&lt;Comment&gt;&gt; repliesByParent = all.stream()
            .filter(c -&gt; c.getParent() != null)
            .collect(Collectors.groupingBy(c -&gt; c.getParent().getId(), LinkedHashMap::new, Collectors.toList()));

    List&lt;CommentThreadResponse&gt; result = new ArrayList&lt;&gt;();
    for (Comment top : all) {
        if (top.getParent() != null) {
            continue; // 답글은 부모와 함께 처리
        }
        if (blockedMemberIds.contains(top.getMember().getId())) {
            continue; // 차단 — 최상위째 뺀다(답글도 함께)
        }

        // &quot;살아 있는 답글&quot;은 지운 것·차단으로 빠지는 것을 제외하고 센다
        List&lt;Comment&gt; visibleReplies = repliesByParent.getOrDefault(top.getId(), List.of()).stream()
                .filter(r -&gt; r.getDeletedAt() == null)
                .filter(r -&gt; !blockedMemberIds.contains(r.getMember().getId()))
                .toList();

        boolean deleted = top.getDeletedAt() != null;
        if (deleted &amp;&amp; visibleReplies.isEmpty()) {
            continue; // 지웠고 남은 답글도 없으면 자리도 남기지 않는다
        }

        List&lt;CommentReplyResponse&gt; replies = visibleReplies.stream()
                .map(r -&gt; new CommentReplyResponse(r.getId(), toAuthor(r.getMember()), r.getContent(), r.getCreatedAt()))
                .toList();

        result.add(new CommentThreadResponse(
                top.getId(),
                deleted ? null : toAuthor(top.getMember()),
                deleted ? &quot;삭제된 댓글입니다&quot; : top.getContent(),
                top.getCreatedAt(),
                deleted,
                replies
        ));
    }
    return result;
}

import org.example.auth.AuthenticatedMember;
import org.example.social.BlockPolicy;

import org.springframework.stereotype.Component;


// "이 사람이 이 글을 볼 수 있나" 규칙을 한 곳에 모은다.
// 상세(GET /api/posts/{id})는 이 자바 코드로 판정하고, 목록(게시판 목록)은
// 같은 다섯 조건을 PostRepository의 JPQL(findViewableByBoard)로 옮겨 건다.
// 규칙을 바꿀 때는 두 곳을 같이 고쳐야 한다.
@Component
public class PostAccessPolicy {


private static final String PUBLISHED = &quot;PUBLISHED&quot;;
private static final String DRAFT = &quot;DRAFT&quot;;
private static final String HIDDEN = &quot;HIDDEN&quot;;
private static final String PUBLIC = &quot;PUBLIC&quot;;
private static final String FOLLOWERS = &quot;FOLLOWERS&quot;;
private static final String ADMIN_ROLE = &quot;ADMIN&quot;;

private final FollowRepository followRepository;
private final BlockPolicy blockPolicy;

public PostAccessPolicy(FollowRepository followRepository, BlockPolicy blockPolicy) {
    this.followRepository = followRepository;
    this.blockPolicy = blockPolicy;
}

public boolean canView(AuthenticatedMember viewer, Post post) {
    // 1. 삭제된 글은 작성자 본인도 못 본다
    if (post.getDeletedAt() != null) {
        return false;
    }

    Long viewerId = viewer == null ? null : viewer.id();
    Long authorId = post.getAuthor().getId();
    boolean isAuthor = viewerId != null &amp;&amp; viewerId.equals(authorId);
    boolean isAdmin = viewer != null &amp;&amp; ADMIN_ROLE.equals(viewer.role());

    // 2. 상태별 허용 — DRAFT는 작성자만, HIDDEN은 운영자만
    boolean statusOk = switch (post.getStatus()) {
        case PUBLISHED -&gt; true;
        case DRAFT -&gt; isAuthor;
        case HIDDEN -&gt; isAdmin;
        default -&gt; false;
    };
    if (!statusOk) {
        return false;
    }

    // 3. PUBLISHED + FOLLOWERS 공개는 작성자 본인이거나 팔로워만
    if (PUBLISHED.equals(post.getStatus()) &amp;&amp; FOLLOWERS.equals(post.getVisibility()) &amp;&amp; !isAuthor) {
        boolean follows = viewerId != null
                &amp;&amp; followRepository.existsByFollower_IdAndFollowee_Id(viewerId, authorId);
        if (!follows) {
            return false;
        }
    }

    // 4. 둘 사이에 차단이 있으면(어느 쪽이 차단했든) 못 본다
    if (viewerId != null &amp;&amp; !isAuthor &amp;&amp; blockPolicy.isBlockedEitherWay(viewerId, authorId)) {
        return false;
    }

    // 5. 발행 글의 공개 범위가 알려진 값인지 검사한다.
    // 비로그인과 일반 열람자는 PUBLIC 또는 위에서 확인한 FOLLOWERS만 볼 수 있다.
    // DB에 PRIVATE/알 수 없는 값이 들어와도 공개로 취급하지 않는다.
    if (PUBLISHED.equals(post.getStatus()) &amp;&amp; !isAuthor
            &amp;&amp; !PUBLIC.equals(post.getVisibility())
            &amp;&amp; !FOLLOWERS.equals(post.getVisibility())) {
        return false;
    }
    return true;
}


}

    PostDetailRow post = visiblePosts.findVisibleDetail(postId, me.id(), me.role());
    if (post == null || !&quot;PUBLISHED&quot;.equals(comments.findPostStatus(postId)))
        throw new PostNotFoundException();

    Long parentId = request.parentId();
    if (parentId != null) {
        ParentCommentRow parent = comments.findParent(parentId);
        if (parent == null) throw new CommentNotFoundException();
        if (!postId.equals(parent.postId))
            throw new InvalidParentCommentException(&quot;다른 글의 댓글에는 답글을 달 수 없습니다.&quot;);

        if (parent.deletedAt != null)
            throw new InvalidParentCommentException(&quot;지워진 댓글에는 답글을 달 수 없습니다.&quot;);
    }
    CommentInsertRow row = new CommentInsertRow(postId, me.id(), parentId,

public LikeResponse like(Long postId, AuthenticatedMember me) {
    return withDeadlockRetry(() -&gt; transactions.execute(status -&gt; doLike(postId, me)));

public LikeResponse unlike(Long postId, AuthenticatedMember me) {

private LikeResponse doLike(Long postId, AuthenticatedMember me) {
    PostDetailRow post = findLikeablePost(postId, me);
    if (post.authorId.equals(me.id())) throw new SelfLikeNotAllowedException();
    if (likes.insertIgnoreLike(postId, me.id()) == 1) likes.increaseLikeCount(postId);
    return new LikeResponse(postId, true, likes.findLikeCount(postId));
}

private LikeResponse doUnlike(Long postId, AuthenticatedMember me) {
    findLikeablePost(postId, me);
    if (likes.deleteLike(postId, me.id()) == 1) likes.decreaseLikeCount(postId);
    return new LikeResponse(postId, false, likes.findLikeCount(postId));
}

@Transactional
public PostDetailResponse patch(Long id, AuthenticatedMember me, PostUpdateRequest request) {
    PostDetailRow current = visibilityMapper.findVisibleDetail(id, me.id(), me.role());
    if (current == null) throw new PostNotFoundException();
    if (!current.authorId.equals(me.id())) throw new PostForbiddenException();

    // 모든 입력을 확인한 뒤 쓰기를 시작한다.
    if (request.title() != null) validateTitle(request.title());
    if (request.content() != null) validateContent(request.content());
    if (request.tags() != null) validateTags(request.tags());
    if (request.visibility() != null) validateVisibility(request.visibility());

    List&lt;String&gt; tags;
    if (request.tags() == null) {
        tags = visibilityMapper.findTagsByPostIds(List.of(id)).stream()
                .map(PostTagRow::name).toList();
    } else {
        List&lt;PostReplaceTagRow&gt; resolved = new ArrayList&lt;&gt;();
        Set&lt;Long&gt; seenIds = new HashSet&lt;&gt;();
        for (String name : request.tags()) {
            replaceMapper.insertTagIfMissing(name);
            PostReplaceTagRow tag = replaceMapper.findTagByName(name);
            if (seenIds.add(tag.id)) resolved.add(tag);
        }
        replaceMapper.deletePostTags(id);
        for (PostReplaceTagRow tag : resolved) replaceMapper.insertPostTag(id, tag.id);
        tags = resolved.stream().map(tag -&gt; tag.name).toList();
    }
    replaceMapper.patchPost(id, request.title(), request.content(), request.visibility());
    return new PostDetailResponse(id, current.boardSlug,
            request.title() == null ? current.title : request.title(),
            request.content() == null ? current.content : request.content(),
            tags,
            request.visibility() == null ? current.visibility : request.visibility(),
            new AuthorResponse(current.authorId, current.authorNickname),
            current.viewCount, current.likeCount, current.commentCount, current.createdAt);
}

}

}

        throw new InvalidPostFieldException(&quot;tags&quot;, &quot;태그는 &quot; + TAGS_MAX_COUNT + &quot;개까지입니다.&quot;);

        if (tag == null || tag.isBlank() || tag.length() &gt; TAG_NAME_MAX_LENGTH)

}

private List&lt;Exception&gt; runConcurrently(int count, java.util.function.IntConsumer task) throws InterruptedException {
    ExecutorService pool = Executors.newFixedThreadPool(count);
    CountDownLatch ready = new CountDownLatch(count);
    CountDownLatch start = new CountDownLatch(1);
    CountDownLatch done = new CountDownLatch(count);
    List&lt;Exception&gt; errors = new CopyOnWriteArrayList&lt;&gt;();

                ready.countDown();
                start.await();
                task.accept(index);
            } catch (Exception e) {
                errors.add(e);
            } finally {
                done.countDown();
            }
        });
    }

import org.springframework.boot.test.context.SpringBootTest;
import org.springframework.boot.webmvc.test.autoconfigure.AutoConfigureMockMvc;
import org.springframework.jdbc.core.JdbcTemplate;
import org.springframework.test.web.servlet.MockMvc;
import org.springframework.transaction.annotation.Transactional;
import tools.jackson.databind.ObjectMapper;


import static org.junit.jupiter.api.Assertions.assertEquals;
import static org.springframework.test.web.servlet.request.MockMvcRequestBuilders.get;
import static org.springframework.test.web.servlet.request.MockMvcRequestBuilders.post;
import static org.springframework.test.web.servlet.request.MockMvcRequestBuilders.put;
import static org.springframework.test.web.servlet.result.MockMvcResultMatchers.jsonPath;
import static org.springframework.test.web.servlet.result.MockMvcResultMatchers.status;


@SpringBootTest
@AutoConfigureMockMvc
@Transactional
class PostReplaceControllerTest {
    @Autowired MockMvc mockMvc;
    @Autowired ObjectMapper objectMapper;
    @Autowired JdbcTemplate jdbc;
    @Autowired EntityManager em;


@Test
void replacesPostAndTagsTogether() throws Exception {
    var created = mockMvc.perform(post(&quot;/api/posts&quot;)
                    .header(&quot;Authorization&quot;, &quot;Bearer tok-kimjava&quot;)
                    .contentType(&quot;application/json&quot;)
                    .content(&quot;{\&quot;boardSlug\&quot;:\&quot;dev\&quot;,\&quot;title\&quot;:\&quot;이전\&quot;,\&quot;content\&quot;:\&quot;이전 본문\&quot;,\&quot;tags\&quot;:[\&quot;spring\&quot;],\&quot;visibility\&quot;:\&quot;FOLLOWERS\&quot;}&quot;))
            .andExpect(status().isCreated()).andReturn();
    long id = objectMapper.readTree(created.getResponse().getContentAsString()).get(&quot;id&quot;).asLong();
    em.flush(); // JPA 생성 결과를 DB에 반영한 뒤 MyBatis 교체를 확인한다.

    mockMvc.perform(put(&quot;/api/posts/{id}&quot;, id)
                    .header(&quot;Authorization&quot;, &quot;Bearer tok-kimjava&quot;)
                    .contentType(&quot;application/json&quot;)
                    .content(&quot;{\&quot;title\&quot;:\&quot;[PUT실습] 새 제목\&quot;,\&quot;content\&quot;:\&quot;수정한 본문\&quot;,\&quot;tags\&quot;:[\&quot;java\&quot;]}&quot;))
            .andExpect(status().isOk())
            .andExpect(jsonPath(&quot;$.title&quot;).value(&quot;[PUT실습] 새 제목&quot;))
            .andExpect(jsonPath(&quot;$.visibility&quot;).value(&quot;PUBLIC&quot;))
            .andExpect(jsonPath(&quot;$.tags[0]&quot;).value(&quot;java&quot;));
    em.flush();
    assertEquals(&quot;PUBLIC&quot;, jdbc.queryForObject(&quot;SELECT visibility FROM post WHERE id=?&quot;, String.class, id));
    assertEquals(&quot;java&quot;, jdbc.queryForObject(&quot;SELECT t.name FROM post_tag pt JOIN tag t ON t.id=pt.tag_id WHERE pt.post_id=?&quot;, String.class, id));

    mockMvc.perform(put(&quot;/api/posts/{id}&quot;, id)
                    .header(&quot;Authorization&quot;, &quot;Bearer tok-kimjava&quot;)
                    .contentType(&quot;application/json&quot;).content(&quot;{\&quot;title\&quot;:\&quot;제목만\&quot;}&quot;))
            .andExpect(status().isBadRequest());
    mockMvc.perform(get(&quot;/api/posts/{id}&quot;, id)
                    .header(&quot;Authorization&quot;, &quot;Bearer tok-kimjava&quot;))
            .andExpect(status().isOk())
            .andExpect(jsonPath(&quot;$.content&quot;).value(&quot;수정한 본문&quot;));
    mockMvc.perform(put(&quot;/api/posts/{id}&quot;, id)
                    .header(&quot;Authorization&quot;, &quot;Bearer tok-lee&quot;)
                    .contentType(&quot;application/json&quot;).content(&quot;{\&quot;title\&quot;:\&quot;남의 글\&quot;,\&quot;content\&quot;:\&quot;본문\&quot;}&quot;))
            .andExpect(status().isForbidden());
    mockMvc.perform(put(&quot;/api/posts/{id}&quot;, id)
                    .contentType(&quot;application/json&quot;).content(&quot;{\&quot;title\&quot;:\&quot;제목\&quot;,\&quot;content\&quot;:\&quot;본문\&quot;}&quot;))
            .andExpect(status().isUnauthorized());
    mockMvc.perform(put(&quot;/api/posts/999999&quot;)
                    .header(&quot;Authorization&quot;, &quot;Bearer tok-kimjava&quot;)
                    .contentType(&quot;application/json&quot;).content(&quot;{\&quot;title\&quot;:\&quot;제목\&quot;,\&quot;content\&quot;:\&quot;본문\&quot;}&quot;))
            .andExpect(status().isNotFound());
}


}
