"삭제 버튼 누르면 글이 없어져야 해요. 근데 운영팀이 신고 처리하려면 지운 글도 남아 있어야 한대요."

행을 진짜로 지우지 않고 "지웠다"는 표시만 남긴다(soft delete). 그러면 사용자에게는 사라진 것처럼 보이고, 운영팀은 기록을 볼 수 있다. 달려 있던 좋아요·댓글 행도 그대로 남는다.

지운 뒤에는 상세(GET)·수정(PATCH)·다시 삭제가 모두 404이고, 목록에서도 빠진다(2-3 규칙 1번).

운영자가 글을 숨기는 것과 작성자·운영자가 글을 삭제하는 것은 다르다. 숨김은 status = 'HIDDEN'으로 남겨 운영자가 상세를 볼 수 있지만, 삭제는 deleted_at을 채워 운영자도 일반 상세에서 못 본다. 삭제 시각은 나중에 휴지통·복구의 기준이 된다.

03⌘어떻게 만들까구현 가이드DELETE 를 받아 기존 행에 삭제 시각을 기록한다. 관련 행을 지우지 않고, 일반 조회 경로에서 삭제된 글이 빠지는지 확인한다.5개 코드 · 열기 ↓

DELETE를 받아 기존 행에 삭제 시각을 기록한다. 관련 행을 지우지 않고, 일반 조회 경로에서 삭제된 글이 빠지는지 확인한다.

Controller — DELETE와 빈 204 응답 
@DeleteMapping("/{id}")
@ResponseStatus(HttpStatus.NO_CONTENT)
public void delete(@PathVariable Long id,
                   @LoginMember AuthenticatedMember loginMember) {
    postService.delete(id, loginMember);
}

회원 id를 요청 본문에서 받지 않는다. 인증 인터셉터가 넣은 회원으로 권한을 판단한다.

Service — 살아 있는 글 확인과 권한 판단 
@Transactional
public void delete(Long id, AuthenticatedMember me) {
    Post post = postRepository.findById(id)
            .orElseThrow(PostNotFoundException::new);
    if (!accessPolicy.canView(me, post)) {
        throw new PostNotFoundException();
    }
    boolean author = post.getAuthor().getId().equals(me.id());
    boolean admin = "ADMIN".equals(me.role());
    if (!author && !admin) {
        throw new PostForbiddenException();
    }
    post.delete(LocalDateTime.now());
}

이 단계의 post.delete(now)는 deletedAt과 updatedAt을 채운다. 트랜잭션의 변경 감지로 UPDATE가 나가므로 repository.delete(post)를 호출하지 않는다. 13-1에서 역할 표를 만들면 위 ADMIN 문자열 비교를 그 권한 검사로 옮긴다.

JPA / Repository — 일반 조회와 복구용 조회 분리 
Post post = postRepository.findById(id)
        .orElseThrow(PostNotFoundException::new);
if (!accessPolicy.canView(me, post)) {
    throw new PostNotFoundException();
}

findById(id)에는 삭제 조건이 자동으로 붙지 않으므로, 이 단계의 서비스는 PostAccessPolicy.canView에서 deletedAt을 먼저 확인한다. 상세·수정·반응 같은 일반 기능도 같은 규칙이 필요하다. 목록은 WHERE p.deletedAt IS NULL과 같은 조건의 COUNT를 사용한다.

반대로 11-5 휴지통·복구는 삭제된 행을 찾아야 한다. 전체 엔티티에 @SQLRestriction("deleted_at IS NULL")을 붙이면 복구 경로에서도 안 보일 수 있으므로, 이 실습에서는 조회 목적에 맞는 메서드를 분리한다.

MyBatis / Mapper — deleted_at만 UPDATE하기

MyBatis 대체 구현도 PostVisibilityMapper.findVisibleDetail에서 삭제·공개 범위를 먼저 확인하고, 그다음 작성자 또는 ADMIN인지 검사한다. PostDeleteMyBatisService는 아래 Mapper를 호출한다. DELETE FROM post나 연관 테이블 삭제 SQL은 사용하지 않는다.

<update id="softDelete">
  UPDATE post SET deleted_at = CURRENT_TIMESTAMP,
                  updated_at = CURRENT_TIMESTAMP
  WHERE id = #{id} AND deleted_at IS NULL
</update>

영향받은 행이 0개면 이미 삭제됐거나 없는 글로 보고 404를 반환한다. 전체 Controller·Service·Mapper Java/XML·테스트 파일은 이 가이드 뒤의 역할별 코드 접기에 있다.

DB / SQL — 행이 남는지 검산 
SELECT id, status, deleted_at FROM post WHERE id = @post_id;
SELECT id FROM post WHERE id = @post_id AND deleted_at IS NULL;
SELECT COUNT(*) FROM post_like WHERE post_id = @post_id;
SELECT COUNT(*) FROM comment WHERE post_id = @post_id;

첫 SELECT에는 행과 삭제 시각이 남고, 둘째에서는 빠진다. 좋아요·댓글 개수는 삭제 전과 같아야 한다. @post_id는 직접 확인에서 만든 Y의 id로 먼저 SET @post_id = ...; 하거나 숫자로 바꿔 실행한다. 새 글 Y에는 좋아요·댓글이 없으므로 PostDeleteControllerTest는 일회용 DB에 좋아요·댓글·태그 연결을 실제로 넣은 뒤 삭제하고 세 연결이 모두 남는지 검증한다.

@GetMapping(&quot;/{id}&quot;)

@PostMapping
public ResponseEntity&lt;PostResponse&gt; create(@LoginMember AuthenticatedMember loginMember,
                                            @Valid @RequestBody PostCreateRequest request) {

    Post post = postService.copy(sourceId, loginMember.id(), copyTags, request);
    return ResponseEntity.created(URI.create(&quot;/api/posts/&quot; + post.getId()))
            .body(toResponse(post));
}

@PutMapping(&quot;/{id}&quot;)

@Service
public class PostService {


private static final String ADMIN_WRITE_ROLE = &quot;ADMIN&quot;;
private static final String ADMIN_ROLE = &quot;ADMIN&quot;;
private static final String DEFAULT_VISIBILITY = &quot;PUBLIC&quot;;

// 1-5(PostCreateRequest)와 같은 규칙 — PATCH는 Bean Validation(@Valid)으로 표현할 수 없다
// (null=그대로, 값이 있을 때만 검사해야 하는데 @NotBlank는 null도 실패로 본다). 숫자만이라도
// 같은 값을 쓰도록 여기 모아 둔다.
private static final int TITLE_MAX_LENGTH = 200;
private static final int TAGS_MAX_COUNT = 5;
private static final int TAG_NAME_MAX_LENGTH = 30;

private final PostRepository postRepository;
private final BoardRepository boardRepository;
private final MemberRepository memberRepository;
private final TagRepository tagRepository;
private final PostAccessPolicy accessPolicy;

public PostService(PostRepository postRepository, BoardRepository boardRepository,
                    MemberRepository memberRepository, TagRepository tagRepository,
                    PostAccessPolicy accessPolicy) {
    this.postRepository = postRepository;
    this.boardRepository = boardRepository;
    this.memberRepository = memberRepository;
    this.tagRepository = tagRepository;
    this.accessPolicy = accessPolicy;
}

@Transactional
public Post create(Long authorId, PostCreateRequest request) {
    Board board = boardRepository.findBySlug(request.boardSlug())
            .orElseThrow(() -&gt; new BoardNotFoundException(request.boardSlug()));
    // 작성자는 요청 본문이 아니라 토큰으로 인증된 회원에서 받는다(authorId 같은 값은 무시한다)
    Member author = memberRepository.getReferenceById(authorId);

    if (ADMIN_WRITE_ROLE.equals(board.getWriteRole()) &amp;&amp; !ADMIN_ROLE.equals(author.getRole())) {
        throw new BoardWriteForbiddenException(board.getSlug());
    }

    String visibility = request.visibility() != null ? request.visibility() : DEFAULT_VISIBILITY;
    LocalDateTime now = LocalDateTime.now();
    Post post = new Post(board, author, request.title(), request.content(),
            &quot;PUBLISHED&quot;, visibility, now);

    for (Tag tag : resolveTags(request.tags(), now)) {
        post.addTag(tag);
    }

    Post saved = postRepository.save(post);
    // 트랜잭션(영속성 컨텍스트) 안에서 지연 로딩 연관을 미리 읽어 둔다.
    // open-in-view: false라서 컨트롤러가 트랜잭션 밖에서 건드리면 LazyInitializationException이 난다.
    saved.getAuthor().getNickname();
    saved.getTags().forEach(Tag::getName);
    return saved;
}

@Transactional
public Post copy(Long sourceId, Long authorId, boolean copyTags, CopyPostRequest request) {
    Post source = postRepository.findById(sourceId).orElseThrow(PostNotFoundException::new);
    if (source.getDeletedAt() != null || !&quot;PUBLISHED&quot;.equals(source.getStatus())
            || !&quot;PUBLIC&quot;.equals(source.getVisibility())) {
        throw new PostNotFoundException();
    }
    Member author = memberRepository.getReferenceById(authorId);
    if (ADMIN_WRITE_ROLE.equals(source.getBoard().getWriteRole())
            &amp;&amp; !ADMIN_ROLE.equals(author.getRole())) {
        throw new BoardWriteForbiddenException(source.getBoard().getSlug());
    }
    LocalDateTime now = LocalDateTime.now();
    Post copied = new Post(source.getBoard(), author, request.title(), source.getContent(),
            &quot;PUBLISHED&quot;, &quot;PUBLIC&quot;, now);
    if (copyTags) {
        source.getTags().forEach(copied::addTag);
    }
    Post saved = postRepository.save(copied);
    saved.getBoard().getSlug();
    saved.getAuthor().getNickname();
    saved.getTags().forEach(Tag::getName);
    return saved;
}

@Transactional
public PostDetailResponse replace(Long id, AuthenticatedMember me, PostReplaceRequest request) {
    Post post = postRepository.findById(id).orElseThrow(PostNotFoundException::new);
    if (!accessPolicy.canView(me, post)) {
        throw new PostNotFoundException();
    }
    if (!post.getAuthor().getId().equals(me.id())) {
        throw new ResponseStatusException(HttpStatus.FORBIDDEN);
    }

    LocalDateTime now = LocalDateTime.now();
    Set&lt;Tag&gt; tags = new LinkedHashSet&lt;&gt;();
    for (String name : distinctTagNames(request.tags())) {
        tags.add(tagRepository.findByName(name)
                .orElseGet(() -&gt; tagRepository.save(new Tag(name, now))));
    }
    post.replace(request.title(), request.content(), request.visibility(), tags, now);

    return new PostDetailResponse(post.getId(), post.getBoard().getSlug(), post.getTitle(),
            post.getContent(), post.getTags().stream().map(Tag::getName).toList(),
            post.getVisibility(),
            new AuthorResponse(post.getAuthor().getId(), post.getAuthor().getNickname()),
            post.getViewCount(), post.getLikeCount(), post.getCommentCount(), post.getCreatedAt());
}

@Transactional
public Post patch(Long id, AuthenticatedMember loginMember, PostUpdateRequest request) {
    Post post = postRepository.findById(id)
            .orElseThrow(PostNotFoundException::new);

    // 404(볼 수 없음)를 먼저 확인하고, 그다음에 403(작성자 아님)을 확인한다.
    // 반대로 하면 볼 수 없는 글의 존재가 403으로 드러난다.
    if (!accessPolicy.canView(loginMember, post)) {
        throw new PostNotFoundException();
    }
    if (!post.getAuthor().getId().equals(loginMember.id())) {
        throw new PostForbiddenException();
    }

    LocalDateTime now = LocalDateTime.now();

    if (request.title() != null) {
        validateTitle(request.title());
        post.changeTitle(request.title());
    }
    if (request.content() != null) {
        validateContent(request.content());
        post.changeContent(request.content());
    }
    if (request.tags() != null) {
        validateTags(request.tags());
        post.replaceTags(resolveTags(request.tags(), now));
    }
    if (request.visibility() != null) {
        validateVisibility(request.visibility());
        post.changeVisibility(request.visibility());
    }
    // boardSlug는 요청에 와도 무시한다(게시판은 못 옮긴다) — PostUpdateRequest에 아예 없다.

    post.touchUpdatedAt(now);

    // 트랜잭션 안에서 지연 로딩 연관을 미리 읽어 둔다(컨트롤러가 세션 밖에서 DTO를 만든다).
    // board는 findById로 읽은 프록시라 건드리지 않으면 LazyInitializationException이 난다
    // (create()의 board는 findBySlug로 이미 로딩된 엔티티라 같은 문제가 없었다).
    post.getBoard().getSlug();
    post.getAuthor().getNickname();
    post.getTags().forEach(Tag::getName);
    return post;
}

@Transactional
public void delete(Long id, AuthenticatedMember loginMember) {
    Post post = postRepository.findById(id)
            .orElseThrow(PostNotFoundException::new);

    // 404(볼 수 없음·이미 삭제됨) → 403(작성자도 운영자도 아님) 순서
    if (!accessPolicy.canView(loginMember, post)) {
        throw new PostNotFoundException();
    }
    boolean isAuthor = post.getAuthor().getId().equals(loginMember.id());
    boolean isAdmin = ADMIN_ROLE.equals(loginMember.role());
    if (!isAuthor &amp;&amp; !isAdmin) {
        throw new PostForbiddenException();
    }

    post.delete(LocalDateTime.now());
}

private void validateTitle(String title) {
    if (title.isBlank()) {
        throw new InvalidPostFieldException(&quot;title&quot;, &quot;제목을 입력해 주세요.&quot;);
    }
    if (title.length() &gt; TITLE_MAX_LENGTH) {
        throw new InvalidPostFieldException(&quot;title&quot;, &quot;제목은 &quot; + TITLE_MAX_LENGTH + &quot;자 이하여야 합니다.&quot;);
    }
}

private void validateContent(String content) {
    if (content.isBlank()) {
        throw new InvalidPostFieldException(&quot;content&quot;, &quot;본문을 입력해 주세요.&quot;);
    }
}

private void validateTags(List&lt;String&gt; tags) {
    if (tags.size() &gt; TAGS_MAX_COUNT) {
        throw new InvalidPostFieldException(&quot;tags&quot;, &quot;태그는 &quot; + TAGS_MAX_COUNT + &quot;개까지입니다.&quot;);
    }
    for (String tag : tags) {
        if (tag == null || tag.isBlank() || tag.length() &gt; TAG_NAME_MAX_LENGTH) {
            throw new InvalidPostFieldException(&quot;tags&quot;, &quot;태그 이름은 1~&quot; + TAG_NAME_MAX_LENGTH + &quot;자여야 합니다.&quot;);
        }
    }
}

private void validateVisibility(String visibility) {
    if (!&quot;PUBLIC&quot;.equals(visibility) &amp;&amp; !&quot;FOLLOWERS&quot;.equals(visibility)) {
        throw new InvalidPostFieldException(&quot;visibility&quot;, &quot;공개 범위는 PUBLIC 또는 FOLLOWERS여야 합니다.&quot;);
    }
}

// 이름으로 찾고 없으면 만든다. 요청 안의 중복은 제거한다(1-4/1-5와 같은 규칙, 3-1에서도 재사용).
private Set&lt;Tag&gt; resolveTags(List&lt;String&gt; tagNames, LocalDateTime now) {
    Set&lt;Tag&gt; tags = new LinkedHashSet&lt;&gt;();
    for (String tagName : distinctTagNames(tagNames)) {
        Tag tag = tagRepository.findByName(tagName)
                .orElseGet(() -&gt; tagRepository.save(new Tag(tagName, now)));
        tags.add(tag);
    }
    return tags;
}

private List&lt;String&gt; distinctTagNames(List&lt;String&gt; tags) {
    if (tags == null) {
        return List.of();
    }
    Set&lt;String&gt; seen = new LinkedHashSet&lt;&gt;(tags);
    return List.copyOf(seen);
}

@Transactional
public PostDetailResponse patch(Long id, AuthenticatedMember me, PostUpdateRequest request) {
    PostDetailRow current = visibilityMapper.findVisibleDetail(id, me.id(), me.role());
    if (current == null) throw new PostNotFoundException();
    if (!current.authorId.equals(me.id())) throw new PostForbiddenException();

    // 모든 입력을 확인한 뒤 쓰기를 시작한다.
    if (request.title() != null) validateTitle(request.title());
    if (request.content() != null) validateContent(request.content());
    if (request.tags() != null) validateTags(request.tags());
    if (request.visibility() != null) validateVisibility(request.visibility());

    List&lt;String&gt; tags;
    if (request.tags() == null) {
        tags = visibilityMapper.findTagsByPostIds(List.of(id)).stream()
                .map(PostTagRow::name).toList();
    } else {
        List&lt;PostReplaceTagRow&gt; resolved = new ArrayList&lt;&gt;();
        Set&lt;Long&gt; seenIds = new HashSet&lt;&gt;();
        for (String name : request.tags()) {
            replaceMapper.insertTagIfMissing(name);
            PostReplaceTagRow tag = replaceMapper.findTagByName(name);
            if (seenIds.add(tag.id)) resolved.add(tag);
        }
        replaceMapper.deletePostTags(id);
        for (PostReplaceTagRow tag : resolved) replaceMapper.insertPostTag(id, tag.id);
        tags = resolved.stream().map(tag -&gt; tag.name).toList();
    }
    replaceMapper.patchPost(id, request.title(), request.content(), request.visibility());
    return new PostDetailResponse(id, current.boardSlug,
            request.title() == null ? current.title : request.title(),
            request.content() == null ? current.content : request.content(),
            tags,
            request.visibility() == null ? current.visibility : request.visibility(),
            new AuthorResponse(current.authorId, current.authorNickname),
            current.viewCount, current.likeCount, current.commentCount, current.createdAt);
}
