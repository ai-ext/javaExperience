#3-0. PUT으로 게시글 전체 교체

#상황

"수정 화면에서 제목·본문·태그를 모두 다시 보냈어요. 서버도 그 값으로 글 전체를 바꿔 주세요."

1장에서 만든 글 하나를 PUT으로 전체 교체한다. 기존 PATCH 과제(3-1)는 보낸 칸만 바꾸지만, 여기서는 수정 폼의 새 상태를 모두 보낸다. 게시판은 이 API에서 옮기지 않는다.

#화면 시나리오

게시글 전체 수정

수정 폼의 제목·본문·태그·공개 범위를 한 번에 보낸다.

#만들 것

항목 계약
메서드·경로 PUT /api/posts/{id}. {id}는 수정할 글, 작성자는 토큰에서 가져온다.
요청 DTO title·content는 필수, tags는 생략 시 빈 목록, visibility는 생략 시 PUBLIC. boardSlug를 받아 게시판을 옮기지 않는다.
성공 200, 2-1의 상세 DTO 형식. id·작성자·게시판은 그대로이고 제목·본문·태그·공개 범위는 새 값이다.
실패 잘못된 필수값·태그·공개 범위 400, 토큰 없음 401, 보이는 남의 글 403, 없는/볼 수 없는 글 404.
저장 post 변경과 post_tag 연결 교체를 한 서비스 트랜잭션에서 처리한다. 검증 실패 시 두 테이블 모두 이전 상태다.

1-5의 길이 규칙(제목 1200, 태그 최대 5개·각 130)을 그대로 쓴다. 본문은 공백만이면 안 된다. 이 단계에서 {"title":"새 제목"}만 보내면 본문이 없어서 400이다. tags를 생략하거나 []로 보내면 기존 태그가 모두 빠진다. visibility를 생략하면 기존 값 유지가 아니라 PUBLIC이 된다. 이 동작이 3-1 PATCH와 다르다.

Controller는 @PathVariable·@Valid @RequestBody로 입력을 받고 상세 DTO를 돌려준다. DTO의 태그 목록을 엔티티에 직접 대입하기 전에 Service에서 태그 이름을 확인한다. 작성자 판단은 요청 본문의 authorId를 믿지 않고 1-6의 인증 결과로 한다. @Transactional 안에서 글 수정과 연결 행 교체를 끝낸다.

#구현 가이드

먼저 태그를 빼고 제목·본문·공개 범위의 전체 교체를 만든다. 그다음 태그 연결을 교체하고 실패 시 원상태가 유지되는지 확인한다.

Controller — 글 ID와 전체 요청 DTO 받기

기존 PostController의 /api/posts 아래에 PUT 매핑을 추가한다. 작성자는 본문이 아니라 토큰의 회원이다.

@PutMapping("/{id}")
public PostDetailResponse replace(@PathVariable Long id,
        @LoginMember AuthenticatedMember loginMember,
        @Valid @RequestBody PostReplaceRequest request) {
    return postService.replace(id, loginMember, request);
}

없는 글과 볼 수 없는 글을 404, 볼 수 있는 남의 글을 403으로 나누는 판단은 Service에 둔다.

DTO — 필수값과 생략 시 기본값

PATCH의 DTO를 재사용하지 않는다. PUT에는 제목과 본문이 항상 필요하다. 다음은 생략한 두 선택값을 정규화하는 부분이다.

public record PostReplaceRequest(
        @NotBlank @Size(max = 200) String title,
        @NotBlank String content,
        @Size(max = 5) List<@NotBlank @Size(max = 30) String> tags,
        @Pattern(regexp = "PUBLIC|FOLLOWERS") String visibility) {
    public PostReplaceRequest {
        tags = tags == null ? List.of() : tags;
        visibility = visibility == null ? "PUBLIC" : visibility;
    }
}

태그 개수·각 이름 길이와 공개 범위 허용값도 1-5의 규칙을 적용한다. 응답은 기존 2-1 상세 DTO를 쓴다.

MyBatis / Mapper — 글과 연결 태그를 한 트랜잭션에서 교체

전체 코드 접기의 MyBatis 대체 구현은 PostReplaceMyBatisService가 PUT을 받고, PostVisibilityMapper.findVisibleDetail로 먼저 가시성과 작성자를 확인한다. PostReplaceMapper는 태그 이름을 기존 ID로 정규화하고 아래 세 쓰기를 실행한다. @Transactional이 Service 메서드에 있으므로 중간 쓰기 실패 시 모두 롤백된다.

<update id="updatePost">
  UPDATE post SET title = #{title}, content = #{content},
                  visibility = #{visibility}, updated_at = CURRENT_TIMESTAMP
  WHERE id = #{id}
</update>
<delete id="deletePostTags">
  DELETE FROM post_tag WHERE post_id = #{postId}
</delete>
<insert id="insertPostTag">
  INSERT INTO post_tag(post_id, tag_id) VALUES (#{postId}, #{tagId})
</insert>

같은 이름을 대소문자만 바꿔 중복 전송해도 tag의 기존 행 하나만 연결한다. Mapper는 Tag의 DB 표기명과 ID를 읽고 중복 ID를 제거한다. 완전한 Service·Mapper Java/XML·테스트 파일은 이 가이드 뒤의 역할별 코드 접기에 있다.

Service — 권한 검사 후 한 트랜잭션에서 교체

@Transactional 메서드에서 글 조회·가시성·작성자·입력 태그를 쓰기 전에 확인한다. 그 뒤 제목·본문·공개 범위를 바꾸고 기존 태그 연결을 지운 다음 요청 태그만 연결한다. 본문에 authorId나 boardSlug가 있어도 작성자·게시판을 옮기지 않는다.

Post post = postRepository.findById(id).orElseThrow(PostNotFoundException::new);
// 먼저 2-3의 가시성 규칙을 적용한다.
if (!post.getAuthor().getId().equals(memberId)) {
    throw new ResponseStatusException(HttpStatus.FORBIDDEN);
}
// 요청값 전체를 검증한 뒤에만 post와 태그 연결을 바꾼다.

검증 실패 요청 V 뒤에 GET 요청 G가 여전히 새 제목·본문·java 태그를 돌려주는지 본다. 여러 테이블 중 하나에서 예외가 나면 트랜잭션 전체가 롤백되어야 한다.

JPA / Repository — 변경 감지와 연결 행 확인

관리 중인 Post 엔티티의 필드를 바꾸면 JPA가 flush할 때 post의 UPDATE를 만든다. 태그 연결 컬렉션을 교체하면 post_tag의 이전 연결이 빠지고 새 연결이 들어간다. 실제 SQL 순서는 매핑에 따라 다르므로 결과 행으로 확인한다.

SET @post_id = 22; -- 실제 생성 응답 id로 교체
SELECT p.id, p.title, p.content, p.visibility, p.author_id, p.board_id
FROM post p WHERE p.id = @post_id;
SELECT t.name FROM post_tag pt
JOIN tag t ON t.id = pt.tag_id
WHERE pt.post_id = @post_id ORDER BY t.name;

MyBatis라면 UPDATE post와 DELETE/INSERT post_tag를 같은 @Transactional Service 메서드에서 호출한다. 두 방식 모두 실패 후 결과가 같아야 한다.

package org.example.post;


import org.example.auth.AuthenticatedMember;
import org.example.board.Board;
import org.example.board.BoardNotFoundException;
import org.example.board.BoardRepository;
import org.example.board.BoardWriteForbiddenException;
import org.example.member.Member;
import org.example.member.MemberRepository;
import org.example.tag.Tag;
import org.example.tag.TagRepository;
import org.springframework.stereotype.Service;
import org.springframework.http.HttpStatus;
import org.springframework.transaction.annotation.Transactional;
import org.springframework.web.server.ResponseStatusException;


import java.time.LocalDateTime;
import java.util.LinkedHashSet;
import java.util.List;
import java.util.Set;


// 글 만들기 규칙. HTTP(ResponseEntity, 헤더 등)는 알지 않는다.
@Service
public class PostService {


private final PostRepository postRepository;
private final BoardRepository boardRepository;
private final MemberRepository memberRepository;
private final TagRepository tagRepository;
private final PostAccessPolicy postAccessPolicy;

public PostService(PostRepository postRepository, BoardRepository boardRepository,
                    MemberRepository memberRepository, TagRepository tagRepository,
                    PostAccessPolicy postAccessPolicy) {
    this.postRepository = postRepository;
    this.boardRepository = boardRepository;
    this.memberRepository = memberRepository;
    this.tagRepository = tagRepository;
    this.postAccessPolicy = postAccessPolicy;
}

private static final String ADMIN_WRITE_ROLE = &quot;ADMIN&quot;;
private static final String ADMIN_ROLE = &quot;ADMIN&quot;;
private static final String DEFAULT_VISIBILITY = &quot;PUBLIC&quot;;

@Transactional
public Post create(Long authorId, PostCreateRequest request) {
    Board board = boardRepository.findBySlug(request.boardSlug())
            .orElseThrow(() -&gt; new BoardNotFoundException(request.boardSlug()));
    // 작성자는 요청 본문이 아니라 토큰으로 인증된 회원에서 받는다(authorId 같은 값은 무시한다)
    Member author = memberRepository.getReferenceById(authorId);

    if (ADMIN_WRITE_ROLE.equals(board.getWriteRole()) &amp;&amp; !ADMIN_ROLE.equals(author.getRole())) {
        throw new BoardWriteForbiddenException(board.getSlug());
    }

    String visibility = request.visibility() != null ? request.visibility() : DEFAULT_VISIBILITY;
    LocalDateTime now = LocalDateTime.now();
    Post post = new Post(board, author, request.title(), request.content(),
            &quot;PUBLISHED&quot;, visibility, now);

    for (String tagName : distinctTagNames(request.tags())) {
        Tag tag = tagRepository.findByName(tagName)
                .orElseGet(() -&gt; tagRepository.save(new Tag(tagName, now)));
        post.addTag(tag);
    }

    Post saved = postRepository.save(post);
    // 트랜잭션(영속성 컨텍스트) 안에서 지연 로딩 연관을 미리 읽어 둔다.
    // open-in-view: false라서 컨트롤러가 트랜잭션 밖에서 건드리면 LazyInitializationException이 난다.
    saved.getAuthor().getNickname();
    saved.getTags().forEach(Tag::getName);
    return saved;
}

@Transactional
public Post copy(Long sourceId, Long authorId, boolean copyTags, CopyPostRequest request) {
    Post source = postRepository.findById(sourceId).orElseThrow(PostNotFoundException::new);
    if (source.getDeletedAt() != null || !&quot;PUBLISHED&quot;.equals(source.getStatus())
            || !&quot;PUBLIC&quot;.equals(source.getVisibility())) {
        throw new PostNotFoundException();
    }
    Member author = memberRepository.getReferenceById(authorId);
    if (ADMIN_WRITE_ROLE.equals(source.getBoard().getWriteRole())
            &amp;&amp; !ADMIN_ROLE.equals(author.getRole())) {
        throw new BoardWriteForbiddenException(source.getBoard().getSlug());
    }
    LocalDateTime now = LocalDateTime.now();
    Post copied = new Post(source.getBoard(), author, request.title(), source.getContent(),
            &quot;PUBLISHED&quot;, &quot;PUBLIC&quot;, now);
    if (copyTags) {
        source.getTags().forEach(copied::addTag);
    }
    Post saved = postRepository.save(copied);
    saved.getBoard().getSlug();
    saved.getAuthor().getNickname();
    saved.getTags().forEach(Tag::getName);
    return saved;
}

@Transactional
public PostDetailResponse replace(Long id, AuthenticatedMember me, PostReplaceRequest request) {
    Post post = postRepository.findById(id).orElseThrow(PostNotFoundException::new);
    if (!postAccessPolicy.canView(me, post)) {
        throw new PostNotFoundException();
    }

        tags.add(tagRepository.findByName(name)
                .orElseGet(() -&gt; tagRepository.save(new Tag(name, now))));
    }
    post.replace(request.title(), request.content(), request.visibility(), tags, now);

    return new PostDetailResponse(post.getId(), post.getBoard().getSlug(), post.getTitle(),
            post.getContent(), post.getTags().stream().map(Tag::getName).toList(),
            post.getVisibility(),
            new AuthorResponse(post.getAuthor().getId(), post.getAuthor().getNickname()),
            post.getViewCount(), post.getLikeCount(), post.getCommentCount(), post.getCreatedAt());
}

private List&lt;String&gt; distinctTagNames(List&lt;String&gt; tags) {
    if (tags == null) {
        return List.of();
    }
    Set&lt;String&gt; seen = new LinkedHashSet&lt;&gt;(tags);
    return List.copyOf(seen);

    private final PostVisibilityMapper visibilityMapper;
    private final PostReplaceMapper replaceMapper;

                                 PostReplaceMapper replaceMapper) {
    this.visibilityMapper = visibilityMapper;
    this.replaceMapper = replaceMapper;

@Transactional
public PostDetailResponse replace(Long id, AuthenticatedMember me, PostReplaceRequest request) {
    PostDetailRow current = visibilityMapper.findVisibleDetail(id, me.id(), me.role());
    if (current == null) {
        throw new PostNotFoundException();
    }
    if (!current.authorId.equals(me.id())) {
        throw new ResponseStatusException(HttpStatus.FORBIDDEN);
    }

    // 이름이 다른 대소문자 표기도 같은 tag 행으로 연결한다.
    List&lt;PostReplaceTagRow&gt; tags = new ArrayList&lt;&gt;();
    Set&lt;Long&gt; seenTagIds = new HashSet&lt;&gt;();
    for (String name : request.tags()) {
        replaceMapper.insertTagIfMissing(name);
        PostReplaceTagRow tag = replaceMapper.findTagByName(name);
        if (seenTagIds.add(tag.id)) {
            tags.add(tag);
        }
    }
    replaceMapper.updatePost(id, request.title(), request.content(), request.visibility());
    replaceMapper.deletePostTags(id);
    for (PostReplaceTagRow tag : tags) {
        replaceMapper.insertPostTag(id, tag.id);
    }
    return new PostDetailResponse(id, current.boardSlug, request.title(),
            request.content(), tags.stream().map(tag -&gt; tag.name).toList(),
            request.visibility(),
            new AuthorResponse(current.authorId, current.authorNickname),

@Component
@Intercepts(@Signature(type = Executor.class, method = "query",
        args = {MappedStatement.class, Object.class, RowBounds.class, ResultHandler.class}))
public class MyBatisStatementCounter implements Interceptor {
    private final ThreadLocal<Long> count = ThreadLocal.withInitial(() -> 0L);


@Override
public Object intercept(Invocation invocation) throws Throwable {
    count.set(count.get() + 1);
    return invocation.proceed();
}

public void clear() { count.set(0L); }
public long getCount() { return count.get(); }


}
