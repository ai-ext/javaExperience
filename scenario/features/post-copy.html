원본을 보존하고 새 id로 글 복사하기

1-8 원본 공개 글을 새 게시글로 복사하면서 새 id/작성자를 쓰고 선택한 경우에만 tag 연결을 복사한다.

이번에 할 일

post2를 title [복사실습] JPA 복습으로 복사해 copyTags true/false 결과를 비교하고 원본의 소유자·내용·태그가 그대로인지 확인한다.

시작 조건

  • post2는 public/published/undeleted이고 tags=[spring,jpa]다.
  • tok-kimjava로 일반 dev board에 작성 가능함을 확인하고 생성 전 post count와 source fields를 기록한다.

사용자 시나리오

  1. 시작
    post2 original owner/content/tags and post/tag relation counts를 기록한다.
    행동
    POST /api/posts/2/copies?copyTags=true with title [복사실습] JPA 복습, 이어 copyTags=false로 두 번째 복사한다.
    결과
    각 성공 201+Location 새 id; true copy는 tags [spring,jpa], false copy는 tags []; 새 글 author는 Kim, original fields unchanged.
    이후
    source missing/hidden/deleted/private, invalid copyTags, blank title, unauthorized board permission을 error contract와 no-insert로 확인.

데이터와 이유

source post2 fields/status/visibility/author/tags
복사 허용 조건과 원본 불변 비교.
new post id and Kim author_id
새 리소스가 원본 id/author를 재사용하지 않는지 확인.
copyTags true/false and post_tag associations
요청 옵션에 따른 연결만 새 글에 포함.
board write permission and response Location
source access와 새 생성 응답 검증.

업무 정책

  • POST /api/posts/{sourceId}/copies?copyTags=true|false; omitted copyTags defaults false. Body contains title only, 1..200 nonblank after trim.
  • source must be PUBLISHED+PUBLIC and not deleted; unreadable/missing source 404. Apply target board write permission again; unauthorized 403.
  • author comes from token. New entity/new id; do not reuse source id or author id. copyTags true shares tag associations; false creates no associations.
  • Post and post_tag writes are one transaction. Any failure leaves source and new rows unchanged.

입력과 출력

  • POST /api/posts/2/copies?copyTags=true body {title:"[복사실습] JPA 복습"}.
  • POST /api/posts/2/copies?copyTags=false body {title:"[복사실습] 태그 없이"}.
  • Failure copyTags=maybe, blank/missing title, no token, source ids 6/hidden or 999999; unauthorized board source.

성공 기준

  • 201 with Location /api/posts/{newId}; response title and new id.
  • true returns spring/jpa tags; false returns empty tags; author is token member2.
  • Original post2 content, status, owner, id, tags unchanged.

실패와 데이터 보존

  • copyTags=maybe or title missing/blank → 400. · 유지: post count and post_tag counts unchanged.
  • no token → 401. · 유지: no copied post/tag rows.
  • source missing/hidden/unpublished/deleted/private → 404. · 유지: source and new rows unchanged.
  • new author cannot write to source board → 403. · 유지: source unchanged and no target row.

입력 사례

  • Copy tags
  • Copy without tags
  • Bad option

개발 과제

  • Capture actual created ids from response Location.
  • Compare source and each copy fields and post_tag joins.
  • Run failure cases one at a time and check no partial insert.

완료 확인

  • source/new id and author separation confirmed.
  • true/false tag outcomes match query.
  • 400/401/403/404 failures leave source and new-row counts unchanged.

선택한 API 계약

POST/api/posts/2/copies?copyTags=true201

C1: HTTP 상태 201이어야 합니다. C1: JSON 경로 $.tags length 2이어야 합니다. C1: JSON 경로 $.tags[*] contains "spring"이어야 합니다. C1: JSON 경로 $.tags[*] contains "jpa"이어야 합니다. C1: JSON 경로 $.author.id equals 2이어야 합니다. C1: 응답 헤더 Location {"contains":"/api/posts/"}이어야 합니다.
