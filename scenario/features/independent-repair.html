  • messy-server 사본 경로·DB/포트·실행 명령·기준 상태를 기록한다. 원본 서버와 1단계 프로젝트는 보존한다.

  • 가설마다 로그·SQL·스택 중 확인한 증거와 배제 이유를 남긴다. 선택 티켓 원인은 정답 접기와 비교한 뒤 기록한다.

  • 이미 새 테스트가 모두 통과하면 D16으로 돌아가 통과 증거를 남기고 미충족 새 계약을 합의한다. 정상 코드를 약화하거나 기대값을 왜곡해 RED를 만들지 않는다.
  • 정상·실패·동시 요청 중 해당 티켓의 반례 2개와 관련 기존 테스트 결과를 남긴다.
  • 원인 서술·재현 테스트·수정 diff·수정 후 결과를 연결하고 D19에서 보강할 Java 공백 하나를 지목한다.
