실제 테이블에서 API의 SQL 수와 병목 찾기

그림 속 테이블이 아니라 접속한 DB의 실제 열·FK·인덱스에서 API 조회 경로와 N+1을 찾습니다.

  • 실제 목록 API가 없는 루트 앱을 이미 완성된 서버로 가정하지 않습니다.
