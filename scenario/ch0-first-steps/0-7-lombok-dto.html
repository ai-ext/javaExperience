#0-7. Lombok DTO — 생성된 메서드와 JSON 확인

#상황

"기존 프로젝트의 요청 DTO에는 필드와 @Getter만 보이는데, getName()은 어디 있죠? 같은 응답을 record로도 만들 수 있나요?"

0-4의 POST /api/start/profile을 그대로 사용한다. 이번에는 요청·응답 DTO를 Lombok 클래스로 바꾸고 record 버전과 요청/응답 결과를 비교한다. API 주소와 정상 응답 모양은 바꾸지 않는다. 이 과제는 Lombok을 사용하는 연습이며, 이후 모든 DTO에 Lombok을 쓰라는 뜻은 아니다.

#구현 가이드

먼저 0-4의 API를 실행해 응답을 기록하고, DTO의 작성법만 바꾼 뒤 같은 요청을 다시 보낸다. 필요한 부분을 하나씩 펼쳐 따라 한다.

DTO — Lombok 의존성과 요청·응답 클래스

실습 레포 build.gradle의 dependencies 안에 두 줄을 추가한다. compileOnly만 넣으면 생성 코드가 컴파일에 반영되지 않을 수 있다.

compileOnly 'org.projectlombok:lombok'
annotationProcessor 'org.projectlombok:lombok'

./gradlew compileJava로 확인한다. IntelliJ에서만 빨간 줄이면 IDE의 annotation processing 설정을 확인하고, 터미널 빌드 결과와 구분한다. 생성된 getter를 눈으로 보고 싶으면 javap -p build/classes/java/main/org/example/start/ProfileController\$ProfileRequest.class를 실행한다(중첩 클래스일 때의 예).

0-4에서 만든 ProfileController.java의 DTO를 다음처럼 바꾼다. 컨트롤러 안에 두면 static 클래스여야 한다. 필요한 import는 IDE에서 추가한다.

import jakarta.validation.constraints.Max;
import jakarta.validation.constraints.Min;
import jakarta.validation.constraints.NotBlank;
import jakarta.validation.constraints.NotNull;
import lombok.Getter;
import lombok.NoArgsConstructor;
import lombok.RequiredArgsConstructor;
import lombok.Setter;

@Getter @Setter @NoArgsConstructor
public static class ProfileRequest {
    @NotBlank private String name;
    @NotNull @Min(0) @Max(150) private Integer age;
}

@Getter @RequiredArgsConstructor
public static class ProfileResponse {
    private final String name;
    private final int age;
    private final boolean adult;
}

Integer를 쓴 이유는 나이가 빠지면 null로 받아 @NotNull이 400으로 거절하게 하기 위해서다. int와 setter를 쓰면 빠진 나이가 0으로 남아 성공할 수 있다. 응답 DTO는 final 필드와 @RequiredArgsConstructor로 생성자를 만든다. 요청 DTO와 응답 DTO를 같은 객체로 돌려주지 않는다.

@Builder는 필드가 많을 때 선택한다. @Builder.Default 없이 @Builder만 붙이면 필드에 쓴 초기값이 빌더 결과에 적용되지 않을 수 있다. 여기서는 필드가 세 개뿐이므로 빌더를 쓰지 않는다. 엔티티에는 @Data를 기본으로 붙이지 않는다. 생성되는 setter·equals·toString이 JPA 연관관계에 영향을 준다.

Controller — 검증한 DTO를 응답 DTO로 변환

0-4의 record에서는 request.name()을 불렀다. Lombok 클래스에서는 생성된 request.getName()을 부른다. @Getter와 달리 @Valid는 요청 필드의 유효성을 검사한다.

@PostMapping("/api/start/profile")
public ProfileResponse profile(@Valid @RequestBody ProfileRequest request) {
    return new ProfileResponse(
        request.getName(), request.getAge(), request.getAge() >= 19);
}

@Valid와 @RequestBody의 import를 확인하고 ./gradlew compileJava로 실제 생성된 getter가 컴파일되는지 본다.

package org.example.start;


import jakarta.validation.Valid;
import jakarta.validation.constraints.Max;
import jakarta.validation.constraints.Min;
import jakarta.validation.constraints.NotBlank;
import jakarta.validation.constraints.NotNull;
import lombok.Getter;
import lombok.NoArgsConstructor;
import lombok.RequiredArgsConstructor;
import lombok.Setter;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestBody;
import org.springframework.web.bind.annotation.RestController;


@RestController
public class ProfileController {


@Getter @Setter @NoArgsConstructor
public static class ProfileRequest {
    @NotBlank private String name;
    @NotNull @Min(0) @Max(150) private Integer age;
}

@Getter @RequiredArgsConstructor
public static class ProfileResponse {
    private final String name;
    private final int age;
    private final boolean adult;
}

@PostMapping(&quot;/api/start/profile&quot;)
public ProfileResponse profile(@Valid @RequestBody ProfileRequest request) {
    return new ProfileResponse(
            request.getName(), request.getAge(), request.getAge() &gt;= 19);
}


}

package org.example.start;


import org.junit.jupiter.api.Test;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.boot.test.context.SpringBootTest;
import org.springframework.boot.webmvc.test.autoconfigure.AutoConfigureMockMvc;
import org.springframework.test.web.servlet.MockMvc;


import static org.springframework.test.web.servlet.request.MockMvcRequestBuilders.post;
import static org.springframework.test.web.servlet.result.MockMvcResultMatchers.jsonPath;
import static org.springframework.test.web.servlet.result.MockMvcResultMatchers.status;


@SpringBootTest
@AutoConfigureMockMvc
class ProfileControllerTest {


@Autowired MockMvc mockMvc;

@Test
void sameJsonAsRecordVersion() throws Exception {
    mockMvc.perform(post(&quot;/api/start/profile&quot;)
                    .contentType(&quot;application/json&quot;)
                    .content(&quot;{\&quot;name\&quot;:\&quot;김자바\&quot;,\&quot;age\&quot;:20}&quot;))
            .andExpect(status().isOk())
            .andExpect(jsonPath(&quot;$.name&quot;).value(&quot;김자바&quot;))
            .andExpect(jsonPath(&quot;$.age&quot;).value(20))
            .andExpect(jsonPath(&quot;$.adult&quot;).value(true));
}

@Test
void missingOrInvalidFieldsReturn400() throws Exception {
    for (String body : new String[] {
            &quot;{\&quot;name\&quot;:\&quot; \&quot;,\&quot;age\&quot;:20}&quot;,
            &quot;{\&quot;name\&quot;:\&quot;김자바\&quot;}&quot;,
            &quot;{\&quot;name\&quot;:\&quot;김자바\&quot;,\&quot;age\&quot;:151}&quot;
    }) {
        mockMvc.perform(post(&quot;/api/start/profile&quot;)
                        .contentType(&quot;application/json&quot;).content(body))
                .andExpect(status().isBadRequest());
    }
}


}
