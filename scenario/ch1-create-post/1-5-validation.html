1-5 · 오류 응답

오류를 사람이 이해할 수 있게 돌려주세요.

검증 실패와 게시판 오류를 한 곳에서 처리하고, 잘못된 필드는 빠짐없이 알려 줍니다.

직접 수정 · ApiExceptionHandler.java
@RestControllerAdvice
class ApiExceptionHandler {
    // 검증 실패와 게시판 오류를
    // ProblemDetail로 변환하세요.
}

컨트롤러마다 try-catch를 복제하지 않습니다.

400 · application/problem+json · 기대 형태
{
  "status": 400,
  "detail": "요청 값을 확인해 주세요.",
  "errors": [
    { "field": "title", "message": "..." },
    { "field": "content", "message": "..." }
  ]
}

한 요청에 두 필드가 틀리면 errors에도 둘 다 있어야 합니다.

프론트 화면이 빈 제목을 막아 줘도, API는 curl·Postman·다른 서비스 누구나 호출할 수 있다. 지금은 빈 제목도, 없는 게시판도 그대로 들어오거나 500이 난다. 1-2~1-4의 관찰 항목(O)에서 직접 본 그대로다.

잘못된 요청은 저장 전에 막고, 무엇이 왜 틀렸는지 정해진 형식으로 알려 준다.

입력 규칙

필드 규칙
boardSlug 필수
title 필수, 공백만 있으면 안 됨, 200자 이하
content 필수, 공백만 있으면 안 됨
tags 없어도 됨(null이나 []). 있으면 최대 5개, 각 이름 1~30자

게시판 규칙

상황 상태
없는 boardSlug 404
글쓰기가 운영자 전용인 게시판(board.write_role = 'ADMIN', 예: notice)에 일반 회원(지금은 작성자 고정 = 김자바)이 쓴다 403

에러 응답 형식 — 모든 에러(400·403·404)에 공통이다. 표준 형식인 RFC 9457 Problem Details를 쓴다.

  • Content-Type: application/problem+json
  • 본문에 status(숫자)와 사람이 읽을 detail을 담는다.
  • Bean Validation으로 거절한 400이면 errors 배열에 틀린 필드를 모두 담는다. 첫 번째 필드만 담으면 안 된다. JSON 문법 오류처럼 요청 본문을 읽지 못한 400은 필드별 검증이 실행되지 않았으므로 errors를 생략한다.

import jakarta.servlet.http.HttpServletRequest;
import org.example.board.BoardNotFoundException;
import org.example.board.BoardWriteForbiddenException;
import org.springframework.http.HttpStatus;
import org.springframework.http.ProblemDetail;
import org.springframework.http.converter.HttpMessageNotReadableException;
import org.springframework.web.bind.MethodArgumentNotValidException;
import org.springframework.web.bind.annotation.ExceptionHandler;
import org.springframework.web.bind.annotation.RestControllerAdvice;

import java.net.URI;
import java.util.List;
import java.util.Map;

// 모든 컨트롤러의 에러 응답을 한 곳에서 RFC 9457 Problem Details로 만든다.
// 컨트롤러마다 try-catch를 두지 않는다.
@RestControllerAdvice
public class ApiExceptionHandler {

    @ExceptionHandler(MethodArgumentNotValidException.class)
    public ProblemDetail handleValidation(MethodArgumentNotValidException ex, HttpServletRequest request) {
        ProblemDetail problem = ProblemDetail.forStatusAndDetail(HttpStatus.BAD_REQUEST, "입력값이 올바르지 않습니다.");
        problem.setInstance(URI.create(request.getRequestURI()));
        List<Map<String, String>> errors = ex.getBindingResult().getFieldErrors().stream()
                .map(fieldError -> Map.of(
                        "field", fieldError.getField(),
                        "message", fieldError.getDefaultMessage() == null ? "" : fieldError.getDefaultMessage()
                ))
                .toList();
        problem.setProperty("errors", errors);
        return problem;
    }

    @ExceptionHandler(HttpMessageNotReadableException.class)
    public ProblemDetail handleUnreadable(HttpServletRequest request) {
        ProblemDetail problem = ProblemDetail.forStatusAndDetail(HttpStatus.BAD_REQUEST, "요청 본문을 읽을 수 없습니다.");
        problem.setInstance(URI.create(request.getRequestURI()));
        return problem;
    }

    @ExceptionHandler(BoardNotFoundException.class)
    public ProblemDetail handleBoardNotFound(BoardNotFoundException ex, HttpServletRequest request) {
        ProblemDetail problem = ProblemDetail.forStatusAndDetail(HttpStatus.NOT_FOUND, ex.getMessage());
        problem.setInstance(URI.create(request.getRequestURI()));
        return problem;
    }

    @ExceptionHandler(BoardWriteForbiddenException.class)
    public ProblemDetail handleBoardWriteForbidden(BoardWriteForbiddenException ex, HttpServletRequest request) {
        ProblemDetail problem = ProblemDetail.forStatusAndDetail(HttpStatus.FORBIDDEN, ex.getMessage());
        problem.setInstance(URI.create(request.getRequestURI()));
        return problem;
    }
}

package org.example.post;

import org.example.board.Board;
import org.example.board.BoardNotFoundException;
import org.example.board.BoardRepository;
import org.example.board.BoardWriteForbiddenException;
import org.example.member.Member;
import org.example.member.MemberRepository;
import org.example.tag.Tag;
import org.example.tag.TagRepository;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

import java.time.LocalDateTime;
import java.util.LinkedHashSet;
import java.util.List;
import java.util.Set;

// 글 만들기 규칙. HTTP(ResponseEntity, 헤더 등)는 알지 않는다.
@Service
public class PostService {

    // 로그인 기능이 없는 동안 작성자를 고정한다 — 1-6에서 토큰 기반으로 바꾼다
    private static final long FIXED_AUTHOR_ID = 2L;

    private final PostRepository postRepository;
    private final BoardRepository boardRepository;
    private final MemberRepository memberRepository;
    private final TagRepository tagRepository;

    public PostService(PostRepository postRepository, BoardRepository boardRepository,
                        MemberRepository memberRepository, TagRepository tagRepository) {
        this.postRepository = postRepository;
        this.boardRepository = boardRepository;
        this.memberRepository = memberRepository;
        this.tagRepository = tagRepository;
    }

    private static final String ADMIN_WRITE_ROLE = "ADMIN";
    private static final String ADMIN_ROLE = "ADMIN";
    private static final String DEFAULT_VISIBILITY = "PUBLIC";

    @Transactional
    public Post create(PostCreateRequest request) {
        Board board = boardRepository.findBySlug(request.boardSlug())
                .orElseThrow(() -> new BoardNotFoundException(request.boardSlug()));
        Member author = memberRepository.getReferenceById(FIXED_AUTHOR_ID);

        if (ADMIN_WRITE_ROLE.equals(board.getWriteRole()) && !ADMIN_ROLE.equals(author.getRole())) {
            throw new BoardWriteForbiddenException(board.getSlug());
        }

        String visibility = request.visibility() != null ? request.visibility() : DEFAULT_VISIBILITY;
        LocalDateTime now = LocalDateTime.now();
        Post post = new Post(board, author, request.title(), request.content(),
                "PUBLISHED", visibility, now);

        for (String tagName : distinctTagNames(request.tags())) {
            Tag tag = tagRepository.findByName(tagName)
                    .orElseGet(() -> tagRepository.save(new Tag(tagName, now)));
            post.addTag(tag);
        }

        Post saved = postRepository.save(post);
        // 트랜잭션(영속성 컨텍스트) 안에서 지연 로딩 연관을 미리 읽어 둔다.
        // open-in-view: false라서 컨트롤러가 트랜잭션 밖에서 건드리면 LazyInitializationException이 난다.
        saved.getAuthor().getNickname();
        saved.getTags().forEach(Tag::getName);
        return saved;
    }

    private List<String> distinctTagNames(List<String> tags) {
        if (tags == null) {
            return List.of();
        }
        Set<String> seen = new LinkedHashSet<>(tags);
        return List.copyOf(seen);
    }
}

package org.example.post;

import org.example.board.BoardNotFoundException;
import org.example.board.BoardWriteForbiddenException;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

import java.time.LocalDateTime;
import java.util.LinkedHashMap;
import java.util.LinkedHashSet;
import java.util.List;
import java.util.Map;
import java.util.Set;

// 게시판·작성자 확인부터 글·태그 연결까지 Mapper SQL로 실행한다.
@Service
public class PostService {
    private static final long FIXED_AUTHOR_ID = 2L;
    private static final String ADMIN_ROLE = "ADMIN";
    private static final String DEFAULT_VISIBILITY = "PUBLIC";
    private final PostCreationMapper mapper;

    public PostService(PostCreationMapper mapper) {
        this.mapper = mapper;
    }

    @Transactional
    public PostResponse create(PostCreateRequest request) {
        BoardWriteRow board = mapper.findBoardBySlug(request.boardSlug());
        if (board == null) {
            throw new BoardNotFoundException(request.boardSlug());
        }
        // 로그인 도입 전이므로 작성자는 고정 회원이다. 1-6에서 토큰 주인으로 바꾼다.
        AuthorWriteRow author = mapper.findAuthorById(FIXED_AUTHOR_ID);
        if (author == null) {
            throw new IllegalStateException("인증된 작성자를 찾을 수 없습니다.");
        }
        if (ADMIN_ROLE.equals(board.writeRole) && !ADMIN_ROLE.equals(author.role)) {
            throw new BoardWriteForbiddenException(board.slug);
        }

        PostInsert post = new PostInsert();
        post.boardId = board.id;
        post.authorId = author.id;
        post.title = request.title();
        post.content = request.content();
        post.visibility = request.visibility() == null ? DEFAULT_VISIBILITY : request.visibility();
        post.now = LocalDateTime.now();
        mapper.insertPost(post);

        Map<Long, String> storedTags = new LinkedHashMap<>();
        for (String tagName : distinctTagNames(request.tags())) {
            mapper.insertTagIfAbsent(tagName, post.now);
            TagWriteRow tag = mapper.findTagByName(tagName);
            if (!storedTags.containsKey(tag.id)) {
                mapper.linkTag(post.id, tag.id);
                storedTags.put(tag.id, tag.name);
            }
        }
        return new PostResponse(post.id, board.slug, post.title, post.content,
                List.copyOf(storedTags.values()), post.visibility,
                new AuthorResponse(author.id, author.nickname), post.now);
    }

    private List<String> distinctTagNames(List<String> tags) {
        if (tags == null) {
            return List.of();
        }
        Set<String> seen = new LinkedHashSet<>(tags);
        return List.copyOf(seen);
    }
}

힌트 1 — 어떤 예외가 나나


V4의 SECRET은 지금 String 필드의 @Pattern에 걸리므로 MethodArgumentNotValidException이 난다. 깨진 JSON처럼 요청을 객체로 만들 수 없으면 HttpMessageNotReadableException이 난다. 서로 다른 예외라 Advice에서 각각 처리한다.






힌트 2 — problem+json


ProblemDetail.forStatusAndDetail(HttpStatus.BAD_REQUEST, "...")로 만들고 setProperty("errors", 목록). @ExceptionHandler 메서드가 ProblemDetail을 반환하면 Spring이 application/problem+json으로 내보낸다. ResponseEntityExceptionHandler를 상속하는 방법도 있다.






힌트 3 — 403과 404


board.write_role이 ADMIN인데 작성자 member.role이 ADMIN이 아니면 403. 이 판단은 서비스에서 하고, 예외 → 상태 코드 매핑은 Advice에서 한다.
