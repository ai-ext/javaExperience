#응답 DTO는 class부터


첫 구현은 일반 Java 클래스로 필드·생성자·getter를 직접 확인한다. 아래는 PostResponse.java 전체 코드다.


package org.example.post;

import java.time.LocalDateTime;

public class PostResponse {
    private final Long id;
    private final String boardSlug;
    private final String title;
    private final String content;
    private final String visibility;
    private final LocalDateTime createdAt;

    public PostResponse(Long id, String boardSlug, String title, String content,
                        String visibility, LocalDateTime createdAt) {
        this.id = id;
        this.boardSlug = boardSlug;
        this.title = title;
        this.content = content;
        this.visibility = visibility;
        this.createdAt = createdAt;
    }

    public Long getId() { return id; }
    public String getBoardSlug() { return boardSlug; }
    public String getTitle() { return title; }
    public String getContent() { return content; }
    public String getVisibility() { return visibility; }
    public LocalDateTime getCreatedAt() { return createdAt; }
}


Spring Boot의 Jackson은 getter를 읽어 같은 JSON 응답을 만든다. 필드는 final이고 setter가 없으므로 필드에 다른 값을 다시 대입할 수 없다. 다만 List 같은 참조 필드가 있으면 내부 요소까지 자동으로 불변이 되는 것은 아니다. 생성자에 전달한 필드가 곧 API 응답 계약이다.


Java 21에서는 같은 DTO를 record로 간결하게 쓸 수도 있다.


package org.example.post;

import java.time.LocalDateTime;

public record PostResponse(
        Long id,
        String boardSlug,
        String title,
        String content,
        String visibility,
        LocalDateTime createdAt
) {
}


record는 구성 요소, 생성자, 접근자, equals·hashCode·toString을 만들어 주며, 구성 요소 참조를 다시 대입할 수 없게 하는 얕은 불변 데이터 표현이다. List 구성 요소를 둬도 그 목록 내부가 자동으로 불변이 되지는 않는다.


응답 DTO처럼 값을 담아 전달할 때 보일러플레이트가 적어 실무에서 편리하다. 우선 class 버전으로 필드와 생성자 관계를 익힌 뒤 record를 선택할 수 있다. 이 단계의 전체 답안 토글은 class 버전을 기준으로 한다.

                saved.getVisibility(),
                saved.getCreatedAt()

package org.example.post;

import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestBody;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RestController;

import java.net.URI;
import java.time.LocalDateTime;

@RestController
@RequestMapping("/api/posts")
public class PostController {
    private static final Logger log = LoggerFactory.getLogger(PostController.class);
    private static final long FIXED_AUTHOR_ID = 2L;
    private final PostCreationMapper mapper;

    public PostController(PostCreationMapper mapper) {
        this.mapper = mapper;
    }

    @PostMapping
    public ResponseEntity<PostResponse> create(@RequestBody PostCreateRequest request) {
        log.info("게시글 작성 요청 제목: {}", request.title());
        BoardWriteRow board = mapper.findBoardBySlug(request.boardSlug());
        if (board == null) {
            throw new IllegalArgumentException("게시판을 찾을 수 없습니다: " + request.boardSlug());
        }
        PostInsert post = new PostInsert();
        post.boardId = board.id;
        post.authorId = FIXED_AUTHOR_ID;
        post.title = request.title();
        post.content = request.content();
        post.visibility = request.visibility();
        post.now = LocalDateTime.now();
        mapper.insertPost(post);
        PostResponse response = new PostResponse(post.id, board.slug, post.title, post.content,
                post.visibility, post.now);
        return ResponseEntity.created(URI.create("/api/posts/" + post.id)).body(response);
    }
