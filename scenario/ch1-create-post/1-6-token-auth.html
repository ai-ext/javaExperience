지금은 누가 보내도 작성자가 김자바다. 실제 서비스에서는 사용자가 로그인한 뒤 받은 토큰을 요청 헤더에 실어 보낸다.

로그인과 토큰 발급은 이번에 만들지 않는다. 토큰은 이미 발급되어 api_token 테이블에 있다고 가정하고, 요청에 실려 온 토큰의 주인을 작성자로 정한다.

02◇무엇을 만들까만들 것요청 헤더 — Authorization: Bearer <토큰>열기 ↓

요청 헤더 — Authorization: Bearer <토큰>

토큰 주인 결과
tok-kimjava 2 김자바 정상
tok-lee 3 이스프링 정상
tok-admin 1 운영자(ADMIN) 정상 — 공지 게시판에 쓸 수 있다
tok-kimjava-old 2 김자바 만료(expires_at = 2026-01-01)
tok-kimjava-revoked 2 김자바 폐기(revoked_at 있음)
tok-choi 5 최정지 토큰은 유효하지만 회원이 정지(SUSPENDED)

규칙

상황 응답
헤더 없음 / Bearer 형식이 아님 / 없는 토큰 / 만료 / 폐기 401, application/problem+json, 응답 헤더 WWW-Authenticate: Bearer
토큰은 유효한데 회원이 ACTIVE가 아님 403, application/problem+json
정상 작성자 = 토큰 주인. 응답 author도 토큰 주인
  • 인증을 먼저 본다. 토큰이 없으면 본문이 잘못돼도 401이다(400이 아님).
  • 요청 본문에 "authorId" 같은 값이 와도 무시한다. 작성자를 클라이언트가 정하게 두면 남의 이름으로 글을 쓸 수 있다.
  • 1-5의 공지 게시판 규칙(운영자만)은 이제 토큰 주인 기준이다.
  • 만료는 "지금 시각 ≥ expires_at"이다.
  • CORS 사전 요청(preflight, OPTIONS)은 토큰 확인에서 뺀다. 브라우저는 토큰을 싣기 전에 OPTIONS로 먼저 묻는데, 이것까지 막으면 1-1에서 연 CORS가 무너져 브라우저 API 실행 화면이 전부 "CORS로 막혔어요"가 된다. 인터셉터 맨 앞에서 CorsUtils.isPreFlightRequest(request)면 통과시킨다.
03⌘어떻게 만들까구현 가이드화면 시나리오의 서버·DB 흐름을 이 단계에서 바뀐 파일에 연결한다. 먼저 만들 것 의 계약대로 직접 작성하고, 필요한 역할만 펼쳐 파일 전문과 비교한다.열기 ↓

화면 시나리오의 서버·DB 흐름을 이 단계에서 바뀐 파일에 연결한다. 먼저 만들 것의 계약대로 직접 작성하고, 필요한 역할만 펼쳐 파일 전문과 비교한다.

이 단계의 처리 흐름:

  • 토큰 확인(인터셉터·ArgumentResolver 등 한 곳): Bearer 형식 → 토큰 조회 → 만료·폐기·회원 상태 확인
  • 작성자 = 토큰 주인(3, 이스프링). 본문에 authorId가 와도 무시한다
  • 토큰 확인에서 막힌다 — 본문은 아예 읽지 않는다(그래서 본문이 깨져도 401)
  • 토큰은 유효하다 — 누구인지는 안다. 하지만 회원 상태가 SUSPENDED → 403
Controller — HTTP 연결

AuthInterceptor.java, PostController.java. 매핑과 메서드의 입력·응답을 위 만들 것의 HTTP 계약과 대조한다. 변경된 메서드: preHandle, create.

Service — 처리 순서

PostService.java. 위 서버 처리 순서가 어디에서 검증·조회·상태 변경으로 이어지는지 따라간다. 변경된 메서드: create. 트랜잭션 경계는 아래 코드의 @Transactional 위치에서 확인한다.

JPA / Repository — DB 조건

ApiTokenRepository.java. 쿼리·파생 메서드의 조건을 화면 시나리오의 DB 단계 및 직접 확인 SQL과 대조한다. 직접 작성한 JPQL·SQL과 아래 파일의 @Query를 비교한다.

MyBatis — 토큰 조회와 글·태그 저장 대체 경로

아래 MyBatis 대체 구현 코드 접기를 선택해 기본 JPA 스냅샷에 15개 파일 변경을 적용한다. AuthTokenMapper.xml은 api_token과 member를 JOIN해 만료·폐기·회원 상태를 한 번에 읽는다.

토큰 원문은 결과 DTO와 로그에 싣지 않는다. PostCreationMapper.xml은 게시판의 write_role과 인증된 작성자를 조회하고, post INSERT의 생성 키로 tag와 post_tag를 연결한다.

태그 ID와 DB에 저장된 이름으로 중복 연결을 막고 응답을 만든다. PostService의 @Transactional이 글·태그 저장을 한 트랜잭션으로 묶는다.

PostController는 요청의 authorId를 읽지 않고 인터셉터가 확인한 회원 ID만 전달한다. JPA와 MyBatis 양쪽에서 T1~T11 및 D1·D2를 같은 계약으로 확인한다.

Entity — 테이블·상태

ApiToken.java. 실제 테이블의 컬럼·외래키와 엔티티 매핑을 대조한다.

AuthenticationRequiredException.java, MemberNotActiveException.java, ApiExceptionHandler.java. 예외가 어떤 HTTP 상태와 오류 본문으로 바뀌는지 실패 계약과 대조한다. 변경된 메서드: handleAuthenticationRequired, handleMemberNotActive.

package org.example.auth;


import jakarta.persistence.Column;
import jakarta.persistence.Entity;
import jakarta.persistence.FetchType;
import jakarta.persistence.GeneratedValue;
import jakarta.persistence.GenerationType;
import jakarta.persistence.Id;
import jakarta.persistence.JoinColumn;
import jakarta.persistence.ManyToOne;
import jakarta.persistence.Table;
import org.example.member.Member;


import java.time.LocalDateTime;


// api_token 테이블 — 로그인 기능 대신 미리 발급해 둔 토큰. Authorization: Bearer <token>
@Entity
@Table(name = "api_token")
public class ApiToken {


@Id
@GeneratedValue(strategy = GenerationType.IDENTITY)
private Long id;

@Column(nullable = false, unique = true)
private String token;

@ManyToOne(fetch = FetchType.LAZY)
@JoinColumn(name = &quot;member_id&quot;, nullable = false)
private Member member;

@Column(name = &quot;expires_at&quot;, nullable = false)
private LocalDateTime expiresAt;

@Column(name = &quot;revoked_at&quot;)
private LocalDateTime revokedAt;

@Column(name = &quot;created_at&quot;, nullable = false)
private LocalDateTime createdAt;

protected ApiToken() {
    // JPA
}

public Long getId() {
    return id;
}

public String getToken() {
    return token;
}

public Member getMember() {
    return member;
}

public LocalDateTime getExpiresAt() {
    return expiresAt;
}

public LocalDateTime getRevokedAt() {
    return revokedAt;
}

public LocalDateTime getCreatedAt() {
    return createdAt;
}


}

package org.example.auth;


import jakarta.servlet.http.HttpServletRequest;
import jakarta.servlet.http.HttpServletResponse;
import org.example.member.Member;
import org.springframework.http.HttpHeaders;
import org.springframework.http.HttpMethod;
import org.springframework.stereotype.Component;
import org.springframework.web.cors.CorsUtils;
import org.springframework.web.servlet.HandlerInterceptor;


import java.time.Clock;
import java.time.LocalDateTime;


// /api/** 요청의 토큰을 한 곳에서 확인한다(컨트롤러마다 반복하지 않는다).
// GET이고 헤더가 없으면 비로그인으로 통과시킨다(2-1에서 필요).
@Component
public class AuthInterceptor implements HandlerInterceptor {


public static final String LOGIN_MEMBER_ATTRIBUTE = &quot;loginMember&quot;;
private static final String BEARER_PREFIX = &quot;Bearer &quot;;
private static final String ACTIVE_STATUS = &quot;ACTIVE&quot;;

private final ApiTokenRepository apiTokenRepository;
private final Clock clock;

public AuthInterceptor(ApiTokenRepository apiTokenRepository, Clock clock) {
    this.apiTokenRepository = apiTokenRepository;
    this.clock = clock;
}

@Override
public boolean preHandle(HttpServletRequest request, HttpServletResponse response, Object handler) {
    // CORS 사전 요청(OPTIONS)은 토큰 없이 온다 — 막으면 브라우저의 요청이 전부 CORS로 실패한다
    if (CorsUtils.isPreFlightRequest(request)) {
        return true;
    }

    String header = request.getHeader(HttpHeaders.AUTHORIZATION);
    boolean isGet = HttpMethod.GET.matches(request.getMethod());

    if (header == null) {
        if (isGet) {
            return true;
        }
        throw new AuthenticationRequiredException(&quot;인증이 필요합니다.&quot;);
    }
    if (!header.startsWith(BEARER_PREFIX)) {
        throw new AuthenticationRequiredException(&quot;인증이 필요합니다.&quot;);
    }

    String token = header.substring(BEARER_PREFIX.length()).trim();
    ApiToken apiToken = apiTokenRepository.findByTokenFetchMember(token)
            .orElseThrow(() -&gt; new AuthenticationRequiredException(&quot;인증이 필요합니다.&quot;));

    LocalDateTime now = LocalDateTime.now(clock);
    boolean expired = !now.isBefore(apiToken.getExpiresAt());
    if (apiToken.getRevokedAt() != null || expired) {
        throw new AuthenticationRequiredException(&quot;인증이 필요합니다.&quot;);
    }

    Member member = apiToken.getMember();
    if (!ACTIVE_STATUS.equals(member.getMemberStatus())) {
        throw new MemberNotActiveException(&quot;정지되었거나 탈퇴한 회원입니다.&quot;);
    }

    request.setAttribute(LOGIN_MEMBER_ATTRIBUTE,
            new AuthenticatedMember(member.getId(), member.getNickname(), member.getRole()));
    return true;
}

import org.springframework.transaction.annotation.Transactional;

import java.util.List;
import java.util.Set;


// 글 만들기 규칙. HTTP(ResponseEntity, 헤더 등)는 알지 않는다.
@Service
public class PostService {


private final PostRepository postRepository;
private final BoardRepository boardRepository;
private final MemberRepository memberRepository;
private final TagRepository tagRepository;

public PostService(PostRepository postRepository, BoardRepository boardRepository,
                    MemberRepository memberRepository, TagRepository tagRepository) {
    this.postRepository = postRepository;
    this.boardRepository = boardRepository;
    this.memberRepository = memberRepository;
    this.tagRepository = tagRepository;
}

private static final String ADMIN_WRITE_ROLE = &quot;ADMIN&quot;;
private static final String ADMIN_ROLE = &quot;ADMIN&quot;;
private static final String DEFAULT_VISIBILITY = &quot;PUBLIC&quot;;

@Transactional
public Post create(Long authorId, PostCreateRequest request) {
    Board board = boardRepository.findBySlug(request.boardSlug())
            .orElseThrow(() -&gt; new BoardNotFoundException(request.boardSlug()));
    // 작성자는 요청 본문이 아니라 토큰으로 인증된 회원에서 받는다(authorId 같은 값은 무시한다)
    Member author = memberRepository.getReferenceById(authorId);

    if (ADMIN_WRITE_ROLE.equals(board.getWriteRole()) &amp;&amp; !ADMIN_ROLE.equals(author.getRole())) {
        throw new BoardWriteForbiddenException(board.getSlug());
    }

    String visibility = request.visibility() != null ? request.visibility() : DEFAULT_VISIBILITY;
    LocalDateTime now = LocalDateTime.now();
    Post post = new Post(board, author, request.title(), request.content(),
            &quot;PUBLISHED&quot;, visibility, now);

    for (String tagName : distinctTagNames(request.tags())) {
        Tag tag = tagRepository.findByName(tagName)
                .orElseGet(() -&gt; tagRepository.save(new Tag(tagName, now)));
        post.addTag(tag);
    }

    Post saved = postRepository.save(post);
    // 트랜잭션(영속성 컨텍스트) 안에서 지연 로딩 연관을 미리 읽어 둔다.
    // open-in-view: false라서 컨트롤러가 트랜잭션 밖에서 건드리면 LazyInitializationException이 난다.
    saved.getAuthor().getNickname();
    saved.getTags().forEach(Tag::getName);
    return saved;
}

private List&lt;String&gt; distinctTagNames(List&lt;String&gt; tags) {
    if (tags == null) {
        return List.of();
    }
    Set&lt;String&gt; seen = new LinkedHashSet&lt;&gt;(tags);
    return List.copyOf(seen);
}


}

package org.example.auth;


import jakarta.servlet.http.HttpServletRequest;
import jakarta.servlet.http.HttpServletResponse;
import org.springframework.http.HttpHeaders;
import org.springframework.http.HttpMethod;
import org.springframework.stereotype.Component;
import org.springframework.web.cors.CorsUtils;
import org.springframework.web.servlet.HandlerInterceptor;


import java.time.Clock;
import java.time.LocalDateTime;


// /api/** 요청의 토큰을 한 곳에서 확인한다(컨트롤러마다 반복하지 않는다).
// GET이고 헤더가 없으면 비로그인으로 통과시킨다(2-1에서 필요).
@Component
public class AuthInterceptor implements HandlerInterceptor {


public static final String LOGIN_MEMBER_ATTRIBUTE = &quot;loginMember&quot;;
private static final String BEARER_PREFIX = &quot;Bearer &quot;;
private static final String ACTIVE_STATUS = &quot;ACTIVE&quot;;

private final AuthTokenMapper authTokenMapper;
private final Clock clock;

public AuthInterceptor(AuthTokenMapper authTokenMapper, Clock clock) {
    this.authTokenMapper = authTokenMapper;
    this.clock = clock;
}

@Override
public boolean preHandle(HttpServletRequest request, HttpServletResponse response, Object handler) {
    // CORS 사전 요청(OPTIONS)은 토큰 없이 온다 — 막으면 브라우저의 요청이 전부 CORS로 실패한다
    if (CorsUtils.isPreFlightRequest(request)) {
        return true;
    }

    String header = request.getHeader(HttpHeaders.AUTHORIZATION);
    boolean isGet = HttpMethod.GET.matches(request.getMethod());

    if (header == null) {
        if (isGet) {
            return true;
        }
        throw new AuthenticationRequiredException(&quot;인증이 필요합니다.&quot;);
    }
    if (!header.startsWith(BEARER_PREFIX)) {
        throw new AuthenticationRequiredException(&quot;인증이 필요합니다.&quot;);
    }

    String token = header.substring(BEARER_PREFIX.length()).trim();
    AuthTokenRow tokenRow = authTokenMapper.findByToken(token);
    if (tokenRow == null) {
        throw new AuthenticationRequiredException(&quot;인증이 필요합니다.&quot;);
    }

    LocalDateTime now = LocalDateTime.now(clock);
    boolean expired = !now.isBefore(tokenRow.expiresAt);
    if (tokenRow.revokedAt != null || expired) {
        throw new AuthenticationRequiredException(&quot;인증이 필요합니다.&quot;);
    }

    if (!ACTIVE_STATUS.equals(tokenRow.memberStatus)) {
        throw new MemberNotActiveException(&quot;정지되었거나 탈퇴한 회원입니다.&quot;);
    }

    request.setAttribute(LOGIN_MEMBER_ATTRIBUTE,
            new AuthenticatedMember(tokenRow.memberId, tokenRow.nickname, tokenRow.role));
    return true;
}


}

import org.example.board.BoardNotFoundException;
import org.example.board.BoardWriteForbiddenException;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;


import java.time.LocalDateTime;
import java.util.LinkedHashMap;
import java.util.LinkedHashSet;
import java.util.List;
import java.util.Map;
import java.util.Set;


// 게시판·작성자 확인부터 글·태그 연결까지 Mapper SQL로 실행한다.
@Service
public class PostService {
    private static final String ADMIN_ROLE = "ADMIN";
    private static final String DEFAULT_VISIBILITY = "PUBLIC";
    private final PostCreationMapper mapper;


public PostService(PostCreationMapper mapper) {
    this.mapper = mapper;
}

@Transactional
public PostResponse create(Long authorId, PostCreateRequest request) {
    BoardWriteRow board = mapper.findBoardBySlug(request.boardSlug());
    if (board == null) {
        throw new BoardNotFoundException(request.boardSlug());
    }
    // authorId는 요청 JSON이 아니라 AuthInterceptor가 확인한 토큰에서 왔다.
    AuthorWriteRow author = mapper.findAuthorById(authorId);
    if (author == null) {
        throw new IllegalStateException(&quot;인증된 작성자를 찾을 수 없습니다.&quot;);
    }
    if (ADMIN_ROLE.equals(board.writeRole) &amp;&amp; !ADMIN_ROLE.equals(author.role)) {
        throw new BoardWriteForbiddenException(board.slug);
    }

    PostInsert post = new PostInsert();
    post.boardId = board.id;
    post.authorId = author.id;
    post.title = request.title();
    post.content = request.content();
    post.visibility = request.visibility() == null ? DEFAULT_VISIBILITY : request.visibility();
    post.now = LocalDateTime.now();
    mapper.insertPost(post);

    Map&lt;Long, String&gt; storedTags = new LinkedHashMap&lt;&gt;();
    for (String tagName : distinctTagNames(request.tags())) {
        mapper.insertTagIfAbsent(tagName, post.now);
        TagWriteRow tag = mapper.findTagByName(tagName);
        if (!storedTags.containsKey(tag.id)) {
            mapper.linkTag(post.id, tag.id);
            storedTags.put(tag.id, tag.name);
        }
    }
    return new PostResponse(post.id, board.slug, post.title, post.content,
            List.copyOf(storedTags.values()), post.visibility,
            new AuthorResponse(author.id, author.nickname), post.now);
}

private List&lt;String&gt; distinctTagNames(List&lt;String&gt; tags) {
    if (tags == null) {
        return List.of();
    }
    Set&lt;String&gt; seen = new LinkedHashSet&lt;&gt;(tags);
    return List.copyOf(seen);
}


}

힌트 1 — 어디서 확인할까


HandlerInterceptor의 preHandle은 컨트롤러 메서드의 매개변수(@RequestBody)를 만들기 전에 실행된다. 그래서 C9(깨진 본문 + 토큰 없음 → 401)를 맞추기 쉽다.


확인한 회원은 request.setAttribute(...)로 넘긴다. /api/**에 적용하되 0장의 공개 실습 API /api/start/**는 excludePathPatterns로 뺀다(WebMvcConfigurer.addInterceptors).


/hello도 /api/** 밖이라 대상이 아니다. 2-1부터는 로그인 없이 보는 GET이 생기므로, "GET이고 Authorization 헤더가 없으면 통과"를 지금 넣어 두거나 2-1에서 고친다(헤더가 있는데 틀리면 GET이라도 401). 



힌트 2 — 컨트롤러에서 회원 받기


@LoginMember 같은 애노테이션을 만들고 HandlerMethodArgumentResolver로 그 매개변수에 회원을 넣어 주면 컨트롤러가 create(@LoginMember LoginMember me, @Valid @RequestBody PostCreateRequest req)처럼 깔끔해진다.
