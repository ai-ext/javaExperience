#1-8. 기존 글 복사 생성 — 경로·쿼리·본문을 함께

#상황

"공개된 글을 바탕으로 새 글을 쓰고 싶어요. 제목은 새로 정하고, 태그는 복사할 수도 있어요."

1-1~1-6의 일반 글 생성은 본문 DTO에 새 글의 값을 모두 담았다. 이번에는 원본 ID는 경로, 태그 복사 여부는 쿼리, 새 제목은 본문 DTO, 작성자는 토큰에서 가져온다. 같은 POST라도 입력의 출처와 저장할 관계 행이 달라진다.

#만들 것

항목 계약
메서드·경로 `POST /api/posts/{sourceId}/copies?copyTags=true
요청 DTO { "title": "..." }만 받는다. 1-5와 같이 공백 아닌 1~200자. 본문·게시판·태그 ID·작성자 ID는 본문에서 받지 않는다.
새 글 원본의 content·board를 복사한다. 새 제목·토큰 작성자, PUBLISHED·PUBLIC, 현재 시각을 쓴다. 좋아요·댓글·조회 수는 0이다. 원본은 수정하지 않는다.
태그 copyTags=true면 원본 post_tag가 가리키는 태그들을 새 글에 연결한다. false면 새 글의 태그는 빈 목록이다.
성공 201, Location: /api/posts/{newId}, 1-2의 생성 응답 DTO. 원본 ID와 새 ID는 달라야 한다.
실패 제목 누락/공백·copyTags 형식 오류 400; 토큰 없음 401; 공지처럼 새 작성자에게 쓰기 권한이 없는 게시판 403; 원본이 없거나 비공개·미발행·삭제됨 404.

Controller는 @PathVariable Long sourceId, @RequestParam(defaultValue="false") boolean copyTags, @Valid @RequestBody CopyPostRequest를 받는다. CopyPostRequest에는 제목만 둔다.

Service는 원본을 읽어 status=PUBLISHED, visibility=PUBLIC, deletedAt=null을 확인하고 1-6의 게시판 쓰기 권한도 다시 적용한 뒤 새 Post를 만든다. 원본을 그대로 save()하면 ID와 작성자까지 재사용되므로 새 엔티티에 복사할 필드만 채운다.

@Transactional 안에서 새 글과 태그 연결을 저장한다. 생성 응답 DTO의 author는 원본 작성자가 아닌 토큰 회원이다.

2-3에서 팔로워·차단에 따른 조회 권한을 배운다. 이 단계에서는 누구나 볼 수 있는 PUBLIC 원본만 복사 가능하게 하여 조건을 단순하게 시작한다. 이후 더 넓은 복사 권한을 만들 때 2-3의 접근 규칙을 재사용한다.

#구현 가이드

원본을 읽어 새 글을 만드는 순서로 작업한다. 처음에는 copyTags=false로 글 한 행을 만들고, 그다음 태그 연결을 같은 트랜잭션에 붙인다.

Controller — 경로·쿼리·본문·토큰을 분리해 받기

네 값의 출처가 다르다. sourceId는 경로, copyTags는 쿼리, 제목은 DTO, 새 작성자는 기존 @LoginMember에서 읽는다.

@PostMapping("/{sourceId}/copies")
public ResponseEntity<PostResponse> copy(
        @PathVariable Long sourceId,
        @RequestParam(defaultValue = "false") boolean copyTags,
        @LoginMember AuthenticatedMember loginMember,
        @Valid @RequestBody CopyPostRequest request) {
    Post copied = postService.copy(sourceId, loginMember.id(), copyTags, request);
    return ResponseEntity.created(URI.create("/api/posts/" + copied.getId()))
            .body(toResponse(copied));
}

기존 PostController가 클래스 경로 @RequestMapping("/api/posts")를 갖는 경우의 조각이다. toResponse는 1-2의 생성 응답 변환을 재사용한다.

DTO — 새 제목만 검증

본문 DTO에 authorId, boardSlug, tags를 추가하지 않는다. 이 값들은 원본·토큰·쿼리에서 결정된다.

public record CopyPostRequest(
        @NotBlank @Size(max = 200) String title
) { }

기존 제목 규칙에 맞춰 공백을 다듬는 위치도 확인한다. JSON에 제목이 없거나 공백뿐이면 저장 전에 400이어야 한다.

Service — 공개 원본·쓰기 권한·트랜잭션

@Transactional 메서드 안에서 원본을 조회하고 deletedAt, status, visibility를 검사한다. 원본 게시판의 쓰기 권한을 토큰 회원에게 다시 적용한다. 통과한 뒤 새 Post를 생성하고, copyTags=true일 때만 원본의 태그를 연결한다.

Post source = postRepository.findById(sourceId)
        .orElseThrow(() -> new ResponseStatusException(
                HttpStatus.NOT_FOUND, "원본 글을 찾을 수 없습니다."));
if (source.getDeletedAt() != null || !"PUBLISHED".equals(source.getStatus())
        || !"PUBLIC".equals(source.getVisibility())) {
    throw new ResponseStatusException(HttpStatus.NOT_FOUND, "원본 글을 찾을 수 없습니다.");
}
// 여기에서 source.board의 쓰기 권한과 토큰 작성자의 역할을 확인한다.

권한 실패 때는 post도 post_tag도 새 행이 없어야 한다. 원본 객체의 ID나 작성자를 바꾸지 않는다. PostNotFoundException은 2-1에서 만들므로 지금은 Spring의 ResponseStatusException으로 404를 돌려준다.

JPA / Repository — 새 엔티티와 태그 연결 저장

원본 Post를 다시 save()하지 않는다. 기존 엔티티 생성자와 태그 연결 메서드를 이용해 새 객체에 복사할 필드만 넣는다.

Post copied = new Post(source.getBoard(), author, request.title(),
        source.getContent(), "PUBLISHED", "PUBLIC", LocalDateTime.now());
if (copyTags) source.getTags().forEach(copied::addTag);
Post saved = postRepository.save(copied);

SQL 로그에서 새 post 한 행과 copyTags=true일 때의 post_tag 연결을 확인한다.

MyBatis — 공개 원본을 읽고 새 글·태그 연결을 저장하기

아래 MyBatis 대체 구현 코드의 16개 파일을 이 단계 전체 소스에 적용한다. 1-6의 토큰 조회·일반 글 생성 Mapper 경로도 함께 포함한다. Controller는 sourceId(경로), copyTags(쿼리), CopyPostRequest.title(본문), 작성자 ID(토큰)를 각각 서비스로 넘긴다.

findCopySourceById는 post와 board를 JOIN해 공개 상태·삭제 여부·본문·게시판 쓰기 역할을 CopySourceRow로 읽는다. 없거나 PUBLISHED/PUBLIC이 아니거나 삭제된 원본은 404, 작성자의 게시판 쓰기 권한이 없으면 403이다.

새 PostInsert에는 원본의 boardId·content, 요청의 새 제목, 토큰 회원 ID, 새 시각을 담는다. insertPost의 useGeneratedKeys가 돌려준 새 ID로만 연결 행을 만든다. 원본 행은 UPDATE하지 않는다.

copyTags=true일 때만 findTagsByPostId로 원본의 태그 ID·DB 저장 이름을 읽고 새 글의 post_tag에 연결한다. false면 태그 조회·연결을 건너뛴다. 서비스 @Transactional 안에서 새 글과 연결을 함께 저장하므로 중간 SQL 실패 시 둘 다 되돌아간다. JPA와 MyBatis 각각 C1~C7, D1에서 새 글 두 행의 작성자·본문·태그 수와 원본 불변을 대조한다.

@PostMapping
public ResponseEntity&lt;PostResponse&gt; create(@LoginMember AuthenticatedMember loginMember,
                                            @Valid @RequestBody PostCreateRequest request) {
    log.info(&quot;게시글 작성 요청 제목: {}&quot;, request.title());

    Post post = postService.create(loginMember.id(), request);

@PostMapping(&quot;/{sourceId}/copies&quot;)
public ResponseEntity&lt;PostResponse&gt; copy(@PathVariable Long sourceId,
                                         @RequestParam(defaultValue = &quot;false&quot;) boolean copyTags,
                                         @LoginMember AuthenticatedMember loginMember,
                                         @Valid @RequestBody CopyPostRequest request) {
    Post post = postService.copy(sourceId, loginMember.id(), copyTags, request);
    return ResponseEntity.created(URI.create(&quot;/api/posts/&quot; + post.getId()))
            .body(toResponse(post));
}

private PostResponse toResponse(Post post) {
    List&lt;String&gt; tagNames = post.getTags().stream().map(Tag::getName).toList();
    AuthorResponse author = new AuthorResponse(post.getAuthor().getId(), post.getAuthor().getNickname());
    return new PostResponse(
            post.getId(),
            post.getBoard().getSlug(),
            post.getTitle(),
            post.getContent(),
            tagNames,
            post.getVisibility(),
            author,
            post.getCreatedAt()
    );
}


}

Service / 규칙 — src/main/java/org/example/post/PostService.java
package org.example.post;


import org.example.board.Board;
import org.example.board.BoardNotFoundException;
import org.example.board.BoardRepository;
import org.example.board.BoardWriteForbiddenException;
import org.example.member.Member;
import org.example.member.MemberRepository;
import org.example.tag.Tag;
import org.example.tag.TagRepository;
import org.springframework.stereotype.Service;
import org.springframework.http.HttpStatus;
import org.springframework.web.server.ResponseStatusException;
import org.springframework.transaction.annotation.Transactional;


import java.time.LocalDateTime;
import java.util.LinkedHashSet;
import java.util.List;
import java.util.Set;


// 글 만들기 규칙. HTTP(ResponseEntity, 헤더 등)는 알지 않는다.
@Service
public class PostService {


private final PostRepository postRepository;
private final BoardRepository boardRepository;
private final MemberRepository memberRepository;
private final TagRepository tagRepository;

public PostService(PostRepository postRepository, BoardRepository boardRepository,
                    MemberRepository memberRepository, TagRepository tagRepository) {
    this.postRepository = postRepository;
    this.boardRepository = boardRepository;
    this.memberRepository = memberRepository;
    this.tagRepository = tagRepository;
}

private static final String ADMIN_WRITE_ROLE = &quot;ADMIN&quot;;
private static final String ADMIN_ROLE = &quot;ADMIN&quot;;
private static final String DEFAULT_VISIBILITY = &quot;PUBLIC&quot;;

@Transactional
public Post create(Long authorId, PostCreateRequest request) {
    Board board = boardRepository.findBySlug(request.boardSlug())
            .orElseThrow(() -&gt; new BoardNotFoundException(request.boardSlug()));
    // 작성자는 요청 본문이 아니라 토큰으로 인증된 회원에서 받는다(authorId 같은 값은 무시한다)
    Member author = memberRepository.getReferenceById(authorId);

    if (ADMIN_WRITE_ROLE.equals(board.getWriteRole()) &amp;&amp; !ADMIN_ROLE.equals(author.getRole())) {
        throw new BoardWriteForbiddenException(board.getSlug());
    }

    String visibility = request.visibility() != null ? request.visibility() : DEFAULT_VISIBILITY;
    LocalDateTime now = LocalDateTime.now();
    Post post = new Post(board, author, request.title(), request.content(),
            &quot;PUBLISHED&quot;, visibility, now);

    for (String tagName : distinctTagNames(request.tags())) {
        Tag tag = tagRepository.findByName(tagName)
                .orElseGet(() -&gt; tagRepository.save(new Tag(tagName, now)));
        post.addTag(tag);
    }

    Post saved = postRepository.save(post);
    // 트랜잭션(영속성 컨텍스트) 안에서 지연 로딩 연관을 미리 읽어 둔다.
    // open-in-view: false라서 컨트롤러가 트랜잭션 밖에서 건드리면 LazyInitializationException이 난다.
    saved.getAuthor().getNickname();
    saved.getTags().forEach(Tag::getName);
    return saved;
}

@Transactional
public Post copy(Long sourceId, Long authorId, boolean copyTags, CopyPostRequest request) {
    Post source = postRepository.findById(sourceId).orElseThrow(() -&gt; new ResponseStatusException(HttpStatus.NOT_FOUND, &quot;원본 글을 찾을 수 없습니다.&quot;));
    if (source.getDeletedAt() != null || !&quot;PUBLISHED&quot;.equals(source.getStatus())
            || !&quot;PUBLIC&quot;.equals(source.getVisibility())) {
        throw new ResponseStatusException(HttpStatus.NOT_FOUND, &quot;원본 글을 찾을 수 없습니다.&quot;);
    }
    Member author = memberRepository.getReferenceById(authorId);
    if (ADMIN_WRITE_ROLE.equals(source.getBoard().getWriteRole())
            &amp;&amp; !ADMIN_ROLE.equals(author.getRole())) {
        throw new BoardWriteForbiddenException(source.getBoard().getSlug());
    }
    LocalDateTime now = LocalDateTime.now();
    Post copied = new Post(source.getBoard(), author, request.title(), source.getContent(),
            &quot;PUBLISHED&quot;, &quot;PUBLIC&quot;, now);
    if (copyTags) {
        source.getTags().forEach(copied::addTag);
    }
    Post saved = postRepository.save(copied);
    saved.getBoard().getSlug();
    saved.getAuthor().getNickname();
    saved.getTags().forEach(Tag::getName);
    return saved;
}

private List&lt;String&gt; distinctTagNames(List&lt;String&gt; tags) {
    if (tags == null) {
        return List.of();
    }
    Set&lt;String&gt; seen = new LinkedHashSet&lt;&gt;(tags);
    return List.copyOf(seen);
}


}

package org.example.auth;


import jakarta.servlet.http.HttpServletRequest;
import jakarta.servlet.http.HttpServletResponse;
import org.springframework.http.HttpHeaders;
import org.springframework.http.HttpMethod;
import org.springframework.stereotype.Component;
import org.springframework.web.cors.CorsUtils;
import org.springframework.web.servlet.HandlerInterceptor;


import java.time.Clock;
import java.time.LocalDateTime;


// /api/** 요청의 토큰을 한 곳에서 확인한다(컨트롤러마다 반복하지 않는다).
// GET이고 헤더가 없으면 비로그인으로 통과시킨다(2-1에서 필요).
@Component
public class AuthInterceptor implements HandlerInterceptor {


public static final String LOGIN_MEMBER_ATTRIBUTE = &quot;loginMember&quot;;
private static final String BEARER_PREFIX = &quot;Bearer &quot;;
private static final String ACTIVE_STATUS = &quot;ACTIVE&quot;;

private final AuthTokenMapper authTokenMapper;
private final Clock clock;

public AuthInterceptor(AuthTokenMapper authTokenMapper, Clock clock) {
    this.authTokenMapper = authTokenMapper;
    this.clock = clock;
}

@Override
public boolean preHandle(HttpServletRequest request, HttpServletResponse response, Object handler) {
    // CORS 사전 요청(OPTIONS)은 토큰 없이 온다 — 막으면 브라우저의 요청이 전부 CORS로 실패한다
    if (CorsUtils.isPreFlightRequest(request)) {
        return true;
    }

    String header = request.getHeader(HttpHeaders.AUTHORIZATION);
    boolean isGet = HttpMethod.GET.matches(request.getMethod());

    if (header == null) {
        if (isGet) {
            return true;
        }
        throw new AuthenticationRequiredException(&quot;인증이 필요합니다.&quot;);
    }
    if (!header.startsWith(BEARER_PREFIX)) {
        throw new AuthenticationRequiredException(&quot;인증이 필요합니다.&quot;);
    }

    String token = header.substring(BEARER_PREFIX.length()).trim();
    AuthTokenRow tokenRow = authTokenMapper.findByToken(token);
    if (tokenRow == null) {
        throw new AuthenticationRequiredException(&quot;인증이 필요합니다.&quot;);
    }

    LocalDateTime now = LocalDateTime.now(clock);
    boolean expired = !now.isBefore(tokenRow.expiresAt);
    if (tokenRow.revokedAt != null || expired) {
        throw new AuthenticationRequiredException(&quot;인증이 필요합니다.&quot;);
    }

    if (!ACTIVE_STATUS.equals(tokenRow.memberStatus)) {
        throw new MemberNotActiveException(&quot;정지되었거나 탈퇴한 회원입니다.&quot;);
    }

    request.setAttribute(LOGIN_MEMBER_ATTRIBUTE,
            new AuthenticatedMember(tokenRow.memberId, tokenRow.nickname, tokenRow.role));
    return true;
}


}

package org.example.post;


import org.example.board.BoardNotFoundException;
import org.example.board.BoardWriteForbiddenException;
import org.springframework.stereotype.Service;
import org.springframework.http.HttpStatus;
import org.springframework.web.server.ResponseStatusException;
import org.springframework.transaction.annotation.Transactional;


import java.time.LocalDateTime;
import java.util.LinkedHashMap;
import java.util.LinkedHashSet;
import java.util.List;
import java.util.Map;
import java.util.Set;


// 게시판·작성자 확인부터 글·태그 연결까지 Mapper SQL로 실행한다.
@Service
public class PostService {
    private static final String ADMIN_ROLE = "ADMIN";
    private static final String DEFAULT_VISIBILITY = "PUBLIC";
    private final PostCreationMapper mapper;


public PostService(PostCreationMapper mapper) {
    this.mapper = mapper;
}

@Transactional
public PostResponse create(Long authorId, PostCreateRequest request) {
    BoardWriteRow board = mapper.findBoardBySlug(request.boardSlug());
    if (board == null) {
        throw new BoardNotFoundException(request.boardSlug());
    }
    // authorId는 요청 JSON이 아니라 AuthInterceptor가 확인한 토큰에서 왔다.
    AuthorWriteRow author = mapper.findAuthorById(authorId);
    if (author == null) {
        throw new IllegalStateException(&quot;인증된 작성자를 찾을 수 없습니다.&quot;);
    }
    if (ADMIN_ROLE.equals(board.writeRole) &amp;&amp; !ADMIN_ROLE.equals(author.role)) {
        throw new BoardWriteForbiddenException(board.slug);
    }

    PostInsert post = new PostInsert();
    post.boardId = board.id;
    post.authorId = author.id;
    post.title = request.title();
    post.content = request.content();
    post.visibility = request.visibility() == null ? DEFAULT_VISIBILITY : request.visibility();
    post.now = LocalDateTime.now();
    mapper.insertPost(post);

    Map&lt;Long, String&gt; storedTags = new LinkedHashMap&lt;&gt;();
    for (String tagName : distinctTagNames(request.tags())) {
        mapper.insertTagIfAbsent(tagName, post.now);
        TagWriteRow tag = mapper.findTagByName(tagName);
        if (!storedTags.containsKey(tag.id)) {
            mapper.linkTag(post.id, tag.id);
            storedTags.put(tag.id, tag.name);
        }
    }
    return new PostResponse(post.id, board.slug, post.title, post.content,
            List.copyOf(storedTags.values()), post.visibility,
            new AuthorResponse(author.id, author.nickname), post.now);
}


@Transactional
public PostResponse copy(Long sourceId, Long authorId, boolean copyTags, CopyPostRequest request) {
    CopySourceRow source = mapper.findCopySourceById(sourceId);
    if (source == null || source.deletedAt != null || !&quot;PUBLISHED&quot;.equals(source.status)
            || !&quot;PUBLIC&quot;.equals(source.visibility)) {
        throw new ResponseStatusException(HttpStatus.NOT_FOUND, &quot;원본 글을 찾을 수 없습니다.&quot;);
    }
    AuthorWriteRow author = mapper.findAuthorById(authorId);
    if (author == null) {
        throw new IllegalStateException(&quot;인증된 작성자를 찾을 수 없습니다.&quot;);
    }
    if (ADMIN_ROLE.equals(source.writeRole) &amp;&amp; !ADMIN_ROLE.equals(author.role)) {
        throw new BoardWriteForbiddenException(source.slug);
    }
    PostInsert copied = new PostInsert();
    copied.boardId = source.boardId;
    copied.authorId = author.id;
    copied.title = request.title();
    copied.content = source.content;
    copied.visibility = DEFAULT_VISIBILITY;
    copied.now = LocalDateTime.now();
    mapper.insertPost(copied);

    List&lt;String&gt; tagNames = List.of();
    if (copyTags) {
        List&lt;TagWriteRow&gt; sourceTags = mapper.findTagsByPostId(sourceId);
        for (TagWriteRow tag : sourceTags) {
            mapper.linkTag(copied.id, tag.id);
        }
        tagNames = sourceTags.stream().map(tag -&gt; tag.name).toList();
    }
    return new PostResponse(copied.id, source.slug, copied.title, copied.content,
            tagNames, copied.visibility, new AuthorResponse(author.id, author.nickname), copied.now);
}

private List&lt;String&gt; distinctTagNames(List&lt;String&gt; tags) {
    if (tags == null) {
        return List.of();
    }
    Set&lt;String&gt; seen = new LinkedHashSet&lt;&gt;(tags);
    return List.copyOf(seen);
}
