#9-3. 컬럼 추가와 백필

학습용 DB(practice) — 앱을 practice 프로파일로 띄운다.

#상황

"목록에 제목만 있으니 심심해요. 본문 앞부분을 한두 줄 미리 보여 주세요."

목록 쿼리에서 매번 content(TEXT, 긴 글은 8천 자)를 읽어 자르면 무겁다(2-2에서 본문을 목록에서 뺀 이유). 그래서 미리 잘라 둔 요약 컬럼을 만든다. 이미 있는 글 145개에도 값을 채워야 한다(백필). 그리고 앞으로 만들거나 고치는 글도 요약이 맞게 유지돼야 한다.

#화면 시나리오

사용자가 화면에서 무엇을 하면 어떤 요청이 서버로 가고, 서버·DB에서 무슨 일이 일어나 어떤 응답이 돌아와 화면이 어떻게 바뀌는지다. 흐름을 펼치면 사용자 행동부터 응답까지 차례대로 볼 수 있다.

#구현 가이드

화면 시나리오의 서버·DB 흐름을 이 단계에서 바뀐 파일에 연결한다. 먼저 만들 것의 계약대로 직접 작성하고, 필요한 역할만 펼쳐 파일 전문과 비교한다.

이 단계의 처리 흐름:

  • Flyway V3가 컬럼을 추가하고 기존 행을 채운 뒤 NOT NULL을 적용한다.
  • 목록·검색은 본문 content(TEXT) 대신 excerpt만 조회하고, 태그는 페이지의 글 ID로 한 번 더 가져온다.
  • JPA는 엔티티의 changeContent에서, MyBatis는 공통 SQL 조각에서 본문과 요약을 함께 바꾼다.
Controller — 기존 요청 경로

BoardPostController.list의 GET /api/boards/{slug}/posts와 PostSearchController의 GET /api/posts/search는 PostQueryService로 이어진다. 작성 POST /api/posts, 전체 수정 PUT /api/posts/{id}, 부분 수정 PATCH /api/posts/{id}는 기존 PostController의 계약을 그대로 사용한다. 이 단계는 응답과 저장 규칙을 바꾸므로 컨트롤러를 중복 작성할 필요가 없다.

DTO — 요청·응답 필드

Service — 처리 순서

PostQueryService.java는 게시판 목록과 검색에 같은 PostSearchRepository.search를 쓴다. @Transactional(readOnly = true) 안에서 조회 결과를 응답 DTO로 바꾸고, 태그는 findTagsByPostIds 한 번으로 모은다.

JPA Repository — 본문을 읽지 않는 목록 투영

PostSearchRepository.java의 CriteriaQuery<PostListRow>는 목록에 필요한 열만 선택한다. content가 이 선택 목록에 없다는 점을 확인한다. Page의 건수는 별도 COUNT로 세며 태그는 선택된 글 ID의 IN 쿼리로 읽는다.

        post.get("likeCount"), post.get("commentCount"), post.get("viewCount"),
        post.get("publishedAt")));
Entity — 테이블·상태

Post.java의 생성자와 changeContent가 같은 계산을 쓴다. 전체 수정 replace도 changeContent(content)를 호출해야 한다. Java는 코드 포인트 기준으로 잘라 MySQL의 LEFT(content, 100)과 맞춘다.

@Column(nullable = false, length = 120)

    this.content = content;

Flyway / SQL — 스키마 변경

V3__add_post_excerpt.sql은 이미 저장된 글을 위한 마이그레이션이다. 기존 값이 채워진 것을 확인한 뒤 NOT NULL을 적용한다.

ALTER TABLE post ADD COLUMN excerpt VARCHAR(120) NULL AFTER content;
UPDATE post SET excerpt = LEFT(content, 100);
ALTER TABLE post MODIFY COLUMN excerpt VARCHAR(120) NOT NULL;
MyBatis Mapper — 조회와 본문 수정

이 단계의 MyBatis 대체 앱은 글 작성 POST와 복사 POST /{sourceId}/copies에 기존 JPA PostService를 사용한다. 생성자의 excerptOf가 작성 시 요약을 계산한다. MyBatis가 맡는 게시판 목록·검색과 PATCH·PUT은 다음 Mapper를 쓴다. PostVisibilityMapper.xml의 목록·검색 SELECT에는 p.excerpt를 넣고 p.content는 넣지 않는다. PostReplaceMapper.xml은 PATCH와 PUT에서 같은 SQL 조각을 사용하며, PATCH의 content: null은 그 조각을 실행하지 않는다.

    CriteriaBuilder cb = em.getCriteriaBuilder();

    CriteriaQuery&lt;PostListRow&gt; query = cb.createQuery(PostListRow.class);
    Root&lt;Post&gt; post = query.from(Post.class);
    query.select(cb.construct(PostListRow.class,
                    post.get(&quot;id&quot;), post.get(&quot;title&quot;), post.get(&quot;excerpt&quot;),
                    post.get(&quot;author&quot;).get(&quot;id&quot;), post.get(&quot;author&quot;).get(&quot;nickname&quot;),
                    post.get(&quot;likeCount&quot;), post.get(&quot;commentCount&quot;), post.get(&quot;viewCount&quot;),
                    post.get(&quot;publishedAt&quot;)))
            .where(conditions(cb, query, post, cond, viewerId))
            .orderBy(cb.desc(post.get(&quot;publishedAt&quot;)), cb.desc(post.get(&quot;id&quot;)));
    CriteriaQuery&lt;Long&gt; countQuery = cb.createQuery(Long.class);
    Root&lt;Post&gt; countRoot = countQuery.from(Post.class);
    countQuery.select(cb.count(countRoot))
            .where(conditions(cb, countQuery, countRoot, cond, viewerId));
    long total = em.createQuery(countQuery).getSingleResult();

    // 전체 건수를 먼저 확인해야 큰 page의 long offset을 int로 잘라 이전 글을 재노출하지 않는다.
    long offset = pageable.getOffset();
    if (offset &gt;= total) {
        return new PageImpl&lt;&gt;(List.of(), pageable, total);
    }
    if (offset &gt; Integer.MAX_VALUE) {
        throw new InvalidSearchConditionException(&quot;요청한 페이지가 너무 큽니다.&quot;);
    }
    List&lt;PostListRow&gt; content = em.createQuery(query)
            .setFirstResult((int) offset)
            .setMaxResults(pageable.getPageSize())
            .getResultList();
    return new PageImpl&lt;&gt;(content, pageable, total);
}

private Predicate[] conditions(CriteriaBuilder cb, CriteriaQuery&lt;?&gt; query, Root&lt;Post&gt; post,
                               PostSearchCondition cond, Long viewerId) {
    List&lt;Predicate&gt; predicates = new ArrayList&lt;&gt;(viewable(cb, query, post, viewerId));

    if (cond.boardId() != null) {
        predicates.add(cb.equal(post.get(&quot;board&quot;).get(&quot;id&quot;), cond.boardId()));
    }
    if (cond.authorId() != null) {
        predicates.add(cb.equal(post.get(&quot;author&quot;).get(&quot;id&quot;), cond.authorId()));
    }
    if (cond.from() != null) {
        predicates.add(cb.greaterThanOrEqualTo(post.get(&quot;publishedAt&quot;), cond.from().atStartOfDay()));
    }
    if (cond.to() != null &amp;&amp; !cond.to().equals(LocalDate.of(9999, 12, 31))) { // 최대 DB 날짜는 상한을 생략한다.
        predicates.add(cb.lessThan(post.get(&quot;publishedAt&quot;), cond.to().plusDays(1).atStartOfDay()));
    }
    if (cond.q() != null &amp;&amp; !cond.q().isBlank()) {
        String pattern = &quot;%&quot; + escapeLike(cond.q().strip().toLowerCase()) + &quot;%&quot;;
        predicates.add(cb.like(cb.lower(post.get(&quot;title&quot;)), pattern, '\\'));
    }
    if (cond.tag() != null &amp;&amp; !cond.tag().isBlank()) {
        // JOIN하면 태그가 여러 개 걸린 글이 중복돼 건수가 부푼다 — EXISTS로 거른다
        Subquery&lt;Long&gt; tagged = query.subquery(Long.class);
        Root&lt;Post&gt; sub = tagged.from(Post.class);
        Join&lt;Post, Tag&gt; tags = sub.join(&quot;tags&quot;);
        tagged.select(sub.get(&quot;id&quot;))
                .where(cb.equal(sub, post), cb.equal(tags.get(&quot;name&quot;), cond.tag()));
        predicates.add(cb.exists(tagged));
    }
    return predicates.toArray(Predicate[]::new);
}

// &quot;볼 수 있는 글&quot; — 목록은 PUBLISHED만(자기 임시저장·숨김 글도 목록에는 없다), 삭제 제외,
// PUBLIC이거나 (로그인 시) 내 글·내가 팔로우하는 작성자의 글, 차단 관계(양방향) 작성자 제외
private List&lt;Predicate&gt; viewable(CriteriaBuilder cb, CriteriaQuery&lt;?&gt; query, Root&lt;Post&gt; post, Long viewerId) {
    List&lt;Predicate&gt; predicates = new ArrayList&lt;&gt;();
    predicates.add(cb.isNull(post.get(&quot;deletedAt&quot;)));
    predicates.add(cb.equal(post.get(&quot;status&quot;), &quot;PUBLISHED&quot;));

    Predicate isPublic = cb.equal(post.get(&quot;visibility&quot;), &quot;PUBLIC&quot;);
    if (viewerId == null) {
        predicates.add(isPublic);
        return predicates;
    }

    Subquery&lt;Long&gt; follows = query.subquery(Long.class);
    Root&lt;Follow&gt; f = follows.from(Follow.class);
    follows.select(f.get(&quot;id&quot;)).where(
            cb.equal(f.get(&quot;follower&quot;).get(&quot;id&quot;), viewerId),
            cb.equal(f.get(&quot;followee&quot;), post.get(&quot;author&quot;)));
    predicates.add(cb.or(isPublic, cb.equal(post.get(&quot;author&quot;).get(&quot;id&quot;), viewerId), cb.exists(follows)));

    Subquery&lt;Long&gt; blocked = query.subquery(Long.class);
    Root&lt;MemberBlock&gt; b = blocked.from(MemberBlock.class);
    blocked.select(b.get(&quot;id&quot;)).where(cb.or(
            cb.and(cb.equal(b.get(&quot;blocker&quot;).get(&quot;id&quot;), viewerId), cb.equal(b.get(&quot;blocked&quot;), post.get(&quot;author&quot;))),
            cb.and(cb.equal(b.get(&quot;blocked&quot;).get(&quot;id&quot;), viewerId), cb.equal(b.get(&quot;blocker&quot;), post.get(&quot;author&quot;)))));
    predicates.add(cb.not(cb.exists(blocked)));
    return predicates;
}

private static String escapeLike(String raw) {
    return raw.replace(&quot;\\&quot;, &quot;\\\\&quot;).replace(&quot;%&quot;, &quot;\\%&quot;).replace(&quot;_&quot;, &quot;\\_&quot;);
}

private static final Logger log = LoggerFactory.getLogger(RecountService.class);

private final MyBatisRecountMapper recountMapper;

public RecountService(MyBatisRecountMapper recountMapper) {
    this.recountMapper = recountMapper;
}

// 찾기와 고치기를 한 트랜잭션에서 한다. 그 사이에 좋아요가 눌리면 응답의 after와 실제 값이

@Transactional
public RecountResponse recount() {
    List&lt;CountFix&gt; likeFixed = toFixes(recountMapper.findLikeCountMismatches());
    List&lt;CountFix&gt; commentFixed = toFixes(recountMapper.findCommentCountMismatches());

    if (!likeFixed.isEmpty()) {
        recountMapper.fixLikeCounts();
    }
    if (!commentFixed.isEmpty()) {
        recountMapper.fixCommentCounts();
    }

    likeFixed.forEach(f -&gt; log.info(&quot;like_count 보정 postId={} {} -&gt; {}&quot;, f.postId(), f.before(), f.after()));
    commentFixed.forEach(f -&gt; log.info(&quot;comment_count 보정 postId={} {} -&gt; {}&quot;, f.postId(), f.before(), f.after()));
    log.info(&quot;정합성 배치 완료: like {}건, comment {}건 보정&quot;, likeFixed.size(), commentFixed.size());
    return new RecountResponse(likeFixed, commentFixed);
}

private List&lt;CountFix&gt; toFixes(List&lt;CountMismatchRow&gt; rows) {
    return rows.stream()
            .map(r -&gt; new CountFix(r.postId, r.beforeCount, r.afterCount))
            .toList();

private LikeResponse doLike(Long postId, AuthenticatedMember loginMember) {
    Post post = findLikeablePost(postId, loginMember);
    if (post.getAuthor().getId().equals(loginMember.id())) {
        throw new SelfLikeNotAllowedException();
    }

    int inserted = postLikeRepository.insertIgnore(postId, loginMember.id());
    if (inserted &gt; 0) {
        postRepository.incrementLikeCount(postId);
    }
    return new LikeResponse(postId, true, postRepository.findLikeCountById(postId));
}

    if (deleted &gt; 0) {
        postRepository.decrementLikeCount(postId);
    }
    return new LikeResponse(postId, false, postRepository.findLikeCountById(postId));
}

        cursorId = Long.valueOf(parts[1]);

private String[] decodeCursor(String cursor) {
    try {
        String raw = new String(Base64.getUrlDecoder().decode(cursor), StandardCharsets.UTF_8);
        String[] parts = raw.split(&quot;\\|&quot;, -1);
        if (parts.length != 2) throw new IllegalArgumentException();
        LocalDateTime.parse(parts[0]);
        if (Long.parseLong(parts[1]) &lt; 1) throw new IllegalArgumentException();
        return parts;
    } catch (IllegalArgumentException | DateTimeException ex) {
        throw new ResponseStatusException(HttpStatus.BAD_REQUEST, &quot;올바르지 않은 cursor입니다.&quot;);
    }
}

@Transactional
public PostDetailResponse patch(Long id, AuthenticatedMember me, PostUpdateRequest request) {
    PostDetailRow current = visibilityMapper.findVisibleDetail(id, me.id(), me.role());
    if (current == null) throw new PostNotFoundException();
    if (!current.authorId.equals(me.id())) throw new PostForbiddenException();

    // 모든 입력을 확인한 뒤 쓰기를 시작한다.
    if (request.title() != null) validateTitle(request.title());
    if (request.content() != null) validateContent(request.content());
    if (request.tags() != null) validateTags(request.tags());
    if (request.visibility() != null) validateVisibility(request.visibility());

    List&lt;String&gt; tags;
    if (request.tags() == null) {
        tags = visibilityMapper.findTagsByPostIds(List.of(id)).stream()
                .map(PostTagRow::name).toList();
    } else {
        List&lt;PostReplaceTagRow&gt; resolved = new ArrayList&lt;&gt;();
        Set&lt;Long&gt; seenIds = new HashSet&lt;&gt;();
        for (String name : request.tags()) {
            replaceMapper.insertTagIfMissing(name);
            PostReplaceTagRow tag = replaceMapper.findTagByName(name);
            if (seenIds.add(tag.id)) resolved.add(tag);
        }
        replaceMapper.deletePostTags(id);
        for (PostReplaceTagRow tag : resolved) replaceMapper.insertPostTag(id, tag.id);
        tags = resolved.stream().map(tag -&gt; tag.name).toList();
    }
    replaceMapper.patchPost(id, request.title(), request.content(), request.visibility());
    return new PostDetailResponse(id, current.boardSlug,
            request.title() == null ? current.title : request.title(),
            request.content() == null ? current.content : request.content(),
            tags,
            request.visibility() == null ? current.visibility : request.visibility(),
            new AuthorResponse(current.authorId, current.authorNickname),
            current.viewCount, current.likeCount, current.commentCount, current.createdAt);
}

private void validateTitle(String title) {
    if (title.isBlank()) throw new InvalidPostFieldException(&quot;title&quot;, &quot;제목을 입력해 주세요.&quot;);

}

}

        throw new InvalidPostFieldException(&quot;tags&quot;, &quot;태그는 &quot; + TAGS_MAX_COUNT + &quot;개까지입니다.&quot;);

        if (tag == null || tag.isBlank() || tag.length() &gt; TAG_NAME_MAX_LENGTH)

    }
}

                start.await();
                task.accept(index);
            } catch (Exception e) {
                errors.add(e);
            } finally {
                done.countDown();
            }
        });
    }
