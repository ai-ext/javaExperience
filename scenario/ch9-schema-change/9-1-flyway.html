#9-1. Flyway 도입 — 지금 스키마를 기준선으로

9장은 학습용 DB(practice)로 채점한다. 앱을 practice 프로파일로 띄운다(8-1 참고). 9장에서 만드는 마이그레이션은 community에도 똑같이 적용된다(두 DB는 같은 스키마). 스키마를 처음으로 되돌리려면 javaExperience 레포 루트에서 docker compose down -v && docker compose up -d.

#상황

지금까지 테이블은 Docker가 처음 뜰 때 dump로 만들었다. 운영 DB는 그렇게 다시 만들 수 없다. 데이터가 이미 있기 때문이다. 앞으로 스키마를 바꾸려면 "어떤 변경이 어느 DB에 적용됐는지"를 기록하면서 순서대로 적용해야 한다. 그 일을 하는 도구가 Flyway다.

이미 테이블과 데이터가 있는 DB에 Flyway를 붙이는 것부터 한다. 지금 스키마를 V1(기준선) 으로 정하고, 이미 있는 DB에서는 V1을 건너뛰게 한다.

#구현 가이드

화면 시나리오의 서버·DB 흐름을 이 단계에서 바뀐 파일에 연결한다. 먼저 만들 것의 계약대로 직접 작성하고, 필요한 역할만 펼쳐 파일 전문과 비교한다.

이 단계의 처리 흐름:

  • Flyway: flyway_schema_history가 없다 + 테이블은 있다 → baseline-on-migrate → 'V1까지 됐다'고만 기록(V1을 실행하지 않음)
  • Testcontainers의 빈 DB → Flyway가 V1(테이블)을 실제로 실행하고, 테스트 전용 V1_1(시드)을 넣는다
Flyway / SQL — 스키마 변경

V1__init.sql: 빈 DB에서 실행할 기준 스키마다. 기존 테이블이 있는 DB에서는 baseline-on-migrate가 V1을 실행하지 않고 이력을 남긴다. 파일 전문에는 이 단계까지 사용한 모든 테이블·외래키·인덱스가 들어 있다.

SET FOREIGN_KEY_CHECKS = 0;
CREATE TABLE `board` (
  `id` bigint NOT NULL AUTO_INCREMENT,
  `slug` varchar(30) NOT NULL,
  `name` varchar(50) NOT NULL,
  `write_role` varchar(20) NOT NULL DEFAULT 'USER',
  `sort_order` int NOT NULL,
  `created_at` datetime NOT NULL,
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_board_slug` (`slug`),
  CONSTRAINT `ck_board_write_role` CHECK ((`write_role` in (_utf8mb4'USER',_utf8mb4'ADMIN')))
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_0900_ai_ci COMMENT='게시판 — write_role=ADMIN이면 운영자만 글쓰기(공지)';
SET FOREIGN_KEY_CHECKS = 1;

위 코드는 V1의 board DDL을 발췌했다. 실제 V1은 post를 포함한 모든 테이블을 생성하므로 아래 전체 구현 코드에서 원문을 확인한다. 적용된 V1을 수정하면 Flyway 체크섬 검증이 실패하므로 다음 변경은 V2 파일에 쓴다.

MyBatis / 같은 마이그레이션 적용

MyBatis를 선택해도 Flyway가 먼저 V1을 판정한다. MyBatis용 별도 스키마 파일은 만들지 않는다. 아래 MyBatis 대체 구현 코드는 8-5까지의 Mapper 경로를 유지하면서 이 단계의 Flyway 의존성과 설정을 합친 전체 파일을 제공한다.

implementation 'org.mybatis.spring.boot:mybatis-spring-boot-starter:4.1.0'
implementation 'org.springframework.boot:spring-boot-starter-flyway'
runtimeOnly 'org.flywaydb:flyway-mysql'
spring:
  flyway:
    baseline-on-migrate: true
    baseline-version: 1
mybatis:
  mapper-locations: classpath:mapper/*.xml
  configuration:
    map-underscore-to-camel-case: true

package org.example.admin;


import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;


import java.util.List;


// 비정규화 숫자(like_count·comment_count)를 실제 행 수로 맞춘다. 몇 번을 돌려도 결과가 같다(멱등).
// 이건 "나중에 맞추는" 안전망이다 — 4-2·5-1처럼 숫자를 원자적으로 바꿔 애초에 어긋나지 않게 하는 게 먼저다.
// 수동 실행(AdminController)과 예약 실행(RecountScheduler)이 이 메서드 하나를 같이 쓴다.
@Service
public class RecountService {


private static final Logger log = LoggerFactory.getLogger(RecountService.class);

private final MyBatisRecountMapper recountMapper;

public RecountService(MyBatisRecountMapper recountMapper) {
    this.recountMapper = recountMapper;
}

// 찾기와 고치기를 한 트랜잭션에서 한다. 그 사이에 좋아요가 눌리면 응답의 after와 실제 값이
// 조금 다를 수 있지만, UPDATE는 그 시점의 실제 행 수로 맞추므로 결과는 맞다.
@Transactional
public RecountResponse recount() {
    List&lt;CountFix&gt; likeFixed = toFixes(recountMapper.findLikeCountMismatches());
    List&lt;CountFix&gt; commentFixed = toFixes(recountMapper.findCommentCountMismatches());

    if (!likeFixed.isEmpty()) {
        recountMapper.fixLikeCounts();
    }
    if (!commentFixed.isEmpty()) {
        recountMapper.fixCommentCounts();
    }

    likeFixed.forEach(f -&gt; log.info(&quot;like_count 보정 postId={} {} -&gt; {}&quot;, f.postId(), f.before(), f.after()));
    commentFixed.forEach(f -&gt; log.info(&quot;comment_count 보정 postId={} {} -&gt; {}&quot;, f.postId(), f.before(), f.after()));
    log.info(&quot;정합성 배치 완료: like {}건, comment {}건 보정&quot;, likeFixed.size(), commentFixed.size());
    return new RecountResponse(likeFixed, commentFixed);
}

private List&lt;CountFix&gt; toFixes(List&lt;CountMismatchRow&gt; rows) {
    return rows.stream()
            .map(r -&gt; new CountFix(r.postId, r.beforeCount, r.afterCount))
            .toList();
}


}

@Transactional
public PostDetailResponse patch(Long id, AuthenticatedMember me, PostUpdateRequest request) {
    PostDetailRow current = visibilityMapper.findVisibleDetail(id, me.id(), me.role());
    if (current == null) throw new PostNotFoundException();
    if (!current.authorId.equals(me.id())) throw new PostForbiddenException();

    // 모든 입력을 확인한 뒤 쓰기를 시작한다.
    if (request.title() != null) validateTitle(request.title());
    if (request.content() != null) validateContent(request.content());
    if (request.tags() != null) validateTags(request.tags());
    if (request.visibility() != null) validateVisibility(request.visibility());

    List&lt;String&gt; tags;
    if (request.tags() == null) {
        tags = visibilityMapper.findTagsByPostIds(List.of(id)).stream()
                .map(PostTagRow::name).toList();
    } else {
        List&lt;PostReplaceTagRow&gt; resolved = new ArrayList&lt;&gt;();
        Set&lt;Long&gt; seenIds = new HashSet&lt;&gt;();
        for (String name : request.tags()) {
            replaceMapper.insertTagIfMissing(name);
            PostReplaceTagRow tag = replaceMapper.findTagByName(name);
            if (seenIds.add(tag.id)) resolved.add(tag);
        }
        replaceMapper.deletePostTags(id);
        for (PostReplaceTagRow tag : resolved) replaceMapper.insertPostTag(id, tag.id);
        tags = resolved.stream().map(tag -&gt; tag.name).toList();
    }
    replaceMapper.patchPost(id, request.title(), request.content(), request.visibility());
    return new PostDetailResponse(id, current.boardSlug,
            request.title() == null ? current.title : request.title(),
            request.content() == null ? current.content : request.content(),
            tags,
            request.visibility() == null ? current.visibility : request.visibility(),

public PostListResponse list(String boardSlug, int page, int size, AuthenticatedMember viewer) {

    PostSearchCondition condition = new PostSearchCondition(boardId, normalizedTag, authorId, from, to, q);
    LocalDateTime fromAt = from == null ? null : from.atStartOfDay();
    LocalDateTime toExclusive = to == null || to.equals(LocalDate.of(9999, 12, 31))
            ? null : to.plusDays(1).atStartOfDay();

    long offset = (long) page * size;

    List&lt;PostListRow&gt; rows = mapper.search(condition, viewerId, fromAt, toExclusive, qPattern, size, offset);
    long total = mapper.countSearch(condition, viewerId, fromAt, toExclusive, qPattern);

    return new PostListResponse(items, page, size, total,
