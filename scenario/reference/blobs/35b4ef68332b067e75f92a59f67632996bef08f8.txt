-- V5 — bookmark.memo → note 이름 변경의 1단계(넓히기). 서비스를 멈추지 않으려고 한 번에 RENAME하지 않는다.
-- 새 컬럼을 NULL 허용으로 추가하고 지금 값을 복사만 한다. 옛 서버는 memo만 읽고 쓰므로 아무 영향이 없다.
-- 다음 배포(같은 커밋의 코드)는 memo·note 둘 다에 쓰고 읽기는 아직 memo다.
ALTER TABLE bookmark ADD COLUMN note VARCHAR(200) NULL AFTER memo;

UPDATE bookmark SET note = memo;
