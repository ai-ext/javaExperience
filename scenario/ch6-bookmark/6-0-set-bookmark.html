#상황

"읽던 글을 나중에 다시 보려고 저장해요. 메모와 폴더를 고를 수 있지만, 다른 사람 폴더에는 저장하면 안 돼요."

먼저 PUT으로 북마크를 만드는 동작에 집중한다. 이미 저장한 글은 다시 요청해도 같은 북마크 한 행이다. 6-1에서는 같은 URL에 수정(upsert)과 DELETE를 붙인다.

#만들 것

항목 계약
메서드·경로 PUT /api/posts/{id}/bookmark; 토큰의 회원으로 저장한다. 내 글도 북마크 가능하다.
요청 DTO { "folderId"?, "memo"? }. 생략·null 폴더는 기본 폴더, 생략·null 메모는 메모 없음. memo는 최대 200자.
성공 200 { "bookmarkId", "postId", "bookmarked": true, "folderId", "memo" }. 반복 PUT은 같은 bookmarkId와 한 행이다.
실패 토큰 없음 401; 없는/볼 수 없는/미발행 글 404; 다른 회원 폴더나 없는 폴더 404; 메모 201자·잘못된 타입 400.
DB bookmark의 UNIQUE(member_id, post_id)를 확인한다. folder_id가 있으면 bookmark_folder.member_id도 토큰 회원과 같아야 한다.

Controller는 경로 ID와 @RequestBody 요청 DTO를 받고 북마크 응답 DTO를 돌려준다. 본문이 없는 요청은 {}와 같이 처리한다.

Service는 먼저 글 가시성을 확인한 뒤 폴더 ID만 찾지 말고 회원 ID까지 조건으로 조회한다. 폴더 검증에 실패하면 북마크 행을 새로 만들지 않는다. 이미 저장돼 있으면 이번 단계에서는 같은 값의 반복 PUT을 처리하고, 보내는 값으로 메모·폴더를 바꾸는 upsert는 6-1에서 완성한다.

좋아요와 달리 내 글 저장은 허용된다. 좋아요의 like_count처럼 post의 숫자 열을 변경하지 않는다. 저장한 글을 나중에 읽을 때 글이 삭제될 수 있으므로 북마크 행을 어떻게 표시할지는 6-3에서 다룬다.

#구현 가이드

먼저 기본 폴더에 메모 없이 저장하고, 다음에 메모와 폴더 소유권 검사를 붙인다.

JsonNode는 Boot 4의 tools.jackson.databind.JsonNode를 import한다. folderId는 isIntegralNumber()와 canConvertToLong()으로 Long 범위의 양의 정수인지, memo는 문자열/null인지 Service에서 확인해 잘못된 입력을 400으로 처리한다. 메모 길이는 최대 200자다. 응답의 bookmarkId는 반복 PUT에서도 같아야 한다.

Service — 내 폴더 확인 뒤 북마크 한 행 저장

글이 보이는지 먼저 검사한다. folderId가 있으면 bookmarkFolderRepository.findByIdAndMemberId(folderId, memberId)처럼 ID와 소유 회원을 함께 조건으로 찾아야 한다. 찾지 못하면 404를 내고 북마크는 쓰지 않는다. 메모는 아래처럼 검사한 뒤 문자열만 저장한다.

JsonNode raw = request.memo();
if (raw != null && !raw.isNull() && !raw.isTextual()) {
    throw new ResponseStatusException(HttpStatus.BAD_REQUEST);
}
String memo = raw == null || raw.isNull() ? null : raw.asText();
if (memo != null && memo.length() > 200) {
    throw new ResponseStatusException(HttpStatus.BAD_REQUEST);
}

@Transactional 안에서 (memberId, postId) 유일 키로 중복을 합친다. 둘 다 먼저 조회하고 저장하는 방식은 동시 PUT에서 한쪽이 중복 키 오류를 맞으므로, DB의 원자적 INSERT를 사용한다. 메모·폴더를 다른 값으로 바꾸는 upsert는 6-1에서 완성한다.

bookmarks.insertIfAbsent(me.id(), postId, folderId, memo);
Bookmark bookmark = bookmarks.findCurrentForUpdate(me.id(), postId)
        .orElseThrow(() -> new IllegalStateException("북마크 저장 결과를 찾을 수 없습니다."));
return new BookmarkResponse(bookmark.getId(), postId, true,
        bookmark.getFolder() == null ? null : bookmark.getFolder().getId(), bookmark.getMemo());

위 코드는 set 메서드 중 저장·응답 부분이다. 글 가시성, 폴더 소유권, 메모 검증은 이 분기보다 먼저 끝낸다. 이 단계에서는 기존 행의 메모·폴더를 바꾸지 않는다. FOR UPDATE는 MySQL REPEATABLE_READ에서 충돌 뒤 오래된 조회 스냅샷 때문에 방금 존재가 확인된 행을 못 찾는 일을 막는다.

JPA / Repository — 유일 제약과 폴더 외래키 확인

bookmark(member_id, post_id) 유일 제약이 마지막 중복 방어선이다. 다음 SELECT로 행 하나와 폴더 소유자를 확인한다.

SELECT bm.id, bm.member_id, bm.post_id, bm.folder_id, bm.memo
FROM bookmark bm WHERE bm.member_id = 2 AND bm.post_id = 2;
SELECT id, member_id FROM bookmark_folder WHERE id = 11;

JPA의 BookmarkRepository.insertIfAbsent는 native SQL INSERT ... ON DUPLICATE KEY UPDATE id = id로 동시에 온 반복 PUT을 한 행으로 합친다. findCurrentForUpdate는 같은 회원·글 조건으로 현재 행을 읽는다.

BookmarkFolderRepository.findByIdAndMember_Id는 폴더 ID와 소유자를 함께 확인한다. DB의 UNIQUE(member_id, post_id)가 중복을 막는다.

MyBatis — 폴더 소유권·멱등 INSERT

MyBatisBookmarkMapper.xml의 폴더 조회는 ID와 회원 ID를 함께 걸고, 북마크는 (member_id, post_id) 유일 키로 한 행만 남긴다.

<select id="findOwnedFolder" resultType="long">
    SELECT id FROM bookmark_folder WHERE id = #{folderId} AND member_id = #{memberId}
</select>
<insert id="insertIfAbsent" parameterType="org.example.bookmark.BookmarkInsertRow"
        useGeneratedKeys="true" keyProperty="id">
    INSERT INTO bookmark(member_id, post_id, folder_id, memo, created_at, updated_at)
    VALUES (#{memberId}, #{postId}, #{folderId}, #{memo}, #{at}, #{at})
    ON DUPLICATE KEY UPDATE id = LAST_INSERT_ID(id)
</insert>

같은 키로 다시 요청하면 기존 행의 메모·폴더를 바꾸지 않는다. MyBatisBookmarkService는 글 가시성·발행 상태와 입력 타입을 확인하고, 폴더 소유권 검사를 통과한 뒤 INSERT와 findBookmark를 한 트랜잭션에서 실행한다.

findBookmark SQL 끝의 FOR UPDATE로 충돌 뒤에도 현재 행을 읽는다. 아래 MyBatis 대체 구현 코드 접기에서 Controller·Service·Mapper·XML 전문을 비교할 수 있다.

package org.example.bookmark;


import org.example.auth.AuthenticatedMember;
import org.example.post.Post;
import org.example.post.PostAccessPolicy;
import org.example.post.PostNotFoundException;
import org.example.post.PostRepository;
import org.springframework.http.HttpStatus;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;
import org.springframework.web.server.ResponseStatusException;
import tools.jackson.databind.JsonNode;


@Service
public class BookmarkService {
    private final PostRepository posts;
    private final PostAccessPolicy accessPolicy;
    private final BookmarkRepository bookmarks;
    private final BookmarkFolderRepository folders;


public BookmarkService(PostRepository posts, PostAccessPolicy accessPolicy,
                       BookmarkRepository bookmarks, BookmarkFolderRepository folders) {
    this.posts = posts;
    this.accessPolicy = accessPolicy;
    this.bookmarks = bookmarks;
    this.folders = folders;
}

@Transactional
public BookmarkResponse set(Long postId, AuthenticatedMember me, BookmarkRequest request) {
    Post post = posts.findById(postId).orElseThrow(PostNotFoundException::new);
    if (!accessPolicy.canView(me, post) || !&quot;PUBLISHED&quot;.equals(post.getStatus())) {
        throw new PostNotFoundException();
    }
    Long folderId = folderId(request.folderId());
    String memo = memo(request.memo());
    BookmarkFolder folder = folderId == null ? null : folders.findByIdAndMember_Id(folderId, me.id())
            .orElseThrow(() -&gt; new ResponseStatusException(HttpStatus.NOT_FOUND));

    bookmarks.insertIfAbsent(me.id(), postId, folderId, memo);
    Bookmark bookmark = bookmarks.findCurrentForUpdate(me.id(), postId)
            .orElseThrow(() -&gt; new IllegalStateException(&quot;북마크 저장 결과를 찾을 수 없습니다.&quot;));
    return new BookmarkResponse(bookmark.getId(), postId, true,
            bookmark.getFolder() == null ? null : bookmark.getFolder().getId(), bookmark.getMemo());
}

private Long folderId(JsonNode node) {
    if (node == null || node.isNull()) return null;
    if (!node.isIntegralNumber() || !node.canConvertToLong() || node.longValue() &lt;= 0) {
        throw new ResponseStatusException(HttpStatus.BAD_REQUEST);
    }
    return node.asLong();
}

private String memo(JsonNode node) {
    if (node == null || node.isNull()) return null;
    if (!node.isTextual()) throw new ResponseStatusException(HttpStatus.BAD_REQUEST);
    String value = node.asText();
    if (value.length() &gt; 200) throw new ResponseStatusException(HttpStatus.BAD_REQUEST);
    return value;
}


}

    private final PostVisibilityMapper visiblePosts;
    private final MyBatisBookmarkMapper bookmarks;


public MyBatisBookmarkService(PostVisibilityMapper visiblePosts, MyBatisBookmarkMapper bookmarks) {
    this.visiblePosts = visiblePosts;
    this.bookmarks = bookmarks;
}

@Transactional
public BookmarkResponse set(Long postId, AuthenticatedMember me, BookmarkRequest request) {
    if (visiblePosts.findVisibleDetail(postId, me.id(), me.role()) == null
            || !&quot;PUBLISHED&quot;.equals(bookmarks.findPostStatus(postId))) {
        throw new PostNotFoundException();
    }
    Long folderId = folderId(request.folderId());
    String memo = memo(request.memo());
    if (folderId != null &amp;&amp; bookmarks.findOwnedFolder(folderId, me.id()) == null) {
        throw new ResponseStatusException(HttpStatus.NOT_FOUND);
    }
    // UNIQUE(member_id,post_id). 충돌해도 기존 행의 메모·폴더를 바꾸지 않는다(6-1에서 upsert).
    bookmarks.insertIfAbsent(new BookmarkInsertRow(me.id(), postId, folderId, memo, LocalDateTime.now()));
    BookmarkRow row = bookmarks.findBookmark(me.id(), postId);
    return new BookmarkResponse(row.id, postId, true, row.folderId, row.memo);
}

private Long folderId(JsonNode node) {
    if (node == null || node.isNull()) return null;
    if (!node.isIntegralNumber() || !node.canConvertToLong() || node.longValue() &lt;= 0) throw new ResponseStatusException(HttpStatus.BAD_REQUEST);
    return node.asLong();
}

private String memo(JsonNode node) {
    if (node == null || node.isNull()) return null;
    if (!node.isTextual()) throw new ResponseStatusException(HttpStatus.BAD_REQUEST);
    String value = node.asText();
    if (value.length() &gt; 200) throw new ResponseStatusException(HttpStatus.BAD_REQUEST);
    return value;
}

public List&lt;CommentThreadResponse&gt; list(Long postId, AuthenticatedMember viewer) {
    Long viewerId = viewer == null ? null : viewer.id();
    String role = viewer == null ? null : viewer.role();
    if (posts.findVisibleDetail(postId, viewerId, role) == null) throw new PostNotFoundException();
    List&lt;CommentTreeRow&gt; all = comments.selectThreadRows(postId);
    Set&lt;Long&gt; blocked = viewerId == null ? Set.of() :
            Set.copyOf(comments.selectBlockedMemberIds(viewerId));
    Map&lt;Long, List&lt;CommentTreeRow&gt;&gt; replies = all.stream()
            .filter(r -&gt; r.parentId != null)
            .collect(Collectors.groupingBy(r -&gt; r.parentId, LinkedHashMap::new, Collectors.toList()));

    for (CommentTreeRow top : all) {

        List&lt;CommentReplyResponse&gt; visible = replies.getOrDefault(top.id, List.of()).stream()
                .filter(r -&gt; r.deletedAt == null &amp;&amp; !blocked.contains(r.authorId))

                        new AuthorResponse(r.authorId, r.authorNickname), r.content, r.createdAt))

                deleted ? null : new AuthorResponse(top.authorId, top.authorNickname),

    if (post == null || !&quot;PUBLISHED&quot;.equals(comments.findPostStatus(postId)))
        throw new PostNotFoundException();

    Long parentId = request.parentId();
    if (parentId != null) {
        ParentCommentRow parent = comments.findParent(parentId);
        if (parent == null) throw new CommentNotFoundException();
        if (!postId.equals(parent.postId))
            throw new InvalidParentCommentException(&quot;다른 글의 댓글에는 답글을 달 수 없습니다.&quot;);
        if (parent.parentId != null)
            throw new InvalidParentCommentException(&quot;답글에는 답글을 달 수 없습니다.&quot;);
        if (parent.deletedAt != null)
            throw new InvalidParentCommentException(&quot;지워진 댓글에는 답글을 달 수 없습니다.&quot;);
    }
    CommentInsertRow row = new CommentInsertRow(postId, me.id(), parentId,
            request.content(), LocalDateTime.now());
    if (comments.insertComment(row) != 1) throw new IllegalStateException(&quot;댓글 저장 실패&quot;);
    if (comments.incrementCommentCount(postId) != 1)
        throw new IllegalStateException(&quot;댓글 수 변경 실패&quot;);

            new CommentAuthorResponse(me.id(), me.nickname()), row.content, row.at, false);
}

public MyLikesResponse myLikes(AuthenticatedMember me, int size, String cursor) {
    LocalDateTime cursorAt = null;
    Long cursorId = null;
    if (cursor != null) {
        String[] parts = decodeCursor(cursor);
        cursorAt = LocalDateTime.parse(parts[0]);
        cursorId = Long.valueOf(parts[1]);
    }
    List&lt;MyLikeRow&gt; rows = likes.findMyLikes(me.id(), cursorAt, cursorId, size + 1);
    boolean hasNext = rows.size() &gt; size;
    List&lt;MyLikeRow&gt; page = hasNext ? rows.subList(0, size) : rows;
    List&lt;MyLikeItemResponse&gt; items = page.stream()
            .map(row -&gt; new MyLikeItemResponse(row.postId, row.title,
                    new AuthorResponse(row.authorId, row.authorNickname), row.likedAt))
            .toList();
    String nextCursor = hasNext ? encodeCursor(page.get(page.size() - 1)) : null;
    return new MyLikesResponse(items, nextCursor);
}

private String encodeCursor(MyLikeRow last) {
    String raw = last.likedAt + &quot;|&quot; + last.likeId;
    return Base64.getUrlEncoder().withoutPadding()
            .encodeToString(raw.getBytes(StandardCharsets.UTF_8));

private String[] decodeCursor(String cursor) {
    try {
        String raw = new String(Base64.getUrlDecoder().decode(cursor), StandardCharsets.UTF_8);
        String[] parts = raw.split(&quot;\\|&quot;, -1);
        if (parts.length != 2) throw new IllegalArgumentException();
        LocalDateTime.parse(parts[0]);
        if (Long.parseLong(parts[1]) &lt; 1) throw new IllegalArgumentException();
        return parts;
    } catch (IllegalArgumentException | DateTimeException ex) {
        throw new ResponseStatusException(HttpStatus.BAD_REQUEST, &quot;올바르지 않은 cursor입니다.&quot;);
    }
}

                throw e;

        }
    }

private List&lt;Exception&gt; runConcurrently(int count, java.util.function.IntConsumer task) throws InterruptedException {
    ExecutorService pool = Executors.newFixedThreadPool(count);
    CountDownLatch ready = new CountDownLatch(count);
    CountDownLatch start = new CountDownLatch(1);
    CountDownLatch done = new CountDownLatch(count);
    List&lt;Exception&gt; errors = new CopyOnWriteArrayList&lt;&gt;();

    for (int i = 0; i &lt; count; i++) {
        int index = i;
        pool.submit(() -&gt; {
            try {
                ready.countDown();
                start.await();
                task.accept(index);
            } catch (Exception e) {
                errors.add(e);
            } finally {
                done.countDown();
            }
        });
    }

    boolean allReady = ready.await(10, TimeUnit.SECONDS);
    start.countDown(); // 모든 스레드가 준비된 뒤 한꺼번에 출발시킨다
    assertTrue(allReady, &quot;모든 스레드가 출발 전에 준비돼야 한다&quot;);
    assertTrue(done.await(30, TimeUnit.SECONDS), &quot;모든 요청이 끝나야 한다&quot;);
    pool.shutdown();
    return errors;
}

import org.apache.ibatis.mapping.MappedStatement;

import org.apache.ibatis.plugin.Intercepts;
import org.apache.ibatis.plugin.Invocation;
import org.apache.ibatis.plugin.Signature;
import org.apache.ibatis.session.ResultHandler;
import org.apache.ibatis.session.RowBounds;
import org.springframework.stereotype.Component;


// 테스트 중 Mapper가 실행한 SELECT 문장 수를 요청 스레드별로 센다.
@Component
@Intercepts(@Signature(type = Executor.class, method = "query",
        args = {MappedStatement.class, Object.class, RowBounds.class, ResultHandler.class}))
public class MyBatisStatementCounter implements Interceptor {
    private final ThreadLocal<Long> count = ThreadLocal.withInitial(() -> 0L);


@Override
public Object intercept(Invocation invocation) throws Throwable {
    count.set(count.get() + 1);
    return invocation.proceed();
}

public void clear() { count.set(0L); }
public long getCount() { return count.get(); }


}
