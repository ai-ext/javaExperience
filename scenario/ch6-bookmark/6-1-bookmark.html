#6-1. 북마크 추가·삭제

#상황

"나중에 다시 보려고 글을 저장(북마크)하고 싶어요. 폴더에 넣을 수도 있고, 메모도 달고요."

좋아요와 비슷하지만 다른 점이 있다. 내 글도 저장할 수 있고, 저장할 때 폴더와 메모를 함께 정한다. PUT은 "없으면 만들고, 있으면 폴더·메모를 바꾼다"(upsert)로 만든다.

#화면 시나리오

사용자가 화면에서 무엇을 하면 어떤 요청이 서버로 가고, 서버·DB에서 무슨 일이 일어나 어떤 응답이 돌아와 화면이 어떻게 바뀌는지다. 흐름을 펼치면 사용자 행동부터 응답까지 차례대로 볼 수 있다.

메서드·경로 의미 응답
PUT /api/posts/{id}/bookmark 북마크 상태로 만든다. 본문 { "folderId"?, "memo"? } 200 아래 JSON

{ "bookmarkId": 7, "postId": 2, "bookmarked": true, "folderId": null, "memo": "[채점] 메모" }
상황 결과
이미 북마크인데 또 PUT 200, 행은 그대로 1개. 보낸 folderId·memo로 바꾼다(안 보내면 null = 기본 폴더·메모 없음)
folderId가 남의 폴더이거나 없는 폴더 404
memo 200자 초과 400
(PUT) 없는 글, 2-3 규칙상 볼 수 없는 글, PUBLISHED가 아닌 글 404
(DELETE) 글이 지워졌거나 볼 수 없게 됐어도 204 — 글 상태를 따지지 않고 내 북마크 행만 지운다. 6-3에서 "볼 수 없는 글"로 남은 북마크도 사용자가 지울 수 있어야 한다
토큰 없음 401

필드 규칙 — PUT 본문. 잘못된 입력은 저장 전에 막고 500이 나면 안 된다

folderId 선택 생략·null이면 기본 폴더 내 폴더 id 숫자 null 숫자가 아니면("abc") 400, 남의 폴더·없는 폴더 404
memo 선택 생략·null이면 메모 없음, ""도 받는다 0~200자(정확히 200자는 성공, 201자는 거절) 문자열 null 400, errors에 memo

{id}(경로) 필수 — — 숫자 — 숫자가 아니면 400, 없는 글·볼 수 없는 글 404

#구현 가이드

화면 시나리오의 서버·DB 흐름을 이 단계에서 바뀐 파일에 연결한다. 먼저 만들 것의 계약대로 직접 작성하고, 필요한 역할만 펼쳐 파일 전문과 비교한다.

이 단계의 처리 흐름:

  • 없으면 만들고, 있으면 폴더·메모를 바꾼다(upsert) — UNIQUE(member_id, post_id)가 최후의 방어선
  • 폴더를 id로만 찾지 않고 '내 폴더인가'까지 확인 → 아니면 404(남의 폴더가 있다는 것도 숨긴다)

DTO — 요청·응답 필드

BookmarkRequest.java, BookmarkResponse.java. 필드 이름·타입·검증·응답 형태를 위 만들 것과 대조한다.

public record BookmarkRequest(Long folderId, String memo) {
    public static BookmarkRequest from(JsonNode body) {
        if (body == null) return new BookmarkRequest(null, null);
        if (!body.isObject()) throw new InvalidBookmarkFieldException("body", "JSON 객체를 보내 주세요.");
        JsonNode folder = body.get("folderId");
        JsonNode memo = body.get("memo");
        Long folderId = null;
        if (folder != null && !folder.isNull()) {
            if (!folder.isIntegralNumber() || !folder.canConvertToLong() || folder.longValue() <= 0) {
                throw new InvalidBookmarkFieldException("folderId", "폴더 ID는 양의 정수여야 합니다.");
            }
            folderId = folder.asLong();
        }
        String memoValue = null;
        if (memo != null && !memo.isNull()) {
            if (!memo.isTextual() || memo.asText().length() > 200) {
                throw new InvalidBookmarkFieldException("memo", "메모는 문자열이며 200자 이하여야 합니다.");
            }
            memoValue = memo.asText();
        }
        return new BookmarkRequest(folderId, memoValue);
    }
}
Service — 처리 순서

BookmarkService.java. 위 서버 처리 순서가 어디에서 검증·조회·상태 변경으로 이어지는지 따라간다. 변경된 메서드: bookmark, unbookmark. 트랜잭션 경계는 아래 코드의 @Transactional 위치에서 확인한다.

@Transactional
public BookmarkResponse bookmark(Long postId, AuthenticatedMember me, BookmarkRequest request) {
    findBookmarkablePost(postId, me); // 볼 수 있는 PUBLISHED 글인지 먼저 확인
    BookmarkFolder folder = findMyFolder(request.folderId(), me.id());
    bookmarkRepository.upsert(me.id(), postId, folder == null ? null : folder.getId(), request.memo());
    Bookmark saved = bookmarkRepository.findCurrentForUpdate(me.id(), postId).orElseThrow();
    return toResponse(saved);

DELETE는 글 공개 상태를 다시 검사하지 않고 (memberId, postId)로 내 행만 지운다. 없는 행을 지워도 204다.

JPA / Repository — DB 조건

BookmarkFolderRepository.java, BookmarkRepository.java. 쿼리·파생 메서드의 조건을 화면 시나리오의 DB 단계 및 직접 확인 SQL과 대조한다.

INSERT INTO bookmark(member_id, post_id, folder_id, memo, created_at, updated_at)
VALUES (:memberId, :postId, :folderId, :memo, NOW(), NOW())
ON DUPLICATE KEY UPDATE folder_id = VALUES(folder_id), memo = VALUES(memo), updated_at = NOW();

        Long folderId,


    String memo

    public static BookmarkRequest from(JsonNode body) {
        if (body == null) return new BookmarkRequest(null, null);
        if (!body.isObject()) throw new InvalidBookmarkFieldException("body", "JSON 객체를 보내 주세요.");
        JsonNode folder = body.get("folderId");
        JsonNode memo = body.get("memo");
        Long folderId = null;
        if (folder != null && !folder.isNull()) {
            if (!folder.isIntegralNumber() || !folder.canConvertToLong() || folder.longValue() <= 0) {
                throw new InvalidBookmarkFieldException("folderId", "폴더 ID는 양의 정수여야 합니다.");
            }
            folderId = folder.asLong();
        }
        String memoValue = null;
        if (memo != null && !memo.isNull()) {
            if (!memo.isTextual() || memo.asText().length() > 200) {
                throw new InvalidBookmarkFieldException("memo", "메모는 문자열이며 200자 이하여야 합니다.");
            }
            memoValue = memo.asText();
        }
        return new BookmarkRequest(folderId, memoValue);
    }

private LikeResponse doLike(Long postId, AuthenticatedMember me) {
    PostDetailRow post = findLikeablePost(postId, me);
    if (post.authorId.equals(me.id())) throw new SelfLikeNotAllowedException();
    if (likes.insertIgnoreLike(postId, me.id()) == 1) likes.increaseLikeCount(postId);
    return new LikeResponse(postId, true, likes.findLikeCount(postId));
}

private LikeResponse doUnlike(Long postId, AuthenticatedMember me) {
    findLikeablePost(postId, me);
    if (likes.deleteLike(postId, me.id()) == 1) likes.decreaseLikeCount(postId);
    return new LikeResponse(postId, false, likes.findLikeCount(postId));
}

@Transactional(readOnly = true)
public MyLikesResponse myLikes(AuthenticatedMember me, int size, String cursor) {
    LocalDateTime cursorAt = null;
    Long cursorId = null;
    if (cursor != null) {
        String[] parts = decodeCursor(cursor);
        cursorAt = LocalDateTime.parse(parts[0]);
        cursorId = Long.valueOf(parts[1]);
    }
    List&lt;MyLikeRow&gt; rows = likes.findMyLikes(me.id(), cursorAt, cursorId, size + 1);
    boolean hasNext = rows.size() &gt; size;
    List&lt;MyLikeRow&gt; page = hasNext ? rows.subList(0, size) : rows;
    List&lt;MyLikeItemResponse&gt; items = page.stream()
            .map(row -&gt; new MyLikeItemResponse(row.postId, row.title,
                    new AuthorResponse(row.authorId, row.authorNickname), row.likedAt))
            .toList();
    String nextCursor = hasNext ? encodeCursor(page.get(page.size() - 1)) : null;
    return new MyLikesResponse(items, nextCursor);
}

private String encodeCursor(MyLikeRow last) {
    String raw = last.likedAt + &quot;|&quot; + last.likeId;
    return Base64.getUrlEncoder().withoutPadding()
            .encodeToString(raw.getBytes(StandardCharsets.UTF_8));
}

private String[] decodeCursor(String cursor) {
    try {
        String raw = new String(Base64.getUrlDecoder().decode(cursor), StandardCharsets.UTF_8);
        String[] parts = raw.split(&quot;\\|&quot;, -1);
        if (parts.length != 2) throw new IllegalArgumentException();
        LocalDateTime.parse(parts[0]);
        if (Long.parseLong(parts[1]) &lt; 1) throw new IllegalArgumentException();
        return parts;
    } catch (IllegalArgumentException | DateTimeException ex) {
        throw new ResponseStatusException(HttpStatus.BAD_REQUEST, &quot;올바르지 않은 cursor입니다.&quot;);
    }
}

    if (post == null || !&quot;PUBLISHED&quot;.equals(likes.findPostStatus(postId)))
        throw new PostNotFoundException();
    return post;
}

private LikeResponse withDeadlockRetry(java.util.function.Supplier&lt;LikeResponse&gt; action) {
    for (int attempt = 1; ; attempt++) {
        try {
            return action.get();

                Thread.sleep((long) (Math.random() * 20 * attempt));
            } catch (InterruptedException interrupted) {
                Thread.currentThread().interrupt();
                throw e;
            }
        }
    }
}

@Service
public class PostPatchMyBatisService {
    private static final int TITLE_MAX_LENGTH = 200;
    private static final int TAGS_MAX_COUNT = 5;
    private static final int TAG_NAME_MAX_LENGTH = 30;


private final PostVisibilityMapper visibilityMapper;
private final PostReplaceMapper replaceMapper;

public PostPatchMyBatisService(PostVisibilityMapper visibilityMapper,
                               PostReplaceMapper replaceMapper) {
    this.visibilityMapper = visibilityMapper;
    this.replaceMapper = replaceMapper;
}

@Transactional
public PostDetailResponse patch(Long id, AuthenticatedMember me, PostUpdateRequest request) {
    PostDetailRow current = visibilityMapper.findVisibleDetail(id, me.id(), me.role());
    if (current == null) throw new PostNotFoundException();
    if (!current.authorId.equals(me.id())) throw new PostForbiddenException();

    // 모든 입력을 확인한 뒤 쓰기를 시작한다.
    if (request.title() != null) validateTitle(request.title());
    if (request.content() != null) validateContent(request.content());
    if (request.tags() != null) validateTags(request.tags());
    if (request.visibility() != null) validateVisibility(request.visibility());

    List&lt;String&gt; tags;
    if (request.tags() == null) {
        tags = visibilityMapper.findTagsByPostIds(List.of(id)).stream()
                .map(PostTagRow::name).toList();
    } else {
        List&lt;PostReplaceTagRow&gt; resolved = new ArrayList&lt;&gt;();
        Set&lt;Long&gt; seenIds = new HashSet&lt;&gt;();
        for (String name : request.tags()) {
            replaceMapper.insertTagIfMissing(name);
            PostReplaceTagRow tag = replaceMapper.findTagByName(name);
            if (seenIds.add(tag.id)) resolved.add(tag);
        }
        replaceMapper.deletePostTags(id);
        for (PostReplaceTagRow tag : resolved) replaceMapper.insertPostTag(id, tag.id);
        tags = resolved.stream().map(tag -&gt; tag.name).toList();
    }
    replaceMapper.patchPost(id, request.title(), request.content(), request.visibility());
    return new PostDetailResponse(id, current.boardSlug,
            request.title() == null ? current.title : request.title(),
            request.content() == null ? current.content : request.content(),
            tags,
            request.visibility() == null ? current.visibility : request.visibility(),
            new AuthorResponse(current.authorId, current.authorNickname),
            current.viewCount, current.likeCount, current.commentCount, current.createdAt);
}

private void validateTitle(String title) {
    if (title.isBlank()) throw new InvalidPostFieldException(&quot;title&quot;, &quot;제목을 입력해 주세요.&quot;);
    if (title.length() &gt; TITLE_MAX_LENGTH)
        throw new InvalidPostFieldException(&quot;title&quot;, &quot;제목은 &quot; + TITLE_MAX_LENGTH + &quot;자 이하여야 합니다.&quot;);
}

private void validateContent(String content) {
    if (content.isBlank()) throw new InvalidPostFieldException(&quot;content&quot;, &quot;본문을 입력해 주세요.&quot;);
}

private void validateTags(List&lt;String&gt; tags) {
    if (tags.size() &gt; TAGS_MAX_COUNT)
        throw new InvalidPostFieldException(&quot;tags&quot;, &quot;태그는 &quot; + TAGS_MAX_COUNT + &quot;개까지입니다.&quot;);
    for (String tag : tags) {
        if (tag == null || tag.isBlank() || tag.length() &gt; TAG_NAME_MAX_LENGTH)
            throw new InvalidPostFieldException(&quot;tags&quot;, &quot;태그 이름은 1~&quot; + TAG_NAME_MAX_LENGTH + &quot;자여야 합니다.&quot;);
    }
}

private void validateVisibility(String visibility) {
    if (!&quot;PUBLIC&quot;.equals(visibility) &amp;&amp; !&quot;FOLLOWERS&quot;.equals(visibility))
        throw new InvalidPostFieldException(&quot;visibility&quot;, &quot;공개 범위는 PUBLIC 또는 FOLLOWERS여야 합니다.&quot;);
}
