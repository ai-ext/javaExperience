#6-5. 내가 표시한 글 — 좋아요·북마크 조건 조합

#상황

"좋아요한 글, 북마크한 글을 한 화면에서 보고 싶어요. 두 조건을 모두 켜면 둘 다 한 글만 보여 주세요."

4장의 post_like와 6장의 bookmark를 함께 조회한다. 좋아요 또는 북마크한 공개 글을 모아 보고, 쿼리 파라미터로 하나 또는 둘 다 있는 글만 걸러낸다. 작성자가 나라는 뜻의 "내 글" 목록과 다르다.

#화면 시나리오

#만들 것

항목 계약
메서드·경로 GET /api/me/posts?liked=&bookmarked=&page=&size=. 인증 필수, 회원은 토큰에서 가져온다.
조건 두 값 생략/false면 좋아요 또는 북마크가 있는 글. liked=true만 주면 좋아요한 글, bookmarked=true만 주면 북마크한 글, 둘 다 true면 교집합.
목록 대상 PUBLISHED·PUBLIC·미삭제 글 중 2-3의 차단 규칙에 걸리지 않는 글. 6-3처럼 볼 수 없는 북마크를 별도 항목으로 내보내는 목록이 아니다.
응답 DTO { "items": [{ "postId", "title", "authorNickname", "boardSlug", "liked", "bookmarked" }], "page", "size", "totalElements" }. postId DESC.
입력·실패 liked·bookmarked는 생략하거나 정확히 true/false만 받는다. 빈 값도 형식 오류다. page 기본 0·최소 0, size 기본 20·범위 1~100. 형식/범위 오류 400, 인증 없음 401. 결과가 없으면 items:[], totalElements:0. 유효하지만 범위를 훨씬 넘는 페이지는 빈 items와 전체 건수를 반환한다.

#구현 가이드

먼저 좋아요 목록 한 조건을 완성한 뒤 북마크 조건과 교집합을 추가한다. 마지막에 응답 항목의 두 상태와 totalElements를 맞춘다.

Controller — 두 필터와 페이지 입력 검증

두 필터를 required=false 문자열로 받아 생략(null)과 빈 값("")을 구별한다. 정확히 true/false인지 확인한다. Spring의 boolean 자동 변환은 yes·1도 받을 수 있고 defaultValue는 빈 값을 생략처럼 처리하므로, 여기서는 요청 형식 오류를 명시적으로 400으로 처리한다. page·size도 문자열로 받아 생략일 때만 기본값 0·20을 적용하고, 빈 값·숫자 외 문자열·범위 밖 값은 400이다. 회원 ID는 요청에 받지 않는다.

@GetMapping("/api/me/posts")
public MarkedPostPageResponse markedPosts(
        @RequestParam(required = false) String liked,
        @RequestParam(required = false) String bookmarked,
        @RequestParam(required = false) String page,
        @RequestParam(required = false) String size,
        @LoginMember AuthenticatedMember loginMember) {
    return markedPostService.list(loginMember.id(),
            parseBoolean(liked), parseBoolean(bookmarked),
            parseNumber(page, 0, 0, Integer.MAX_VALUE),
            parseNumber(size, 20, 1, 100));
}

private boolean parseBoolean(String value) {
    if (value == null) return false;
    if ("true".equals(value)) return true;
    if ("false".equals(value)) return false;
    throw new ResponseStatusException(HttpStatus.BAD_REQUEST);
}

private int parseNumber(String value, int fallback, int min, int max) {
    if (value == null) return fallback;
    if (!value.matches("[0-9]+")) {
        throw new ResponseStatusException(HttpStatus.BAD_REQUEST);
    }
    try {
        int number = Integer.parseInt(value);
        if (number >= min && number <= max) return number;
    } catch (NumberFormatException ignored) { }
    throw new ResponseStatusException(HttpStatus.BAD_REQUEST);
}

page < 0과 size < 1 || size > 100을 쓰기 전에 400으로 거절한다. 인증 없는 요청은 401이다.

public record MarkedPostPageResponse(List<MarkedPostItem> items,

liked와 bookmarked는 지금 로그인한 회원과 글의 관계 여부다. items를 20개 읽은 뒤 Java에서 필터링하면 페이지와 totalElements가 틀어진다.

Service — 글 페이지와 관계 상태를 묶어 DTO 만들기

먼저 필터·차단·공개 조건을 적용한 글 페이지와 같은 조건의 총 개수를 DB에서 얻는다. author·board는 @EntityGraph로 함께 읽고, 현재 회원의 좋아요·북마크 상태는 페이지 ID들에 대해서만 각각 한 번에 조회한다.

Page<Post> posts = postRepository.findMarkedPosts(memberId, liked, bookmarked,
        PageRequest.of(page, size, Sort.by(Sort.Direction.DESC, "id")));
List<Long> ids = posts.getContent().stream().map(Post::getId).toList();

관계 상태를 일괄 조회한 다음 posts.getContent() 순서대로 DTO를 만든다. posts.getTotalElements()를 응답의 totalElements에 쓴다.

두 조건을 모두 생략하면 관계 중 하나 이상인 글만, 둘 다 true면 둘 다 있는 글만 반환한다. 전체 일치 글이 없을 때만 totalElements:0이다. 범위를 넘는 page를 요청해 items:[]가 되어도 totalElements는 전체 일치 건수를 유지한다.

JPA/Hibernate의 조회 시작 위치는 int 범위이므로 (long) page * size > Integer.MAX_VALUE인 유효한 요청은 큰 OFFSET 쿼리를 실행하지 않는다. 같은 필터로 첫 페이지를 크기 1로 조회해 totalElements만 얻고 빈 items를 반환한다. MyBatis는 long 오프셋을 SQL에 바인딩하므로 두 구현의 응답 계약은 같다.

JPA / Repository — EXISTS로 필터한 뒤 페이지 읽기

먼저 SQL로 관계를 눈으로 본다. post_like와 bookmark는 각각 회원·글 쌍에 UNIQUE가 있어서 한 글이 여러 행으로 불어나지 않는다. 아래는 두 조건이 모두 true일 때의 완성 SQL이다. 자기 회원 ID 2를 대입해 시드 데이터와 새로 만든 글의 결과를 확인한다.

SELECT p.id, p.title, a.nickname, b.slug,
       (l.id IS NOT NULL) AS liked, (bm.id IS NOT NULL) AS bookmarked
FROM post p
JOIN member a ON a.id = p.author_id
JOIN board b ON b.id = p.board_id
LEFT JOIN post_like l ON l.post_id = p.id AND l.member_id = 2
LEFT JOIN bookmark bm ON bm.post_id = p.id AND bm.member_id = 2
WHERE p.status = 'PUBLISHED' AND p.visibility = 'PUBLIC' AND p.deleted_at IS NULL
  AND NOT EXISTS (
    SELECT 1 FROM member_block mb
    WHERE (mb.blocker_id = 2 AND mb.blocked_id = a.id)
       OR (mb.blocker_id = a.id AND mb.blocked_id = 2)
  )
  AND l.id IS NOT NULL AND bm.id IS NOT NULL
ORDER BY p.id DESC
LIMIT 20 OFFSET 0;

다음 순서로 직접 바꾼다. ① AND bm.id IS NOT NULL만 빼서 좋아요 목록, ② AND l.id IS NOT NULL만 빼서 북마크 목록, ③ 두 줄 대신 AND (l.id IS NOT NULL OR bm.id IS NOT NULL)을 넣어 전체 표시 목록을 만든다. COUNT(*) 쿼리도 LIMIT/OFFSET만 빼고 같은 WHERE를 써야 totalElements가 맞는다. 관계가 없는 글까지 읽은 뒤 Java에서 거르면 페이지가 20개보다 적게 차는 오류가 생긴다.

JPA에서는 Post의 likes 컬렉션을 새로 만들 필요가 없다. PostLike와 Bookmark에 이미 post·member 연관 필드가 있으므로 EXISTS 서브쿼리로 Post 페이지를 직접 읽는다. @EntityGraph(attributePaths = {"author", "board"})로 응답에 필요한 두 관계를 함께 읽는다. 다음 세 조건을 모두 WHERE에 넣고, 공개·미삭제·차단 제외 조건까지 같은 countQuery에 복사한다.

AND (:liked = false OR EXISTS (SELECT 1 FROM PostLike l
    WHERE l.member.id = :memberId AND l.post = p))
AND (:bookmarked = false OR EXISTS (SELECT 1 FROM Bookmark bm
    WHERE bm.member.id = :memberId AND bm.post = p))
AND (EXISTS (SELECT 1 FROM PostLike l WHERE l.member.id = :memberId AND l.post = p)
     OR EXISTS (SELECT 1 FROM Bookmark bm WHERE bm.member.id = :memberId AND bm.post = p))

글 페이지를 얻은 뒤 그 페이지 ID들에 대해서만 좋아요/북마크 관계를 각각 한 번에 조회해 DTO의 두 boolean을 채운다. 항목마다 두 관계를 따로 SELECT하지 않는다. 전체 @Query와 countQuery는 아래 PostRepository.java 접기에서 확인한다. 8-4의 동적 검색에서 이 조건 조립을 더 확장한다.

private boolean parseBoolean(String value) {
    if (value == null) return false;
    if (&quot;true&quot;.equals(value)) return true;
    if (&quot;false&quot;.equals(value)) return false;

}

private int parseNumber(String value, int fallback, int min, int max) {
    if (value == null) return fallback;
    if (!value.matches(&quot;[0-9]+&quot;)) {

    }
    try {
        int parsed = Integer.parseInt(value);
        if (parsed &gt;= min &amp;&amp; parsed &lt;= max) return parsed;
    } catch (NumberFormatException ignored) {
        // int 범위를 벗어나는 값도 동일한 요청 오류다.
    }

@Transactional(readOnly = true)
public MarkedPostPageResponse list(Long memberId, boolean liked, boolean bookmarked,
                                   int page, int size) {
    // JPA/Hibernate의 조회 시작 위치는 int 범위다. 유효한 큰 page는 빈 페이지와 전체 건수를 돌려준다.
    if ((long) page * size &gt; Integer.MAX_VALUE) {
        long total = posts.findMarkedPosts(memberId, liked, bookmarked,
                PageRequest.of(0, 1, Sort.by(Sort.Direction.DESC, &quot;id&quot;))).getTotalElements();
        return new MarkedPostPageResponse(List.of(), page, size, total);
    }
    Page&lt;Post&gt; result = posts.findMarkedPosts(memberId, liked, bookmarked,
            PageRequest.of(page, size, Sort.by(Sort.Direction.DESC, &quot;id&quot;)));
    List&lt;Long&gt; ids = result.getContent().stream().map(Post::getId).toList();
    if (ids.isEmpty()) return new MarkedPostPageResponse(List.of(), page, size, result.getTotalElements());

    // 관계 상태는 항목마다 조회하지 않고 각 테이블에서 한 번씩 읽는다.
    Set&lt;Long&gt; likedIds = Set.copyOf(likes.findPostIdsForMember(memberId, ids));
    Set&lt;Long&gt; bookmarkedIds = Set.copyOf(bookmarks.findPostIdsForMember(memberId, ids));
    List&lt;MarkedPostItem&gt; items = result.getContent().stream()
            .map(post -&gt; new MarkedPostItem(post.getId(), post.getTitle(),
                    post.getAuthor().getNickname(), post.getBoard().getSlug(),
                    likedIds.contains(post.getId()), bookmarkedIds.contains(post.getId())))
            .toList();
    return new MarkedPostPageResponse(items, page, size, result.getTotalElements());
}

import org.example.auth.AuthenticatedMember;
import org.springframework.dao.DataIntegrityViolationException;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;
import java.time.LocalDateTime;
import java.util.List;


@Service
public class MyBatisBookmarkFolderService {
    private static final int MAX_FOLDERS = 10;
    private final MyBatisBookmarkFolderMapper folders;


public MyBatisBookmarkFolderService(MyBatisBookmarkFolderMapper folders) {
    this.folders = folders;
}

@Transactional(readOnly = true)
public List&lt;BookmarkFolderSummaryResponse&gt; list(AuthenticatedMember me) {
    return folders.findSummaries(me.id());
}

@Transactional
public BookmarkFolderResponse create(AuthenticatedMember me, BookmarkFolderRequest request) {
    String name = normalizeName(request.name());
    // 같은 회원의 생성 요청을 직렬화해 10개 한도를 지킨다.
    folders.lockMember(me.id());
    if (folders.countByMember(me.id()) &gt;= MAX_FOLDERS) {
        throw new InvalidBookmarkFolderException(&quot;폴더는 10개까지 만들 수 있습니다.&quot;);
    }
    if (folders.countByName(me.id(), name, null) &gt; 0) throw new DuplicateBookmarkFolderNameException();
    BookmarkFolderInsertRow row = new BookmarkFolderInsertRow(me.id(), name, LocalDateTime.now());
    try {
        folders.insert(row);
    } catch (DataIntegrityViolationException ex) {
        throw new DuplicateBookmarkFolderNameException();
    }
    return new BookmarkFolderResponse(row.id, name);
}

@Transactional
public BookmarkFolderResponse rename(AuthenticatedMember me, Long folderId, BookmarkFolderRequest request) {
    String name = normalizeName(request.name());
    if (folders.findMine(folderId, me.id()) == null) throw new BookmarkFolderNotFoundException();
    if (folders.countByName(me.id(), name, folderId) &gt; 0) throw new DuplicateBookmarkFolderNameException();
    try {
        if (folders.rename(folderId, me.id(), name) != 1) throw new BookmarkFolderNotFoundException();
    } catch (DataIntegrityViolationException ex) {
        throw new DuplicateBookmarkFolderNameException();
    }
    return new BookmarkFolderResponse(folderId, name);
}

@Transactional
public void delete(AuthenticatedMember me, Long folderId) {
    if (folders.findMine(folderId, me.id()) == null) throw new BookmarkFolderNotFoundException();
    folders.moveAllToDefault(folderId, me.id());
    if (folders.deleteMine(folderId, me.id()) != 1) throw new BookmarkFolderNotFoundException();
}

private String normalizeName(String raw) {
    String name = raw == null ? &quot;&quot; : raw.strip();
    if (name.isEmpty() || name.length() &gt; 50) {
        throw new InvalidBookmarkFolderException(&quot;폴더 이름은 1~50자여야 합니다.&quot;);
    }
    return name;
}

@Service
public class MyBatisBookmarkService {
    private final PostVisibilityMapper visiblePosts;
    private final MyBatisBookmarkMapper bookmarks;


public MyBatisBookmarkService(PostVisibilityMapper visiblePosts, MyBatisBookmarkMapper bookmarks) {
    this.visiblePosts = visiblePosts;
    this.bookmarks = bookmarks;

@Transactional
public BookmarkResponse bookmark(Long postId, AuthenticatedMember me, BookmarkRequest request) {
    if (visiblePosts.findVisibleDetail(postId, me.id(), me.role()) == null
            || !&quot;PUBLISHED&quot;.equals(bookmarks.findPostStatus(postId))) {
        throw new PostNotFoundException();
    }
    Long folderId = request.folderId();
    if (folderId != null &amp;&amp; bookmarks.findOwnedFolder(folderId, me.id()) == null) {
        throw new BookmarkFolderNotFoundException();
    }
    // UNIQUE(member_id,post_id)를 이용해 생성과 변경을 하나의 SQL로 처리한다.
    bookmarks.upsert(new BookmarkInsertRow(me.id(), postId, folderId, request.memo(), LocalDateTime.now()));
    // FOR UPDATE로 현재 행을 읽는다. 반복 PUT도 같은 bookmarkId를 돌려준다.
    BookmarkRow row = bookmarks.findBookmark(me.id(), postId);
    return new BookmarkResponse(row.id, postId, true, row.folderId, row.memo);
}

@Transactional
public BookmarkResponse patchMemo(Long postId, AuthenticatedMember me,
                                  BookmarkMemoPatchRequest request) {
    if (request == null) throw new ResponseStatusException(HttpStatus.BAD_REQUEST);
    // 회원과 글 조건으로 행을 잠그고, 생략된 memo는 UPDATE하지 않는다.
    BookmarkRow row = bookmarks.findBookmark(me.id(), postId);
    if (row == null) throw new BookmarkNotFoundException();
    if (request.isMemoPresent()) {
        JsonNode value = request.getMemo();
        if (value != null &amp;&amp; !value.isNull() &amp;&amp; !value.isTextual()) {
            throw new ResponseStatusException(HttpStatus.BAD_REQUEST);
        }
        String memo = value == null || value.isNull() ? null : value.asText();
        if (memo != null &amp;&amp; memo.length() &gt; 200) {
            throw new ResponseStatusException(HttpStatus.BAD_REQUEST);
        }
        if (bookmarks.updateMemo(me.id(), postId, memo) != 1) {
            throw new BookmarkNotFoundException();
        }
        row.memo = memo;
    }
    return new BookmarkResponse(row.id, postId, true, row.folderId, row.memo);
}

@Transactional
public void unbookmark(Long postId, AuthenticatedMember me) {
    bookmarks.deleteByMemberAndPost(me.id(), postId);
}

@Transactional
public BookmarkResponse move(Long bookmarkId, AuthenticatedMember me, BookmarkMoveRequest request) {
    BookmarkRow row = bookmarks.findOwnedBookmark(bookmarkId, me.id());
    if (row == null) throw new BookmarkNotFoundException();
    Long folderId = request.folderId();
    if (folderId != null &amp;&amp; bookmarks.findOwnedFolder(folderId, me.id()) == null) {
        throw new BookmarkFolderNotFoundException();
    }
    if (bookmarks.moveBookmark(bookmarkId, me.id(), folderId) != 1) {
        throw new BookmarkNotFoundException();
    }
    return new BookmarkResponse(bookmarkId, row.postId, true, folderId, row.memo);
}

@Transactional(readOnly = true)
public MyBookmarksResponse myBookmarks(AuthenticatedMember me, String folder, int size, String cursor) {
    String mode;
    Long folderId = null;
    if (folder == null) {
        mode = &quot;ALL&quot;;
    } else if (&quot;default&quot;.equals(folder)) {
        mode = &quot;DEFAULT&quot;;
    } else {
        mode = &quot;ID&quot;;
        try {
            folderId = Long.valueOf(folder);
        } catch (NumberFormatException ex) {
            throw new InvalidBookmarkFolderException(&quot;folder는 생략·default·폴더 id 중 하나여야 합니다.&quot;);
        }
        if (bookmarks.findOwnedFolder(folderId, me.id()) == null) {
            throw new BookmarkFolderNotFoundException();
        }
    }
    Cursor after = Cursor.decode(cursor);
    List&lt;BookmarkListRow&gt; rows = bookmarks.findMyBookmarks(me.id(), me.role(), mode, folderId,
            after == null ? null : after.at(), after == null ? null : after.id(), size + 1);
    boolean hasNext = rows.size() &gt; size;
    List&lt;BookmarkListRow&gt; page = hasNext ? rows.subList(0, size) : rows;
    List&lt;BookmarkItemResponse&gt; items = page.stream().map(row -&gt; {
        boolean available = Boolean.TRUE.equals(row.available);
        return new BookmarkItemResponse(row.id, row.postId, row.folderId, row.memo,
                row.bookmarkedAt, available, available ? row.title : null,
                available ? new AuthorResponse(row.authorId, row.authorNickname) : null);
    }).toList();
    BookmarkListRow last = page.isEmpty() ? null : page.get(page.size() - 1);
    return new MyBookmarksResponse(items,
            hasNext ? new Cursor(last.bookmarkedAt, last.id).encode() : null);
}

public MyLikesResponse myLikes(AuthenticatedMember me, int size, String cursor) {
    LocalDateTime cursorAt = null;
    Long cursorId = null;
    if (cursor != null) {
        String[] parts = decodeCursor(cursor);
        cursorAt = LocalDateTime.parse(parts[0]);
        cursorId = Long.valueOf(parts[1]);
    }
    List&lt;MyLikeRow&gt; rows = likes.findMyLikes(me.id(), cursorAt, cursorId, size + 1);
    boolean hasNext = rows.size() &gt; size;
    List&lt;MyLikeRow&gt; page = hasNext ? rows.subList(0, size) : rows;
    List&lt;MyLikeItemResponse&gt; items = page.stream()
            .map(row -&gt; new MyLikeItemResponse(row.postId, row.title,
                    new AuthorResponse(row.authorId, row.authorNickname), row.likedAt))
            .toList();
    String nextCursor = hasNext ? encodeCursor(page.get(page.size() - 1)) : null;
    return new MyLikesResponse(items, nextCursor);
}

private String encodeCursor(MyLikeRow last) {
    String raw = last.likedAt + &quot;|&quot; + last.likeId;
    return Base64.getUrlEncoder().withoutPadding()
            .encodeToString(raw.getBytes(StandardCharsets.UTF_8));
}

private String[] decodeCursor(String cursor) {
    try {
        String raw = new String(Base64.getUrlDecoder().decode(cursor), StandardCharsets.UTF_8);
        String[] parts = raw.split(&quot;\\|&quot;, -1);
        if (parts.length != 2) throw new IllegalArgumentException();
        LocalDateTime.parse(parts[0]);
        if (Long.parseLong(parts[1]) &lt; 1) throw new IllegalArgumentException();
        return parts;
    } catch (IllegalArgumentException | DateTimeException ex) {
        throw new ResponseStatusException(HttpStatus.BAD_REQUEST, &quot;올바르지 않은 cursor입니다.&quot;);
    }
}

@Service
public class PostPatchMyBatisService {

    private static final int TAGS_MAX_COUNT = 5;
    private static final int TAG_NAME_MAX_LENGTH = 30;


private final PostVisibilityMapper visibilityMapper;

    this.visibilityMapper = visibilityMapper;
    this.replaceMapper = replaceMapper;
}

@Transactional
public PostDetailResponse patch(Long id, AuthenticatedMember me, PostUpdateRequest request) {
    PostDetailRow current = visibilityMapper.findVisibleDetail(id, me.id(), me.role());
    if (current == null) throw new PostNotFoundException();
    if (!current.authorId.equals(me.id())) throw new PostForbiddenException();

    // 모든 입력을 확인한 뒤 쓰기를 시작한다.
    if (request.title() != null) validateTitle(request.title());
    if (request.content() != null) validateContent(request.content());
    if (request.tags() != null) validateTags(request.tags());
    if (request.visibility() != null) validateVisibility(request.visibility());

    List&lt;String&gt; tags;
    if (request.tags() == null) {
        tags = visibilityMapper.findTagsByPostIds(List.of(id)).stream()
                .map(PostTagRow::name).toList();
    } else {
        List&lt;PostReplaceTagRow&gt; resolved = new ArrayList&lt;&gt;();
        Set&lt;Long&gt; seenIds = new HashSet&lt;&gt;();
        for (String name : request.tags()) {
            replaceMapper.insertTagIfMissing(name);
            PostReplaceTagRow tag = replaceMapper.findTagByName(name);
            if (seenIds.add(tag.id)) resolved.add(tag);
        }
        replaceMapper.deletePostTags(id);
        for (PostReplaceTagRow tag : resolved) replaceMapper.insertPostTag(id, tag.id);
        tags = resolved.stream().map(tag -&gt; tag.name).toList();
    }
    replaceMapper.patchPost(id, request.title(), request.content(), request.visibility());
    return new PostDetailResponse(id, current.boardSlug,
            request.title() == null ? current.title : request.title(),
            request.content() == null ? current.content : request.content(),
            tags,
            request.visibility() == null ? current.visibility : request.visibility(),
            new AuthorResponse(current.authorId, current.authorNickname),
            current.viewCount, current.likeCount, current.commentCount, current.createdAt);
}

private void validateTitle(String title) {
    if (title.isBlank()) throw new InvalidPostFieldException(&quot;title&quot;, &quot;제목을 입력해 주세요.&quot;);
    if (title.length() &gt; TITLE_MAX_LENGTH)
        throw new InvalidPostFieldException(&quot;title&quot;, &quot;제목은 &quot; + TITLE_MAX_LENGTH + &quot;자 이하여야 합니다.&quot;);
}

private void validateContent(String content) {
    if (content.isBlank()) throw new InvalidPostFieldException(&quot;content&quot;, &quot;본문을 입력해 주세요.&quot;);
}

private void validateTags(List&lt;String&gt; tags) {
    if (tags.size() &gt; TAGS_MAX_COUNT)
        throw new InvalidPostFieldException(&quot;tags&quot;, &quot;태그는 &quot; + TAGS_MAX_COUNT + &quot;개까지입니다.&quot;);
    for (String tag : tags) {
        if (tag == null || tag.isBlank() || tag.length() &gt; TAG_NAME_MAX_LENGTH)
            throw new InvalidPostFieldException(&quot;tags&quot;, &quot;태그 이름은 1~&quot; + TAG_NAME_MAX_LENGTH + &quot;자여야 합니다.&quot;);
    }
}

private void validateVisibility(String visibility) {
    if (!&quot;PUBLIC&quot;.equals(visibility) &amp;&amp; !&quot;FOLLOWERS&quot;.equals(visibility))
        throw new InvalidPostFieldException(&quot;visibility&quot;, &quot;공개 범위는 PUBLIC 또는 FOLLOWERS여야 합니다.&quot;);
}
