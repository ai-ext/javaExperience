#6-2. 폴더 — 최대 10개, 이름 중복 불가

#상황

"북마크를 폴더로 정리하고 싶어요. 폴더는 10개까지, 같은 이름은 못 만들게요. 폴더를 지우면 안에 있던 북마크는 지우지 말고 기본 폴더로 옮겨 주세요."

규칙이 여럿인 작은 CRUD다. 한도·중복·소유자 확인을 각각 어디서 어떻게 막을지가 핵심이다.

#화면 시나리오

사용자가 화면에서 무엇을 하면 어떤 요청이 서버로 가고, 서버·DB에서 무슨 일이 일어나 어떤 응답이 돌아와 화면이 어떻게 바뀌는지다. 흐름을 펼치면 사용자 행동부터 응답까지 차례대로 볼 수 있다.

#구현 가이드

화면 시나리오의 서버·DB 흐름을 이 단계에서 바뀐 파일에 연결한다. 먼저 만들 것의 계약대로 직접 작성하고, 필요한 역할만 펼쳐 파일 전문과 비교한다.

이 단계의 처리 흐름:

  • 서비스가 먼저 확인해도, 동시에 두 요청이 오면 DB의 UNIQUE(member_id, name)가 막는다 → 그 예외를 409로
  • 북마크는 지우지 않고 기본 폴더로 — 한 번의 UPDATE
Controller — HTTP 연결

BookmarkController.java, BookmarkFolderController.java. 매핑과 메서드의 입력·응답을 위 만들 것의 HTTP 계약과 대조한다. 이번 단계 매핑: @PatchMapping("/api/me/bookmarks/{bookmarkId}"), @RequestMapping("/api/me/bookmark-folders"), @GetMapping. 변경된 메서드: move, list, create, rename.

@PostMapping
public ResponseEntity<BookmarkFolderResponse> create(@LoginMember AuthenticatedMember me,
                                                       @RequestBody JsonNode request) {
    BookmarkFolderResponse created = folderService.create(me, BookmarkFolderRequest.from(request));
    return ResponseEntity.created(URI.create("/api/me/bookmark-folders/" + created.id())).body(created);
}

GET은 읽기 요청이지만 내 자료이므로 토큰이 없으면 AuthenticationRequiredException으로 401을 돌린다.

DTO — 요청·응답 필드

BookmarkFolderRequest.java, BookmarkFolderResponse.java, BookmarkFolderSummaryResponse.java, BookmarkMoveRequest.java. 필드 이름·타입·검증·응답 형태를 위 만들 것과 대조한다. Controller는 JsonNode를 받은 뒤 from에서 타입을 검사한다.

public record BookmarkFolderRequest(String name) {
    public static BookmarkFolderRequest from(JsonNode body) {
        if (body == null || !body.isObject() || body.get("name") == null
                || !body.get("name").isTextual()) {
            throw new InvalidBookmarkFolderException("폴더 이름은 문자열이어야 합니다.");
        }
        return new BookmarkFolderRequest(body.get("name").asText());
    }
}
public record BookmarkFolderSummaryResponse(Long id, String name, long bookmarkCount) {}
public record BookmarkMoveRequest(Long folderId) {
    public static BookmarkMoveRequest from(JsonNode body) {
        if (body == null || !body.isObject()) {
            throw new InvalidBookmarkFieldException("body", "JSON 객체를 보내 주세요.");
        }
        JsonNode folder = body.get("folderId");
        if (folder == null || folder.isNull()) return new BookmarkMoveRequest(null);
        if (!folder.isIntegralNumber() || !folder.canConvertToLong() || folder.longValue() <= 0) {
            throw new InvalidBookmarkFieldException("folderId", "폴더 ID는 양의 정수여야 합니다.");
        }
        return new BookmarkMoveRequest(folder.asLong());
    }
}

BookmarkFolderRequest.from은 name이 JSON 문자열인지, BookmarkMoveRequest.from은 folderId가 양의 정수인지 먼저 검사한다. 이름은 서비스에서 앞뒤 공백을 자른 뒤 검사한다. 북마크 이동 응답은 6-1의 BookmarkResponse를 그대로 쓴다.

Service — 처리 순서

BookmarkFolderService.java, BookmarkService.java. 위 서버 처리 순서가 어디에서 검증·조회·상태 변경으로 이어지는지 따라간다. 변경된 메서드: list, create, rename, delete. 트랜잭션 경계는 아래 코드의 @Transactional 위치에서 확인한다.

@Transactional
public void delete(AuthenticatedMember me, Long folderId) {
    BookmarkFolder folder = findMine(folderId, me.id());
    bookmarkRepository.moveAllToDefaultFolder(folder.getId());
    folderRepository.delete(folder);
}

생성은 normalizeName → MemberRepository.findByIdForUpdate로 회원 행 잠금 → 내 폴더 수 10개 미만 확인 → 같은 이름 확인 → 저장 순서다. 서로 다른 이름의 동시 생성도 잠금 뒤 차례로 수를 읽어 최대 10개를 지킨다. 이름 바꾸기는 폴더 소유권과 중복 이름을 확인한다. 이동은 북마크와 목적지 폴더 모두 내 것인지 확인한다.

JPA / Repository — DB 조건

BookmarkFolderRepository.java, BookmarkRepository.java. 쿼리·파생 메서드의 조건을 화면 시나리오의 DB 단계 및 직접 확인 SQL과 대조한다. 직접 작성한 JPQL·SQL과 아래 파일의 @Query를 비교한다.

@Modifying
@Query("UPDATE Bookmark b SET b.folder = null WHERE b.folder.id = :folderId")
int moveAllToDefaultFolder(@Param("folderId") Long folderId);

폴더별 북마크 수는 findSummaries의 JPQL 한 번으로 읽고, findByIdAndMember_Id로 소유권을 제한한다. 폴더 삭제 시 위 UPDATE와 폴더 DELETE가 같은 트랜잭션이다.

Entity — 테이블·상태

Bookmark.java, BookmarkFolder.java. 실제 테이블의 컬럼·외래키와 엔티티 매핑을 대조한다. 변경된 메서드: moveTo, rename.

BookmarkFolder는 (member_id, name) 유일 제약을 전제로 한다. Bookmark.moveTo는 folder_id를 바꾸고 updated_at을 갱신한다.

예외 처리 — 실패 응답

BookmarkNotFoundException.java, DuplicateBookmarkFolderNameException.java, InvalidBookmarkFolderException.java, ApiExceptionHandler.java. 예외가 어떤 HTTP 상태와 오류 본문으로 바뀌는지 실패 계약과 대조한다. 변경된 메서드: handleBookmarkNotFound, handleInvalidBookmarkFolder, handleDuplicateBookmarkFolderName.

// 저장 시점의 UNIQUE(member_id, name) 충돌도 409로 바꾼다.
try {
    return folderRepository.saveAndFlush(folder);
} catch (DataIntegrityViolationException e) {
    throw new DuplicateBookmarkFolderNameException();
}

이름 공백·길이·10개 한도는 400, 중복 이름은 409, 남의 폴더나 북마크는 404로 매핑한다.

MyBatis — 폴더 목록·생성·이동·삭제 SQL

MyBatis 대체 코드 토글의 MyBatisBookmarkFolderService와 Mapper XML을 펼쳐 JPA 경로와 비교한다.

<select id="findSummaries" resultType="org.example.bookmark.BookmarkFolderSummaryResponse">
    SELECT f.id, f.name, COUNT(b.id) AS bookmarkCount
    FROM bookmark_folder f LEFT JOIN bookmark b ON b.folder_id = f.id
    WHERE f.member_id = #{memberId}
    GROUP BY f.id, f.name, f.created_at
    ORDER BY f.created_at ASC, f.id ASC
</select>
<update id="moveAllToDefault">
    UPDATE bookmark SET folder_id = NULL, updated_at = NOW()
    WHERE folder_id = #{folderId} AND member_id = #{memberId}
</update>

생성은 SELECT id FROM member WHERE id = #{memberId} FOR UPDATE로 회원 행을 잠근 뒤 개수를 센다. 생성·이름 변경·삭제 SQL도 member_id를 조건에 포함한다. 삭제 트랜잭션은 북마크를 기본 폴더로 옮긴 뒤 폴더 행을 지운다.

// 북마크(즐겨찾기) — UNIQUE(member_id, post_id). folder가 null이면 기본 폴더
@Entity
@Table(name = "bookmark")
public class Bookmark {


@Id
@GeneratedValue(strategy = GenerationType.IDENTITY)
private Long id;

@ManyToOne(fetch = FetchType.LAZY)
@JoinColumn(name = &quot;member_id&quot;, nullable = false)
private Member member;

@ManyToOne(fetch = FetchType.LAZY)
@JoinColumn(name = &quot;post_id&quot;, nullable = false)
private Post post;

@ManyToOne(fetch = FetchType.LAZY)
@JoinColumn(name = &quot;folder_id&quot;)
private BookmarkFolder folder;

@Column(length = 200)
private String memo;

@Column(name = &quot;created_at&quot;, nullable = false)
private LocalDateTime createdAt;

@Column(name = &quot;updated_at&quot;, nullable = false)
private LocalDateTime updatedAt;

protected Bookmark() {
    // JPA
}

public Bookmark(Member member, Post post, BookmarkFolder folder, String memo, LocalDateTime now) {
    this.member = member;
    this.post = post;
    this.folder = folder;
    this.memo = memo;
    this.createdAt = now;
    this.updatedAt = now;
}

// PUT(upsert)으로 다시 오면 보낸 폴더·메모로 바꾼다(안 보내면 null = 기본 폴더·메모 없음)
public void change(BookmarkFolder folder, String memo, LocalDateTime now) {
    this.folder = folder;
    this.memo = memo;
    this.updatedAt = now;
}

// 6-2 — 다른 폴더로 옮기기(null이면 기본 폴더)
public void moveTo(BookmarkFolder folder, LocalDateTime now) {
    this.folder = folder;
    this.updatedAt = now;
}

public Long getId() {
    return id;
}

public Member getMember() {
    return member;
}

public Post getPost() {
    return post;
}

public BookmarkFolder getFolder() {
    return folder;
}

public String getMemo() {
    return memo;
}

    return createdAt;
}

public LocalDateTime getUpdatedAt() {
    return updatedAt;
}


}

@Transactional
public BookmarkFolderResponse create(AuthenticatedMember me, BookmarkFolderRequest request) {
    String name = normalizeName(request.name());
    memberRepository.findByIdForUpdate(me.id()).orElseThrow();
    if (folderRepository.countByMember_Id(me.id()) &gt;= MAX_FOLDERS) {
        throw new InvalidBookmarkFolderException(&quot;폴더는 &quot; + MAX_FOLDERS + &quot;개까지 만들 수 있습니다.&quot;);
    }
    if (folderRepository.existsByMember_IdAndName(me.id(), name)) {
        throw new DuplicateBookmarkFolderNameException();
    }
    BookmarkFolder saved = saveOrConflict(
            new BookmarkFolder(memberRepository.getReferenceById(me.id()), name, LocalDateTime.now()));
    return new BookmarkFolderResponse(saved.getId(), saved.getName());
}

@Transactional
public BookmarkFolderResponse rename(AuthenticatedMember me, Long folderId, BookmarkFolderRequest request) {
    String name = normalizeName(request.name());
    BookmarkFolder folder = findMine(folderId, me.id());
    if (folderRepository.existsByMember_IdAndNameAndIdNot(me.id(), name, folderId)) {
        throw new DuplicateBookmarkFolderNameException();
    }
    folder.rename(name, LocalDateTime.now());
    BookmarkFolder saved = saveOrConflict(folder);
    return new BookmarkFolderResponse(saved.getId(), saved.getName());
}

// 북마크를 기본 폴더로 옮기는 것(UPDATE 한 번)과 폴더 삭제가 한 트랜잭션이다
@Transactional
public void delete(AuthenticatedMember me, Long folderId) {
    BookmarkFolder folder = findMine(folderId, me.id());
    bookmarkRepository.moveAllToDefaultFolder(folder.getId());
    folderRepository.delete(folder);
}

private BookmarkFolder findMine(Long folderId, Long memberId) {
    return folderRepository.findByIdAndMember_Id(folderId, memberId)
            .orElseThrow(BookmarkFolderNotFoundException::new);
}

// 서비스에서 먼저 확인해도 두 요청이 동시에 오면 둘 다 통과할 수 있다.
// 그때는 DB의 UNIQUE(member_id, name)가 막으므로, 그 예외를 409로 바꾼다(flush로 이 자리에서 터지게 한다).
private BookmarkFolder saveOrConflict(BookmarkFolder folder) {
    try {
        return folderRepository.saveAndFlush(folder);
    } catch (DataIntegrityViolationException e) {
        throw new DuplicateBookmarkFolderNameException();
    }
}

// 앞뒤 공백을 자른 뒤 1~50자
private String normalizeName(String raw) {
    String name = raw == null ? &quot;&quot; : raw.strip();
    if (name.isEmpty() || name.length() &gt; NAME_MAX_LENGTH) {
        throw new InvalidBookmarkFolderException(&quot;폴더 이름은 1~&quot; + NAME_MAX_LENGTH + &quot;자여야 합니다.&quot;);
    }
    return name;
}

    Post post = findBookmarkablePost(postId, loginMember);
    BookmarkFolder folder = findMyFolder(request.folderId(), loginMember.id());
    bookmarkRepository.upsert(loginMember.id(), postId,
            folder == null ? null : folder.getId(), request.memo());
    Bookmark bookmark = bookmarkRepository.findCurrentForUpdate(loginMember.id(), postId)
            .orElseThrow(() -&gt; new IllegalStateException(&quot;북마크 저장 결과를 찾을 수 없습니다.&quot;));

        return null;

        throw new PostNotFoundException();
    }
    return post;
}

import org.example.auth.AuthenticatedMember;
import org.springframework.dao.DataIntegrityViolationException;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;
import java.time.LocalDateTime;
import java.util.List;


@Service
public class MyBatisBookmarkFolderService {
    private static final int MAX_FOLDERS = 10;
    private final MyBatisBookmarkFolderMapper folders;


public MyBatisBookmarkFolderService(MyBatisBookmarkFolderMapper folders) {
    this.folders = folders;
}

@Transactional(readOnly = true)
public List&lt;BookmarkFolderSummaryResponse&gt; list(AuthenticatedMember me) {
    return folders.findSummaries(me.id());
}

@Transactional
public BookmarkFolderResponse create(AuthenticatedMember me, BookmarkFolderRequest request) {
    String name = normalizeName(request.name());
    // 같은 회원의 생성 요청을 직렬화해 10개 한도를 지킨다.
    folders.lockMember(me.id());
    if (folders.countByMember(me.id()) &gt;= MAX_FOLDERS) {
        throw new InvalidBookmarkFolderException(&quot;폴더는 10개까지 만들 수 있습니다.&quot;);
    }
    if (folders.countByName(me.id(), name, null) &gt; 0) throw new DuplicateBookmarkFolderNameException();
    BookmarkFolderInsertRow row = new BookmarkFolderInsertRow(me.id(), name, LocalDateTime.now());
    try {
        folders.insert(row);
    } catch (DataIntegrityViolationException ex) {
        throw new DuplicateBookmarkFolderNameException();
    }
    return new BookmarkFolderResponse(row.id, name);
}

@Transactional
public BookmarkFolderResponse rename(AuthenticatedMember me, Long folderId, BookmarkFolderRequest request) {
    String name = normalizeName(request.name());
    if (folders.findMine(folderId, me.id()) == null) throw new BookmarkFolderNotFoundException();
    if (folders.countByName(me.id(), name, folderId) &gt; 0) throw new DuplicateBookmarkFolderNameException();
    try {
        if (folders.rename(folderId, me.id(), name) != 1) throw new BookmarkFolderNotFoundException();
    } catch (DataIntegrityViolationException ex) {
        throw new DuplicateBookmarkFolderNameException();
    }
    return new BookmarkFolderResponse(folderId, name);
}

@Transactional
public void delete(AuthenticatedMember me, Long folderId) {
    if (folders.findMine(folderId, me.id()) == null) throw new BookmarkFolderNotFoundException();
    folders.moveAllToDefault(folderId, me.id());
    if (folders.deleteMine(folderId, me.id()) != 1) throw new BookmarkFolderNotFoundException();
}

private String normalizeName(String raw) {
    String name = raw == null ? &quot;&quot; : raw.strip();
    if (name.isEmpty() || name.length() &gt; 50) {
        throw new InvalidBookmarkFolderException(&quot;폴더 이름은 1~50자여야 합니다.&quot;);
    }
    return name;
}

@Transactional
public BookmarkResponse bookmark(Long postId, AuthenticatedMember me, BookmarkRequest request) {
    if (visiblePosts.findVisibleDetail(postId, me.id(), me.role()) == null
            || !&quot;PUBLISHED&quot;.equals(bookmarks.findPostStatus(postId))) {
        throw new PostNotFoundException();
    }
    Long folderId = request.folderId();
    if (folderId != null &amp;&amp; bookmarks.findOwnedFolder(folderId, me.id()) == null) {
        throw new BookmarkFolderNotFoundException();
    }
    // UNIQUE(member_id,post_id)를 이용해 생성과 변경을 하나의 SQL로 처리한다.
    bookmarks.upsert(new BookmarkInsertRow(me.id(), postId, folderId, request.memo(), LocalDateTime.now()));
    // FOR UPDATE로 현재 행을 읽는다. 반복 PUT도 같은 bookmarkId를 돌려준다.
    BookmarkRow row = bookmarks.findBookmark(me.id(), postId);

}

public MyLikesResponse myLikes(AuthenticatedMember me, int size, String cursor) {
    LocalDateTime cursorAt = null;
    Long cursorId = null;
    if (cursor != null) {
        String[] parts = decodeCursor(cursor);
        cursorAt = LocalDateTime.parse(parts[0]);
        cursorId = Long.valueOf(parts[1]);
    }
    List&lt;MyLikeRow&gt; rows = likes.findMyLikes(me.id(), cursorAt, cursorId, size + 1);
    boolean hasNext = rows.size() &gt; size;
    List&lt;MyLikeRow&gt; page = hasNext ? rows.subList(0, size) : rows;
    List&lt;MyLikeItemResponse&gt; items = page.stream()
            .map(row -&gt; new MyLikeItemResponse(row.postId, row.title,
                    new AuthorResponse(row.authorId, row.authorNickname), row.likedAt))
            .toList();
    String nextCursor = hasNext ? encodeCursor(page.get(page.size() - 1)) : null;
    return new MyLikesResponse(items, nextCursor);
}

private String encodeCursor(MyLikeRow last) {
    String raw = last.likedAt + &quot;|&quot; + last.likeId;
    return Base64.getUrlEncoder().withoutPadding()
            .encodeToString(raw.getBytes(StandardCharsets.UTF_8));
}

private String[] decodeCursor(String cursor) {
    try {
        String raw = new String(Base64.getUrlDecoder().decode(cursor), StandardCharsets.UTF_8);
        String[] parts = raw.split(&quot;\\|&quot;, -1);
        if (parts.length != 2) throw new IllegalArgumentException();
        LocalDateTime.parse(parts[0]);
        if (Long.parseLong(parts[1]) &lt; 1) throw new IllegalArgumentException();
        return parts;
    } catch (IllegalArgumentException | DateTimeException ex) {
        throw new ResponseStatusException(HttpStatus.BAD_REQUEST, &quot;올바르지 않은 cursor입니다.&quot;);
    }
}

private LikeResponse withDeadlockRetry(java.util.function.Supplier&lt;LikeResponse&gt; action) {

                throw e;

        }
    }

@Transactional
public PostDetailResponse patch(Long id, AuthenticatedMember me, PostUpdateRequest request) {
    PostDetailRow current = visibilityMapper.findVisibleDetail(id, me.id(), me.role());
    if (current == null) throw new PostNotFoundException();
    if (!current.authorId.equals(me.id())) throw new PostForbiddenException();

    // 모든 입력을 확인한 뒤 쓰기를 시작한다.
    if (request.title() != null) validateTitle(request.title());
    if (request.content() != null) validateContent(request.content());
    if (request.tags() != null) validateTags(request.tags());
    if (request.visibility() != null) validateVisibility(request.visibility());

    List&lt;String&gt; tags;
    if (request.tags() == null) {
        tags = visibilityMapper.findTagsByPostIds(List.of(id)).stream()
                .map(PostTagRow::name).toList();

        List&lt;PostReplaceTagRow&gt; resolved = new ArrayList&lt;&gt;();

            replaceMapper.insertTagIfMissing(name);
            PostReplaceTagRow tag = replaceMapper.findTagByName(name);
            if (seenIds.add(tag.id)) resolved.add(tag);
        }
        replaceMapper.deletePostTags(id);
        for (PostReplaceTagRow tag : resolved) replaceMapper.insertPostTag(id, tag.id);
        tags = resolved.stream().map(tag -&gt; tag.name).toList();
    }
    replaceMapper.patchPost(id, request.title(), request.content(), request.visibility());
    return new PostDetailResponse(id, current.boardSlug,
            request.title() == null ? current.title : request.title(),
            request.content() == null ? current.content : request.content(),
            tags,

@Transactional
public PostDetailResponse replace(Long id, AuthenticatedMember me, PostReplaceRequest request) {
    PostDetailRow current = visibilityMapper.findVisibleDetail(id, me.id(), me.role());
    if (current == null) {
        throw new PostNotFoundException();
    }
    if (!current.authorId.equals(me.id())) {
        throw new ResponseStatusException(HttpStatus.FORBIDDEN);
    }

    // 이름이 다른 대소문자 표기도 같은 tag 행으로 연결한다.

    for (String name : request.tags()) {
        replaceMapper.insertTagIfMissing(name);
        PostReplaceTagRow tag = replaceMapper.findTagByName(name);
        if (seenTagIds.add(tag.id)) {
            tags.add(tag);
        }
    }
    replaceMapper.updatePost(id, request.title(), request.content(), request.visibility());
    replaceMapper.deletePostTags(id);
    for (PostReplaceTagRow tag : tags) {
        replaceMapper.insertPostTag(id, tag.id);
    }
    return new PostDetailResponse(id, current.boardSlug, request.title(),
            request.content(), tags.stream().map(tag -&gt; tag.name).toList(),
            request.visibility(),
