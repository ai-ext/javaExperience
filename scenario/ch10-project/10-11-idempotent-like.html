10-10의 토글은 화면에서 잘 동작했다. 그런데 운영을 시작하자 문의가 들어온다.

"좋아요를 눌렀는데 가끔 안 눌려 있어요." "가끔 에러 토스트가 떠요."

원인은 세 가지 상황이다.

상황 토글에서 생기는 일
재시도 — 모바일 네트워크가 느려 응답을 못 받자 앱이 같은 요청을 다시 보냄 서버는 두 번 다 처리했다. 좋아요 → 취소. 사용자는 한 번 눌렀는데 결과는 "안 누름"
더블클릭 재시도와 같다
동시 도착 — 두 요청이 거의 같은 순간 둘 다 "없다"를 보고 둘 다 INSERT → 한쪽 500(Duplicate entry, 10-10 망가뜨리기 ③)

토글은 같은 요청을 두 번 보내면 결과가 달라지는 API다. 요청 하나가 "지금 상태를 뒤집어라"라는 동작이기 때문이다. 해결은 요청이 원하는 상태를 말하게 하는 것이다.

  • PUT .../like — "좋아요 된 상태로 해라". 이미 그렇다면 아무것도 안 하고 성공한다.
  • DELETE .../like — "좋아요 안 된 상태로 해라". 이미 그렇다면 역시 성공한다.

몇 번을 보내도 결과가 같은 성질을 멱등(idempotent) 이라고 한다. HTTP 명세가 PUT·DELETE를 멱등 메서드로 정한 이유가 이것이다. 재시도해도 안전하다.

왜 v2인가. 이미 나간 앱은 POST /api/v1/posts/{id}/like(토글)를 부른다. 같은 주소의 의미를 바꾸면 옛 앱이 깨진다. 그래서 새 계약은 새 버전 경로(/api/v2/...)로 열고, v1 토글은 그대로 둔다. 새 화면은 v2를 쓰고, 옛 앱이 사라지면 v1을 닫는다.

#"없으면 넣기"를 한 문장으로

existsById → save처럼 두 번 나눠 하면, 그 사이에 다른 요청이 끼어든다(10-10의 500). MySQL의 INSERT IGNORE는 키가 이미 있으면 에러 대신 0행을 돌려준다. @Modifying 네이티브 쿼리의 반환값(바뀐 행 수)이 1일 때만 like_count를 올리면, 숫자도 한 번만 오른다. DELETE는 원래 없으면 0행이라 그대로 쓴다.

#그런데 동시에 보내면 데드락 — 실측

INSERT IGNORE + 바뀐 행 수만으로 만들고 같은 토큰으로 PUT 5개를 동시에 보내면 이렇게 된다.

org.springframework.dao.CannotAcquireLockException: JDBC exception executing SQL [Deadlock found when trying to get lock; try restarting transaction] [insert ignore into post_likes (post_id, user_id, created_at) values (?, ?, now())]
...
Caused by: com.mysql.cj.jdbc.exceptions.MySQLTransactionRollbackException: Deadlock found when trying to get lock; try restarting transaction

MySQL이 남긴 데드락 기록(SHOW ENGINE INNODB STATUS의 LATEST DETECTED DEADLOCK, 줄임)은 다음과 같다.

*** (1) TRANSACTION:
insert ignore into post_likes (post_id, user_id, created_at) values (39, 1, now())
*** (1) HOLDS THE LOCK(S):
... index PRIMARY of table `project`.`posts` ... lock mode S locks rec but not gap
*** (1) WAITING FOR THIS LOCK TO BE GRANTED:
... index PRIMARY of table `project`.`post_likes` ... lock mode S locks rec but not gap waiting

*** (2) TRANSACTION:
update posts p1_0 set like_count=(p1_0.like_count+1) where p1_0.id=39
*** (2) HOLDS THE LOCK(S):
... index PRIMARY of table `project`.`post_likes` ... lock_mode X locks rec but not gap
*** (2) WAITING FOR THIS LOCK TO BE GRANTED:
... index PRIMARY of table `project`.`posts` ... lock_mode X locks rec but not gap waiting
*** WE ROLL BACK TRANSACTION (1)

읽는 법은 이렇다.

  1. (2)가 먼저 post_likes에 행을 넣었다(그 행에 X락).
  2. (1)도 같은 행을 넣으려다 "이미 있나?"를 확인하려고 그 행의 S락을 기다린다. 그런데 (1)은 INSERT하면서 외래 키 확인을 위해 부모 행 posts(39)에 S락을 이미 잡았다.
  3. (2)는 이제 UPDATE posts ... like_count + 1을 하려고 posts(39)에 X락이 필요하다. (1)의 S락 때문에 기다린다.
  4. 서로가 서로를 기다린다. MySQL이 (1)을 되돌린다 → 500.

고치는 법 — 부모 행을 먼저 잠근다. 글을 확인할 때 SELECT ... FOR UPDATE로 읽는다(JPA: @Lock(LockModeType.PESSIMISTIC_WRITE)). 같은 글에 대한 좋아요 요청은 이 줄에서 한 줄로 서고, 앞 요청이 커밋한 뒤에 다음 요청이 INSERT IGNORE를 한다.

그러면 0행이 나오고 숫자는 그대로다. 실측으로 PUT 10개가 동시에 와도 모두 200, likeCount 1이었다.

  • 대가: 같은 글의 좋아요가 줄을 선다. 인기 글 하나에 초당 수천 번이 몰리는 서비스라면 다른 설계(숫자를 따로 모아 나중에 반영 등)를 쓴다. 이 게시판 규모에서는 충분하다.
  • 다른 선택지: 데드락이 나면 트랜잭션을 처음부터 재시도한다. MySQL 메시지도 "try restarting transaction"이라고 말한다. 재시도 코드가 늘고, 멱등이라서 가능한 방법이다.

#토글은 왜 안 고치나

고칠 수도 있다. 하지만 토글은 재시도에 약한 것이 본질이다(같은 요청 = 다른 결과). 서버를 아무리 고쳐도 "두 번 보낸 요청"과 "두 번 누른 사용자"를 구별할 수 없다. 그래서 새 계약을 v2로 열고 옛 앱이 줄어들기를 기다린다. 실무에서는 v1 응답에 Deprecation 헤더를 붙여 알리기도 한다.

        postRepository.changeLikeCount(postId, userId, Visibility.PUBLIC, -1);
    return new LikeResponse(false, postRepository.findLikeCount(postId));
}

import org.example.board.common.ApiException;
import org.example.board.common.ErrorCode;

import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

@Service
public class LikeService {

    private final PostLikeRepository postLikeRepository;
    private final PostRepository postRepository;

    public LikeService(PostLikeRepository postLikeRepository, PostRepository postRepository) {
        this.postLikeRepository = postLikeRepository;
        this.postRepository = postRepository;
    }

    // 토글: 없으면 만들고, 있으면 지운다. like_count도 함께(한 트랜잭션)
    @Transactional
    public LikeResponse toggle(Long userId, Long postId) {
        findVisiblePost(postId, userId);
        PostLikeId id = new PostLikeId(postId, userId);
        boolean liked;
        if (postLikeRepository.existsById(id)) {
            postLikeRepository.deleteById(id);
            if (postRepository.changeLikeCount(postId, userId, Visibility.PUBLIC, -1) == 0)
                throw new ApiException(ErrorCode.NOT_FOUND, "게시글을 찾을 수 없습니다.");
            liked = false;
        } else {
            postLikeRepository.save(new PostLike(postId, userId));
            if (postRepository.changeLikeCount(postId, userId, Visibility.PUBLIC, 1) == 0)
                throw new ApiException(ErrorCode.NOT_FOUND, "게시글을 찾을 수 없습니다.");
            liked = true;
        }
        return new LikeResponse(liked, postRepository.findLikeCount(postId));
    }

    // v2 멱등 API — 몇 번을 보내도(재시도·더블클릭·동시) 결과는 "누른 상태" 하나
    @Transactional
    public LikeResponse like(Long userId, Long postId) {
        lockVisiblePost(postId, userId);
        if (postLikeRepository.insertIfAbsent(postId, userId) == 1) {
            postRepository.changeLikeCount(postId, userId, Visibility.PUBLIC, 1);
        }
        return new LikeResponse(true, postRepository.findLikeCount(postId));
    }

    @Transactional
    public LikeResponse unlike(Long userId, Long postId) {
        lockVisiblePost(postId, userId);
        if (postLikeRepository.deleteIfPresent(postId, userId) == 1) {
            postRepository.changeLikeCount(postId, userId, Visibility.PUBLIC, -1);
        }
        return new LikeResponse(false, postRepository.findLikeCount(postId));
    }

    // 글 행을 먼저 잠근다(SELECT … FOR UPDATE). 같은 글의 좋아요 요청은 여기서 한 줄로 선다.
    // 잠그지 않으면 post_likes INSERT(외래 키 확인용 공유 락)와 posts UPDATE(배타 락)가 엇갈려 데드락이 난다
    private void lockVisiblePost(Long postId, Long userId) {
        Post post = postRepository.findByIdForUpdate(postId)
                .orElseThrow(() -> new ApiException(ErrorCode.NOT_FOUND, "게시글을 찾을 수 없습니다."));
        if (post.getVisibility() == Visibility.PRIVATE && !post.getAuthor().getId().equals(userId)) {
            throw new ApiException(ErrorCode.NOT_FOUND, "게시글을 찾을 수 없습니다.");
        }
    }

    private Post findVisiblePost(Long postId, Long userId) {
        Post post = postRepository.findByIdAndDeletedAtIsNull(postId)
                .orElseThrow(() -> new ApiException(ErrorCode.NOT_FOUND, "게시글을 찾을 수 없습니다."));
        if (post.getVisibility() == Visibility.PRIVATE && !post.getAuthor().getId().equals(userId)) {
            throw new ApiException(ErrorCode.NOT_FOUND, "게시글을 찾을 수 없습니다.");
        }
        return post;
    }
}

@Service
public class CommentService {
    private final CommentMapper commentMapper;
    private final PostMapper postMapper;
    private final UserMapper userMapper;

    public CommentService(CommentMapper commentMapper, PostMapper postMapper, UserMapper userMapper) {
        this.commentMapper = commentMapper;
        this.postMapper = postMapper;
        this.userMapper = userMapper;
    }

    @Transactional
    public CommentCreatedResponse create(Long userId, Long postId, CommentRequest request) {
        // 같은 글의 삭제·공개 범위 변경과 댓글 작성을 한 행 잠금으로 직렬화한다.
        if (commentMapper.lockActivePost(postId) == null)
            throw new ApiException(ErrorCode.NOT_FOUND, "게시글을 찾을 수 없습니다.");
        findVisiblePost(postId, userId);
        User author = userMapper.findById(userId);
        if (author == null) throw new ApiException(ErrorCode.UNAUTHORIZED);
        if (request.parentId() != null) {
            CommentWriteRow parent = commentMapper.findParent(request.parentId());
            if (parent == null || !postId.equals(parent.postId) || parent.parentId != null)
                throw ApiException.invalid("parentId", "답글은 같은 글의 최상위 댓글에만 달 수 있습니다.");
        }
        CommentWriteRow comment = new CommentWriteRow();
        comment.postId = postId;
        comment.authorId = userId;
        comment.parentId = request.parentId();
        comment.content = request.content();
        comment.createdAt = LocalDateTime.now().truncatedTo(ChronoUnit.SECONDS);
        commentMapper.insert(comment);
        return CommentCreatedResponse.of(comment, author);
    }

    @Transactional(readOnly = true)
    public List<CommentResponse> list(Long postId, Long loginUserId) {
        findVisiblePost(postId, loginUserId);
        return CommentTree.build(postMapper.findCommentRows(postId));
    }

    @Transactional
    public void delete(Long userId, Long commentId) {
        Long postId = commentMapper.findPostIdByCommentId(commentId);
        if (postId == null) throw new ApiException(ErrorCode.NOT_FOUND, "댓글을 찾을 수 없습니다.");
        if (commentMapper.lockActivePost(postId) == null)
            throw new ApiException(ErrorCode.NOT_FOUND, "댓글을 찾을 수 없습니다.");
        CommentWriteRow comment = commentMapper.findActiveById(commentId);
        if (comment == null) throw new ApiException(ErrorCode.NOT_FOUND, "댓글을 찾을 수 없습니다.");
        if (!comment.authorId.equals(userId))
            throw new ApiException(ErrorCode.FORBIDDEN, "작성자만 삭제할 수 있습니다.");
        if (commentMapper.softDelete(commentId, LocalDateTime.now().truncatedTo(ChronoUnit.SECONDS)) == 0)
            throw new ApiException(ErrorCode.NOT_FOUND, "댓글을 찾을 수 없습니다.");
    }

            throw new ApiException(ErrorCode.NOT_FOUND, "게시글을 찾을 수 없습니다.");
    }

package org.example.board.comment;

import java.util.ArrayList;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;

// 평평한 댓글 목록(시간순) → 최상위 + replies 트리
public final class CommentTree {

    private CommentTree() {
    }

    public static List<CommentResponse> build(List<CommentRow> flat) {
        Map<Long, List<CommentResponse>> repliesByParent = new LinkedHashMap<>();
        for (CommentRow c : flat) {
            if (c.parentId != null && c.deletedAt == null) {
                repliesByParent.computeIfAbsent(c.parentId, k -> new ArrayList<>()).add(CommentResponse.reply(c));
            }
        }
        List<CommentResponse> result = new ArrayList<>();
        for (CommentRow c : flat) {
            if (c.parentId != null) {
                continue;
            }
            List<CommentResponse> replies = repliesByParent.getOrDefault(c.id, List.of());
            // 지운 댓글에 살아 있는 답글이 없으면 자리도 남기지 않는다
            if (c.deletedAt != null && replies.isEmpty()) {
                continue;
            }
            result.add(CommentResponse.top(c, replies));
        }
        return result;

import org.example.board.common.ApiException;
import org.example.board.common.ErrorCode;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

@Service
public class LikeService {
    private final LikeMapper mapper;

    public LikeService(LikeMapper mapper) {
        this.mapper = mapper;
    }

    // 토글은 의도적으로 동시 재시도에 약하다. 다음 단계의 멱등 API에서 글 행 잠금을 도입한다.
    @Transactional
    public LikeResponse toggle(Long userId, Long postId) {
        LikePostRow post = mapper.findVisiblePost(postId);
        if (post == null || ("PRIVATE".equals(post.visibility) && !post.authorId.equals(userId)))
            throw new ApiException(ErrorCode.NOT_FOUND, "게시글을 찾을 수 없습니다.");
        boolean liked;
        if (mapper.exists(postId, userId)) {
            if (mapper.delete(postId, userId) == 0)
                throw new IllegalStateException("좋아요가 동시에 취소되어 토글을 완료할 수 없습니다.");
            if (mapper.changeCount(postId, userId, -1) == 0)
                throw new ApiException(ErrorCode.NOT_FOUND, "게시글을 찾을 수 없습니다.");
            liked = false;
        } else {
            mapper.insert(postId, userId);
            if (mapper.changeCount(postId, userId, 1) == 0)
                throw new ApiException(ErrorCode.NOT_FOUND, "게시글을 찾을 수 없습니다.");
            liked = true;
        }
        return new LikeResponse(liked, mapper.findCount(postId));
    }

    // 글 행을 먼저 잠가 INSERT의 외래 키 확인과 카운터 UPDATE가 충돌하지 않게 한다.
    @Transactional
    public LikeResponse like(Long userId, Long postId) {
        lockVisiblePost(postId, userId);
        if (mapper.insertIfAbsent(postId, userId) == 1) {
            if (mapper.changeCount(postId, userId, 1) != 1)
                throw new IllegalStateException("좋아요 수를 변경하지 못했습니다.");
        }
        return new LikeResponse(true, mapper.findCount(postId));
    }

    @Transactional
    public LikeResponse unlike(Long userId, Long postId) {
        lockVisiblePost(postId, userId);
        if (mapper.delete(postId, userId) == 1) {
            if (mapper.changeCount(postId, userId, -1) != 1)
                throw new IllegalStateException("좋아요 수를 변경하지 못했습니다.");
        }
        return new LikeResponse(false, mapper.findCount(postId));
    }

    private void lockVisiblePost(Long postId, Long userId) {
        LikePostRow post = mapper.lockVisiblePost(postId);
        if (post == null || ("PRIVATE".equals(post.visibility) && !post.authorId.equals(userId)))
            throw new ApiException(ErrorCode.NOT_FOUND, "게시글을 찾을 수 없습니다.");
    }

import java.util.List;
import java.util.Map;
import java.util.stream.Collectors;

import org.example.board.common.ApiException;
import org.springframework.stereotype.Service;

// 게시글 목록·검색 — MyBatis 동적 SQL
@Service
public class PostQueryService {
    private final PostQueryMapper mapper;

    public PostQueryService(PostQueryMapper mapper) {
        this.mapper = mapper;
    }

    @Transactional(readOnly = true)
    public Object list(PostListQuery query, Long loginUserId) {
        if (query.cursorMode()) {
            return cursorList(query, loginUserId);
        }
        int page = query.page() == null ? 0 : query.page();
        long offset = (long) page * query.size();
        List<PostListRow> rows = mapper.findPage(query, loginUserId, offset);
        long total = mapper.count(query, loginUserId);
        return new PageResponse<>(withTags(rows), page, query.size(), total, offset + rows.size() < total);
    }

    private CursorResponse<PostListItemResponse> cursorList(PostListQuery query, Long loginUserId) {
        // 인기순은 좋아요가 바뀌면 순서가 흔들려 커서가 글을 빠뜨리거나 두 번 준다 — 최신순만 허락한다
        if ("popular".equals(query.sort())) {
            throw ApiException.invalid("cursor", "커서 페이징은 최신순(latest)에서만 쓸 수 있습니다.");
        }
        if (query.page() != null) {
            throw ApiException.invalid("page", "page와 cursor는 함께 쓸 수 없습니다.");
        }
        Long cursorId = parseCursor(query.cursor());
        // size + 1행으로 다음 페이지 존재 여부를 판단한다.
        List<PostListRow> rows = mapper.findAfterCursor(query, loginUserId, cursorId, query.size() + 1);
        boolean hasNext = rows.size() > query.size();
        List<PostListRow> page = hasNext ? rows.subList(0, query.size()) : rows;
        String next = hasNext ? String.valueOf(page.get(page.size() - 1).id) : null;
        return new CursorResponse<>(withTags(page), next);
    }

    private Long parseCursor(String cursor) {
        if (cursor.isBlank()) {
            return null;
        }
        try {
            return Long.valueOf(cursor);
        } catch (NumberFormatException e) {
            throw ApiException.invalid("cursor", "커서 값이 올바르지 않습니다.");
        }
    }

    // 글과 태그를 JOIN한 채 페이징하지 않는다 — 이번 페이지 글들의 태그를 IN 한 번으로 읽는다.
    private List<PostListItemResponse> withTags(List<PostListRow> rows) {
        if (rows.isEmpty()) {
            return List.of();
        }
        Map<Long, List<String>> tagsByPost = mapper.findTagsByPostIds(rows.stream().map(row -> row.id).toList())
                .stream()
                .collect(Collectors.groupingBy(PostTagRow::postId, Collectors.mapping(PostTagRow::name, Collectors.toList())));
        return rows.stream()
                .map(row -> PostListItemResponse.of(row, tagsByPost.getOrDefault(row.id, List.of())))
                .toList();
    }

    public PostDetailResponse create(Long userId, PostRequest request) {

        if (author == null) throw new ApiException(ErrorCode.UNAUTHORIZED);
        Set<Tag> tags = findOrCreateTags(request.tags());
        Post post = new Post(author, request.title(), request.content(),
                Visibility.valueOf(request.visibility()), tags);
        postMapper.insertPost(post);
        for (Tag tag : tags) postMapper.linkTag(post.getId(), tag.getId());

    }

    @Transactional
    public PostDetailResponse detail(Long postId, Long loginUserId) {

        postMapper.increaseViewCount(postId);
        boolean liked = loginUserId != null && postMapper.countLike(postId, loginUserId) > 0;
        return response(rows, rows.get(0).viewCount + 1, liked, postId);

    @Transactional
    public PostDetailResponse update(Long userId, Long postId, PostRequest request) {
        findWritable(userId, postId, "작성자만 수정할 수 있습니다.");
        LocalDateTime updatedAt = LocalDateTime.now().truncatedTo(ChronoUnit.SECONDS);
        if (postMapper.updatePost(postId, request.title(), request.content(), request.visibility(), updatedAt) == 0)
            throw new ApiException(ErrorCode.NOT_FOUND, "게시글을 찾을 수 없습니다.");
        postMapper.unlinkTags(postId);
        for (Tag tag : findOrCreateTags(request.tags())) postMapper.linkTag(postId, tag.getId());
        List<PostDetailRow> rows = postMapper.findDetailRows(postId);
        boolean liked = postMapper.countLike(postId, userId) > 0;
        return response(rows, rows.get(0).viewCount, liked, postId);
    }

    @Transactional
    public void delete(Long userId, Long postId) {
        findWritable(userId, postId, "작성자만 삭제할 수 있습니다.");
        if (postMapper.softDelete(postId, LocalDateTime.now().truncatedTo(ChronoUnit.SECONDS)) == 0)
            throw new ApiException(ErrorCode.NOT_FOUND, "게시글을 찾을 수 없습니다.");
    }

    private void findWritable(Long userId, Long postId, String message) {
        List<PostDetailRow> rows = findVisibleRows(postId, userId);
        if (!rows.get(0).authorId.equals(userId)) throw new ApiException(ErrorCode.FORBIDDEN, message);
    }

    private List<PostDetailRow> findVisibleRows(Long postId, Long loginUserId) {
        List<PostDetailRow> rows = postMapper.findDetailRows(postId);
        if (rows.isEmpty()) throw new ApiException(ErrorCode.NOT_FOUND, "게시글을 찾을 수 없습니다.");
        PostDetailRow first = rows.get(0);
        if ("PRIVATE".equals(first.visibility) && !first.authorId.equals(loginUserId))
            throw new ApiException(ErrorCode.NOT_FOUND, "게시글을 찾을 수 없습니다.");
        return rows;
    }

                Visibility.valueOf(first.visibility), viewCount, first.likeCount,

            if (tag == null) {
                tag = new Tag(name);
                postMapper.insertTag(tag);
            }
            tags.add(tag);
        }
        return tags;
    }
