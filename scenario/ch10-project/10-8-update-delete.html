#10-8. 수정(PUT 전체 교체)과 삭제(soft) — 작성자 검증 403

#상황

API 규칙 성공 실패
PUT /api/v1/posts/{postId} 작성자만. 전체 교체(title·content·tags·visibility) — 빠진 필드는 기본값 200 400, 401, 403, 404
DELETE /api/v1/posts/{postId} 작성자만. soft delete(deleted_at) 200 data: null 401, 403, 404

두 가지가 새로 나온다.

  • PUT은 "전체 교체"다. 보낸 것이 글의 새 모습 전부다. {"title": "새 제목"}만 보내면 본문은 null, 태그는 없음, 공개 범위는 PUBLIC이 된다. 일부만 바꾸는 것은 PATCH의 몫이다(이 명세서에는 없다). 화면은 수정 폼의 모든 칸을 다시 보낸다.
  • 403이 처음 나온다. 로그인은 했지만(401 아님) 남의 글이다. 단, 남의 비공개 글은 10-6처럼 404다. 403을 주면 "그런 글이 있다"가 샌다.

실패를 판단하는 순서는 다음과 같다. 토큰이 없으면 401(인터셉터). 본문 규칙 위반이면 400(@Valid). 글이 없거나, 삭제됐거나, 남의 비공개면 404. 남의 글이면 403. 모두 통과하면 200이다.

#만들 것

항목 내용
PUT /api/v1/posts/{postId} 로그인 필수. 본문 규칙은 작성(10-5)과 같다 — 요청 record를 함께 쓴다(PostRequest). 빠진 필드는 기본값(본문 null, 태그 없음, PUBLIC)
성공(PUT) 200, data = 상세 모양(10-6과 같음, 조회수는 올리지 않는다), updatedAt 갱신
DELETE /api/v1/posts/{postId} 로그인 필수. deleted_at에 지금 시각. 행·태그·댓글은 지우지 않는다
성공(DELETE) 200, data = null
실패 토큰 없음 401 · 규칙 위반 400 · 없음·이미 삭제·남의 비공개 404 · 남의 글 403 FORBIDDEN

필드 규칙 — 작성(10-5)과 같은 PostRequest다. 전체 교체라 빠진 필드는 기본값이 된다. 잘못된 입력은 500이 나면 안 된다

필드 필수 null·빈 값 길이·범위 형식 기본값 틀렸을 때
title 필수 안 됨 — 없음·null·공백만 거절 다듬은 뒤 5~100자 문자열 없음 400 VALIDATION_FAILED, errors에 title
content 선택 생략·null이면 null로 바뀐다 10000자 이하 문자열 null 400, errors에 content
tags 선택 생략·null이면 모두 뗀다 05개, 각 120자 문자열 배열 [] 400, errors에 tags·tags[0]
visibility 선택 생략·null이면 PUBLIC PUBLIC·PRIVATE 정해진 값 PUBLIC 400, errors에 visibility
{postId}(경로) 필수 — — 숫자 — 숫자가 아니면 400(errors에 postId), 없는 글 404
본문 전체 필수 — — JSON — 400 BAD_JSON

#설계 포인트

  • 변경 감지. 트랜잭션 안에서 읽은 엔티티의 값을 바꾸면 save를 부르지 않아도 커밋 때 UPDATE가 나간다. 그래서 엔티티에 "값을 바꾸는 메서드"(replace(...), delete())를 두고 서비스는 그것만 부른다. setter를 열어 두지 않는다.
  • 덮어쓰기 주의 — @DynamicUpdate. Hibernate는 기본으로 UPDATE에 모든 컬럼을 넣는다. 수정 요청이 글을 읽은 뒤 커밋하기 전에, 다른 요청이 view_count를 올렸다(10-6). 그러면 수정의 UPDATE가 읽었던 옛 조회수로 덮어쓴다. 엔티티에 @DynamicUpdate를 붙이면 바뀐 컬럼만 SET에 들어간다.
  • 태그 교체. 엔티티의 태그 Set을 clear() 후 addAll(...) 하면 JPA가 post_tags의 지울 행·넣을 행을 계산해 DELETE·INSERT한다. post_tags를 직접 SQL로 다루지 않는다.
  • 동시 수정·삭제. 쓰기 트랜잭션은 posts 한 행을 SELECT ... FOR UPDATE로 먼저 잠근다. 앞선 삭제가 커밋됐다면 행이 없어 404다. MyBatis 경로는 deleted_at IS NULL 조건부 UPDATE의 영향 행 수가 0이면 404로 끝낸다.
  • 찾기 + 권한을 한 메서드로. 수정·삭제가 "없으면 404, 남의 비공개면 404, 남의 글이면 403"을 똑같이 쓴다. findWritable(userId, postId) 같은 메서드 하나로 모은다(10-9의 댓글 삭제도 같은 모양이다).
  • soft delete 뒤의 조회. 10-6의 상세·10-7의 목록이 이미 deleted_at IS NULL만 보므로, 삭제된 글은 자동으로 404·목록 제외가 된다. 그래서 조건을 한 곳에 두는 것이 중요하다.

DTO — 요청·응답 필드

PostRequest.java. 필드 이름·타입·검증·응답 형태를 위 만들 것과 대조한다.

public record PostRequest(
        @NotNull @Size(min = 5, max = 100) String title,
        @Size(max = 10000) String content,
        @Size(max = 5) List<@Size(min = 1, max = 20) String> tags,
        @Pattern(regexp = "PUBLIC|PRIVATE") String visibility) {
    public PostRequest {
        title = title == null ? null : title.strip();
        tags = tags == null ? List.of() : tags.stream()
                .map(t -> Objects.requireNonNullElse(t, "").strip().toLowerCase(Locale.ROOT))
                .distinct().toList();
        visibility = visibility == null ? "PUBLIC" : visibility;
    }
}

PostService.java. 위 서버 처리 순서가 어디에서 검증·조회·상태 변경으로 이어지는지 따라간다. 변경된 메서드: create, update, delete. 트랜잭션 경계는 아래 코드의 @Transactional 위치에서 확인한다.

@Transactional
public PostDetailResponse update(Long userId, Long postId, PostRequest request) {
    Post post = findWritable(userId, postId, "작성자만 수정할 수 있습니다.");
    post.replace(request.title(), request.content(), Visibility.valueOf(request.visibility()),
            findOrCreateTags(request.tags()));
    boolean liked = postRepository.countLike(postId, userId) > 0;
    return PostDetailResponse.of(post, post.getViewCount(), liked,
            CommentTree.build(commentRepository.findAllWithAuthorByPostId(postId)));
}

@Transactional
public void delete(Long userId, Long postId) {
    findWritable(userId, postId, "작성자만 삭제할 수 있습니다.").delete();
}

private Post findWritable(Long userId, Long postId, String forbiddenMessage) {
    if (entityManager.createNativeQuery("select id from posts where id = :id and deleted_at is null for update")
            .setParameter("id", postId).getResultList().isEmpty())
        throw new ApiException(ErrorCode.NOT_FOUND, "게시글을 찾을 수 없습니다.");
    Post post = postRepository.findDetailById(postId)
            .orElseThrow(() -> new ApiException(ErrorCode.NOT_FOUND, "게시글을 찾을 수 없습니다."));
    boolean isAuthor = post.getAuthor().getId().equals(userId);
    if (post.getVisibility() == Visibility.PRIVATE && !isAuthor)
        throw new ApiException(ErrorCode.NOT_FOUND, "게시글을 찾을 수 없습니다.");
    if (!isAuthor) throw new ApiException(ErrorCode.FORBIDDEN, forbiddenMessage);
    return post;
}

    List&lt;PostListRow&gt; rows = mapper.findAfterCursor(query, loginUserId, cursorId, query.size() + 1);
    boolean hasNext = rows.size() &gt; query.size();
    List&lt;PostListRow&gt; page = hasNext ? rows.subList(0, query.size()) : rows;
    String next = hasNext ? String.valueOf(page.get(page.size() - 1).id) : null;
    return new CursorResponse&lt;&gt;(withTags(page), next);
}

private Long parseCursor(String cursor) {
    if (cursor.isBlank()) {
        return null;
    }
    try {
        return Long.valueOf(cursor);
    } catch (NumberFormatException e) {
        throw ApiException.invalid(&quot;cursor&quot;, &quot;커서 값이 올바르지 않습니다.&quot;);
    }
}

// 글과 태그를 JOIN한 채 페이징하지 않는다 — 이번 페이지 글들의 태그를 IN 한 번으로 읽는다.
private List&lt;PostListItemResponse&gt; withTags(List&lt;PostListRow&gt; rows) {
    if (rows.isEmpty()) {
        return List.of();
    }
    Map&lt;Long, List&lt;String&gt;&gt; tagsByPost = mapper.findTagsByPostIds(rows.stream().map(row -&gt; row.id).toList())
            .stream()
            .collect(Collectors.groupingBy(PostTagRow::postId, Collectors.mapping(PostTagRow::name, Collectors.toList())));
    return rows.stream()
            .map(row -&gt; PostListItemResponse.of(row, tagsByPost.getOrDefault(row.id, List.of())))
            .toList();
}

    postMapper.increaseViewCount(postId);
    boolean liked = loginUserId != null &amp;&amp; postMapper.countLike(postId, loginUserId) &gt; 0;
    return response(rows, rows.get(0).viewCount + 1, liked, postId);
}

@Transactional
public PostDetailResponse update(Long userId, Long postId, PostRequest request) {
    findWritable(userId, postId, &quot;작성자만 수정할 수 있습니다.&quot;);
    LocalDateTime updatedAt = LocalDateTime.now().truncatedTo(ChronoUnit.SECONDS);
    if (postMapper.updatePost(postId, request.title(), request.content(), request.visibility(), updatedAt) == 0)
        throw new ApiException(ErrorCode.NOT_FOUND, &quot;게시글을 찾을 수 없습니다.&quot;);
    postMapper.unlinkTags(postId);
    for (Tag tag : findOrCreateTags(request.tags())) postMapper.linkTag(postId, tag.getId());
    List&lt;PostDetailRow&gt; rows = postMapper.findDetailRows(postId);
    boolean liked = postMapper.countLike(postId, userId) &gt; 0;
    return response(rows, rows.get(0).viewCount, liked, postId);
}

    findWritable(userId, postId, &quot;작성자만 삭제할 수 있습니다.&quot;);
    if (postMapper.softDelete(postId, LocalDateTime.now().truncatedTo(ChronoUnit.SECONDS)) == 0)
        throw new ApiException(ErrorCode.NOT_FOUND, &quot;게시글을 찾을 수 없습니다.&quot;);
}

private void findWritable(Long userId, Long postId, String message) {
    List&lt;PostDetailRow&gt; rows = findVisibleRows(postId, userId);

}

private List&lt;PostDetailRow&gt; findVisibleRows(Long postId, Long loginUserId) {
    List&lt;PostDetailRow&gt; rows = postMapper.findDetailRows(postId);
    if (rows.isEmpty()) throw new ApiException(ErrorCode.NOT_FOUND, &quot;게시글을 찾을 수 없습니다.&quot;);
    PostDetailRow first = rows.get(0);
    if (&quot;PRIVATE&quot;.equals(first.visibility) &amp;&amp; !first.authorId.equals(loginUserId))
        throw new ApiException(ErrorCode.NOT_FOUND, &quot;게시글을 찾을 수 없습니다.&quot;);
    return rows;
}

private PostDetailResponse response(List&lt;PostDetailRow&gt; rows, int viewCount, boolean liked, Long postId) {
    PostDetailRow first = rows.get(0);
    List&lt;String&gt; tags = new ArrayList&lt;&gt;();
    for (PostDetailRow row : rows) if (row.tagName != null) tags.add(row.tagName);
    return new PostDetailResponse(first.id, first.title, first.content,
            Visibility.valueOf(first.visibility), viewCount, first.likeCount,
            liked, new AuthorResponse(first.authorId, first.authorNickname), tags,
            CommentTree.build(postMapper.findCommentRows(postId)), first.createdAt, first.updatedAt);
}

private Set&lt;Tag&gt; findOrCreateTags(List&lt;String&gt; names) {
    Set&lt;Tag&gt; tags = new LinkedHashSet&lt;&gt;();
    for (String name : names) {
        Tag tag = postMapper.findTagByName(name);
        if (tag == null) {
            tag = new Tag(name);
            postMapper.insertTag(tag);
        }
        tags.add(tag);
    }
    return tags;
}

private Post findWritable(Long userId, Long postId, String forbiddenMessage) {
    if (entityManager.createNativeQuery("select id from posts where id = :id and deleted_at is null for update")
            .setParameter("id", postId).getResultList().isEmpty())
        throw new ApiException(ErrorCode.NOT_FOUND, "게시글을 찾을 수 없습니다.");
    Post post = postRepository.findDetailById(postId)          // 삭제된 글은 여기서 빈 값
            .orElseThrow(() -> new ApiException(ErrorCode.NOT_FOUND, "게시글을 찾을 수 없습니다."));
    boolean isAuthor = post.getAuthor().getId().equals(userId);
    if (post.getVisibility() == Visibility.PRIVATE && !isAuthor) {
        throw new ApiException(ErrorCode.NOT_FOUND, "게시글을 찾을 수 없습니다.");
    }
    if (!isAuthor) {
        throw new ApiException(ErrorCode.FORBIDDEN, forbiddenMessage);
    }
    return post;
}
