#만들 것

항목 내용
POST /api/v1/posts/{postId}/comments 로그인 필수. 본문 {content, parentId?}. content는 앞뒤 공백 제거 후 1~500자
글 확인 글이 없음·삭제·남의 비공개면 404
부모 확인 parentId가 있으면 그 댓글이 같은 글의, 최상위(부모 없음), 안 지운 댓글이어야 한다. 아니면 400 VALIDATION_FAILED, errors[0].field=parentId
성공(작성) 201, Location: /api/v1/comments/{id}, data = {id, postId, parentId, content, author{id, nickname}, createdAt}
GET /api/v1/posts/{postId}/comments 로그인 선택. 글 확인은 위와 같다(404). data = 10-6 상세의 comments와 같은 트리 배열
DELETE /api/v1/comments/{commentId} 로그인 필수. 없음·이미 지움·글이 지워짐 404 → 남의 댓글 403 → deleted_at 기록, 200 data: null

명세서에 없던 것을 정했다. 작성 응답의 Location은 /api/v1/comments/{id}다(삭제 주소와 같은 자원). 댓글 목록의 data는 페이지 없이 트리 배열 그대로다.

필드 규칙 — 잘못된 입력은 저장 전에 막고 500이 나면 안 된다

필드 필수 null·빈 값 길이·범위 형식 기본값 틀렸을 때
content 필수 안 됨 — 없음·null·""·공백만 거절 앞뒤 공백 제거 뒤 1~500자(다듬어 500자는 성공, 501자는 거절) JSON 문자열(숫자는 400) 없음 400 VALIDATION_FAILED, errors에 content
parentId 선택 생략·null이면 최상위 댓글 같은 글의 최상위·안 지운 댓글 id JSON 정수(소수·숫자 문자열은 400) null 숫자가 아니면 400 BAD_JSON, 규칙 위반·없는 댓글 400 VALIDATION_FAILED(errors[0].field=parentId)
{postId}(경로) 필수 — — 숫자 — 숫자가 아니면 400(errors에 postId), 없는 글 404
본문 전체 필수 — — JSON — 400 BAD_JSON

#설계 포인트

  • 트리는 10-6의 것을 그대로. 상세와 댓글 목록이 같은 함수(평평한 목록 → 트리)를 쓰면 "삭제된 부모" 규칙이 두 곳에서 어긋나지 않는다.
  • 부모 규칙은 서비스에서, 400으로. 부모를 찾고 세 조건을 본다. 10-7에서 넓힌 ApiException.invalid("parentId", "...")를 그대로 쓴다. 없는 부모도 400이다. 부모 댓글은 경로의 자원(글)이 아니라 본문의 값이라서다. 경로의 글이 없을 때만 404다.
  • "지운 부모에 답글"은? 지운 댓글에는 답글을 달지 못하게 했다(부모 조건 "안 지운"). 이미 달린 답글은 부모가 지워져도 남는다.
  • 동시 쓰기 순서. 작성·답글·삭제는 글 행을 먼저 잠그고 필요하면 부모 또는 대상 댓글 행을 잠근다. 이미 삭제된 글/댓글은 기다린 다음 404 또는 parentId 400으로 끝낸다. 그래서 삭제된 부모에 새 답글이 달리지 않는다.
  • 삭제 순서. 404(없음·지움)를 먼저, 그다음 403(남의 것)이다. 이미 지운 댓글을 남이 지우려 하면 404다. "지워진 남의 댓글"이 있다는 것을 알려 줄 이유가 없다.
  • 연관관계 저장. new Comment(post, author, parent, content)처럼 엔티티 객체를 넣으면 JPA가 post_id·author_id·parent_id를 채운다. 응답의 postId는 comment.getPost().getId()로 꺼내며, 추가 쿼리는 나가지 않는다.

    @JsonCreator(mode = JsonCreator.Mode.DELEGATING)

                rawParent == null || rawParent.isNull() ? null : rawParent.longValue());
    }
}

CommentService.java. 위 서버 처리 순서가 어디에서 검증·조회·상태 변경으로 이어지는지 따라간다. 변경된 메서드: create, list, delete. 트랜잭션 경계는 아래 코드의 @Transactional 위치에서 확인한다.

@Transactional
public CommentCreatedResponse create(Long userId, Long postId, CommentRequest request) {
    lockActivePost(postId); // posts 한 행을 FOR UPDATE로 잠근다.
    Post post = findVisiblePost(postId, userId);
    User author = userRepository.findById(userId)
            .orElseThrow(() -> new ApiException(ErrorCode.UNAUTHORIZED));
    Comment parent = request.parentId() == null ? null : findParent(post, request.parentId());
    Comment comment = commentRepository.save(new Comment(post, author, parent, request.content()));
    return CommentCreatedResponse.from(comment);
}

private Comment findParent(Post post, Long parentId) {
    if (!lockActiveComment(parentId))
        throw ApiException.invalid("parentId", "답글은 같은 글의 최상위 댓글에만 달 수 있습니다.");
    return commentRepository.findById(parentId)
            .filter(p -> p.getPost().getId().equals(post.getId()) && p.getParent() == null && !p.isDeleted())
            .orElseThrow(() -> ApiException.invalid("parentId", "답글은 같은 글의 최상위 댓글에만 달 수 있습니다."));
}

@Transactional
public void delete(Long userId, Long commentId) {
    List<?> postIds = entityManager.createNativeQuery("select post_id from comments where id = :id")
            .setParameter("id", commentId).getResultList();
    if (postIds.isEmpty()) throw new ApiException(ErrorCode.NOT_FOUND, "댓글을 찾을 수 없습니다.");
    lockActivePost(((Number) postIds.get(0)).longValue());
    if (!lockActiveComment(commentId))
        throw new ApiException(ErrorCode.NOT_FOUND, "댓글을 찾을 수 없습니다.");
    Comment comment = commentRepository.findById(commentId)
            .filter(c -> !c.isDeleted() && !c.getPost().isDeleted())
            .orElseThrow(() -> new ApiException(ErrorCode.NOT_FOUND, "댓글을 찾을 수 없습니다."));
    if (!comment.getAuthor().getId().equals(userId))
        throw new ApiException(ErrorCode.FORBIDDEN, "작성자만 삭제할 수 있습니다.");
    comment.delete();
}

private void lockActivePost(Long postId) {
    if (entityManager.createNativeQuery("select id from posts where id = :id and deleted_at is null for update")
            .setParameter("id", postId).getResultList().isEmpty())
        throw new ApiException(ErrorCode.NOT_FOUND, "게시글을 찾을 수 없습니다.");
}

private boolean lockActiveComment(Long commentId) {
    return !entityManager.createNativeQuery("select id from comments where id = :id and deleted_at is null for update")
            .setParameter("id", commentId).getResultList().isEmpty();
}

@Entity
@Table(name = "comments")
public class Comment {
    @ManyToOne(fetch = FetchType.LAZY, optional = false)

    private Post post;

import java.util.List;


import jakarta.persistence.EntityManager;


import org.example.board.common.ApiException;
import org.example.board.common.ErrorCode;
import org.example.board.post.Post;

@Service
public class CommentService {


private final CommentRepository commentRepository;
private final PostRepository postRepository;
private final UserRepository userRepository;
private final EntityManager entityManager;

public CommentService(CommentRepository commentRepository, PostRepository postRepository,
                      UserRepository userRepository, EntityManager entityManager) {
    this.commentRepository = commentRepository;
    this.postRepository = postRepository;
    this.userRepository = userRepository;
    this.entityManager = entityManager;
}

@Transactional
public CommentCreatedResponse create(Long userId, Long postId, CommentRequest request) {
    lockActivePost(postId);
    Post post = findVisiblePost(postId, userId);
    User author = userRepository.findById(userId).orElseThrow(() -&gt; new ApiException(ErrorCode.UNAUTHORIZED));
    Comment parent = request.parentId() == null ? null : findParent(post, request.parentId());
    Comment comment = commentRepository.save(new Comment(post, author, parent, request.content()));
    return CommentCreatedResponse.from(comment);
}

@Transactional(readOnly = true)
public List&lt;CommentResponse&gt; list(Long postId, Long loginUserId) {
    findVisiblePost(postId, loginUserId);
    return CommentTree.build(commentRepository.findAllWithAuthorByPostId(postId));
}

@Transactional
public void delete(Long userId, Long commentId) {
    List&lt;?&gt; postIds = entityManager.createNativeQuery(&quot;select post_id from comments where id = :id&quot;)
            .setParameter(&quot;id&quot;, commentId).getResultList();
    if (postIds.isEmpty()) throw new ApiException(ErrorCode.NOT_FOUND, &quot;댓글을 찾을 수 없습니다.&quot;);
    lockActivePost(((Number) postIds.get(0)).longValue());
    if (!lockActiveComment(commentId))
        throw new ApiException(ErrorCode.NOT_FOUND, &quot;댓글을 찾을 수 없습니다.&quot;);
    Comment comment = commentRepository.findById(commentId)
            .filter(c -&gt; !c.isDeleted() &amp;&amp; !c.getPost().isDeleted())
            .orElseThrow(() -&gt; new ApiException(ErrorCode.NOT_FOUND, &quot;댓글을 찾을 수 없습니다.&quot;));
    if (!comment.getAuthor().getId().equals(userId)) {
        throw new ApiException(ErrorCode.FORBIDDEN, &quot;작성자만 삭제할 수 있습니다.&quot;);
    }
    comment.delete();
}

// 부모는 같은 글의, 지워지지 않은, 최상위 댓글이어야 한다(답글의 답글 금지)
private Comment findParent(Post post, Long parentId) {
    if (!lockActiveComment(parentId))
        throw ApiException.invalid(&quot;parentId&quot;, &quot;답글은 같은 글의 최상위 댓글에만 달 수 있습니다.&quot;);
    return commentRepository.findById(parentId)
            .filter(p -&gt; p.getPost().getId().equals(post.getId()) &amp;&amp; p.getParent() == null &amp;&amp; !p.isDeleted())
            .orElseThrow(() -&gt; ApiException.invalid(&quot;parentId&quot;, &quot;답글은 같은 글의 최상위 댓글에만 달 수 있습니다.&quot;));
}

// 모든 댓글 쓰기는 글 행 → 댓글 행 순서로 잠가 삭제·답글 추가를 직렬화한다.
private void lockActivePost(Long postId) {
    if (entityManager.createNativeQuery(&quot;select id from posts where id = :id and deleted_at is null for update&quot;)
            .setParameter(&quot;id&quot;, postId).getResultList().isEmpty())
        throw new ApiException(ErrorCode.NOT_FOUND, &quot;게시글을 찾을 수 없습니다.&quot;);
}

private boolean lockActiveComment(Long commentId) {
    return !entityManager.createNativeQuery(&quot;select id from comments where id = :id and deleted_at is null for update&quot;)
            .setParameter(&quot;id&quot;, commentId).getResultList().isEmpty();
}

private Post findVisiblePost(Long postId, Long loginUserId) {
    Post post = postRepository.findByIdAndDeletedAtIsNull(postId)
            .orElseThrow(() -&gt; new ApiException(ErrorCode.NOT_FOUND, &quot;게시글을 찾을 수 없습니다.&quot;));
    if (post.getVisibility() == Visibility.PRIVATE &amp;&amp; !post.getAuthor().getId().equals(loginUserId)) {
        throw new ApiException(ErrorCode.NOT_FOUND, &quot;게시글을 찾을 수 없습니다.&quot;);
    }
    return post;
}


}

    User user = userMapper.findByEmail(request.email());
    if (user == null) throw new ApiException(ErrorCode.UNAUTHORIZED, LOGIN_FAILED);

    return new TokenResponse(jwtProvider.issue(user.getId()), jwtProvider.validitySeconds());
}

    private final CommentMapper commentMapper;
    private final PostMapper postMapper;
    private final UserMapper userMapper;


public CommentService(CommentMapper commentMapper, PostMapper postMapper, UserMapper userMapper) {
    this.commentMapper = commentMapper;
    this.postMapper = postMapper;
    this.userMapper = userMapper;

@Transactional
public CommentCreatedResponse create(Long userId, Long postId, CommentRequest request) {
    // 같은 글의 삭제·공개 범위 변경과 댓글 작성을 한 행 잠금으로 직렬화한다.
    if (commentMapper.lockActivePost(postId) == null)
        throw new ApiException(ErrorCode.NOT_FOUND, &quot;게시글을 찾을 수 없습니다.&quot;);
    findVisiblePost(postId, userId);
    User author = userMapper.findById(userId);
    if (author == null) throw new ApiException(ErrorCode.UNAUTHORIZED);
    if (request.parentId() != null) {
        CommentWriteRow parent = commentMapper.findParent(request.parentId());
        if (parent == null || !postId.equals(parent.postId) || parent.parentId != null)
            throw ApiException.invalid(&quot;parentId&quot;, &quot;답글은 같은 글의 최상위 댓글에만 달 수 있습니다.&quot;);
    }
    CommentWriteRow comment = new CommentWriteRow();
    comment.postId = postId;
    comment.authorId = userId;
    comment.parentId = request.parentId();
    comment.content = request.content();
    comment.createdAt = LocalDateTime.now().truncatedTo(ChronoUnit.SECONDS);
    commentMapper.insert(comment);
    return CommentCreatedResponse.of(comment, author);
}

@Transactional(readOnly = true)
public List&lt;CommentResponse&gt; list(Long postId, Long loginUserId) {
    findVisiblePost(postId, loginUserId);
    return CommentTree.build(postMapper.findCommentRows(postId));
}

@Transactional
public void delete(Long userId, Long commentId) {
    Long postId = commentMapper.findPostIdByCommentId(commentId);
    if (postId == null) throw new ApiException(ErrorCode.NOT_FOUND, &quot;댓글을 찾을 수 없습니다.&quot;);
    if (commentMapper.lockActivePost(postId) == null)
        throw new ApiException(ErrorCode.NOT_FOUND, &quot;댓글을 찾을 수 없습니다.&quot;);
    CommentWriteRow comment = commentMapper.findActiveById(commentId);
    if (comment == null) throw new ApiException(ErrorCode.NOT_FOUND, &quot;댓글을 찾을 수 없습니다.&quot;);
    if (!comment.authorId.equals(userId))
        throw new ApiException(ErrorCode.FORBIDDEN, &quot;작성자만 삭제할 수 있습니다.&quot;);
    if (commentMapper.softDelete(commentId, LocalDateTime.now().truncatedTo(ChronoUnit.SECONDS)) == 0)
        throw new ApiException(ErrorCode.NOT_FOUND, &quot;댓글을 찾을 수 없습니다.&quot;);
}

private void findVisiblePost(Long postId, Long loginUserId) {

    if (rows.isEmpty()) throw new ApiException(ErrorCode.NOT_FOUND, &quot;게시글을 찾을 수 없습니다.&quot;);
    PostDetailRow first = rows.get(0);
    if (&quot;PRIVATE&quot;.equals(first.visibility) &amp;&amp; !first.authorId.equals(loginUserId))
        throw new ApiException(ErrorCode.NOT_FOUND, &quot;게시글을 찾을 수 없습니다.&quot;);
}

    List&lt;CommentResponse&gt; result = new ArrayList&lt;&gt;();

        result.add(CommentResponse.top(c, replies));

@Transactional(readOnly = true)
public Object list(PostListQuery query, Long loginUserId) {
    if (query.cursorMode()) {
        return cursorList(query, loginUserId);
    }
    int page = query.page() == null ? 0 : query.page();
    long offset = (long) page * query.size();
    List&lt;PostListRow&gt; rows = mapper.findPage(query, loginUserId, offset);
    long total = mapper.count(query, loginUserId);
    return new PageResponse&lt;&gt;(withTags(rows), page, query.size(), total, offset + rows.size() &lt; total);
}

private CursorResponse&lt;PostListItemResponse&gt; cursorList(PostListQuery query, Long loginUserId) {
    // 인기순은 좋아요가 바뀌면 순서가 흔들려 커서가 글을 빠뜨리거나 두 번 준다 — 최신순만 허락한다
    if (&quot;popular&quot;.equals(query.sort())) {
        throw ApiException.invalid(&quot;cursor&quot;, &quot;커서 페이징은 최신순(latest)에서만 쓸 수 있습니다.&quot;);
    }
    if (query.page() != null) {
        throw ApiException.invalid(&quot;page&quot;, &quot;page와 cursor는 함께 쓸 수 없습니다.&quot;);
    }
    Long cursorId = parseCursor(query.cursor());
    // size + 1행으로 다음 페이지 존재 여부를 판단한다.
    List&lt;PostListRow&gt; rows = mapper.findAfterCursor(query, loginUserId, cursorId, query.size() + 1);
    boolean hasNext = rows.size() &gt; query.size();
    List&lt;PostListRow&gt; page = hasNext ? rows.subList(0, query.size()) : rows;
    String next = hasNext ? String.valueOf(page.get(page.size() - 1).id) : null;
    return new CursorResponse&lt;&gt;(withTags(page), next);
}

private Long parseCursor(String cursor) {
    if (cursor.isBlank()) {
        return null;
    }
    try {
        return Long.valueOf(cursor);
    } catch (NumberFormatException e) {
        throw ApiException.invalid(&quot;cursor&quot;, &quot;커서 값이 올바르지 않습니다.&quot;);
    }
}

    if (rows.isEmpty()) {
        return List.of();
    }
    Map&lt;Long, List&lt;String&gt;&gt; tagsByPost = mapper.findTagsByPostIds(rows.stream().map(row -&gt; row.id).toList())
            .stream()
            .collect(Collectors.groupingBy(PostTagRow::postId, Collectors.mapping(PostTagRow::name, Collectors.toList())));
    return rows.stream()
            .map(row -&gt; PostListItemResponse.of(row, tagsByPost.getOrDefault(row.id, List.of())))
            .toList();
}
