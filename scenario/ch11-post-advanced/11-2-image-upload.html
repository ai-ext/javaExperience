#11-2. 글에 이미지 첨부

시나리오 DB(community). 이번 단계 마이그레이션은 V20이다.

#상황

"글에 사진을 넣고 싶다는 요청이 제일 많아요. 사진을 고르면 바로 올라가서 미리보기가 뜨고, [발행]을 누르면 그 사진들이 글에 붙게 해 주세요. 사진 아닌 파일이나 너무 큰 파일은 막아 주시고요."

지금까지 요청 본문은 전부 JSON이었다. 파일은 JSON에 담지 않고 **multipart/form-data**로 보낸다 — 본문을 경계 문자열(boundary)로 나눠 "파트"마다 이름·파일 이름·형식·내용을 담는 형식이다.

실무에서는 보통 두 번에 나눈다.

  1. 사진을 고르는 순간 이미지만 먼저 올린다 → 서버가 저장하고 id와 주소를 돌려준다(미리보기에 쓴다).
  2. 글을 저장할 때 본문 JSON에 그 이미지 id들만 넣는다 → 서버가 이미지를 글에 연결한다.

파일 내용은 DB가 아니라 디스크(설정한 폴더)에 두고, DB에는 "누가 올린 어떤 파일인지, 어느 글에 붙었는지"만 남긴다. T-007은 외부 저장소가 준 주소만 받는 경우였다. 이번에는 서버가 파일을 직접 받는다.

#화면 시나리오

사용자가 화면에서 무엇을 하면 어떤 요청이 서버로 가고, 서버·DB에서 무슨 일이 일어나 어떤 응답이 돌아와 화면이 어떻게 바뀌는지다. 흐름을 펼치면 사용자 행동부터 응답까지 차례대로 볼 수 있다.

    status

    url로 미리보기를 띄운다(GET /api/images/3f2a…e1.gif)

@PostMapping(value = "/api/images", consumes = MediaType.MULTIPART_FORM_DATA_VALUE)
public ResponseEntity<ImageUploadResponse> upload(@LoginMember AuthenticatedMember me,
        @RequestPart(value = "file", required = false) MultipartFile file) {

    return ResponseEntity.created(URI.create(image.url()))
            .body(new ImageUploadResponse(image.getId(), image.getStoredName(), image.url(),
                    image.getContentType(), image.getSizeBytes()));
}

// 11-2 업로드 규칙 — 크기 상한은 설정(spring.servlet.multipart.max-file-size)이 먼저 막고,
// 여기서는 빈 파일과 형식(파일 서명)을 본다.
@Service
public class ImageService {


private static final int ORIGINAL_NAME_MAX_LENGTH = 255;

private final PostImageRepository postImageRepository;
private final MemberRepository memberRepository;
private final ImageStorage storage;

public ImageService(PostImageRepository postImageRepository, MemberRepository memberRepository,
                    ImageStorage storage) {
    this.postImageRepository = postImageRepository;
    this.memberRepository = memberRepository;
    this.storage = storage;
}

@Transactional
public PostImage upload(Long uploaderId, MultipartFile file) {
    if (file.isEmpty()) {
        throw new EmptyImageException();
    }
    byte[] bytes;
    try {
        bytes = file.getBytes();
    } catch (IOException e) {
        throw new UncheckedIOException(e);
    }
    ImageType type = ImageType.detect(bytes).orElseThrow(UnsupportedImageException::new);

    // 저장 이름은 서버가 짓는다 — 사용자가 보낸 이름(../../etc/passwd.png, 같은 이름 덮어쓰기)을 경로에 쓰지 않는다
    String storedName = UUID.randomUUID().toString().replace(&quot;-&quot;, &quot;&quot;) + &quot;.&quot; + type.extension();
    Member uploader = memberRepository.getReferenceById(uploaderId);
    PostImage image = postImageRepository.save(new PostImage(uploader, storedName, originalNameOf(file),
            type.contentType(), bytes.length, LocalDateTime.now()));

    // 파일 쓰기 자체가 중간에 실패해도 롤백 때 일부 기록된 파일을 지울 수 있게 먼저 등록한다.
    TransactionSynchronizationManager.registerSynchronization(new TransactionSynchronization() {
        @Override
        public void afterCompletion(int status) {
            if (status != STATUS_COMMITTED) {
                storage.delete(storedName);
            }
        }
    });
    storage.save(storedName, bytes);
    return image;
}

@Transactional(readOnly = true)
public PostImage findByStoredName(String storedName) {
    return postImageRepository.findByStoredName(storedName).orElseThrow(ImageNotFoundException::new);
}

private static String originalNameOf(MultipartFile file) {
    String name = file.getOriginalFilename();
    if (name == null || name.isBlank()) {
        return &quot;image&quot;;
    }
    return name.length() &gt; ORIGINAL_NAME_MAX_LENGTH ? name.substring(0, ORIGINAL_NAME_MAX_LENGTH) : name;
}

private static final byte[] PNG_SIGNATURE = {(byte) 0x89, 'P', 'N', 'G', '\r', '\n', 0x1A, '\n'};

public static Optional&lt;ImageType&gt; detect(byte[] bytes) {
    if (startsWith(bytes, PNG_SIGNATURE)) {
        return Optional.of(PNG);
    }
    if (startsWith(bytes, JPEG_SIGNATURE)) {
        return Optional.of(JPEG);
    }
    if (startsWith(bytes, ascii(&quot;GIF87a&quot;)) || startsWith(bytes, ascii(&quot;GIF89a&quot;))) {
        return Optional.of(GIF);
    }
    // WebP: &quot;RIFF&quot; + 길이 4바이트 + &quot;WEBP&quot;

            &amp;&amp; Arrays.equals(Arrays.copyOfRange(bytes, 8, 12), ascii(&quot;WEBP&quot;))) {
        return Optional.of(WEBP);
    }
    return Optional.empty();
}

private static boolean startsWith(byte[] bytes, byte[] prefix) {
    return bytes.length &gt;= prefix.length &amp;&amp; Arrays.equals(Arrays.copyOf(bytes, prefix.length), prefix);

@Transactional
public Post create(Long authorId, PostCreateRequest request) {
    Board board = boardRepository.findBySlug(request.boardSlug())
            .orElseThrow(() -&gt; new BoardNotFoundException(request.boardSlug()));
    // 작성자는 요청 본문이 아니라 토큰으로 인증된 회원에서 받는다(authorId 같은 값은 무시한다)
    Member author = memberRepository.getReferenceById(authorId);

    if (ADMIN_WRITE_ROLE.equals(board.getWriteRole()) &amp;&amp; !ADMIN_ROLE.equals(author.getRole())) {
        throw new BoardWriteForbiddenException(board.getSlug());
    }

    String visibility = request.visibility() != null ? request.visibility() : DEFAULT_VISIBILITY;

            status, visibility, now);

    for (Tag tag : resolveTags(request.tags(), now)) {
        post.addTag(tag);
    }

    Post saved = postRepository.save(post);
    attachImages(saved, authorId, request.imageIds());

    return saved;
}

private void attachImages(Post post, Long authorId, JsonNode imageIds) {
    if (imageIds == null || imageIds.isNull()) {
        return;
    }
    if (!imageIds.isArray()) {
        throw new InvalidPostFieldException(&quot;imageIds&quot;, &quot;이미지 ID는 숫자 배열이어야 합니다.&quot;);
    }
    if (imageIds.size() == 0) {
        return;
    }
    List&lt;Long&gt; requestedIds = new java.util.ArrayList&lt;&gt;();
    for (int index = 0; index &lt; imageIds.size(); index++) {
        JsonNode id = imageIds.get(index);
        if (!id.isIntegralNumber() || !id.canConvertToLong()) {
            throw new InvalidPostFieldException(&quot;imageIds[&quot; + index + &quot;]&quot;, &quot;이미지 ID는 정수여야 합니다.&quot;);
        }
        requestedIds.add(id.longValue());
    }
    List&lt;Long&gt; ids = requestedIds.stream().distinct().sorted().toList();
    if (ids.size() &gt; 10) {
        throw new InvalidPostFieldException(&quot;imageIds&quot;, &quot;이미지는 10개까지입니다.&quot;);
    }
    List&lt;PostImage&gt; images = postImageRepository.findAllByIdForUpdate(ids);
    boolean allUsable = images.size() == ids.size() &amp;&amp; images.stream().allMatch(image -&gt;
            image.getUploader().getId().equals(authorId) &amp;&amp; image.getPost() == null);
    if (!allUsable) {
        throw new InvalidPostFieldException(&quot;imageIds&quot;, &quot;내가 올렸고 아직 글에 붙지 않은 이미지만 붙일 수 있습니다.&quot;);
    }
    images.forEach(image -&gt; {
        image.attachTo(post);
        post.getImages().add(image);
    });
}

            .orElseThrow(PostNotFoundException::new);

    // 반대로 하면 볼 수 없는 글의 존재가 403으로 드러난다.

    }
    if (!post.getAuthor().getId().equals(loginMember.id())) {
        throw new PostForbiddenException();
    }

    LocalDateTime now = LocalDateTime.now();

    if (request.title() != null) {
        validateTitle(request.title());
        post.changeTitle(request.title());
    }
    if (request.content() != null) {
        validateContent(request.content());
        post.changeContent(request.content());
    }
    if (request.tags() != null) {
        validateTags(request.tags());
        post.replaceTags(resolveTags(request.tags(), now));
    }
    if (request.visibility() != null) {
        validateVisibility(request.visibility());
        post.changeVisibility(request.visibility());
    }
    // boardSlug는 요청에 와도 무시한다(게시판은 못 옮긴다) — PostUpdateRequest에 아예 없다.

    post.touchUpdatedAt(now);

    // 트랜잭션 안에서 지연 로딩 연관을 미리 읽어 둔다(컨트롤러가 세션 밖에서 DTO를 만든다).
    // board는 findById로 읽은 프록시라 건드리지 않으면 LazyInitializationException이 난다
    // (create()의 board는 findBySlug로 이미 로딩된 엔티티라 같은 문제가 없었다).
    post.getBoard().getSlug();
    post.getAuthor().getNickname();
    post.getTags().forEach(Tag::getName);
    post.getImages().forEach(PostImage::getStoredName);
    return post;
}

@Transactional
public PostImage upload(Long uploaderId, MultipartFile file) {
    if (file.isEmpty()) {
        throw new EmptyImageException();
    }
    byte[] bytes;
    try {
        bytes = file.getBytes();
    } catch (IOException e) {
        throw new UncheckedIOException(e);
    }
    ImageType type = ImageType.detect(bytes).orElseThrow(UnsupportedImageException::new);

    // 저장 이름은 서버가 짓는다 — 사용자가 보낸 이름(../../etc/passwd.png, 같은 이름 덮어쓰기)을 경로에 쓰지 않는다

    MyImageInsertRow row = new MyImageInsertRow(uploaderId, storedName, originalNameOf(file),
            type.contentType(), bytes.length, LocalDateTime.now());
    myImageMapper.insert(row);
    PostImage image = postImageRepository.findById(row.getId()).orElseThrow(ImageNotFoundException::new);

    // 파일 쓰기 자체가 중간에 실패해도 롤백 때 일부 기록된 파일을 지울 수 있게 먼저 등록한다.
    TransactionSynchronizationManager.registerSynchronization(new TransactionSynchronization() {
        @Override
        public void afterCompletion(int status) {
            if (status != STATUS_COMMITTED) {
                storage.delete(storedName);
            }
        }
    });
    storage.save(storedName, bytes);
    return image;
}

            .orElseThrow(() -&gt; new BoardNotFoundException(request.boardSlug()));
    // 작성자는 요청 본문이 아니라 토큰으로 인증된 회원에서 받는다(authorId 같은 값은 무시한다)

private void attachImages(Post post, Long authorId, JsonNode imageIds) {
    if (imageIds == null || imageIds.isNull()) {
        return;
    }
    if (!imageIds.isArray()) {
        throw new InvalidPostFieldException(&quot;imageIds&quot;, &quot;이미지 ID는 숫자 배열이어야 합니다.&quot;);
    }
    if (imageIds.size() == 0) {
        return;
    }
    List&lt;Long&gt; requestedIds = new java.util.ArrayList&lt;&gt;();
    for (int index = 0; index &lt; imageIds.size(); index++) {
        JsonNode id = imageIds.get(index);
        if (!id.isIntegralNumber() || !id.canConvertToLong()) {
            throw new InvalidPostFieldException(&quot;imageIds[&quot; + index + &quot;]&quot;, &quot;이미지 ID는 정수여야 합니다.&quot;);
        }
        requestedIds.add(id.longValue());
    }
    List&lt;Long&gt; ids = requestedIds.stream().distinct().sorted().toList();
    if (ids.size() &gt; 10) {
        throw new InvalidPostFieldException(&quot;imageIds&quot;, &quot;이미지는 10개까지입니다.&quot;);
    }
    // UPDATE 자체가 미연결 조건을 검사하며 행을 잠근다. 하나라도 실패하면 글·앞선 연결도 함께 롤백한다.
    postRepository.flush();
    for (Long imageId : ids) {
        if (myImageMapper.attach(imageId, authorId, post.getId()) != 1) {
            throw new InvalidPostFieldException(&quot;imageIds&quot;, &quot;내가 올렸고 아직 글에 붙지 않은 이미지만 붙일 수 있습니다.&quot;);
        }
    }
}

@Transactional
public Post patch(Long id, AuthenticatedMember loginMember, PostUpdateRequest request) {
    Post post = postRepository.findByIdForUpdate(id)
            .orElseThrow(PostNotFoundException::new);

    // 404(볼 수 없음)를 먼저 확인하고, 그다음에 403(작성자 아님)을 확인한다.
    // 반대로 하면 볼 수 없는 글의 존재가 403으로 드러난다.
    if (!accessPolicy.canView(loginMember, post)) {
        throw new PostNotFoundException();
    }
    if (!post.getAuthor().getId().equals(loginMember.id())) {
        throw new PostForbiddenException();
    }

    LocalDateTime now = LocalDateTime.now();

    if (request.title() != null) {
        validateTitle(request.title());
        post.changeTitle(request.title());
    }
    if (request.content() != null) {
        validateContent(request.content());
        post.changeContent(request.content());
    }
    if (request.tags() != null) {
        validateTags(request.tags());
        post.replaceTags(resolveTags(request.tags(), now));
    }
    if (request.visibility() != null) {
        validateVisibility(request.visibility());
        post.changeVisibility(request.visibility());
    }
    // boardSlug는 요청에 와도 무시한다(게시판은 못 옮긴다) — PostUpdateRequest에 아예 없다.

    post.touchUpdatedAt(now);

    // 트랜잭션 안에서 지연 로딩 연관을 미리 읽어 둔다(컨트롤러가 세션 밖에서 DTO를 만든다).
    // board는 findById로 읽은 프록시라 건드리지 않으면 LazyInitializationException이 난다
    // (create()의 board는 findBySlug로 이미 로딩된 엔티티라 같은 문제가 없었다).
    post.getBoard().getSlug();
    post.getAuthor().getNickname();
    post.getTags().forEach(Tag::getName);
    post.getImages().forEach(PostImage::getStoredName);
    return post;
}

@Transactional

@Transactional

    Set&lt;Tag&gt; tags = new LinkedHashSet&lt;&gt;();
    for (String tagName : distinctTagNames(tagNames)) {

        tags.add(tag);
    }

}

    if (tags == null) {
        return List.of();

    Set&lt;String&gt; seen = new LinkedHashSet&lt;&gt;(tags);

R4

required = false로 받고 null이거나 file.isEmpty()면 400 예외를 직접 던지면 응답 모양을 다른 400과 맞추기 쉽다. 크기 제한은 application.yml에:


spring:
  servlet:

넘으면 요청을 읽는 단계에서 MaxUploadSizeExceededException이 난다 — @RestControllerAdvice에 핸들러를 더해 413(HttpStatus.CONTENT_TOO_LARGE)으로 바꾼다.






힌트 2 — 형식 판정과 저장


file.getBytes()로 읽어 앞 바이트를 비교한다. GIF는 "GIF89a".getBytes(StandardCharsets.US_ASCII)와 앞 6바이트를 Arrays.equals로 비교하면 된다. PNG·JPEG 서명은 (byte) 0x89처럼 byte로 바꿔 적는다(자바 byte는 -128~127이라 0x89를 그대로 못 넣는다).


저장 이름은 UUID.randomUUID().toString().replace("-", "") + "." + 확장자. 폴더는 @Value("${app.upload-dir:uploads}")로 받아 Files.createDirectories → Files.write(root.resolve(이름), bytes).


받기는 ResponseEntity.ok().contentType(MediaType.parseMediaType(행의 content_type)).body(new FileSystemResource(경로)). 이름은 [0-9a-f]{32}\.(png|jpg|gif|webp) 정규식에 맞을 때만 찾는다.






힌트 3 — 글에 연결


PostImage에 @ManyToOne Post post(nullable)를 두고, PostService.create()에서 글을 save한 뒤 postImageRepository.findAllById(ids)로 읽어 "개수가 같은가, 모두 uploader가 나인가, 모두 post == null인가"를 본다. 하나라도 아니면 3-1에서 만든 InvalidPostFieldException("imageIds", …)를 던진다 — 같은 트랜잭션이라 방금 저장한 글도 롤백된다. 상세 응답은 Post에 @OneToMany(mappedBy = "post") @OrderBy("id")를 두거나 findByPostIdOrderById로 따로 읽는다(트랜잭션 안에서).
