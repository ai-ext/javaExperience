#실행과 완료 조건

  • ./gradlew test --tests 'J30EvidenceTest' (직접 이 이름으로 만든 테스트). 기존 테스트를 재사용하면 실제 클래스 이름으로 실행한다.
  • 구클라이언트 fixture JSON과 새 DTO를 비교하고 선택 필드 추가·enum 추가의 실패를 테스트한다.
  • 선택한 경계의 기대값과 실제 출력·실행 명령을 남긴다. 단순 설명만으로 완료하지 않는다.

통합 관찰은 disposable DB/별도 JVM에서 실행한다. 실행 불가는 이유와 함께 확인 불가로 기록한다. 성공/실패·예상/실측을 나눈다.
