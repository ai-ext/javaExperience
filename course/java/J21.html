#J21. 프록시·flush·rollback 관찰

이 연습을 쓰는 날: D21 · 필수 관찰: flush 뒤 rollback

확장 실험은 학습자 프로젝트 루트에서 작성·실행한다. 기존 java-track 과제는 해당 J 페이지의 모듈 명령을 따른다.

소요 20~40분 · D21 연결 실험 · 기존 J 재사용과 새 경계 관찰을 구분한다.

#만들 파일과 실행 위치

내 프로젝트 루트에서 진행한다. D21의 통합 관찰·테스트와 같은 증거를 사용한다. 실제 사용한 테스트 클래스 또는 요청/SQL 스크립트 경로·실행 명령·시각·예상/실제 결과를 기록한다. 별도 J21EvidenceTest.java를 만들 필요가 없다.

#오늘 실험

JPA 관찰용 통합 테스트에서 flush 뒤 예외를 던지고 트랜잭션 종료 후 새 연결로 읽는다. 프록시 경계와 테스트 트랜잭션을 구분한다.

이 Java 항목은 D21 통합 관찰의 일부다. J10의 프록시 기초를 복습하되 flush·commit·rollback은 D21의 실제 EntityManager와 별도 DB 연결로 검증한다. 별도 중복 테스트를 만들 필요가 없다.

#재사용할 Java

  • J10 기존 연습

#실행과 완료 조건

  • 테스트를 사용했다면 ./gradlew test --tests <실제클래스명>으로 재실행한다. 요청·SQL 관찰이면 해당 일자의 실제 명령과 출력을 보존한다.
  • JPA 관찰용 통합 테스트에서 flush 뒤 예외를 던지고 트랜잭션 종료 후 새 연결로 읽는다. 프록시 경계와 테스트 트랜잭션을 구분한다.
  • 선택한 경계의 기대값과 실제 출력·실행 명령을 남긴다. 단순 설명만으로 완료하지 않는다.

통합 관찰은 disposable DB/별도 JVM에서 실행한다. 실행 불가는 이유와 함께 확인 불가로 기록한다. 성공/실패·예상/실측을 나눈다.
