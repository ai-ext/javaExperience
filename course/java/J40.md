# J40. timeout·취소·실패 구분

> 소요 20~40분 · D40 연결 실험 · 기존 J 재사용과 새 경계 관찰을 구분한다.

## 만들 파일과 실행 위치

**내 프로젝트 루트**에서 `src/test/java/J40EvidenceTest.java`를 만든다. 기존 테스트로 동일 증거가 있으면 재실행·조건을 기록하고 재사용한다. java-track에 존재하지 않는 J16 이후 테스트가 있다고 가정하지 않는다.

## 오늘 실험

timeout/실패/취소를 구분하고 재시도 중복을 기록하는 테스트를 복습한다.

## 재사용할 Java

- [J08 기존 연습](J08.md)

## 실행과 완료 조건

- `./gradlew test --tests 'J40EvidenceTest'` (직접 이 이름으로 만든 테스트). 기존 테스트를 재사용하면 실제 클래스 이름으로 실행한다.
- timeout/실패/취소를 구분하고 재시도 중복을 기록하는 테스트를 복습한다.
- 선택한 경계의 기대값과 실제 출력·실행 명령을 남긴다. 단순 설명만으로 완료하지 않는다.

통합 관찰은 disposable DB/별도 JVM에서 실행한다. 실행 불가는 이유와 함께 확인 불가로 기록한다. 성공/실패·예상/실측을 나눈다.
