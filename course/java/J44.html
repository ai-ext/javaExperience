#J44. 독립 변경의 계약 테스트

이 연습을 쓰는 날: D44 · 예시 해법 없는 작은 변경 독립 수행

확장 실험은 학습자 프로젝트 루트에서 작성·실행한다. 기존 java-track 과제는 해당 J 페이지의 모듈 명령을 따른다.

요구 제시·초기 진단 뒤 수행 중 증거 또는 사후 확인으로 진행한다.

소요 20~40분 · D44 수행 중 증거·사후 확인 · 기존 J 재사용과 새 경계 관찰을 구분한다.

#만들 파일과 실행 위치

내 프로젝트 루트에서 src/test/java/J44EvidenceTest.java를 만든다. 기존 테스트로 동일 증거가 있으면 재실행·조건을 기록하고 재사용한다. java-track에 존재하지 않는 J16 이후 테스트가 있다고 가정하지 않는다.

#오늘 실험

오늘 변경에서 필요한 Java 계약 테스트를 스스로 골라 실행하고 선택 이유를 적는다.

요구 제시·초기 진단 뒤에 테스트를 선택한다. Java를 독립 평가의 선행 과제로 수행하지 않는다.

#재사용할 Java

  • J15 기존 연습

#실행과 완료 조건

  • ./gradlew test --tests 'J44EvidenceTest' (직접 이 이름으로 만든 테스트). 기존 테스트를 재사용하면 실제 클래스 이름으로 실행한다.
  • 오늘 변경에서 필요한 Java 계약 테스트를 스스로 골라 실행하고 선택 이유를 적는다.
  • 선택한 경계의 기대값과 실제 출력·실행 명령을 남긴다. 단순 설명만으로 완료하지 않는다.
  • 요구 제시/초기 진단 뒤 수행 중 증거 또는 사후 확인으로 남긴다. 독립 평가 전에 과제나 가설을 미리 정하지 않는다.

통합 관찰은 disposable DB/별도 JVM에서 실행한다. 실행 불가는 이유와 함께 확인 불가로 기록한다. 성공/실패·예상/실측을 나눈다.
