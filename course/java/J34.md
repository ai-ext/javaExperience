# J34. 두 worker의 소유권

> 소요 20~40분 · D34 연결 실험 · 기존 J 재사용과 새 경계 관찰을 구분한다.

## 만들 파일과 실행 위치

**내 프로젝트 루트**에서 진행한다. D34의 통합 관찰·테스트와 같은 증거를 사용한다. 실제 사용한 테스트 클래스 또는 요청/SQL 스크립트 경로·실행 명령·시각·예상/실제 결과를 기록한다. 별도 J34EvidenceTest.java를 만들 필요가 없다.

## 오늘 실험

두 worker가 같은 작업을 획득하도록 latch를 걸고 한쪽 lease 만료 후 오래된 worker의 완료를 검사한다.

J07 synchronized는 단일 JVM 내부만 보호한다. 운영 실습 출발 자료 D34에서 두 JVM의 PID를 분리하고 A에 kill -STOP, B의 회수 뒤 A에 kill -CONT를 보낸다. owner·lease·세대 번호와 조건부 갱신 결과를 시간순으로 수집한다. DB 소유권·오래된 worker 차단 정책은 학습자가 설계한다.

## 재사용할 Java

- [J07 기존 연습](J07.md)

## 실행과 완료 조건

- 테스트를 사용했다면 `./gradlew test --tests <실제클래스명>`으로 재실행한다. 요청·SQL 관찰이면 해당 일자의 실제 명령과 출력을 보존한다.
- 두 worker가 같은 작업을 획득하도록 latch를 걸고 한쪽 lease 만료 후 오래된 worker의 완료를 검사한다.
- 선택한 경계의 기대값과 실제 출력·실행 명령을 남긴다. 단순 설명만으로 완료하지 않는다.

통합 관찰은 disposable DB/별도 JVM에서 실행한다. 실행 불가는 이유와 함께 확인 불가로 기록한다. 성공/실패·예상/실측을 나눈다.
