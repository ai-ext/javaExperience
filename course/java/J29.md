# J29. 앱 복귀와 DB 복원의 판단 경계

> 소요 20~40분 · D29 연결 실험 · 기존 J 재사용과 새 경계 관찰을 구분한다.

## 만들 파일과 실행 위치

**내 프로젝트 루트**에서 진행한다. D29의 앱 smoke·별도 DB 복원 기록과 판단표를 함께 제출한다. 보상 트랜잭션 테스트나 새 JUnit 클래스는 필수가 아니다.

## 오늘 실험

이미지 복귀와 DB 복원을 구분하는 판단표를 만든다. 앱 버전·스키마 호환성·백업 시각·복원 대상·현재 DB 보존 여부를 입력으로 복귀 가능/불가와 별도 복원 검증 필요를 적고 D29 실행 로그에 대조한다.

## 재사용할 Java

- [J08 기존 연습](J08.md)

## 실행과 완료 조건

- D29 운영 실습의 이미지 복귀·별도 DB 복원 명령을 실행하고 판단표의 기대·실제를 대조한다.
- 이미지 복귀와 DB 복원을 구분하는 판단표를 만든다. 앱 버전·스키마 호환성·백업 시각·복원 대상·현재 DB 보존 여부를 입력으로 복귀 가능/불가와 별도 복원 검증 필요를 적고 D29 실행 로그에 대조한다.
- 선택한 경계의 기대값과 실제 출력·실행 명령을 남긴다. 단순 설명만으로 완료하지 않는다.

통합 관찰은 disposable DB/별도 JVM에서 실행한다. 실행 불가는 이유와 함께 확인 불가로 기록한다. 성공/실패·예상/실측을 나눈다.
