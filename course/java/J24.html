#만들 파일과 실행 위치

내 프로젝트 루트에서 진행한다. D24의 통합 관찰·테스트와 같은 증거를 사용한다. 실제 사용한 테스트 클래스 또는 요청/SQL 스크립트 경로·실행 명령·시각·예상/실제 결과를 기록한다. 별도 J24EvidenceTest.java를 만들 필요가 없다.

#오늘 실험

동일 DTO를 MyBatis와 JdbcClient 또는 JPQL 한 가지로 매핑하고 null·중복·정렬 결과를 비교한다.

J05는 DTO 변환·null 처리, J06은 정렬 계약을 지원한다. MyBatis/JdbcClient의 실제 매핑과 DB 관찰은 D24 통합 테스트로 확인한다.

#재사용할 Java

  • J05 기존 연습
  • J06 기존 연습

#실행과 완료 조건

  • 테스트를 사용했다면 ./gradlew test --tests <실제클래스명>으로 재실행한다. 요청·SQL 관찰이면 해당 일자의 실제 명령과 출력을 보존한다.
  • 동일 DTO를 MyBatis와 JdbcClient 또는 JPQL 한 가지로 매핑하고 null·중복·정렬 결과를 비교한다.
  • 선택한 경계의 기대값과 실제 출력·실행 명령을 남긴다. 단순 설명만으로 완료하지 않는다.

통합 관찰은 disposable DB/별도 JVM에서 실행한다. 실행 불가는 이유와 함께 확인 불가로 기록한다. 성공/실패·예상/실측을 나눈다.
