#만들 파일과 실행 위치

내 프로젝트 루트에서 src/test/java/J17EvidenceTest.java를 만든다. 기존 테스트로 동일 증거가 있으면 재실행·조건을 기록하고 재사용한다. java-track에 존재하지 않는 J16 이후 테스트가 있다고 가정하지 않는다.

#오늘 실험

예외 번역을 바꾼 A라면 번역 전후 원인 예외 보존을 assertThrows로 확인한다. 예외 번역과 무관한 선택한 A라면 실제 변경 경계의 실패 입력·기대값·회귀 테스트를 증거로 쓰고 무관한 예외 번역 구현을 추가하지 않는다.

#재사용할 Java

  • J08 기존 연습

#실행과 완료 조건

  • ./gradlew test --tests 'J17EvidenceTest' (직접 이 이름으로 만든 테스트). 기존 테스트를 재사용하면 실제 클래스 이름으로 실행한다.
  • 예외 번역을 바꾼 A라면 번역 전후 원인 예외 보존을 assertThrows로 확인한다. 예외 번역과 무관한 선택한 A라면 실제 변경 경계의 실패 입력·기대값·회귀 테스트를 증거로 쓰고 무관한 예외 번역 구현을 추가하지 않는다.
  • 선택한 경계의 기대값과 실제 출력·실행 명령을 남긴다. 단순 설명만으로 완료하지 않는다.

통합 관찰은 disposable DB/별도 JVM에서 실행한다. 실행 불가는 이유와 함께 확인 불가로 기록한다. 성공/실패·예상/실측을 나눈다.
