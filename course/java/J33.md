# J33. 중단 지점과 재시작

> 소요 20~40분 · D33 연결 실험 · 기존 J 재사용과 새 경계 관찰을 구분한다.

## 만들 파일과 실행 위치

**내 프로젝트 루트**에서 진행한다. D33의 통합 관찰·테스트와 같은 증거를 사용한다. 실제 사용한 테스트 클래스 또는 요청/SQL 스크립트 경로·실행 명령·시각·예상/실제 결과를 기록한다. 별도 J33EvidenceTest.java를 만들 필요가 없다.

## 오늘 실험

commit 직전/직후 장애 지점을 테스트에서 주입해 재실행 결과를 비교한다.

D33의 beforeCommit/afterCommit 통제 실험에 통합한다. 운영 실습 출발 자료의 marker·gate·실제 JVM 종료 명령을 사용하고 별도 DB 연결로 확정 시점을 확인한다. 예외만 던지는 단위 테스트를 실제 프로세스 중단 증거로 대체하지 않는다.

## 재사용할 Java

- [J08 기존 연습](J08.md)

## 실행과 완료 조건

- 테스트를 사용했다면 `./gradlew test --tests <실제클래스명>`으로 재실행한다. 요청·SQL 관찰이면 해당 일자의 실제 명령과 출력을 보존한다.
- commit 직전/직후 장애 지점을 테스트에서 주입해 재실행 결과를 비교한다.
- 선택한 경계의 기대값과 실제 출력·실행 명령을 남긴다. 단순 설명만으로 완료하지 않는다.

통합 관찰은 disposable DB/별도 JVM에서 실행한다. 실행 불가는 이유와 함께 확인 불가로 기록한다. 성공/실패·예상/실측을 나눈다.
