내 프로젝트 루트에서 src/test/java/J23EvidenceTest.java를 만든다. 기존 테스트로 동일 증거가 있으면 재실행·조건을 기록하고 재사용한다. java-track에 존재하지 않는 J16 이후 테스트가 있다고 가정하지 않는다.

#오늘 실험

예약 시각·금액·상태를 값 타입으로 표현하고 유효하지 않은 전이를 단위 테스트한다.

J03의 enum·불변 객체를 예약 값/상태에 적용한다. 상태 전이 허용표와 거부 테스트는 자신의 모델에서 정한다.

✓ 확인끝났는지 판단

#실행과 완료 조건

  • ./gradlew test --tests 'J23EvidenceTest' (직접 이 이름으로 만든 테스트). 기존 테스트를 재사용하면 실제 클래스 이름으로 실행한다.
  • 예약 시각·금액·상태를 값 타입으로 표현하고 유효하지 않은 전이를 단위 테스트한다.
  • 선택한 경계의 기대값과 실제 출력·실행 명령을 남긴다. 단순 설명만으로 완료하지 않는다.

통합 관찰은 disposable DB/별도 JVM에서 실행한다. 실행 불가는 이유와 함께 확인 불가로 기록한다. 성공/실패·예상/실측을 나눈다.
