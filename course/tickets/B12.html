#힌트

1. 브라우저는 무엇을 먼저 보내는가▸

Authorization이나 Content-Type: application/json이 붙은 교차 출처 요청은 본 요청 전에 OPTIONS preflight를 먼저 보낸다. preflight가 200과 Access-Control-Allow-Origin을 받지 못하면 브라우저는 본 요청을 아예 보내지 않는다. 그래서 컨트롤러 로그도, 에러 로그도 없다. Network 탭에서 OPTIONS 줄의 상태 코드와 응답 헤더를 본다. 403이고 본문이 Invalid CORS request면 서버의 CORS 처리기가 출처를 거절한 것이다.

2. preflight를 누가 처리하는가▸

요청은 Security 필터 체인을 먼저 지나고, 그 뒤에 DispatcherServlet(컨트롤러)에 닿는다. SecurityConfig의 .cors(...)는 필터 체인 안에 CorsFilter를 넣는데, 이 필터는 CorsConfigurationSource 빈의 설정을 쓴다. 출처가 그 목록에 없으면 여기서 403으로 끝난다. WebMvcConfigurer.addCorsMappings는 DispatcherServlet 단계의 설정이라 그보다 뒤에 있다. 새 출처 설정이 코드 어디에 들어갔는지, 그리고 preflight가 그 설정까지 도달하는지 따져 본다.

3. 테스트로 고정하기▸

MockMvc의 options("/api/posts").header("Origin", …).header("Access-Control-Request-Method", "POST").header("Access-Control-Request-Headers", "authorization,content-type")로 새 출처·기존 출처·목록에 없는 출처(http://evil.example)를 각각 보내고, 상태 코드와 Access-Control-Allow-Origin·-Methods·-Headers를 본다. 새 출처로 토큰을 붙인 실제 POST /api/posts에도 허용 출처 헤더가 붙는지 함께 본다.

#원인과 구현 예시

펼치기▸

원인. 새 출처 http://127.0.0.1:8765가 CorsConfig.addCorsMappings(Spring MVC의 CORS 매핑)에만 들어가 있고, Security가 쓰는 corsConfigurationSource() 빈의 허용 목록에는 localhost:3000만 있다. preflight는 Security 필터 체인 안의 CorsFilter가 먼저 처리하므로, 새 출처는 여기서 403으로 거절되고 MVC 매핑까지 오지 못한다. 설정 파일에는 새 도메인이 "있으니" 서버 쪽은 맞다고 믿기 쉽다(받은 티켓의 오진). 같은 API를 curl로 부르면 멀쩡해 보이는 것도 헷갈림을 키운다. curl은 preflight를 보내지 않고 Origin도 붙이지 않아 CORS 검사를 받지 않는다.

구현 예시 수정. 허용 출처를 Security가 쓰는 CorsConfigurationSource 한 곳에 모은다(spec-v2 3절의 두 출처). MVC 쪽 중복 매핑은 지운다. CORS 설정이 두 곳에 있으면 다음 사람도 또 엉뚱한 곳에 추가한다. 와일드카드(*)나 allowedOriginPatterns("*")로 여는 것은 오답이다. (tickets/B12/answer/fix.patch)

확인 테스트. tickets/B12/answer/B12ConfirmTest.java — 새 출처 preflight 200·허용 헤더, 새 출처 로그인 preflight 200, 기존 출처 200, 목록에 없는 출처 거절, 새 출처 실제 글쓰기 201·허용 출처 헤더

1단계 구현 예시 서버는? board-server/src/main/java/com/example/board/config/CorsConfig.java의 CorsConfigurationSource 빈 하나에 두 출처를 두고, SecurityConfig의 .cors(Customizer.withDefaults())가 그 빈을 인증 필터 앞에서 쓴다. SecurityRulesTest가 두 출처의 preflight를 확인했는데, 이 서버에서는 기존 출처만 본다.
