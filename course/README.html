#1. 이 과정이 약속하는 것

  • 만들기 · 인증·조회·동시성·외부 연동 서버 구현
  • 말하기 · 문제 → 원인 → 선택 → 결과를 내 경험으로 설명
  • 운영·협의 · 배포·복원·두 앱 부하 검증, 반론에 따라 결정 수정

데이터는 직접 설계하고 API 계약·DB 불변식·실행 증거로 확인합니다.

과정의 범위·데이터 설계·연습 기준

이 과정을 마치면 3–6년차가 쓰는 말과 판단을 직접 겪어 본 상태가 된다. 세 가지를 한다.

  • 만들기: Spring Boot + JPA/MyBatis + MySQL + Redis로 인증, CRUD, 복잡 조회, 동시성이 걸린 상점, 외부 결제 연동, 관리자 기능이 있는 서버를 규칙에 맞게 만든다.
  • 말하기: 각 결정을 자기 경험으로 설명한다. 순서는 문제 상황, 원인, 선택, 결과다.

테이블·컬럼·키·제약·인덱스는 명세 §6 데이터 요구사항을 보고 직접 설계한다. 설계 메모와 DB 불변식 확인 결과를 남긴다. API 필드·상태·오류는 계약대로 유지한다. board-server/는 직접 설계한 뒤 비교할 구현 예시이며 그 물리 이름을 따라야 하는 구현 예시가 아니다. 더미 SQL은 내 테이블 이름에 맞춰 붙여 넣고 SQL을 매일 연습한다. 2단계는 messy-server/의 자체 데이터를 사용한다.

  • 운영·협의: 앱 배포·스키마 변경·복원·중단 재개·두 앱 부하를 검증하고, 설계 리뷰·API 협의·장애 회고·일정 산정에서 반론에 따라 결정을 수정한다.

D15는 중간 점검이다. D16부터는 messy-server 사본에서 개인 미수행 과제를 고르고, 이후 1단계의 내 프로젝트에 예약 쿠폰 기능을 설계부터 운영까지 이어 붙인다. 원본 board-server·messy-server 코드는 실습 중 보존한다. 실제 업무 이슈가 없어도 제공 변형으로 진행한다.

#3. 하루 진행 방법

  1. 오늘 순서: 페이지 맨 위의 순서대로 만든다.
  2. 확인·오늘의 SQL: 각 단계의 확인 항목(명령, 응답)을 직접 실행해 맞는지 본다. 구현 순서 뒤의 SQL을 내 테이블과 그날 범위 더미 데이터로 푼다.
  3. 말하기 카드: 하루가 끝나면 카드의 질문에 문제 상황, 원인, 선택, 결과 순서로 소리 내어 답한다.
  4. AI 채점: 일자 페이지 아래의 AI 채점 프롬프트를 복사해 에이전트에 붙여 넣는다. D01–D45 모두 채점 프롬프트를 제공한다. 구현 체크는 자가 기록이며, SQL·말하기와 에이전트 채점 결과를 따로 확인한다.

#API 하나 만드는 순서

  1. 명세 확인: 엔드포인트·상태 코드·오류 응답을 적는다.
  2. 데이터 요구사항: 필요한 테이블·키·제약·인덱스를 설계하고 테이블을 먼저 생성한다.
  3. 그날 데이터 넣기: 테이블을 만든 뒤 “이 날 데이터 넣기”에서 내 이름에 맞춘 SQL을 넣는다.
  4. 쿼리: Repository·Mapper를 만들고 저장소 테스트로 저장·조회 조건을 확인한다.
  5. 서비스: 트랜잭션 경계·검증·예외와 업무 처리 순서를 정한다.
  6. 컨트롤러: DTO·상태 코드·오류 응답을 명세에 맞춰 연결한다.
  7. 테스트·호출: 정상·잘못된 입력·권한·대상 없음 요청을 보내 응답과 DB 상태를 확인한다.

끝났는지 아는 법 그 순서의 완료 조건에 적힌 테스트·호출 결과와 DB 상태를 명세와 대조해 모두 맞으면 끝이다. 이미 만든 층은 재사용하고 오늘 바꿀 부분만 이어 만든다.

#2단계 티켓 규칙

2단계(D11–D14) 티켓은 아래만 꼭 처리하고 채점받는다. 일자 페이지 머리와 채점 프롬프트도 같은 규칙을 쓴다.

  • 필수 4건: B01·B02·B03·B04 (D11 ④, D12 ①–③, D13 ①에서 B03 마무리)
  • 선택 1건: D11을 시작할 때 Security 후보(B12·B13·B14)나 Redis 후보(B15·B16)에서 하나를 골라 끝까지 처리한다
  • 모두: D14의 고도화 E01과 모의 장애 훈련
  • 나머지 B05–B11은 연습 티켓이다. 했으면 채점 프롬프트에 알려 채점받고, 하지 않았으면 채점에서 빠진다. D13은 필수 B03 마무리부터 하고, 나머지 순서는 연습 티켓이다
