#오늘 할 것

D01부터는 Spring 코드 안에서 메서드를 만들고, 필드를 선언하고, List<Post>를 돌며 DTO로 바꾸는 일이 매일 나온다. 그 전에 Spring 없이 순수 Java로 손을 푼다. 시간이 없으면 건너뛰고 D01로 간다.

#워밍업 주제

  • 워밍업: 메서드 만들기(매개변수·반환 타입·return), 필드 선언과 초기화, for·향상된 for, 값 전달(기본형은 값 복사, 객체는 참조 복사), 컬렉션에 담고 꺼내기, 제네릭 타입 읽기(List<Post>), 반복문을 stream으로 옮기기
  • 기본기: 값 전달 테스트 3개: 메서드 안에서 int를 바꾸면 호출한 쪽은 그대로, 객체 필드를 바꾸면 호출한 쪽도 바뀜, 매개변수에 새 객체를 대입하면 호출한 쪽은 그대로

데이터 요구사항을 보고 테이블·키·제약·인덱스는 직접 설계한다. D01부터 매일 SQL을 풀고, 더미 SQL은 내 테이블 이름에 맞춰 붙여 넣는다. board-server는 직접 설계한 뒤 비교할 구현 예시다.
