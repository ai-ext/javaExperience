02 · 소리 내어 설명하기

#말하기 카드

하루가 끝나면 질문에 "문제 상황 → 원인 → 선택 → 결과" 순서로 소리 내어 답한 뒤, 접힌 "답에 들어가야 할 것"과 비교한다. 세 줄이 모두 나오면 통과다.

#TC-D22-1

질문 1차 캐시와 RR의 반복 읽기는 어떻게 구분했나요?

답에 들어가야 할 것
  • 1차 캐시는 같은 EntityManager의 객체 재사용이고 RR은 DB snapshot 규칙이다.
  • 같은 EM·clear 후 EM·새 트랜잭션을 나눠 관찰한 결과를 제시한다.
  • RC/RR의 실제 격리 수준·commit 시각·예상과 다른 결과를 설명한다.

#TC-D22-2

질문 공유 태그는 글과 수명이 같나요?

답에 들어가야 할 것
  • 공유 태그는 여러 게시글이 참조하므로 한 게시글과 수명이 같지 않다.
  • 연결 행 삭제와 태그 자체 삭제를 나누고 다른 글의 참조 보존을 설명한다.
  • 공유 fixture의 삭제 전후 SQL·회귀 결과와 선택한 관계 비용을 제시한다.

#TC-D22-3

질문 새 연결에서 확인하는 이유는 무엇인가요?

답에 들어가야 할 것
  • 같은 연결/EM은 1차 캐시나 미커밋 변경을 보므로 외부 가시성 증거가 아니다.
  • 새 연결·새 트랜잭션의 격리 수준과 시작/조회 시각을 고정한다.
  • 독립 조회 결과로 확정 행을 검증하고 connection만 새로 만든 경우의 한계를 말한다.
