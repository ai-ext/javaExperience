## 말하기 카드

하루가 끝나면 질문에 "문제 상황 → 원인 → 선택 → 결과" 순서로 소리 내어 답한 뒤, 접힌 "답에 들어가야 할 것"과 비교한다. 세 줄이 모두 나오면 통과다.

### TC-D39-1

**질문** CPU 과다와 외부 대기를 어떻게 구분했나요?

<details class="card-answer" data-card="TC-D39-1">
<summary>답에 들어가야 할 것</summary>

- CPU 사용률과 같은 시각의 스레드 스택/실제 작업을 함께 본다.
- 외부 HTTP/DB 대기·큐 대기와 CPU 연산을 단일 RUNNABLE 상태만으로 단정하지 않는다.
- 각 조건의 PID·jcmd/ps 출력·배제 가설과 추가 증거를 제시한다.

</details>

### TC-D39-2

**질문** DB 풀을 늘리면 항상 빨라지나요?

<details class="card-answer" data-card="TC-D39-2">
<summary>답에 들어가야 할 것</summary>

- DB 풀 확대는 DB 자원·락 경쟁·체류 시간 병목을 악화시킬 수 있다.
- 처리율×체류 시간 가설과 요청 풀/DB 풀/queue/timeout 상한을 말한다.
- 한 설정만 바꾼 재측정과 유입 제한 대안의 비용·한계를 제시한다.

</details>

### TC-D39-3

**질문** 메모리 증가와 누수는 어떤 추가 증거가 필요한가요?

<details class="card-answer" data-card="TC-D39-3">
<summary>답에 들어가야 할 것</summary>

- 정상 부하의 일시 할당·의도적 보유와 회수되지 않는 누수를 구분한다.
- 부하 종료/GC 전후 heap·객체 수/보유 경로의 시간 추이를 더 확인한다.
- 실제 관찰·회복 여부와 heap 증가만으로 누수라고 확정하지 못하는 한계를 말한다.

</details>
