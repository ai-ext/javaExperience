  2. A·B 실행 구간에서 대기 상태를 비교한다.

02 · 소리 내어 설명하기

#말하기 카드

하루가 끝나면 질문에 "문제 상황 → 원인 → 선택 → 결과" 순서로 소리 내어 답한 뒤, 접힌 "답에 들어가야 할 것"과 비교한다. 세 줄이 모두 나오면 통과다.

#TC-D18-1

질문 A와 B의 증상이 비슷해도 왜 같은 원인이 아닐 수 있나요?

답에 들어가야 할 것
  • A/B의 같은 HTTP 증상과 서로 다른 상태·실행 경계를 나눈다.
  • 각 원인을 지지하는 독립 로그/테스트를 제시한다.
  • 한 수정으로 둘 다 고치려는 대안의 위험과 선택 비용을 말한다.

#TC-D18-2

질문 두 과제에서 배제한 가설은 무엇인가요?

답에 들어가야 할 것
  • 각 과제의 초기 가설과 예상 관찰값을 말한다.
  • 실제 출력이 어느 가설을 반증했는지 테스트별로 설명한다.
  • 배제하지 못한 가설과 추가 확인 조건을 남긴다.

#TC-D18-3

질문 보충이 끝났다는 판단은 어떤 증거로 하나요?

답에 들어가야 할 것
  • 보충 전 실패했던 경계와 완료 기준을 말한다.
  • 같은 입력 재실행·반례·회귀 결과를 근거로 제시한다.
  • 이해 설명과 직접 수행 증거를 구분하고 남은 공백을 기록한다.
