# 과정 지도

Java → Spring 일자 → 티켓 → 결함 영역의 연결을 탐색합니다. **노드는 관계 선택**, **‘페이지 열기’는 문서 이동**입니다. 전체 목록은 지도 안에서 스크롤하고, 모든 연결은 아래 관계 표에서도 찾을 수 있습니다.

## 지도 읽는 법과 학습 기준

1단계는 [데이터 요구사항](spec-v2.md#6-데이터-요구사항)으로 테이블을 직접 설계하고 [더미 SQL](start/dummy/README.md)을 내 테이블 이름에 맞춰 붙여 넣는다. 매일 일자 페이지의 오늘의 SQL을 푼다. 구현 예시는 직접 설계한 뒤 접기를 펼쳐 비교한다.

45일 과정의 네 갈래를 한 장에 둔다. **Java 트랙**(J00–J45)은 같은 날 **Spring 일자**(D00–D45)에서 쓰는 Java를 먼저 연습하고, 2단계 일자(D11–D14)는 **티켓**(B01–B16, 고도화 E01)을 다루며, 티켓마다 어긋난 **결함 영역**이 있다. 노드를 고르면 관계 보기에 맞는 노드만 밝힌다. 스크립트 없이도 아래 관계 표에 모든 연결이 글로 있다.

- 화살표는 영향이 흐르는 방향이다: Java → 같은 날 Spring 일자 → 그날 다루는 티켓 → 결함 영역.
- "영향 주는 쪽"은 고른 노드로 들어오는 쪽 전체, "영향 받는 쪽"은 고른 노드에서 나가는 쪽 전체다.
- 날과 티켓의 연결은 날짜별 원본 `course/days/Dnn.json`에서, 티켓 제목·필수 여부·결함 영역은 [map-tickets.json](map-tickets.json)에서 빌드할 때 읽는다.

D15는 중간 점검이며 D16–D45는 개인 미수행 과제·설계·운영·새 업무·네 회의·독립 수행으로 이어진다. J16 이후는 기존 J를 재사용한다. D16–D18의 A/B는 학습자의 선택이므로 지도에 모든 후보를 수행 확정으로 표시하지 않는다. [분량과 선행 설계](../docs/course-redesign/plans/2026-10-24-p9-d16-d30.md)에서 묶음별 산출물·완료 기준을 확인한다.
