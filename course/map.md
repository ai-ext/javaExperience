# 과정 지도

1단계는 [데이터 요구사항](spec-v2.md#6-데이터-요구사항)으로 테이블을 직접 설계하고 [더미 SQL](start/dummy/README.md)을 내 테이블 이름에 맞춰 붙여 넣는다. 매일 일자 페이지의 오늘의 SQL을 푼다. 구현 예시는 직접 설계한 뒤 접기를 펼쳐 비교한다.

15일 과정의 네 갈래를 한 장에 둔다. **Java 트랙**(J00~J15)은 같은 날 **Spring 일자**(D00~D15)에서 쓰는 Java를 먼저 연습하고, 2단계 일자(D11~D14)는 **티켓**(B01~B16, 고도화 E01)을 다루며, 티켓마다 어긋난 **결함 영역**이 있다. 노드를 고르면 관계 보기에 맞는 노드만 밝힌다. 스크립트 없이도 아래 관계 표에 모든 연결이 글로 있다.

- 화살표는 영향이 흐르는 방향이다: Java → 같은 날 Spring 일자 → 그날 다루는 티켓 → 결함 영역.
- "영향 주는 쪽"은 고른 노드로 들어오는 쪽 전체, "영향 받는 쪽"은 고른 노드에서 나가는 쪽 전체다.
- 날과 티켓의 연결은 [roadmap.json](roadmap.json)에서, 티켓 제목·필수 여부·결함 영역은 [map-tickets.json](map-tickets.json)에서 빌드할 때 읽는다.
